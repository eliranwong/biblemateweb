# 圣经选择器

每个圣经窗口顶部都有一排下拉菜单，其后跟着[三点菜单](three_dot_menu.md)。

| 选择器 | 功能 |
|---|---|
| 版本 | 切换至其他圣经版本；保持当前经文段落 |
| 书卷 | 选择书卷（名称依据您的界面语言显示） |
| 篇章 | 选择篇章 |
| 经节 | 选择经节；自动滚动至该节并高亮显示 |

选择任何项目都会重新加载该窗口中的经文。若开启[同步](../layout/sync.md)功能，另一个窗口也会跟随同步。

这些选择器定义了三点菜单的上下文：书卷／全章／单节工具以及搜索均使用所选的值。

篇章底部设有：`◀️ 上一章` 与 `下一章 ▶️` 按钮。
