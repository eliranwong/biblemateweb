# 书卷工具菜单

可从三点菜单 → `书卷工具` 开启，或在书卷标题上右键点击开启。

| 项目 | 说明 |
|---|---|
| ⏳ **圣经时间轴** | 该书卷的时间轴（[圣经时间轴](../tools/tool_timelines.md)） |
| 🔘 **概述** | 简介、作者、写作日期与目的 |
| 📐 **结构大纲** | 书卷的分层结构划分 |
| 🧵 **书卷脉络** | 论述或叙事的推进脉络 |
| 🕰️ **历史背景** | 写作背景与历史处境 |
| 🎨 **主题** | 主要神学与文学主题 |
| 🏷️ **关键字** | 重要且反复出现的词汇与概念 |
| ⛪ **神学** | 书卷中呈现的教义 |
| 🚩 **正典位置** | 该书卷在圣经正典中的定位与关联 |
| 🌱 **生活应用** | 对今日生活的实践应用 |
| 💎 **摘要** | 书卷信息的精简摘要 |
| 📝 **新增笔记／编辑笔记** | 书卷笔记（仅在已配置 Google 云端硬盘笔记时可用） |

这十项分析项目各自会在[书卷分析](../ai_features/book_analysis.md)中开启相应板块（[完整指南](../tools/tool_analysis.md)）。
