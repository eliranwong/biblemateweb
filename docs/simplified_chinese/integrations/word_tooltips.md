# 单词提示框与原文词典链接

原文圣经与带有注解的文本中的单词，在鼠标悬停（或轻触）时会开启交互式弹出窗口。

## 弹出窗口运行方式

- **触发：** 鼠标悬停在标记的单词上时，会在短暂延迟（`100 ms`）后开启弹出窗口。
- **保持开启以便播放语音与点击链接：** 将光标移入弹出窗口内可保持其开启状态，以便你播放语音或点击其中的链接；光标同时离开单词与弹出窗口 `300 ms` 后，窗口将会关闭。
- **智能定位：** 根据可用的屏幕空间，自动将自身定位在单词的上方、下方、右侧或左侧，并在页面滚动或窗口调整大小时重新调整位置。
- **按需获取与缓存：** 数据通过 `GET /api/tooltip/{word}` 获取，并缓存于浏览器中，以便实现即时的重复查询。

## 三种弹出窗口类型

### 1. 原文单词弹出窗口（希伯来文与希腊文）

在[原文圣经](../bibles/README.md)（`ORB`、`OIB`、`OPB`、`ODB`、`OLB`）中，每个希伯来文／亚兰文（旧约）与希腊文（新约）单词都配有丰富的形态学与语音弹出窗口：

| 元素 | 描述 |
|---|---|
| **手抄本原形** | 文本中出现的精确屈折单词形式。**点击它**即可在工具区域中开启该词的原文词典词条。 |
| **音译与发音** | 显示于手抄本形式旁（`word \| transliteration \| pronunciation`）。 |
| **手抄本形式语音** | 内嵌语音播放器（`<audio controls>`），用于播放单词**手抄本形式（屈折形式）**的发音。 |
| **原形（Lemma）** | 单词的字典／词根形式。**点击它**即可在工具区域中开启该原形的原文词典词条。 |
| **原形语音** | 第二个内嵌语音播放器，用于播放单词**原形（字典形式）**的发音。 |
| **形态学分析** | 语法分析标签（例如：词性、时态、语态、语气、格、性、数、人称、词干）。 |
| **逐字对照释义** | 逐词逐字对照释义。 |
| **翻译** | 该单词在上下文中的翻译。 |

#### 单词级语音详情

手抄本形式语音与原形语音均可直接在弹出窗口内播放，无需离开页面：

- **旧约（希伯来文／亚兰文 — BHS5）：** 由 `/bhs5_audio/{book}_{chapter}/BHS5_{book}_{chapter}_{verse}_{wordID}.mp3`（手抄本形式）与 `lex_BHS5_{book}_{chapter}_{verse}_{wordID}.mp3`（原形形式）提供。
- **新约（希腊文 — OGNT）：** 由 `/ognt_audio/{book}_{chapter}/OGNT_{book}_{chapter}_{verse}_{wordID}.mp3`（手抄本形式）与 `lex_OGNT_{book}_{chapter}_{verse}_{wordID}.mp3`（原形形式）提供。

> [!NOTE]
> 单词级语音需要 `~/biblemate/data/audio/bibles/` 中的 `BHS5` 与 `OGNT` 语音文件（参见[数据与资源](../server_setup/data_and_resources.md)）。

### 2. 词汇弹出窗口（Strong 编码）

在带有 Strong 编码标注的译本圣经中，鼠标悬停在 Strong 编码（`H...` 或 `G...`）上会显示：

- 可点击的标题（`[Lexicon] Strong's ID`），点击可开启[原文词典](../search/search_lexicons.md)中的完整词条。
- 来自你所配置的[希伯来文词典](../user_preferences/hebrew_lexicon.md)或[希腊文词典](../user_preferences/greek_lexicon.md)中的词典定义。
- 定义内包含可点击的经文串珠与原文词典链接。

### 3. 圣经笔记弹出窗口

鼠标悬停在译本注解标记上时，会显示笔记文本以及可点击的圣经经文参照。

## 点击跳转至原文词典

点击希伯来文／希腊文手抄本单词、原形或 Strong 链接，即可在工具区域中开启[原文词典](../search/search_lexicons.md)，并将该词条作为查询条件，应用你偏好的希伯来文或希腊文词典。

## 单词与子句互联高亮

在[原文圣经](original_language_bibles.md)（`ORB`、`OIB`、`OPB`、`ODB`、`OLB`）中，将鼠标悬停在任何希伯来文或希腊文单词上，会同时在所有已开启的圣经窗口中高亮显示相关元素（例如在[平行圣经](../layout/parallel_bibles.md)中并排阅读 `OPB` 与 `OLB` 时）：

1. **子句高亮（`.c<cl>`）：** 高亮显示属于同一语法子句的所有单词（浅色模式为 `PAPAYAWHIP`；深色模式为 `#d48f28`）。
2. **词汇互联高亮（`.G<sn>`）：** 在所有已开启的窗口中高亮显示相同词汇／Strong 编号的每一个出现处（浅色模式为 `#E7EDFF`；深色模式为 `#5d85fc`）。
3. **焦点单词高亮（`#w<id>`）：** 高亮显示该目标单词（浅色模式为 `#C9CFFF`；深色模式为 `#5a64b0`）。

移开光标后即会清除这三层高亮。由于子句与词汇高亮会查询整个文档（`document.querySelectorAll`），因此在其中一个窗口悬停单词时，平行窗口中对应的单词与子句也会同步高亮。

## 编程式访问

提示框数据由 `GET /api/tooltip/{word}` 提供——参见 [REST API](rest_api.md)。
