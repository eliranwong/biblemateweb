# 原文圣经

五种整合希伯来文／希腊文版本，各自具备相同的[选择器](bible_selectors.md)、[三点菜单](three_dot_menu.md)、单节弹出窗口、单词提示框以及原文词典链接。

| 代码 | 名称 | 重点 |
|---|---|---|
| ORB | Original Reader's Bible（原文朗读版圣经） | 易读的原文文本 |
| OIB | Original Interlinear Bible（原文逐字对照圣经） | 逐词附带字义释义 |
| OPB | Original Parallel Bible（原文平行圣经） | 原文与译本并排对照 |
| ODB | Original Discourse Bible（原文语法分析圣经） | 篇章语法结构 |
| OLB | Original Linguistic Bible（原文语言学圣经） | 语言学标注 |

通过“圣经”或“平行圣经”菜单开启，或在[快速搜索](../basics/quick_search.md)中输入代码。

点击单词可跳转至[原文词典](word_tooltips.md)，或将鼠标悬停在单词上以显示提示框并在平行窗口间触发[单词与子句互联高亮](word_tooltips.md#单词与子句互联高亮)；在[单节菜单](verse_menu.md)中使用 🧬 形态学分析以获取完整分析。
