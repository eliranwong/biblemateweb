# 经文节号菜单

在圣经中点击**经文节号**（或右键点击经文；亦可通过 ⋮ → `Verse Tools`），即可开启单节弹出菜单。该节经文会在节数下拉菜单中被选定，且所有工具都会在空的工具区域标签页中针对该节经文开启。

## 菜单项目

| 项目 | 描述 |
|---|---|
| 📋 **复制**（Copy） | 将经文以 `[Reference] text` 格式（移除标签）复制到剪贴板 |
| 🔊 **圣经语音**（Bible Audio） | 播放与你的圣经同步的全章语音（[圣经语音](../tools/tool_audio.md)） |
| 🔗 **经文串珠**（Cross-references） | 该节经文的相关经文段落（[经文串珠](../tools/tool_xrefs.md)） |
| 🏦 **经文宝库**（Treasury） | 经文宝库（Treasury of Scripture Knowledge）词条（[经文宝库](../tools/tool_treasury.md)） |
| 🧠 **AI 注释**（AI Commentary） | AI 编写的注释（按界面语言提供 AIC/AICTC/AICSC）（[指南](../ai_features/ai_commentary.md)） |
| 📚 **圣经注释**（Commentaries） | 使用你最喜爱的注释开启经文注释工具（[注释](../tools/tool_commentary.md)） |
| 🧬 **形态学分析**（Morphology） | 逐词原文分析（[形态学分析](../tools/tool_morphology.md)） |
| 👀 **版本对比**（Comparison） | 同时在多个圣经版本中显示该节经文：你的主要圣经、当前圣经以及逐字对照的 OHGBi |
| 📑 **资源索引**（Indexes） | 引用此节经文的各项资源（[单节索引](../tools/tool_indexes.md)） |
| 📝 **新增笔记／编辑笔记**（Add Note / Edit Note） | 若配置 Google Drive 笔记：开启该节笔记（若已存在则为编辑）。若未配置：将经文发送至[笔记本](../tools/tool_notepad.md) |
| 💬 **问 BibleMate**（Ask BibleMate） | 将经文发送至对话模式（[指南](../ai_features/ask_biblemate.md)） |

## 备注

- 工具开启时**未同步**于你点击的经文，因此当你滚动页面时，工具内容不会随之跳动。
- 在触控设备上，轻触经文节号即可开启此菜单。
