# AI 提供商与订阅

BibleMate 在单一界面下整合了多种 AI 服务：

- API 提供商：Google AI、OpenAI、Anthropic、Cohere、DeepSeek、Mistral、xAI、Azure 系列、Ollama Cloud 以及自定义端点。
- 已登录的订阅式 CLI（管理员启用时）：Grok Build、Claude Code、Antigravity。
- 自带密钥（BYOK），或使用服务器默认设置。

详细信息：[AI 后端](../ai_features/ai_backends.md)、[自带密钥](../user_preferences/api_key_setup.md)。AI 功能亦可调用整合的圣经[工具](../ai_features/chat_tool_selection.md)。
