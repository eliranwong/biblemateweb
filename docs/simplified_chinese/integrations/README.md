# 整合

> [!IMPORTANT]
> **整合各项研经资源是 BibleMate AI Web 最显著的优势之一。**
> 圣经、原文文本、原文词典、形态学分析、圣经注释、经文串珠、经文宝库、圣经字典、百科全书、地图、圣经时间轴、资源索引、圣经笔记、圣经语音与人工智能／AI 并非孤立的模块。它们紧密交织在一起：从任何经节、篇章或书卷，只需轻轻一点，即可开启所有相关资源，与您正在阅读的经文并排显示，并同步至同一段经文。

## 为什么这很重要

- **单一段落，多种资源。** 点击经节编号即可在工具区开启经文串珠、经文宝库、圣经注释、形态学分析、资源索引、圣经语音、版本对比或 AI。
- **悬停并点击字词。** 原文文本与圣经笔记中的字词均链接至词典与形态学数据。
- **处处相连。** 圣经注释、笔记与搜索结果中的经文引用皆可在圣经区开启。
- **保持同步。** [同步](../layout/sync.md)功能让圣经窗口与工具窗口维持在同一章。
- **AI 与数据结合。** AI 功能可调用相同的圣经数据工具（[选择工具](../ai_features/chat_tool_selection.md)）。
- **向其他软件开放。** 支持 REST API、命令行客户端、Google 云端硬盘笔记以及自定义数据。
