# Google 云端硬盘笔记

针对经节、篇章与书卷的研经笔记，存储在**您自己的 Google 云端硬盘**（隐藏的应用数据文件夹）中，而非服务器上。

## 用户指南

1. 开启笔记工具（或任何 📝 菜单项）并选择 `Login with Google`。
2. 授权访问应用数据文件夹。
3. 笔记可在多个设备间自动同步。

## 笔记显示位置

- [三点菜单](three_dot_menu.md)、[经节菜单](verse_menu.md)、[全章菜单](chapter_menu.md)与[书卷菜单](book_menu.md)中的 📝 项目。
- 经节编号旁的[笔记标记](note_indicators.md)。
- 若未配置 Google，经节菜单会提供添加至[笔记本](../tools/tool_notepad.md)的 `Add Note` 选项。

## 管理员说明

创建 Google OAuth 凭据并在配置文件中设置客户端 ID 与密钥（client id/secret）：[Google 云端硬盘笔记设置](../server_setup/google_drive_notes_setup.md)。相同的登录亦用于跟踪[代理模式／伙伴模式](../ai_features/usage_limits.md)的每日使用配额。

工具指南：[云端笔记](../tools/tool_notes.md)。
