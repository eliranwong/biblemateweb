# BibleMate AI (CLI 与 MCP)

BibleMate AI Web 结合了 [BibleMate AI](https://github.com/eliranwong/biblemate) 的网页界面与 [UniqueBible](https://github.com/eliranwong/UniqueBible) 的丰富资源。

- 配套项目 **BibleMate AI** 提供了 CLI 版本、MCP 服务器、完整的代理模式后端以及圣经数据（可通过 `biblematedata` 安装数据）。
- 在禁用网页版本的服务器上，代理模式会引导用户使用 CLI（[可用性](../ai_features/usage_limits.md)）。
- 网页应用程序复用了 BibleMate 的工具定义（[MCP 工具整合](../ai_features/chat_tool_selection.md)），使 AI 代理与用户界面能够访问完全相同的资源。
