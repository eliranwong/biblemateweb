# 自定义资源

管理员可以整合自己的私人数据。

- 将自定义圣经放入 `~/biblemate/data_custom/bibles`，将自定义 OPB 子句模块放入 `~/biblemate/data_custom/clauses`，并将自定义参考书籍放入 `~/biblemate/data_custom/books`。
- 用户可通过输入[自定义令牌](../user_preferences/custom_token.md)来解锁这些资源，或在单次访问时于网址中加入 `?t=TOKEN`。
- 自定义圣经随后会显示于圣经菜单、偏好设定列表以及 API 查询中。
- 该令牌亦可绕过[使用限制](../ai_features/usage_limits.md)。

请参阅[参考书籍](../tools/tool_books.md)与[配置指南](../server_setup/configuration.md)。
