# 经文串珠与经文链接

圣经文本内（译本注解、经文串珠标记）以及工具输出内容中（注释、笔记、搜索结果）的参照均可点击。

| 链接 | 结果 |
|---|---|
| 经文参照（例如 `John 3:16`） | 在圣经窗口中开启该章 |
| 经文串珠标记 | 开启所参照的经文段落 |
| 经文节号 | 开启[单节菜单](verse_menu.md) |

## 在哪个窗口开启？

- 当[同步](../layout/sync.md)**开启**时，链接会更改包含该链接的窗口内容。
- 当同步**关闭**时，链接会在*另一个*窗口中开启该经文段落，让你在查阅参照时仍能保留原本阅读的位置。

在译本圣经与工具中均以相同方式运行。
