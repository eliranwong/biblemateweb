# AI 菜单

**AI** 菜单（`auto_awesome` 图标）提供：

| 项目 | 打开内容 |
|---|---|
| 书卷分析 | 书卷的 AI 分析（[指南](../tools/tool_analysis.md)） |
| 全章摘要 | 篇章的 AI 摘要（[指南](../tools/tool_summary.md)） |
| AI 注释 | 当前经文段落的 AI 注释（[指南](../tools/tool_commentary.md)） |
| 对话模式 | 对话页面 |
| 伙伴模式 | 互动式研经伙伴 |
| 代理模式 | 自主代理 |

全部均在工具区中打开。

## 配置设置

- 在[偏好设定](../user_preferences/README.md)中选择您的提供商、密钥与模型——请参阅 [BYOK](../user_preferences/api_key_setup.md)。
- 管理员可能会限制代理模式与伙伴模式的使用量；使用您自己的密钥可不受这些限制。
