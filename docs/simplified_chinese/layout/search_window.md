## 相关偏好设定

- [相似词条](../user_preferences/top_similar_entries.md)与[相似经文](../user_preferences/top_similar_verses.md)用于限制语义搜索结果的数量。
- [希伯来文](../user_preferences/hebrew_lexicon.md) / [希腊文](../user_preferences/greek_lexicon.md) 原文词典默认值。

## 快速访问

在[快速搜索](quick_search.md)框中输入不含经文出处的任意文本，即可直接搜索经文。
