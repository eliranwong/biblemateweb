# 同步

当**同步**开启时，圣经区与工具区会保持在相同的书卷与篇章。

| 键值 | 默认 |
|---|---|
| `sync` | 开启 |

## 切换方式

- **桌面端：**设定（齿轮）→ `Sync` 开关。
- **移动端：**左侧抽屉 → `Sync` 开关。
- **URL：**`s=true` 或 `s=false`（[URL 参数](url_parameters.md)）。

## 行为表现

- 在圣经区更改篇章也会将工具区中的**平行圣经**或使用中的**全章工具**（`圣经播客`、`圣经语音`、`整章译本对照`、`整章摘要`、`全章索引`）移至相同位置（反之亦然）。
- 在同步模式下打开的工具（圣经语音、AI 注释、经文串珠、经文宝库、形态学分析、资源索引等）将从圣经区显示的经文处开始。
- 在**多工具工作区**中，仅开启**同步**的面板会随圣经区切换书卷、章或节而自动刷新；未开启同步的搜索面板保持不变。
- 关闭同步时，各工具会保留各自的书卷/篇章/节数。
