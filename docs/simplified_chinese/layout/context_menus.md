# 右键菜单

在圣经中的书卷标题、篇章标题或经文上单击右键（触摸屏上则为长按），即可打开右键菜单。操作结果会在工具区的空白标签页中打开。

## 单节

复制、圣经语音、经文串珠、经文宝库、AI 注释、圣经注释、形态学分析、版本对比、资源索引、添加/编辑笔记（或添加至笔记本）、问 BibleMate。

## 篇章

篇章层级的操作，例如地图、笔记和 AI 功能。

## 书卷

圣经时间轴，以及 AI 分析区段：总览、结构大纲、逻辑流程、历史背景、主题、关键词、神学意涵、正典地位、生活应用、摘要；若已配置 Google 笔记，还包含添加/编辑笔记。

> [!NOTE]
> 笔记标记可在[设定菜单](settings_menu.md)中使用 `Notes` 开启或关闭。
