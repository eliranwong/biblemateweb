# 快速搜索

页顶标题栏中的输入框（在移动端位于左侧抽屉中）。支持书卷名称、工具名称和圣经版本的自动完成功能。按 **Enter** 键即可执行。

## 可输入的内容

| 输入内容 | 结果 |
|---|---|
| 圣经版本，例如 `KJV` | 在圣经区打开该圣经 |
| 单一经文出处，例如 `John 3:16` | 在圣经区打开该篇章 |
| `KJV:::John 3:16` | 以指定的版本打开它 |
| `bible:::John 3:16` | 在工具区中以平行圣经打开 |
| `bible:::KJV:::John 3:16` | 指定版本的平行圣经 |
| `tool:::query`，例如 `xrefs:::John 3:16` | 打开工具并带入查询内容 |
| 任何其他内容或多个经文出处 | 在工具区中搜索经文 |

搜索后会清空输入框。`tool:::` 可用的工具名称即为自动完成建议中提供的名称。
