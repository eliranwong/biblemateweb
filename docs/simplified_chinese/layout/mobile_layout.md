# 移动端版面

在窄屏幕上，页顶标题栏会显示一个**汉堡按钮**用以打开左侧抽屉，取代桌面端的标题与快速搜索框。

## 抽屉内容

- 头像/标题按钮（显示 [URL 与二维码](url_qr_code.md)）
- [快速搜索](quick_search.md)
- 开关：`Go`、`Swap`、`Notes`、`Tooltip`、`Sync`、`Fullscreen`、`Dark Mode`
- 可展开的圣经与工具列表
- 版面选项：只显示圣经、只显示工具、圣经与工具

做出选择后，抽屉会自动关闭。

## 竖向模式

在竖向屏幕下，两个区域呈垂直堆叠。使用[切换版面](toggle_layout.md)可让单一区域全屏显示。
