# 圣经选单对话框

无需输入文字即可快速导航至任何经文的便捷方式。

## 打开

点击 **开启** [浮动按钮](floating_buttons.md)（书本图标，工具提示为 `圣经选单`）。

## 步骤

1. **选择书卷** – 包含全部 66 卷书的网格（书卷名称遵循您的[界面语言](../user_preferences/ui_language.md)）。当前书卷会显示外框。
2. **选择章** – 该书卷的篇章。当前篇章会显示外框。
3. **选择节** – 该篇章的节数。

选取节数后会关闭对话框，并在当前使用的圣经标签页中打开该位置，同时保留当前圣经版本。若[同步](sync.md)已开启，工具区中的圣经亦会随之跟进。

使用对话框顶部标题栏的 `x` 按钮可在不选取的情况下关闭。
