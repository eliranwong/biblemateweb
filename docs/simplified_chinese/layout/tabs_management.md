# 标签页管理

两个区域都有各自独立的标签页。圣经区标签页命名为 `Bible 1, 2, ...`；工具区标签页命名为 `Tool 1, 2, ...`（会根据加载的内容重新命名）。

## 添加标签页

| 区域 | 菜单 | 项目 |
|---|---|---|
| 圣经 | 圣经（`local_library`） | 新圣经标签页 |
| 平行 | 平行圣经（`devices_fold`） | 新平行标签页 |
| 工具 | 工具（`build`） | 新工具标签页 |

平行圣经标签页与工具标签页皆属于工具区。

## 关闭标签页

- 点击标签页上的小 **x** 即可关闭该标签页（即使它当前处于非活动状态）。
- 菜单 → `Close Bible Tab`（关闭圣经标签页）、`Close Parallel Tab`（关闭平行标签页）或 `Close Tool Tab`（关闭工具标签页）可关闭当前标签页。
- 菜单 → `Close Others`（关闭其他）可关闭除当前标签页之外的所有其他标签页。
- **最后剩下的一个标签页无法关闭**（会显示警告）。

## 持久性保存

标签页内容保存在您的用户存储空间中，并在下次访问时予以还原。已关闭的标签页会从存储空间中移除。

## 默认标签页数量

首次启动时打开的标签页数量可在偏好设定中进行设置：

- [圣经标签页](../user_preferences/default_number_of_tabs1.md)（`default_number_of_tabs1`，默认为 3）
- [工具标签页](../user_preferences/default_number_of_tabs2.md)（`default_number_of_tabs2`，默认为 3）

## 提示

- 每个圣经版本各保留一个标签页，方便进行译本对比。
- 搜索结果会加载至当前工具标签页；若想保留先前的结果，请先打开一个新标签页。
