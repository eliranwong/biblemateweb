# 工具

**工具**菜单（`build` 图标）会在工具区中打开研经工具。

## 标签页项目

`新工具标签页`（`Add Tool Tab`）、`关闭工具标签页`（`Close Tool Tab`）、`关闭其他`（`Close Others`）——请参阅[标签页管理](tabs_management.md)。

## 同步工具

大多数工具会在圣经区当前显示的经文处打开（请参阅[同步](sync.md)）。`Books` 不会进行同步。

## 从快速搜索打开工具

输入 `toolname:::query`（例如 `xrefs:::John 3:16`）——请参阅[快速搜索](quick_search.md)。
