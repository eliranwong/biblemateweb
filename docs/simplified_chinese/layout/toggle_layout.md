# 切换版面

BibleMate 提供三种版面模式。当前的模式会保存在您的用户存储空间中（`layout`，默认为 `2`）。

| 模式 | 数值 | 结果 |
|---|---|---|
| 只显示圣经 | `1` | 仅显示圣经区（分隔线位于 100%） |
| 圣经与工具 | `2` | 同时显示两个区域，以 50/50 对半分割 |
| 只显示工具 | `3` | 仅显示工具区（分隔线位于 0%） |

## 更改版面的方式

1. **版面转换浮动按钮**（`swap_horiz` 图标）。每次点击依序循环 `1 → 2 → 3 → 1`。请参阅[浮动按钮](floating_buttons.md)。
2. **设定菜单**（页顶标题栏中的齿轮图标）：直接选择“只显示圣经”、“只显示工具”或“圣经与工具”。
3. **URL 参数** `l=1|2|3`，例如 `/?l=1`。请参阅[URL 参数](url_parameters.md)。

## 自动切换

- 在**只显示工具**模式下加载内容至圣经区，会自动切换为**圣经与工具**。
- 在**只显示圣经**模式下加载内容至工具区，会自动切换为**圣经与工具**。

因此，从菜单中选取工具或圣经时，一定会使其所属视窗显示出来。

## 提示

- 在手机上，可使用“只显示圣经”进行阅读，使用“只显示工具”以获取最大的研经空间。
- 您也可以在两个区域之间手动拖动分隔线。
