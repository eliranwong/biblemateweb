# 平行圣经

并排阅读两本圣经：一本在圣经区，另一本在工具区。

## 打开平行圣经

1. 点击**平行圣经**按钮（`devices_fold` 图标）。
2. 选择一本圣经：主要圣经、次要圣经、原文语言圣经之一（ORB、OIB、OPB、ODB、OLB），或任何其他版本。

圣经会在当前工具区标签页中打开。若原先版面为只显示圣经，则会切换为圣经与工具（[切换版面](toggle_layout.md)）。

## 菜单项目

`新平行标签页`（`Add Parallel Tab`）、`关闭平行标签页`（`Close Parallel Tab`）、`关闭其他`（`Close Others`）——请参阅[标签页管理](tabs_management.md)。

## 快速搜索

输入 `bible:::John 3:16` 即可在工具区中使用默认工具圣经打开该篇章，或输入 `bible:::KJV:::John 3:16` 以指定版本。

## 同步

在[同步](sync.md)开启时（默认），在一本圣经中导航会将另一本圣经移至相同的书卷与篇章。关闭同步即可在各窗口中阅读不同的经文段落。

并排查看原文圣经（例如 `OPB` 与 `OLB`）时，将鼠标悬停在希伯来文或希腊文单词上，也会触发跨窗口的**单词与子句互联高亮**——详见[单词提示框与原文词典链接](../integrations/word_tooltips.md#单词与子句互联高亮)。
