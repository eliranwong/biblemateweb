# URL 参数

地址栏会随着您的导航操作即时更新，因此任何视图皆可加入书签或进行分享。示例：`/?bbt=NET&bb=43&bc=3&bv=16&l=2`。

| 参数 | 说明 |
|---|---|
| `l` | 版面：`1` 只显示圣经，`2` 圣经与工具，`3` 只显示工具 |
| `bbt`, `bb`, `bc`, `bv` | 圣经区：版本、书卷编号、篇章、节数 |
| `tool` | 工具区内容：`bible`、`audio`、`chronology`、搜索或工具名称 |
| `tbt`, `tb`, `tc`, `tv` | 工具区：版本、书卷、篇章、节数 |
| `tq` | 工具查询字符串 |
| `s` | 同步开启/关闭 |
| `d` | 深色模式开启/关闭 |
| `fs` | 字体大小（%） |
| `pc`, `sc`, `nc` | 主要、次要、否定色彩 |
| `lang` | 界面语言 |
| `m` | 显示菜单（`false` 会隐藏页顶标题栏） |
| `k` | 在浏览器历史记录中保留有效参数 |
| `t` | 仅限本次访问使用的自定义凭证（不会保存；适用于公用设备） |

书卷编号为 1–66。
