# 圣经

BibleMate AI Web 提供译本圣经（完整安装下超过 100 种，包含希伯来文和希腊文原文文本）以及五部原文圣经。全部共享相同的[选择器](../integrations/bible_selectors.md)、[三点菜单](../integrations/three_dot_menu.md)、[经文菜单](../integrations/verse_menu.md)与[同步](../layout/sync.md)功能。

| 圣经 | 指南 |
|---|---|
| 译本圣经（例如 KJV、NET、CUV） | [译本圣经](bible_translations.md) |
| ORB – 原文读本圣经 (Original Reader's Bible) | [原文读本圣经](original_reader.md) |
| OIB – 原文逐字对照圣经 (Original Interlinear Bible) | [原文逐字对照圣经](original_interlinear.md) |
| OPB – 原文平行圣经 (Original Parallel Bible) | [原文平行圣经](original_parallel.md) |
| ODB – 原文语法结构圣经 (Original Discourse Bible) | [原文语法结构圣经](original_discourse.md) |
| OLB – 原文语言分析圣经 (Original Linguistic Bible) | [原文语言分析圣经](original_linguistic.md) |

可从[“圣经”菜单](../basics/menu_bibles.md)或[“平行圣经”菜单](../basics/menu_parallel_bibles.md)开启其中任何一部，或在[快速搜索](../basics/quick_search.md)中输入其代码。你也可以通过[主要](../user_preferences/primary_bible.md)与[次要](../user_preferences/secondary_bible.md)圣经设定偏好的常用版本。
