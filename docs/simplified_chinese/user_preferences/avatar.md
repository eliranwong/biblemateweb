# 头像 URL

用作个人资料头像的图片 URL。留空则使用默认头像，例如 `https://example.com/avatar.png`。

| | |
|---|---|
| 位置 | `Preferences` → `User & Custom Data` → `Avatar URL` |
| 存储键 | `avatar` |
| 默认值 | `(empty)` |

## 如何更改

1. 打开 `Preferences`（`/settings` 页面）。
2. 展开 `User & Custom Data` 分类。
3. 调整 `Avatar URL`。

更改会自动保存在与您浏览器关联的用户存储中。使用 `Reset All Preferences` 可恢复默认值。
