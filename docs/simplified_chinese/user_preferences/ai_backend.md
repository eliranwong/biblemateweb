# AI 后端

AI 服务提供商。选项包括：`default`（服务器设置）、`googleai`、`openai`、`anthropic`、`cohere`、`deepseek`、`mistral`、`xai`、`azure_*` 变体、`ollamacloud`、`custom`。若管理员已启用，`grok`、`claude` 和 `antigravity` 将使用服务器已登录的订阅 CLI，无需 API 密钥。

| | |
|---|---|
| 位置 | `Preferences` → `AI Backend` → `AI Backend` |
| 存储键 | `ai_backend` |
| 默认值 | `default` |

## 如何更改

1. 打开 `Preferences`（`/settings` 页面）。
2. 展开 `AI Backend` 分类。
3. 调整 `AI Backend`。

更改会自动保存在与您浏览器关联的用户存储中。使用 `Reset All Preferences` 可恢复默认值。

另请参阅 [api_key_setup.md](api_key_setup.md)。
