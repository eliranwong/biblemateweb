# 自定义令牌

自定义令牌用于自定义资源和 AI 功能的访问控制。

## 给开发者

若要设置自定义令牌，请在配置文件 `~/biblemate/biblemateweb.config` 中将字符串指定为 `config.custom_token` 的值。

## 给用户

若要使用由服务器管理员提供的自定义令牌：

1. 向您的服务器管理员获取令牌
2. 前往 `Preferences`
3. 在 `User & Custom Data` 分类下
4. 在 `Custom Token` 字段中输入有效的令牌
