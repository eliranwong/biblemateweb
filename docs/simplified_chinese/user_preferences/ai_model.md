# AI 模型

与所选后端搭配使用的模型 ID。例如：`grok` 可填写 `grok-4.7`；`claude` 可填写 `sonnet`、`opus`、`haiku` 或完整的模型 ID；`antigravity` 可填写 `gemini-3.8-flash-high`。留空则使用该后端的默认值。

| | |
|---|---|
| 位置 | `Preferences` → `AI Backend` → `AI Model` |
| 存储键 | `ai_model` |
| 默认值 | `(empty)` |

## 如何更改

1. 打开 `Preferences`（`/settings` 页面）。
2. 展开 `AI Backend` 分类。
3. 调整 `AI Model`。

更改会自动保存在与您浏览器关联的用户存储中。使用 `Reset All Preferences` 可恢复默认值。
