# API 密钥

您用于所选后端的个人 API 密钥（自带密钥 / BYOK）。它可让您绕过管理员限制并选择自己的提供商。`grok`、`claude` 和 `antigravity` 会忽略此项。

| | |
|---|---|
| 位置 | `Preferences` → `AI Backend` → `API Key` |
| 存储键 | `api_key` |
| 默认值 | `(empty)` |

## 如何更改

1. 打开 `Preferences`（`/settings` 页面）。
2. 展开 `AI Backend` 分类。
3. 调整 `API Key`。

更改会自动保存在与您浏览器关联的用户存储中。使用 `Reset All Preferences` 可恢复默认值。

另请参阅 [api_key_setup.md](api_key_setup.md)。
