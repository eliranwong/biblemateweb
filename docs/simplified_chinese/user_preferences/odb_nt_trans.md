# ODB NT Translation

在[原文语法结构圣经 (ODB)](../bibles/original_discourse.md)中显示的新约译本。选项来自服务器上可用的 `.bible` 译本模块（启用有效自定义令牌时亦包含 `~/biblemate/data_custom/bibles/`）。

| | |
|---|---|
| 位置 | `Preferences` → `Frequently Used Resources` → `ODB NT Translation` |
| 存储键 | `odb_nt_trans` |
| 默认值 | `NET` |

## 如何更改

1. 打开 `Preferences`（`/settings` 页面）。
2. 展开 `Frequently Used Resources` 区块。
3. 调整 `ODB NT Translation`。

设定会自动保存在与浏览器关联的用户存储中。使用 `Reset All Preferences` 可恢复默认值。
