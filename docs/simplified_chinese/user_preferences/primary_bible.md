# 主要圣经 (Primary Bible)

开启圣经内容时作为主要版本使用的圣经版本。可选列表取决于服务器上可用的资源（以及是否启用了有效的自定义令牌）。

| | |
|---|---|
| 位置 | `偏好设定` → `常用资源` → `Primary Bible` |
| 存储键 | `primary_bible` |
| 默认值 | `NET` |

## 如何修改

1. 打开 `偏好设定`（`/settings` 页面）。
2. 展开 `常用资源` 区块。
3. 调整 `Primary Bible`。

更改会自动保存在与您浏览器关联的用户存储空间中。使用 `重置所有偏好设定` 可恢复默认值。
