# 模型温度 (Model Temperature)

控制 AI 输出的随机性，范围为 0.0 至 2.0，步长为 0.1。数值较低时回答更聚焦且具确定性；数值较高时回答更多样化。

| | |
|---|---|
| 位置 | `偏好设定` → `AI Backend` → `Model Temperature (Optional)` |
| 存储键 | `temperature` |
| 默认值 | `0.3` |

## 如何修改

1. 打开 `偏好设定`（`/settings` 页面）。
2. 展开 `AI Backend` 区块。
3. 调整 `Model Temperature (Optional)`。

更改会自动保存在与您浏览器关联的用户存储空间中。使用 `重置所有偏好设定` 可恢复默认值。
