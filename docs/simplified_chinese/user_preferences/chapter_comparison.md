# 整章对照版本

设置从全章右键菜单打开**整章译本对照**时默认显示的圣经译本。

- **位置**：`偏好设置` → `常用资源` → `整章对照版本`
- **存储键值**：
  - `chapter_comparison_mode`：`'default'`（默认）或 `'custom'`
  - `chapter_comparison_bibles`：已选圣经译本缩写列表（例如 `['NET', 'KJV', 'CUV', 'OHGBi']`）

## 行为说明

- **默认**：将当前打开的圣经译本置于第一栏，接着显示您的`主要圣经`、`次要圣经`及 `OHGBi`（自动去重）。
- **自定义**：显示多选标签下拉选单（`选择对照译本`）供您指定常用译本。从特定译本打开时，该译本会置于自定义列表之前；若未选择任何译本，则回退至`默认`。
