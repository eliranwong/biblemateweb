# 次要圣经 (Secondary Bible)

作为次要版本使用的圣经版本，例如用于版本对比。可选列表取决于服务器上可用的资源。

| | |
|---|---|
| 位置 | `偏好设定` → `常用资源` → `Secondary Bible` |
| 存储键 | `secondary_bible` |
| 默认值 | `KJV` |

## 如何修改

1. 打开 `偏好设定`（`/settings` 页面）。
2. 展开 `常用资源` 区块。
3. 调整 `Secondary Bible`。

更改会自动保存在与您浏览器关联的用户存储空间中。使用 `重置所有偏好设定` 可恢复默认值。
