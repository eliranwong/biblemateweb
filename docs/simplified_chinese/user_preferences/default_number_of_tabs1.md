# 圣经标签页

默认开启的圣经标签页数量。为 1 到 10 的滑块。

| | |
|---|---|
| 位置 | `Preferences` → `Tabs Management` → `Bible Tabs` |
| 存储键 | `default_number_of_tabs1` |
| 默认值 | `3` |

## 如何更改

1. 打开 `Preferences`（`/settings` 页面）。
2. 展开 `Tabs Management` 分类。
3. 调整 `Bible Tabs`。

更改会自动保存在与您浏览器关联的用户存储中。使用 `Reset All Preferences` 可恢复默认值。
