# OPB OT Translation 2

在[原文平行圣经 (OPB)](../bibles/original_parallel.md)中显示的旧约第二平行子句译本。选项来自 `~/biblemate/data/clauses/` 中的 `.clause` 模块（启用有效自定义令牌时亦包含 `~/biblemate/data_custom/clauses/`）。

| | |
|---|---|
| 位置 | `Preferences` → `Frequently Used Resources` → `OPB OT Translation 2` |
| 存储键 | `opb_ot_trans2` |
| 默认值 | `NET` |

## 如何更改

1. 打开 `Preferences`（`/settings` 页面）。
2. 展开 `Frequently Used Resources` 区块。
3. 调整 `OPB OT Translation 2`。

设定会自动保存在与浏览器关联的用户存储中。使用 `Reset All Preferences` 可恢复默认值。
