# 经文对照版本

控制从经文右键菜单或单节索引的**单节工具**触发**版本对比**时所打开的圣经译本。

- **位置**：`偏好设定` → `常用资源` → `经文对照版本`
- **存储键**：
  - `verse_comparison_mode`：`'default'`（默认）或 `'custom'`（自定义）
  - `verse_comparison_bibles`：所选圣经译本缩写列表（例如 `['NET', 'KJV', 'CUV', 'OHGBi']`）

## 行为说明

- **默认**：比较您的 `主要圣经`、当前打开或点击的圣经版本，以及 `OHGBi`。
- **自定义**：显示多选标签下拉菜单（`选择对照译本`），让您自由指定偏好的对照版本；若列表留空则自动回退至**默认**行为。
