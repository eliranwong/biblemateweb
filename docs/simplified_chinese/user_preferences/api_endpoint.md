# API 端点

自定义 API 端点 URL，适用于 `custom` 后端或由 Azure 托管的后端。留空则使用提供商的默认值。该字段已掩码隐藏；点击眼睛图标即可显示。

| | |
|---|---|
| 位置 | `Preferences` → `AI Backend` → `API Endpoint (Optional)` |
| 存储键 | `api_endpoint` |
| 默认值 | `(empty)` |

## 如何更改

1. 打开 `Preferences`（`/settings` 页面）。
2. 展开 `AI Backend` 分类。
3. 调整 `API Endpoint (Optional)`。

更改会自动保存在与您浏览器关联的用户存储中。使用 `Reset All Preferences` 可恢复默认值。
