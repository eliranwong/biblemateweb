# 代理模式

一种自主运行的模式：描述一项复杂的圣经研读任务，AI 便会自行规划、选择工具并运行多个回合，最后生成一份总结报告。

## 开启

**AI** 菜单 → `代理模式`。部分服务器可能禁用网页版本，转而显示导向 [BibleMate CLI](https://github.com/eliranwong/biblemate) 的页面（详见[可用性](usage_limits.md)）。

## 工作流程

1. **需求 (Request)** – 可选择通过[优化](prompt_engineering.md)加以改进。
2. **研读计划 (Study Plan)** – 生成一份总体计划。
3. **回合 (Rounds)** – 每个回合均包含建议、选择工具（系统会自动使用第一个建议的工具）、工具指示、输出内容与进度。回合会持续进行，直到 AI 判定完成为止。
4. **总结报告 (Final Report)** – 汇总所有结果的最终回复。

## 控制选项

`编辑需求`、`编辑计划`、`编辑回合`、`修剪回合`、`继续`；点击 **停止** 可中断运行。

## 下载

每个输出均支持复制、TXT、DOCX；`下载完整对话`；`只下载总结报告`。

## 每日限制

管理员可针对未设定自备密钥的用户将代理模式限制为每日一次 – 请参阅[使用限制](usage_limits.md)。

如需逐步控制研读过程，请使用[伙伴模式](partner_mode.md)。
