# 优化（优化用户要求）

在回答前自动将您的请求重新改写为更清晰、更精准的提示词指示。

| | |
|---|---|
| 位置 | 对话模式、伙伴模式与代理模式中的 `优化` 复选框 |
| 键值 | `prompt_engineering` |
| 默认 | 开启 |

## 运作方式

1. 您发送请求。
2. **优化用户要求** 面板实时流式显示经优化的指示。
3. 若开启[审查](chat_review.md)（对话模式），您可以在继续运行前编辑经优化的指示。
4. 随后系统将使用该经优化的指示运行后续流程。完成后该面板会自动收起。

若优化过程失败或未返回任何内容，流程将会停止，您可以重新尝试。

遇到简短直接的提问，或希望完全按照您输入的原始字句提问时，可将此选项关闭。
