# AI 注释

由 AI 撰写的逐节注释，随附为 **AIC** 注释模块（英文），另有 **AICTC**（繁体中文）与 **AICSC**（简体中文）。

## 开启

- **AI** 菜单 → `AI 注释`
- 右键点击经文 → `🧠 AI 注释`
- **工具** 菜单 → `圣经注释` 并选择 AIC。

此模块会自动匹配您的[界面语言](../user_preferences/ui_language.md)（`eng` → AIC、`tc` → AICTC、`sc` → AICSC），并保存于 `favorite_commentary` 中。

## 使用

输入经文编号（如 `John 3:16` 或 `Romans 8:1-17`），或让它自动开启于您正在阅读的经文（[同步](../layout/sync.md)）。

更多信息：[注释工具指南](../tools/tool_commentary.md)。
