# 伙伴模式

适用于复杂多步骤圣经研读的协作模式。AI 负责规划并运行各个步骤，但**主导权始终在您手中**：您可以审查并微调计划、批准工具，并编辑每个步骤的指示。

## 开启

**AI** 菜单 → `伙伴模式`。（请参阅[可用性](usage_limits.md) – 部分服务器仅提供 CLI 版本。）

## 工作流程

1. **需求 (Request)** – 描述研读内容（可选择通过[优化](prompt_engineering.md)加以改进）。
2. **研读计划 (Study Plan)** – AI 起草一份总体计划。您可以审查并编辑该计划。
3. **回合 (Rounds)** – 在每个回合中，AI 会：
   - 提供下一步的**建议 (Suggestion)**，
   - 提议工具（**选择工具 (Tool Selection)**）；您可以从列表中挑选，或选择 `更多...` 查看全部工具，
   - 撰写您可以编辑的**工具指示 (Tool Instruction)**，
   - 运行工具或生成内容，并在每回合后附上**进度 (Progress)** 说明。
4. **总结报告 (Final Report)** – 汇总所有已完成内容的全面报告。

## 运行后的控制选项

`编辑需求`、`编辑计划`、`编辑回合`、`修剪回合`（从选定位置舍弃之后的回合）、`继续`（停止后恢复运行）。

## 下载

每个输出均支持复制、TXT 与 DOCX，另提供 `下载完整对话` 与 `只下载总结报告`。

## 与其他模式比较

| | 对话模式 | 伙伴模式 | 代理模式 |
|---|---|---|---|
| 多步骤计划 | 否 | 是 | 是 |
| 由您批准工具／指示 | 选配（审查） | 是 | 否 |

请参阅[代理模式](agent_mode.md)与[对话模式](chat_mode.md)。
