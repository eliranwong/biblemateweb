# 复制、下载、编辑与停止

## 每次回复之后（对话模式、伙伴模式、代理模式）

| 按钮 | 操作 |
|---|---|
| 📋 复制 | 复制回复文本 |
| 📥 TXT | 下载为纯文本文件 |
| 📥 DOCX | 下载为 Word 文档 |
| ✒️ 编辑 | 在对话框中编辑回复（对话模式）；编辑内容会保留在对话语境中 |

## 完整对话

`下载完整对话` 会将所有请求与回复保存为 `.txt` 文件（可自定义文件名；默认为 `BibleMate_AI_Conversation`）。伙伴模式与代理模式亦提供 `只下载总结报告`。

## 自动滚动

`自动滚动` 复选框（`auto_scroll`，默认开启）可在流式输出时使画面始终保持在最新内容处。

## 停止运行中的任务

点击 **停止**（运行时“发送”按钮会变为“停止”）并确认。伙伴模式与代理模式随后可通过 `继续` 恢复运行。
