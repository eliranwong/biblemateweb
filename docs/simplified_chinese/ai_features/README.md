# AI 功能

BibleMate AI Web 中的所有 AI 功能。对话、伙伴、代理以及生成的内容，可从导航栏中的 **AI** 菜单（`auto_awesome` 图标）、工具菜单，或经文的右键菜单中开启。语义搜索从 **搜索** 菜单开启。

## 互动模式

| 功能 | 说明 |
|---|---|
| [对话模式](chat_mode.md) | 对话式圣经助手 |
| [伙伴模式](partner_mode.md) | 需经您逐步批准的多步骤研经模式 |
| [代理模式](agent_mode.md) | 自主运行的多步骤研经模式 |
| [工作室模式](studio_mode.md) | 集成 `biblemate-agentic-workspace`（CLI/SDK 代理、技能、笔记与导出） |

## 对话模式选项

| 选项 | 说明 |
|---|---|
| [优化（优化用户要求）](prompt_engineering.md) | 在发送前优化您的提示词指示 |
| [代理选项](chat_agent_option.md) | 让辅助代理提升回复质量 |
| [工具（选择工具）](chat_tool_selection.md) | 使用研经工具与专家提示词 |
| [审查](chat_review.md) | 在每个阶段批准或编辑 |
| [导出与编辑回复](export_edit_responses.md) | 复制、下载 TXT/DOCX、编辑、停止 |
