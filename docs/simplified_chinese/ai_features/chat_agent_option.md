# 代理选项（对话模式）

`代理` 复选框可让 BibleMate 创建辅助代理，以生成更详尽、推理更完善的回复（提示文字：“创建代理优化回应”）。

| | |
|---|---|
| 键值 | `use_agent` |
| 默认 | 开启 |

## 运行机制

- 当开启此选项并生成纯文本回答时，**代理** 面板会显示代理的工作过程，随后呈现回答内容。
- 关闭时，AI 会直接给出单次回复（速度更快、成本更低）。
- 某些专业[工具](chat_tool_selection.md)无论此设置为何，都会自动调用代理。

这与[代理模式](agent_mode.md)不同，后者是专门处理多回合任务的独立页面。
