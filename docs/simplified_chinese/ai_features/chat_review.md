# 审查

启用后，AI 会在关键节点暂停，以便您在继续运行前进行批准、编辑或取消。

| | |
|---|---|
| 位置 | 对话模式中的 `审查` 复选框 |
| 键值 | `chat_mode_review` |
| 默认 | 关闭 |

## 审查节点

- **经优化的指示**（若[优化](prompt_engineering.md)开启）：编辑重写后的提示词指示。
- **工具选择**（若[工具](chat_tool_selection.md)开启）：从建议的工具中选择；`更多...` 可列出全部工具。
- **工具指示**：在运行前编辑工具指示。

在任何对话框中取消都会停止该请求，并显示 `[Cancelled!]`。

在[伙伴模式](partner_mode.md)中，这些审查步骤一律保持开启。在[代理模式](agent_mode.md)中，这些步骤则不会出现。
