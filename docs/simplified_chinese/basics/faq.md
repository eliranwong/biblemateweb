# 常见问题

**我需要注册账号吗？** 不需要。设置保存在您的浏览器中。仅在需要使用[云端硬盘笔记](../integrations/google_drive_notes.md)或受到每日额度限制时，才需要登录 Google 账号。

**使用 AI 需要付费吗？** 服务器默认设置由管理员设定。您也可以使用自己的密钥（[自带密钥 (BYOK)](../user_preferences/api_key_setup.md)）。

**如何并排阅读两部圣经？** 请参阅[平行圣经](../layout/parallel_bibles.md)。

**如何查询希伯来文或希腊文字词？** 在原文圣经中点击该字词即可（[字词工具提示](../integrations/word_tooltips.md)）。

**如何查看与某节经文相关的所有信息？** 点击该节经文编号（[经文菜单](../integrations/verse_menu.md)）。

**如何分享我正在阅读的内容？** 请参阅[分享链接或二维码](share_link_qr_code.md)。

**为什么代理模式或伙伴模式会显示 CLI 页面？** 管理员已将其禁用；请使用您自己的 API 密钥（[使用额度限制](../ai_features/usage_limits.md)）。

**为什么语义搜索无法工作？** 请参阅[语义搜索设定](../server_setup/semantic_search_setup.md)。

**如何重置所有设置？** `偏好设定` → `重置所有偏好设定`（[用户数据](../user_preferences/user_data_and_storage.md)）。

**我可以添加自己的书籍或圣经版本吗？** 可以，请参阅[自定义资源](../integrations/custom_resources.md)。

**我可以在手机上使用吗？** 可以：请参阅[移动端布局](../layout/mobile_layout.md)，或在 Android 上运行服务器（[Termux](../android_termux/README.md)）。

更多信息请参阅：[故障排除](../server_setup/troubleshooting.md)。
