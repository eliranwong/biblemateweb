# 切换选项

开启导航栏中的**设定**（齿轮）菜单。

| 选项 | 效果 | 默认值 |
|---|---|---|
| 返回 / 前进箭头 | 浏览器历史记录 | – |
| 只显示圣经 / 只显示工具 / 圣经与工具 | [更改布局](../layout/toggle_layout.md) | 圣经与工具 |
| 版面转换 | 显示/隐藏版面转换按钮 | 开启 |
| 开启 | 显示/隐藏开启（圣经选单）按钮 | 开启 |
| 笔记 | 显示/隐藏笔记标记（页面重新加载） | 开启 |
| 提示框 (Tooltip) | 悬停显示单词提示框（关闭时需点击单词才显示；[详细信息](../integrations/word_tooltips.md)） | 开启 |
| <a id="sync"></a>同步 | 保持圣经与工具窗口同步在同一章（[详细信息](../layout/sync.md)） | 开启 |
| 全萤幕 | 切换全萤幕 | 关闭 |
| 深色/浅色模式 | 切换主题（页面重新加载） | 深色 |
| 偏好设定 | 开启[偏好设定](../user_preferences/README.md)页面 | – |

在移动设备上，相同的切换开关位于左侧抽屉菜单中。

切换设置会自动保存。更多关于悬浮按钮的说明：[悬浮按钮](../layout/floating_buttons.md)。
