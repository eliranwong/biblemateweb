# 导航栏

位于页面顶部的功能栏。

| 元素 | 用途 |
|---|---|
| 头像 / **BibleMate AI** | 显示当前视图的[链接与二维码](share_link_qr_code.md) |
| 快速搜索框 | 通过输入文本进行[搜索或导航](quick_search.md) |
| 圣经 (`local_library`) | [圣经菜单](menu_bibles.md) |
| 平行圣经 (`devices_fold`) | [平行圣经菜单](menu_parallel_bibles.md) |
| 工具 (`build`) | [工具菜单](menu_tools.md) |
| 搜索 (`search`) | [搜索菜单](menu_search.md) |
| AI (`auto_awesome`) | [AI 菜单](menu_ai.md) |
| 设定 (`settings`) | [切换选项](toggle_options.md)与偏好设定 |

将鼠标悬停在图标上可查看工具提示。在小屏幕设备上，标题和快速搜索框会移入点击汉堡图标开启的左侧抽屉菜单中；五个菜单按钮则保留在顶部导航栏中。
