# 快速搜索

位于导航栏中的输入框（在移动端位于抽屉菜单内）。输入内容后按 **Enter**。自动完成功能会推荐书卷名称、圣经版本和工具名称。

## 示例

| 输入 | 结果 |
|---|---|
| `KJV` | 在圣经区域开启 KJV |
| `John 3:16` | 开启约翰福音第 3 章第 16 节 |
| `KJV:::John 3:16` | 同上，使用 KJV 版本 |
| `bible:::John 3:16` | 在工具区域将其作为平行圣经开启 |
| `faith hope love` | 搜索经文（结果显示于工具区域） |
| `xrefs:::John 3:16` | 开启经文串珠工具 |

多个经文引用或自定义文本将会执行经文搜索。每次搜索后输入框会自动清空。

完整语法请参阅：[快速搜索（布局）](../layout/quick_search.md)。
