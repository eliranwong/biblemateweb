# 快速入门

在浏览器中开启 BibleMate AI Web。无需登录；您的设置会直接保存在浏览器中。

## 界面结构

- **导航栏（顶部）：** 头像/标题、[快速搜索](quick_search.md)框，以及五个菜单按钮——圣经、平行圣经、工具、搜索、AI，随后是设定（齿轮）按钮。
- **圣经区域：** 阅读圣经的地方，支持分页标签。
- **工具区域：** 平行圣经、研经工具、搜索结果和 AI 功能显示的区域，同样支持分页标签。
- **悬浮按钮（右下角）：** 版面转换与开启（圣经选单）。

## 入门操作

1. 点击**圣经**按钮并选择一个圣经版本，或在快速搜索框中输入 `John 3:16` 并按 Enter。
2. 点击**开启**按钮以跳转至其他书卷、章节与经节。
3. 从**工具**中开启研经工具（例如经文串珠），即可在圣经旁并列查看。
4. 使用**版面转换**按钮专注于圣经、工具或两者并列显示。

在手机上，点击汉堡图标即可开启抽屉菜单（[移动端布局](../layout/mobile_layout.md)）。
