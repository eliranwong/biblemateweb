# 工具菜单

图标：`build`。在**工具区域**中开启研经工具。

- **标签页：** 新工具标签页、关闭工具标签页、关闭其他。
- **语音：** 圣经广播、圣经语音。
- **AI 研经：** 书卷分析、全章摘要。
- **注释与参考：** 圣经注释、经文串珠、经文宝库。
- **汇编选辑：** 圣经应许、平行经文。
- **时间：** 圣经时间轴、圣经时序。
- **参考书籍**
- **形态学分析**
- **资源索引：** 全书索引、全章索引（启动默认工具）、单节索引。
- **译本对照：** 整章对照版本、经文对照版本。
- **书签与读经计划：** 书签（含荧光标记与阅读记录）、一年读经计划（365 天每日读经计划，支持进度跟踪与多语言经文引用）。
- **笔记：** 圣经笔记（当配置 Google 云端硬盘时）、笔记本。

多数工具会在您当前阅读的经节开启。完整列表与指南请参阅：[工具](../layout/tools_window.md)。
