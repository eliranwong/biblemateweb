# 语言与字体

## 界面语言

| 代码 | 语言 |
|---|---|
| `eng` | English (英文) |
| `tc` | 繁體中文 (Traditional Chinese) |
| `sc` | 简体中文 (Simplified Chinese) |

在 `偏好设定` → 语言（[指南](../user_preferences/ui_language.md)）中更改，或使用 URL 参数 `lang`。语言设定会影响菜单、对话框、圣经书卷名称，以及多项工具的内容语言：AI 注释 (AIC / AICTC / AICSC)、[书卷分析](../tools/tool_analysis.md)、[全章摘要](../tools/tool_summary.md)、AI 欢迎信息和 [API](../integrations/rest_api.md) 输出（`language` 参数）。

## 字体

希伯来文和希腊文文本使用内置字体（Ezra SIL、KoineGreek），因此原文圣经可以在任何设备上正确显示。可通过[字体大小](../user_preferences/font_size.md)调整整体文本大小。
