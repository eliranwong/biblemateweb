# AI 菜单

图标：`auto_awesome`。在**工具区域**中开启各项 AI 功能。

| 项目 | 用途 |
|---|---|
| 书卷分析 | 圣经书卷的 AI 分析 |
| 全章摘要 | 篇章的 AI 摘要 |
| AI 注释 | 经文段落的 AI 注释 |
| 对话模式 | 通过对话询问问题 |
| 伙伴模式 | 与交互式伙伴一同研经 |
| 代理模式 | 自主研究代理 |

若要使用您自己的 AI 服务提供商，请参阅[自带密钥 (BYOK)](../user_preferences/api_key_setup.md)。更多信息：[AI 菜单](../layout/ai_menu.md)。
