# 键盘快捷键

| 位置 | 按键 | 动作 |
|---|---|---|
| 快速搜索框 | **Enter** | 执行搜索或导航 |
| 工具 / 搜索输入框（经文、注释、串珠、宝库、原文词典、圣经字典、主题、人物、地点、平行经文、应许、名字、地图...） | **Enter** | 执行查询 |
| 上述输入框 | **↑**（向上键） | 恢复上一条查询内容（亦可点击历史记录图标 ⏱️） |
| AI 对话 / 伙伴 / 代理请求输入框 | **Shift+Enter** | 发送 |
| 浏览器 | 后退 / 前进 (Back / Forward) | 在导航历史记录中移动；每次更换圣经和工具都会更新地址栏（[URL 参数](../layout/url_parameters.md)） |

鼠标与触控操作：点击经节编号可打开[经文菜单](../integrations/verse_menu.md)；单击鼠标右键（长按）可打开[右键菜单](../layout/context_menus.md)；拖动[悬浮按钮](../layout/floating_buttons.md)或分割线可调整布局。
