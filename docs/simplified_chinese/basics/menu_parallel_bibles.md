# 平行圣经菜单

图标：`devices_fold`。在圣经区域旁的**工具区域**中开启圣经以进行对比。

| 项目 | 动作 |
|---|---|
| 新平行标签页 | 在工具区域创建新标签页 |
| 关闭平行标签页 | 关闭当前启用的工具区域标签页 |
| 关闭其他 | 关闭当前标签页以外的所有其他工具区域标签页 |
| 主要 / 次要圣经 | 您偏好的版本 |
| 原文圣经 | ORB, OIB, OPB, ODB, OLB |
| 其他圣经 | 所有其他版本 |

开启[同步](toggle_options.md#sync)后，两个窗口将保持在同一章。

更多信息：[平行圣经](../layout/parallel_bibles.md)。
