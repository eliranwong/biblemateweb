# 圣经菜单

图标：`local_library`。在**圣经区域**中开启圣经。

| 项目 | 动作 |
|---|---|
| 新圣经标签页 | 在圣经区域创建新标签页 |
| 关闭圣经标签页 | 关闭当前启用的标签页（最后一个标签页无法关闭） |
| 关闭其他 | 关闭当前标签页以外的所有其他标签页 |
| 主要 / 次要圣经 | 您最常用的两个版本（[前往设置](../user_preferences/primary_bible.md)） |
| 原文读本、逐字对照、平行对照、语法分析、语言学圣经 | ORB, OIB, OPB, ODB, OLB |
| 其他圣经 | 服务器上的所有其他版本（输入有效的[自定义令牌](../user_preferences/custom_token.md)后会显示自定义圣经） |

如果已选择经节，或工具查询中包含经文引用，圣经将在该节经文开启。

更多信息：[圣经窗口](../layout/bible_window.md)、[标签页管理](../layout/tabs_management.md)。
