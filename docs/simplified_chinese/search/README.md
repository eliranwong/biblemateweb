# 搜索指南

可从 **搜索** 菜单（`search` 图标）开启，或通过 [快速搜索](../basics/quick_search.md) 中的关键字（例如 `verses:::love`）进入。

| 搜索 | 关键字 | 指南 |
|---|---|---|
| 经文（字面、模式、语义） | `verses` | [经文搜索](search_bible_verses.md)、[高级示例](search_bible_verses_examples.md) |
| 平行经文 | `parallels` | [平行经文搜索](search_bible_parallels.md) |
| 圣经应许 | `promises` | [圣经应许搜索](search_bible_promises.md) |
| 圣经主题 | `topics` | [圣经主题搜索](search_bible_topics.md) |
| 圣经人物 | `characters` | [圣经人物搜索](search_bible_characters.md) |
| 人物关系 | `relationships` | [人物关系搜索](search_bible_relationships.md) |
| 圣经地点 | `locations` | [圣经地点搜索](search_bible_locations.md) |
| 圣经地图 | `maps` | [圣经地图搜索](search_bible_maps.md) |
| 圣经名字 | `names` | [圣经名字搜索](search_bible_names.md) |
| 圣经字典 | `dictionaries` | [圣经字典搜索](search_dictionaries.md) |
| 百科全书 | `encyclopedias` | [百科全书搜索](search_encyclopedias.md) |
| 原文词典 | `lexicons` | [原文词典搜索](search_lexicons.md) |

## 影响搜索的设定

- [搜索模式](../user_preferences/search_mode.md)（字面 / 模式 / 语义）
- [区分大小写](../user_preferences/search_case_sensitivity.md)
- [相似条目数量](../user_preferences/top_similar_entries.md)、[相似经文数量](../user_preferences/top_similar_verses.md)
