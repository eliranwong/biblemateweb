# **圣经应许搜索指南**

此工具可帮助您搜索并探索按主题分类整理的神的应许。通过查考神在整本圣经中对祂子民所立下的应许，从中寻得安慰、盼望与确据。

## **什么是圣经应许搜索？**

圣经应许搜索工具提供精心汇编、按主题分类的神的应许数据库。您可以搜索特定的生活情境或属灵主题，以发掘整本圣经中相关联的宝贵应许。

## **您将找到的内容**

对于每个应许主题，该工具提供：
- **主题名称**：应许类别的明确标示
- **应许描述**：神在此主题上所立下的应许概述
- **经文汇编**：集中归纳的所有相关圣经应许经节
- **背景语境**：理解应许何时以及如何适用
- **成就条件**：领受应许的任何先决要求或心态
- **生活应用**：如何凭信心抓住并在生活中活出这些应许

## **如何使用**

1. **输入主题**：输入一个主题或生活处境
2. **从建议中选择**：自动完成功能会在您输入时显示应许主题建议
3. **按 Enter 键**：加载与该主题相关的所有应许
4. **查看应许**：研读神在此主题上的坚定承诺
5. **点击参考**：开启经文以在完整上下文中研读应许
6. **支取应许**：将神的应许切实应用于您的日常生活中

### **搜索特色**

- **自动完成**：在您输入时实时显示应许主题建议
- **模糊匹配**：即使使用近似词汇也能找到主题
- **相似度搜索**：通过 AI 技术匹配关联的属灵概念
- **多个结果**：如果找到多个匹配项，可从列表中选择
- **历史记录**：按向上箭头键可恢复您上次的搜索
- **专题分类**：按切身生活处境组织编排应许

## **深入理解圣经应许**

### **应许的架构类型**

**无条件的应许：**
- 单单奠基于神的性情与主权旨意
- 不附带任何人为功德或要求
- 示例：新约恩典、神永远的爱、基督的荣耀重临

**有条件的应许：**
- 需要人以信心、顺服或具体行动回应
- 具备“若……就……”的互动架构
- 示例：“你们若常在我里面……”“你们若寻求我……”

**普遍性应许：**
- 面向普天下所有愿意相信的人
- 示例：“凡信祂的……”“凡愿意的……”

**特定性应许：**
- 赐予特定历史人物、族群或特定处境
- 示例：对亚伯拉罕个人的应许、对以色列民的约、对特定使徒的托付

**“已然与未然”（Already / Not Yet）：**
- 当下已领受部分初熟的果子
- 最终完满的成就尚待未来显现
- 示例：神的国度、新造的荣耀

### **如何切实支取应许**

**1. 透彻理解应许：**
- 在上下文脉络中研读
- 理解原始受众与历史处境
- 确立该应许如何正确认知并适用于今日的我们
- 仔细厘清是否有伴随条件

**2. 满足应许条件：**
- 坚定不移的信心（最基本的要素）
- 顺服真理的生活（不可或缺的要求）
- 具体的配合行动（照神吩咐而行）
- 纯洁正直的动机（切忌妄求与私欲）

**3. 坚信神的话语：**
- 单单信靠神全然信实的品格
- 毫不疑惑动摇
- 即使环境未见立即好转，依旧站立得稳
- 时常数算神过去历史中的恩典与信实

**4. 根据应许展开行动：**
- 祷告呼求（以神的话语作为祈求的法理依据）
- 行事为人（活出应许已经成就的信心笃定）
- 开口颂赞（在应验之前提前感谢神）
- 忍耐等候（存着盼望等候神的最好时刻）

**5. 满怀盼望恒久等候：**
- 时候在神的手中
- 成就的过程往往是渐进塑造的
- 应许的兑现是确凿无疑的
- 信心在等候的试炼中愈显宝贵精金

### **应许的神学根基**

**神的绝对信实：**
- 神决不谎言（提多书 1:2）
- 祂的话语永远立定（以赛亚书 40:8）
- 应许没有一句落空（约书亚记 21:45）
- 祂亲自看守祂的话语，为要成就（耶利米书 1:12）

- 祂的宝血立定了新约
- 祂的死里复活保证了未来一切应许的终极成全

**圣灵作为承受基业的凭据：**
