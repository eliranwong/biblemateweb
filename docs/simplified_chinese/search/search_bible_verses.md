# **经文搜索指南**

此强大的搜索工具可让您使用三种不同的搜索方法来寻找圣经经文：字面文本搜索、正则表达式（模式）搜索以及由 AI 驱动的语义搜索。

## **什么是经文搜索？**

经文搜索工具提供三种精密的搜索方式，在整本圣经中精准查找符合您条件的经节。无论您是在寻找特定字词、字符模式还是属灵概念，此工具都能帮助您准确找到所需内容。

## **搜索方法**

### **1. 字面搜索**

在圣经经文中精确查找特定的字词或短语。

**运行方式：**
- 查找完全包含您所输入搜索词汇的经文
- 默认不区分大小写
- 支持多词组合（查找同时包含“所有”输入字词的经文）
- 速度飞快且直观直接

**最适用于：**
- 查找特定字词或固定短语
- 定位耳熟能详的名言金句
- 快速查找经文参考
- 查找某个字词在圣经中的所有出现处

**示例：**
```
Search: "love your enemies"
→ Finds verses containing all three words

Search: "faith hope love"
→ Finds verses with all three words present

Search: "Jesus wept"
→ Finds the shortest verse in the Bible
```

### **2. 模式搜索（正则表达式 Regex）**

利用字符模式匹配进行高级复杂搜索。

**运行方式：**
- 采用标准正则表达式（Regex）语法
- 寻找符合复杂结构模式的经节
- 支持通配符、逻辑或（OR）及重复计数
- 功能强大，适合熟悉正则表达式的高级用户

**最适用于：**
- 基于特定规则模式的结构搜索
- 查找词形变化与词根派生
- 复杂的多条件组合检索
- 圣经语言学与文本分析

**常用 Regex 模式：**

| 模式 | 含义 | 示例 |
| :---- | :---- | :---- |
| `.` | 任意单个字符 | `l.ve` 匹配 "love", "live" |
| `*` | 零次或多次重复 | `God.*love` 匹配 "God is love", "God shows love" |
| `+` | 一次或多次重复 | `lov+e` 匹配 "love", "loove" |
| `?` | 可选字符（零次或一次） | `colou?r` 匹配 "color" 或 "colour" |
| `\|` | 逻辑“或” | `love\|hate` 匹配包含任一词的经文 |
| `^` | 经节开头 | `^In the beginning` 匹配以此短语开头的经文 |
| `$` | 经节结尾 | `Amen\.$` 匹配以 "Amen." 结尾的经文 |
| `[abc]` | 括号内任一字符 | `[Jj]esus` 匹配 "Jesus" 或 "jesus" |
| `[a-z]` | 字符范围 | `[A-Z]ove` 匹配 "Love", "Dove", "Move" |
| `\w` | 单词字符 | `\w+` 匹配任意单词 |
| `\d` | 数字字符 | `\d+` 匹配任意数字 |

**示例：**
```
Search: "love.*neighbor"
→ Finds verses with "love" followed by "neighbor"

Search: "(faith|hope|love)"
→ Finds verses with any of these words

Search: "^Blessed"
→ Finds verses beginning with "Blessed"

Search: "Jesus (said|spoke|answered)"
→ Finds verses where Jesus said, spoke, or answered
```

### **3. 语义搜索（AI 驱动）**

运用人工智能依核心含义查找经文，而非受限于字面词句。

**运行方式：**
- 深刻理解您查询内容的大体意涵
- 寻找在概念上相近或相关的经节
- 不需要字面完全吻合
- 运用向量嵌入（Vector Embeddings）进行相似度计算

**最适用于：**
- 依神学概念或属灵主题寻找经文
- 发掘您未曾知晓但含义紧密相关的段落
- 专题查经与灵修默想
- 清楚明白所求含义却记不清确切字词时

**示例：**
```
Query: "God's forgiveness"
→ Finds verses about mercy, pardon, grace, redemption

Query: "trusting in difficult times"
→ Finds verses about faith, perseverance, hope during trials

Query: "treating others with kindness"
→ Finds verses about love, compassion, good works, golden rule

Query: "end times prophecy"
→ Finds verses about second coming, judgment, apocalypse
```

**语义搜索技巧：**
- 使用自然语言提问与查询
- 清楚描述您所寻求的属灵概念
- 无须拘泥于特定的圣经专门术语
- AI 能自动理解同义词与相关概念
- 结果按关联相似度由高至低智能排序

## **如何使用经文搜索**

1. **选择搜索类型**：从标签页或下拉列表中选择“字面”、“模式”或“语义”
2. **输入查询语句**：输入您的搜索字词、正则模式或思想概念
3. **按 Enter 键或点击搜索按钮**：执行检索
4. **查看结果**：浏览滚动匹配的经文列表
5. **点击参考**：点击任何经文参考即可在完整圣经章节上下文中阅读

### **搜索界面说明**

- **搜索类型选择器**：切换搜索方式的标签页或下拉列表
- **搜索输入框**：键入查询内容的文本框
- **搜索按钮**：触发执行搜索
- **结果显示区域**：展示匹配经文及其详细参考
- **结果计数器**：显示找到的匹配经节总数
- **清除按钮**：重置清空搜索输入框

## **搜索选项与筛选机制**

### **圣经译本选取**

在特定的圣经译本中进行检索：
- 使用圣经译本选择器
- 默认：您当前所选用的圣经译本
- 仅在选定的单一译本中进行检索
- 可切换不同译本以跨版本对照搜索

### **搜索范围控制**

您可以限定检索范围：
- **全本圣经**：全部 66 卷书（默认）
- **旧约圣经**：创世记至玛拉基书
- **新约圣经**：马太福音至启示录
- **单一书卷**：仅限特定某一卷书
- **圣经分卷区块**：摩西五经、先知书、福音书、书信等

### **结果数量限制与分页加载**

- 默认上限：最多返回前 2000 节匹配经文（`config.verses_limit`）
- 若达到上限，系统会显示提示通知
- 结果每次加载 100 节经文以保持流畅性能；点击底部的 **加载更多** 按钮即可继续加载下一批结果
- 在筛选框输入文字时，会对所有已获取的结果进行筛选，而不仅限于当前已显示的经文
- 上限阈值可在服务器设定中进行配置调整

## **高效搜索技巧**

### **字面搜索技巧**

1. **短语使用双引号**：`"love your neighbor"` 可精准查找连续短语
2. **多词逻辑**：多个词汇必须同时存在（隐含 AND 逻辑）
3. **避免单独虚词**：避免单独搜索 "the", "a", "and" 等高频常用词
4. **尝试词形变体**：如 "forgive" 与 "forgiveness" 在字面上视为不同单词
5. **大小写无关**："GOD"、“God”、“god” 均会视为相同

### **模式搜索（Regex）技巧**

1. **从简易模式开始**：先构建基础表达式，再视需要逐步增添复杂度
2. **先测试后使用**：在样例文本上验证正则模式的正确性
3. **注意转义特殊字符**：在 `.?*+[]{}()|^$` 前务必加上反斜线 `\` 进行转义
4. **善用定位锚点**：使用 `^` 锁定经节开头，使用 `$` 锁定经节结尾
5. **逻辑或（OR）**：使用 `|` 实现多词任选匹配（如 `faith|hope|love`）
6. **单词边界**：使用 `\b` 确保整词匹配，避免被包含在更长词汇中

### **语义搜索技巧**

1. **描述具体生动**：例如“神对全人类无条件的浩大慈爱”
2. **使用自然语言**：以如同向人请教提问的语气进行输入
3. **把握核心意涵**：将焦点置于概念本身，而非拘泥于具体字词
4. **着重查看顶部结果**：相似度最高的最佳匹配项目排在最前列
5. **精细化提问**：若检索结果过于宽泛，可适度增添具体语境
6. **尝试不同措辞**：换用不同的叙述方式可能激发出来更多维度的宝贵亮光

## **高级特色功能**

### **布尔逻辑（字面搜索）**

以隐含的 AND 逻辑组合多个关键词：
- `faith works` = 同时包含这两个词的所有经节
- 所有输入字词必须同时具备
- 不支持显式的 OR 运算符（如需 OR 请改用模式搜索）

### **通配符灵活匹配（模式搜索）**

运用正则通配符实现强大检索：
- `.*` 匹配任意长度的任意字符
- `\w+` 匹配任意完整的单词
- `\d+` 匹配任意数字序列
- `.{3,5}` 匹配指定长度范围内的字符

### **语境化深入过滤**

- 在现有搜索结果中进行二次过滤筛选
- 按新旧约范围快速缩小范畴
- 排除特定不相关书卷
- 依历史时期进行时序筛选（若有元数据支持）

### **保存常用搜索**

- 将高频使用的搜索条件加入书签收藏
- 为常用搜索命名并分类归档
- 快速重现复杂的研经检索式

## **常见问题排查**

### **找不到任何结果**

- **核对文字拼写**：确认输入的关键词无错字漏字
- **尝试同义词**：换用同一概念的其他表达方式
- **放宽搜索条件**：删减过于苛刻的限制词汇
- **切换检索方式**：若字面搜索无果，尝试改用语义搜索
- **更换圣经版本**：不同译本在用字选词上常有差异

### **结果过多难以浏览**

- **增加限定词**：增添更多关键词以提高字面精确度
- **加用引号**：使用双引号进行精确短语匹配
- **缩小检索范围**：限定在单一书卷或单一约章内检索
- **精确概念描述**：在语义搜索中提供更具体详尽的情境描述
- **应用筛选器**：启用书卷或分卷过滤机制

### **正则表达式语法错误**

- **检查语法结构**：核验正则模式中的括号与运算符是否配对完整
- **注意转义处理**：确认保留特殊符号前已正确加上反斜线 `\`
- **在线验证测试**：在专业正则测试网站上先行验证逻辑
- **化繁为简**：先从最简单的模式开始，逐步测试扩展
- **参考语法手册**：查阅标准 Regex 语法参考指引

### **语义结果不够切题**

- **充实查询细节**：在查询语句中增添更多上下文细节
- **更换叙述视角**：换用不同的语句结构重塑问题
- **聚焦前列结果**：优先关注排名最前列的高度相关项目
- **切换检索模式**：若语义搜索过于发散，果断改用精准的字面搜索
- **补全背景脉络**：在提问中提供更为丰富的神学背景

4. **记录** → 将所得亮光沉淀于“笔记本”中
5. **分享** → 导出成果应用于讲道、教学与团契分享

## **搜索语法快速参考**

### **字面搜索语法**

- 单词检索：`love`
- 多词同时匹配（AND）：`faith hope love`
- 固定短语（强烈推荐）：`"love your neighbor"`
- 不区分大小写：`GOD` = `god` = `God`

### **模式搜索（Regex）语法**

**基础元字符：**
- `.`——任意单一字符
- `*`——零次或多次重复
- `+`——一次或多次重复
- `?`——可选（零次或一次）
- `|`——逻辑“或”
- `()`——群组分组
- `[]`——字符集类别
- `^`——行首 / 节首锚点
- `$`——行尾 / 节尾锚点

**预定义字符集：**
- `\w`——单词字符 [a-zA-Z0-9_]
- `\d`——数字字符 [0-9]
- `\s`——空白字符
- `\W`——非单词字符
- `\D`——非数字字符
- `\S`——非空白字符

**量词语法：**
- `{n}`——恰好出现 n 次
- `{n,}`——至少出现 n 次
- `{n,m}`——出现 n 至 m 次

### **语义搜索语法**

- 自然语言输入
- 无需掌握任何特殊语法
- 句意完整、描述丰富的查询往往能获得更佳结果
- 采用提问式句型效果极佳
- 提供适当的上下文背景能大幅提升精准度

## **性能提升建议**

1. **精准缩小范围**：在明确知道出处时尽量限定在具体书卷内检索
2. **合理控制上限**：设定适当的结果数量上限
3. **善用查询缓存**：重复执行的搜索会因缓存机制而大幅提速
4. **优先尝试字面**：在只需简单查找时，字面搜索最为轻快迅捷
5. **明确搜索词汇**：具体清晰的条件比模糊宽泛的检索更加高效

- 绝无任何搜索数据或查询记录上传至外部服务器

- 搜索历史记录安全存储于本地存储库中

## **其他交互分析功能**

- **点击图表实时筛选与按需加载书卷**：在**分布分析**图表中点击任一书卷或章节柱条，即可将下方经文列表筛选至该书卷或章节（图表上方并显示**旧约 | 新约**总数）。当搜索结果超过显示上限（`verses_limit`）时，超出上限的书卷会以较浅蓝色显示并出现提示信息，点击任意书卷即可按需加载该卷的完整搜索结果；点击 **重置筛选** 按钮（或再次点击当前选中的章节柱条）即可恢复显示全部结果。
- **标示译本差异（平行对照）**：当同时查看同一节经文的多个译本（例如通过**版本对比**）时，可开启 **标示译本差异** 开关，以第一个译本为基准高亮显示各译本的用词差异。
- **导出经文**：点击经文列表上方的 **导出经文** 按钮，即可下载当前显示（或已筛选）的经文。若 `.bible` 文件包含可选的 `VersesPlain` 数据表，会优先使用其中的纯文本经文；否则回退使用 `Verses` 数据表并去除 HTML 标签。
- **词形变化分布图**：执行词形搜索（`E...|` 或 `G...|`）时，**分布分析**区块内会额外显示各词形语法特征的分布柱状图。
- **译本对照**：在任一经文标签的菜单中点击 **译本对照**，即可并排比较该节经文在当前、主要、次要及所选圣经译本中的翻译，并高亮标示用词差异。
- **导出对照表格**：当同一节（或多节）经文显示多个译本时，点击 **导出对照表格** 即可下载按经节分组的 Excel（`.xlsx`）对照表格。
