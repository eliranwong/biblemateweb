# **圣经字典搜索指南**

此工具提供整本圣经中出现的圣经词汇、神学概念与重要字词的全面定义与详尽阐释。搜索任何词条即可发掘其原意与属灵重要性。

## **什么是圣经字典搜索？**

圣经字典搜索工具让您能够查阅详细的字典词条，精准定义并深入阐明圣经术语、神学概念、人物、地理地点以及教义思想。这就如同将多部权威圣经字典随时置于您的指尖。

## **您将找到的内容**

对于每个字典条目，该工具提供：
- **词条定义**：对该词汇或概念含义的清晰阐释
- **圣经用法**：该词汇在圣经经文中的具体使用情境
- **字源辞源**：词汇起源与语言学背景（相关时提供）
- **神学重要性**：该词汇在教义神学中的关键地位
- **经文参考**：相关的圣经经文章节
- **历史背景**：古代文化处境与历史环境
- **相关词汇**：关联概念与同义词

1. **输入词条**：输入任何圣经字词或神学概念

## **工作流程示例**

### **剖析核心神学名词——称义（Justification）**

1. 搜索：`Justification`
2. 研读定义：
   - 法庭法律用语，意为“被宣判为义”
   - 并非“主观上被改造成完全无罪”，而是“在法理地位上被算为义”
   - 属法理宣告（forensic），而非内在质变（transformative）
3. 追溯字源学：
   - 希腊文：*dikaiosis*（宣判为义）
   - 源自 *dikaios*（公义、义人）
4. 查考圣经用法：
   - 罗马书 3:24, 28
   - 罗马书 4:25
   - 罗马书 5:1
5. 在完整上下文语境中精读核心章节
6. 与关联神学术语细致对比：
   - 成圣（Sanctification，生命被造就圣洁）
   - 重生（Regeneration，获得全新属天生命）
   - 得儿女名分（Adoption，成为神的儿女）
7. 记录全面透彻的神学笔记

### **探索文化名词——经文匣（Phylactery）**

1. 搜索：`Phylactery`
2. 研读定义：
   - 内置微型手抄经文的皮革小盒子
   - 佩戴于额前与左臂上
   - 源于对申命记 6:8 字面意义的恪守
3. 理解历史文化处境：
   - 犹太教传统虔敬实践
   - 对律法命令的字面化落实
   - 作为对神委身的公开标记
4. 参考耶稣的亲口教训：
   - 马太福音 23:5——批评法利赛人故意做宽经文匣以夸耀虔诚
   - 警告切莫落入形式主义与炫耀虚荣
5. 领悟现代属灵应用：
   - 信仰不在乎外在仪式的炫耀
   - 内心对神真实的敬畏爱慕才是神所悦纳的
6. 反思当代基督徒生活：
   - 我们在日常生活中如何真诚“见证”信仰？

### **探讨教会体制名词——圣礼（Sacrament）**

1. 搜索：`Sacrament`
2. 研读定义：
   - 神圣的属天圣仪
   - 恩典的传递途径
   - 内在不可见属天实质的外在可见标记
3. 掌握各宗派传统差异：
   - 天主教会：七件圣事
   - 基督新教：两大圣礼（洗礼与圣餐）
   - 理解各自背后不同的神学诠释架构
4. 扎根圣经权威基础：
   - 洗礼：马太福音 28:19、使徒行传 2:38
   - 圣餐：哥林多前书 11:23-26
5. 带着相互尊重的态度客观对待不同神学观点
6. 确立深具圣经纯正根基的信仰立场

### **研读古代度量衡——肘（Cubit）**

1. 搜索：`Cubit`
2. 研读定义：
   - 古代通行长度计量单位
   - 前臂长度（自肘关节至中指尖）
   - 约合 18 英寸（约 45 厘米）
3. 留意尺寸规格差异：
   - 普通肘：约 18 英寸
   - 长肘（王室肘）：约 20-21 英寸
4. 检索圣经具体使用实例：
   - 挪亚方舟的建造尺寸（创世记 6:15）
   - 会幕各项圣物的规格（出埃及记 25-27 章）
   - 所罗门圣殿的宏伟尺寸（列王纪上 6 章）
   - 歌利亚的惊人身高（撒母耳记上 17:4）
5. 换算为现代公制单位
6. 在脑海中生动勾勒并可视化圣经历史场景
