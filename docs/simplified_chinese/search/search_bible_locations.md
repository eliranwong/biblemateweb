# **圣经地点搜索指南**

此工具可帮助您发掘并探索整本圣经中提到的地理地点，从耶路撒冷和伯利恒等著名城市，到在圣经历史中扮演重要角色的不知名村庄和地标。

## **什么是圣经地点搜索？**

圣经地点搜索工具提供对经文中所提及地理地点的全面数据库访问。您可以按名称搜索地点，并探索每个地点的详细信息，包括描述、经纬度坐标以及圣经经文参考。

## **您将找到的内容**

对于每个圣经地点，该工具提供：
- **名称**：该地点在经文中所出现的名称
- **描述**：该地点是什么及其重要意义
- **地理数据**：经纬度坐标、所属区域、现代名称（如适用）
- **圣经重要性**：在该处发生的关键事件
- **圣经参考**：提及该地点的经节
- **地图可视化**：在交互式地图上查看该地点

## **如何使用**

1. **输入地点**：在搜索框中输入地点名称
2. **从建议中选择**：自动完成功能会在您输入时显示匹配的地点
3. **按 Enter 键**：加载该地点的详细信息
4. **查看详情**：阅读该地点的描述与重要意义
5. **在地图上查看**：在交互式地图上查看标记的地点（若有坐标数据）
6. **点击参考**：开启经文以在上下文中阅读与该地点相关的事迹

### **搜索特色**

- **自动完成**：在您输入时实时显示地点建议
- **模糊匹配**：即使有轻微拼写错误也能找到地点
- **相似度搜索**：通过 AI 技术匹配相近的名称
- **多个结果**：如果找到多个匹配项，可从列表中选择
- **历史记录**：按向上箭头键可恢复您上次的搜索
- **地图整合**：直观可视化呈现地点位置

## **搜索方法**

### **精确名称搜索**

输入确切的地点名称：
```
Jerusalem
Bethlehem
Nazareth
Egypt
Jordan
```

### **部分名称搜索**

开始输入并从自动完成中选取：
```
Type: "Jerusa..."
Suggestions: Jerusalem, Salem, Jebus, etc.
```

### **相似度搜索**

如果没有完全匹配的项，AI 会寻找相似的名称：
```
Search: "Golgotha"
Finds: Golgotha, Calvary (same place, different names)

Search: "Red Sea"
Finds: Red Sea, Sea of Reeds (alternate translations)
```

### **替代名称**

许多地点拥有多个名称：
- **耶布斯 / 耶路撒冷**（原名与后来的名称）
- **各各他 / 髑髅地**（亚兰文与拉丁文）
- **加利利海 / 革尼撒勒湖 / 提比哩亚海**
- **巴别 / 巴比伦**（早期与后期的形式）

如果第一次搜索没有找到结果，请尝试替代名称。

- **耶利哥**：迦南地被攻克的第一座城
- **撒玛利亚**：北方王国的首都
- **迦百农**：耶稣在加利利事工的中心
- **伯大尼**：马利亚、马大与拉撒路的家

**其他国家：**
- **巴比伦**：巴比伦帝国的首都，犹太人被掳之地
- **尼尼微**：亚述首都，约拿传道之处
- **吾珥**：美索不达米亚中亚伯拉罕的故乡
- **大马士革**：叙利亚的古老城市
- **大数**：保罗的出生地
- **罗马**：罗马帝国的中心
- **雅典**：保罗在亚略巴古讲道之地
- **哥林多**：希腊主要城市，教会所在地

### **水域水体**

- **红海**：以色列人出埃及跨越的海
- **约旦河**：应许之地的边界，耶稣受洗之地
- **加利利海**：耶稣事工的核心舞台
- **死海**：地球表面最低点，靠近所多玛
- **地中海**：以色列的西部边界
- **尼罗河**：埃及境内，摩西在河水中被发现
- **幼发拉底河**：东部边界，伊甸园的四河之一

### **山脉与丘陵**

- **西奈山（何烈山）**：摩西颁受律法之地
- **亚拉腊山**：挪亚方舟停歇之处
- **摩利亚山**：亚伯拉罕献以撒之地，圣殿遗址
- **迦密山**：以利亚挑战巴力先知之处
- **橄榄山**：耶稣升天与未来重临之地
- **锡安山**：耶路撒冷的诗意称号
- **黑门山**：北部边界，耶稣登山变相之地
- **各各他（髑髅地）**：耶稣被钉十字架之地

### **地区与国家**

- **迦南 / 应许之地**：赐给以色列人的土地
- **加利利**：北部地区，耶稣主要的事工区域
- **犹太**：南部地区，包含耶路撒冷
- **撒玛利亚**：中部地区，混血族群居住地
- **埃及**：以色列人曾为奴之地
- **巴比伦 / 美索不达米亚**：两河流域之地
- **亚述**：征服北国以色列的北方帝国
- **波斯**：准许犹太人回归的帝国
- **马其顿**：希腊北部，保罗看见异象之地
- **小亚细亚**：现代土耳其，启示录七教会所在地

### **旷野地区**

- **西奈旷野**：以色列人漂流四十年的荒野
- **犹太旷野**：施洗约翰传道、耶稣受试探之地

- **巴兰旷野**：以色列人安营扎寨之地

### **谷地**

- **以拉谷**：大卫迎战歌利亚之地
- **耶斯列谷**：诸多重大战役的发生地
