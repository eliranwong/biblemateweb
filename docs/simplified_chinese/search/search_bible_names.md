# **圣经名字搜索指南**

此工具可帮助您探索整本圣经中所载名字的含义、字源起源与重要意义。了解圣经名字对承载它们的人们意味着什么，以及名字如何往往反映了性格、命运或神的旨意。

## **什么是圣经名字搜索？**

圣经名字搜索工具提供对经文中所出现人名、地名及重要术语的全面数据库访问。每个条目都详细阐明了该名字的含义、字源学背景以及圣经神学意义。

## **您将找到的内容**

对于每个圣经名字，该工具提供：
- **名字**：该名字在经文中所出现的形式
- **含义**：该名字在原文中的字面意义
- **字源学**：语言来源（希伯来文、希腊文、亚兰文等）
- **重要性**：该名字在圣经神学中的关键意义
- **圣经语境**：该名字在何处以及如何被使用
- **相关名字**：变体与关联形式
- **圣经参考**：该名字出现的经节

## **如何使用**

1. **输入名字**：在搜索框中输入圣经名字
2. **从建议中选择**：自动完成功能会在您输入时显示匹配的名字
3. **按 Enter 键**：加载该名字的详细信息
4. **查看含义**：阅读该名字的含义及其重要意义
5. **点击参考**：开启经文以在上下文语境中查看该名字
6. **探索相关名字**：发掘关联或相近的名字

### **搜索特色**

- **自动完成**：在您输入时实时显示名字建议
- **模糊匹配**：即使有轻微拼写错误也能找到名字
- **相似度搜索**：通过 AI 技术匹配变体拼写
- **多个结果**：如果找到多个匹配项，可从列表中选择
- **历史记录**：按向上箭头键可恢复您上次的搜索
- **字源信息**：了解原文语言与字根构造

## **理解名字的含义**

### **为何名字至关重要**

在圣经文化中，名字：
- **反映性格**：名字往往描绘内在品格
- **标志命运**：名字可能具有预言性指引
- **纪念历史**：名字铭刻重大历史处境
- **寄托盼望**：父母对儿女的热切期许
- **归荣耀与神**：许多名字融入神圣元素

### **神圣名根（Theophoric Names）**

融入神的名字的名字：
- **El**（神）：但以理（Daniel）、加百列（Gabriel）、米迦勒（Michael）、撒母耳（Samuel）、以色列（Israel）
- **Yah / Jah**（耶和华）：以赛亚（Isaiah）、耶利米（Jeremiah）、以利亚（Elijah）、约西亚（Josiah）
- **Baal**（主——有时指假神）：巴力（Baal）、耶路巴力（Jerubbaal）

### **改名换姓**

神亲自改变名字以赋予全新身份：
- **亚伯兰 → 亚伯拉罕**：“尊贵之父”→“多国之父”
- **撒莱 → 撒拉**：名字的升华，两者皆有“公主”之意
- **雅各 → 以色列**：“抓夺者”→“与神较力者”
- **西门 → 彼得**：“听见”→“磐石”
- **扫罗 → 保罗**：希伯来名字 → 希腊 / 罗马名字

### **复合名字**

由多个词素构成的名字：
- **约雅敬**——“耶和华坚立”
- **尼布甲尼撒**——“尼波神，请护卫我的疆土”
- **麦基洗德**——“仁义之王”

## **高效使用技巧**

1. **结合语境思考**：名字的含义融入其历史故事时最为鲜活
2. **注意原文语言**：希伯来文与希腊文名字在涵义上各有特色
3. **留意命名规律**：家族命名的传统与模式（如撒迦利亚、约翰）
4. **查验不同变体**：同一名字可能以多种形态出现
5. **深入阅读参考**：观察名字如何与性格或重大事件交织
6. **探索字源根基**：原始字根往往揭示更深刻的神学内涵
7. **对比不同译本**：部分译本侧重意译，部分译本侧重音译

## **常见搜索问题**

### **找不到名字**

- **尝试替代拼写**：不同圣经译本之间的音译差异
- **检查变体形式**：尝试缩写或完整名称
- **使用人物搜索**：可能收录于人物数据库中
- **尝试相似度搜索**：AI 会提示相近的匹配项
- **核对译本**：比对您当前所用的圣经版本

### **多重含义争议**

- 某些古老名字在字源学上仍存学术争议
- 不同学者可能提出多种不同诠释
- 条目中通常会列出主要的可能解释
- 结合上下文脉络有助于判断最贴切的含义

### **翻译差异**

- 希伯来名字在中文音译上可能因译本而异
- 希腊文形式与希伯来原文形式常有转化
- 部分译本采意译，部分译本采音译
- 例如：约书亚（希伯来文）对应新约的耶稣（希腊文音译）
