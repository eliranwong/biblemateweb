# **圣经人物搜索指南**

此工具可帮助您发掘并探索整本圣经中提到的人物，从摩西和大卫等著名人物，到丰富了圣经历史的鲜为人知的人物。

## **什么是圣经人物搜索？**

圣经人物搜索工具提供对经文中所提及人物的全面数据库访问。您可以按名字搜索人物，并获取有关他们是谁、其角色以及在圣经中何处出现的详细信息。

## **您将找到的内容**

对于每个圣经人物，该工具提供：
- **名字**：该人物在经文中所出现的名字
- **描述**：他们是谁以及在圣经历史中的角色
- **关键信息**：人物关系、职业、重要意义
- **圣经参考**：提及他们的经节
- **相关人物**：家庭成员与同工同伴

## **如何使用**

1. **输入名字**：在搜索框中输入人物名字
2. **从建议中选择**：自动完成功能会在您输入时显示匹配的名字
3. **按 Enter 键**：加载该人物的详细信息
4. **查看详情**：阅读该人物的描述与经文参考
5. **点击参考**：开启经文以在上下文中阅读该人物的相关事迹

### **搜索特色**

- **自动完成**：在您输入时实时显示建议
- **模糊匹配**：即使有轻微拼写错误也能找到名字
- **相似度搜索**：通过 AI 技术匹配相近的名字
- **多个结果**：如果找到多个匹配项，可从列表中选择
- **历史记录**：按向上箭头键可恢复您上次的搜索

## **搜索方法**

### **精确名字搜索**

输入确切的名字：
```
Moses
David
Mary
Paul
```

### **部分名字搜索**

开始输入并从自动完成中选取：
```
Type: "Abra..."
Suggestions: Abraham, Abram, Abiram, etc.
```

### **相似度搜索**

如果没有完全匹配的项，AI 会寻找相似的名字：
```
Search: "Nabuchodonazar"
Finds: Nebuchadnezzar (similar name, different spelling)

Search: "Jonah"
Finds: Jonah, Jonas (alternate forms)
```

### **替代名字**

许多人物拥有多个名字：
- **扫罗 / 保罗**（同一人，归信前 / 归信后）
- **西门 / 彼得**（耶稣为他取名）
- **亚伯兰 / 亚伯拉罕**（上帝改变他的名字）
- **雅各 / 以色列**（被赐予新名）

如果一个名字找不到，请尝试另一种形式。

## **高效使用技巧**

1. **尝试不同变体**：搜索不同的名字拼写（例如 Elijah/Elias）
2. **善用自动完成**：开始输入并从建议中选取
3. **阅读上下文**：点击经文参考以在故事背景中查看人物
4. **探索相关人物**：查阅家庭成员与同工
5. **比较不同译本**：部分名字在不同圣经版本中有所差异
6. **检查描述内容**：了解鲜为人知的人物
7. **追踪谱系链**：探索家族树与人物关系

## **工作流程示例**

### **人物查经——彼得**

1. 搜索：`Peter`
2. 阅读西门彼得的描述
3. 注意他是渔夫，是安得烈的兄弟
4. 点击经文参考阅读彼得的关键故事：
   - 蒙召（马太福音 4:18-20）
   - 行走在水面上（马太福音 14:22-33）
   - 认耶稣为基督（马太福音 16:13-20）
   - 不认耶稣（马太福音 26:69-75）
   - 重新被建立（约翰福音 21:15-19）
   - 五旬节讲道（使徒行传 2）
5. 使用“人物关系”工具查看彼得的人际关联
6. 在“笔记本”中记录心得洞见

### **家族谱系查经——大卫家系**

1. 搜索：`David`
2. 注意他的父亲：耶西
3. 搜索：`Jesse` → 查看大卫的祖先
4. 搜索：`Solomon` → 大卫的儿子，王统延续
5. 追溯世系直到耶稣
6. 绘制家族谱系图
7. 注意弥赛亚的重要意义

### **圣经女性查经**

1. 搜索：`Sarah` → 第一位族长之妻
2. 搜索：`Deborah` → 士师与女先知
3. 搜索：`Ruth` → 忠贞的摩押女子
4. 搜索：`Esther` → 勇敢的王后
5. 搜索：`Mary` → 耶稣的母亲
6. 搜索：`Mary Magdalene` → 耶稣的跟随者
7. 比较各人的角色与重要意义
8. 注意一贯的主题

### **发挥重大影响的小人物**

1. 搜索：`Ananias`（医治保罗的人）
2. 搜索：`Onesimus`（逃跑的奴隶）
3. 搜索：`Epaphroditus`（忠心的使者）
4. 搜索：`Phoebe`（女执事与资助者）
5. 发现“小人物”如何扮演了至关重要的角色
6. 应用在小事上忠心的功课

## **理解人物描述**

### **名字含义**

许多描述包含名字的含义：
- **亚伯拉罕**：“多国之父”
- **以撒**：“喜笑”
- **摩西**：“拉出来”（从水中拉出）
- **耶稣**：“耶和华拯救”
- **彼得**：“磐石”

### **职业**

人物档案通常会注明他们的工作：
- 渔夫（彼得、安得烈、雅各、约翰）
- 税吏（马太、撒该）
- 织帐棚者（保罗）
- 牧羊人（大卫、摩西等多位）
- 木匠（耶稣、约瑟）

### **人物关系**

描述包含家族联系：
- **父子**：“亚伯拉罕，以撒的父亲”
- **兄弟姐妹**：“摩西，亚伦与米利暗的兄弟”
- **配偶**：“亚伯拉罕与撒拉”
- **后裔**：“大卫，耶稣的先祖”

### **性格特征**

档案突显关键特质：
- **忠心**：亚伯拉罕、约伯
- **勇敢**：大卫、以斯帖
- **智慧**：所罗门、但以理
- **悔改**：大卫与拔示巴犯罪之后

- **马利亚**：新约中至少有 6 位不同的马利亚
