# **高级圣经搜索指南**

本指南介绍应用程序中提供的强大搜索模式与设定。

## **1. 搜索模式**

应用程序支持三种不同的内容搜索模式，以及一个专门用于寻找经文参考的模式。

### **A. 搜索经文参考（导航）**

若要快速导航至特定经文段落，只需输入圣经参考。

**示例：**

John 3:16; Gen 1:1-5; Ps 23:1-6

### **B. 字面搜索（纯文本）**

这是寻找单词或短语完全匹配的默认模式。搜索引擎会寻找您输入的特定字符序列。

**示例：**

In the beginning  
The Lord is my shepherd

### **C. 正则表达式（模式）搜索**

**正则表达式（Regex）** 是定义搜索模式的字符序列。此高级模式可让您在单节经文中寻找复杂模式、单词变化形式或单词组合。

*有关 Regex 语法的详细指南，建议参考外部资源，例如 [regexone.com](https://regexone.com) 或 [regular-expressions.info](https://regular-expressions.info)。*

使用此高级模式可在单节经文中寻找复杂模式、单词变化形式或单词组合。

| 模式 | 说明 | 示例 |
| :---- | :---- | :---- |
| **OR 搜索** | 寻找包含所列任一单词的经文。 | `love|hope|faith` |
| **AND 搜索** | 寻找包含所有指定单词的经文，无论顺序如何。 | `^(?=.\blove\b)(?=.\bhope\b)(?=.\bfaith\b).` |
| **邻近搜索** | 寻找按特定顺序出现的单词，中间可夹带其他单词。 | Naomi.\*?Ruth |

### **D. 语义搜索（含义）**

使用此模式可搜索短语背后的*相似词*、*含义*或*概念*，而非精确的字词。这对于寻找表达相似思想的经文非常有用。

**示例：**

* David fled
* wisdom
* new creation

**关于相似度的说明：** 显示的相似经文最大数量由 **相似经文数量** 设定控制，可在应用程序的偏好设定中进行调整。

## **2. 搜索范围与设定**

这些选项允许您精细控制搜索执行的位置与方式。

### **搜索范围**

| 设定 | 说明 | 默认行为 |
| :---- | :---- | :---- |
| **书卷过滤** | 从下拉列表中选择特定书卷，以限制仅在这些书卷中搜索（例如仅搜索福音书）。 | 包含所有书卷。 |
| **多本圣经** | 从圣经下拉列表中选择一本或多本圣经，以同时跨多个译本进行搜索。 | 若未明确选择圣经，搜索仅针对当前在活动标签页中开启的圣经执行。 |

### **区分大小写切换**

此功能让您可以控制搜索是否区分英文字母的大写与小写。

* **适用范围：** 仅适用于字面搜索与正则表达式（模式）搜索模式。  
* **位置：** 使用专用的复选框切换是否支持区分大小写的匹配。

## **3. 搜索后操作**

### **过滤搜索结果**

搜索完成后，您可以在输入框中输入其他单词以筛选结果列表。这会对已找到的经文进行实时过滤。

### **开启全章**

若要查看经文的完整上下文，请单击搜索结果列表中的经文参考按钮（例如 Jn 3:16）。这将根据您的选择，在主圣经区域或工具区域中开启全章。
