# 安装 Antigravity CLI

Antigravity CLI（`agy`）可在 BibleMate AI Web 中作为基于订阅的 AI 后端（`antigravity`）使用 – 请参阅 [AI 后端](../ai_features/ai_backends.md) 以及 [配置设定指南](../server_setup/configuration.md) 中的 `config.show_antigravity`。

首先启动 Ubuntu 环境（[install_ubuntu.md](install_ubuntu.md)）：

```
ubuntu
```

安装：

```
curl -fsSL https://antigravity.google/cli/install.sh | bash
```

启动并登录：

```
agy
```
