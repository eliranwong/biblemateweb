# **经文串珠指南**

本工具采用 ScrollMapper 数据库为圣经经文提供全面的经文串珠参照，帮助您发掘有关经文段落，并探索贯穿全本圣经的内在连接。

## **什么是经文串珠？**

经文串珠是圣经经节之间在主题、神学或语境脉络上相互关联的桥梁。本工具使用 ScrollMapper 串珠系统，为您所查询的任何经文段落展示所有有关经节，让您得以在更广阔的圣经背景中研读经文。

## **如何使用经文串珠**

### **基本用法**

1. **输入经文参照**：在输入字段中键入圣经经节或段落参照。
2. **按下 Enter**：系统加载并显示所有经文串珠。
3. **浏览结果**：滚动浏览包含完整经文内容的有关经节列表。
4. **筛选结果**：在输入字段中键入字词，即可实时筛选所显示的经节。
5. **点击经文参照**：点击经节标签，可通过多种方式开启经文。

### **输入选项**

输入字段支持：
- **单节经文**：`John 3:16`
- **经文范围**：`Romans 8:1-17`
- **多重参照**：`John 3:16; Romans 5:8; 1 John 4:9`
- **自动完成**：开始键入书卷名称即可获得即时建议提示

## **功能特点**

### **全方位经文串珠展示**

针对您所搜索的每一节经文，本工具均会呈现：
- **原始经文**：您所搜索的经节及其完整经文文本
- **所有关联经文**：所有与您搜索的经节互为串珠参照的经节
- **完整经文文本**：显示完整经文内容，而非仅仅是经文出处编号
- **条理分明的排版**：清晰、优雅且易于阅读的卡片式版面

### **实时动态筛选**

搜索结果加载后，您可以实时进行二次筛选：
1. 直接在输入字段中键入关键字
2. 结果将根据您键入的内容进行实时动态筛选
3. 可通过以下维度筛选：
   - 圣经经文参照（例如键入“John”仅显示约翰著作经节）
   - 经文内容文本（例如键入“爱”仅显示包含“爱”的经节）
4. 实时查看符合条件的条数提示

**示例**：搜索“John 3:16”，接着键入“永生”，即可快速筛选出所有提及永生的串珠经节。

### **多元灵活的开启选项**

每个经节参照标签均提供右键菜单功能：

| 选项 | 功能 |
| :---- | :---- |
| **在圣经区域开启** | 在区域 1（主圣经阅读区域）中开启该段经文 |
| **在此处开启** | 在当前工具区域标签页中开启该段经文 |
| **在下一标签页开启** | 在工具区域的下一个标签页中开启该段经文 |
| **在新标签页开启** | 在工具区域的新空白标签页中开启该段经文 |

### **可移除的经文卡片**

- 每节经文均展示在一张带有可关闭标签（Chip）的卡片中
- 点击任何标签上的 X 按钮即可从当前视图中暂时移除该节经文
- 非常有助于排除干扰，专注于最具关联性的核心经文
- 被移除的经文会在下一次全新搜索时恢复显示

### **交互式元素**

- **可点击的经文引用**：点击任何经节标签即可弹出开启选项菜单
- **悬停视觉效果**：光标悬停时卡片高亮提示，方便辨识
- **搜索历史**：按向上箭头键快速还原上一次搜索内容
- **清空重置**：使用清除按钮一键重置输入字段

## **界面呈现解析**

### **结果卡片**

每处经文串珠均呈现在卡片中，包含：

1. **经节参照标签（Chip）**：
   - 书卷缩写、篇章与经节编号
   - 色彩背景（蓝色／强调色）
   - 书本图标
   - 可移除（X 按钮）
   - 可点击弹出操作菜单

2. **经文正文**：
   - 该节经文的完整文本内容
   - HTML 排版确保优异的可读性
   - 必要时可包含圣经原文标签
   - 清晰的换行排版便于阅读

### **标题标签**

当经文串珠加载时，顶部标题将显示：
- “经文串珠 - [您的经文参照]”
- 清楚提醒您当前正在查阅哪处经文
- 在连续运行多次搜索时尤为实用

### **结果统计计数**

加载完成后，您会看到：
- 找到的经文串珠总条数
- 显示总数的通知提示（例如“找到 25 条结果”）
- 便于直观评估该经文段落的关联广度

## **搜索工作流程**

### **1. 初始搜索**

```
用户输入：Romans 8:28
→ 加载所有与罗马书 8:28 互为串珠的经节
→ 呈现原始经文与所有关联经文全文
→ 显示找到的串珠总条数
```

### **2. 筛选结果**

```
输入："爱"
→ 将显示的经节实时筛选为仅包含“爱”的经文
→ 显示匹配的经节数量
→ 其他不相干经节暂时隐藏
```

### **3. 开启关联经文**

```
点击经节参照标签
→ 弹出包含 4 种开启方式的菜单
→ 选择开启目标位置
→ 经文在指定区域开启
→ 工具区域中的经文串珠列表持续完整保留
```

### **4. 排除无关干扰**

```
点击任何经节标签上的 X
→ 该经节即刻从当前视图中移除
→ 聚焦于剩余的核心经节
→ 移除的经节不影响筛选逻辑
```

## **高效使用技巧**

1. **先广后狭**：先直接搜索经文而不加筛选，综观所有潜在的串珠关联。
2. **策略性筛选**：利用实时关键字筛选，精准定位特定主题的串珠。
3. **多标签并行**：使用“在新标签页开启”并排对照阅读多处串珠经文。
4. **排除干扰项**：点击 X 移除关联度较低的经文，专注于关键段落。
5. **连锁追踪**：进一步搜索串珠经文的串珠，进行层层深入的查考。
6. **多段同查**：一次输入多节经文，观察它们彼此之间如何交织关联。
7. **善用历史键**：随时按向上箭头键快速返回刚才的搜索。
8. **跨工具对照**：与《经文宝库》及“圣经注释”搭配使用，获取最全面的理解。

## **认识经文串珠的内在类型**

本工具涵盖各种类型的经文串珠：

### **1. 直接平行对照**

不同书卷记述同一历史事件：
- 对观福音平行记载
- 列王纪／历代志历史对照
- 圣经中重复出现的篇章（如诗篇中的平行篇）

### **2. 主题性内在关联**

表达相似主题或教导：
- 爱（约翰福音 3:16 → 约翰一书 4:8）
- 信心（罗马书 5:1 → 希伯来书 11:1）
- 盼望（罗马书 8:28 → 罗马书 15:13）

### **3. 预言与应验**

旧约先知宣告 → 新约基督成就：
- 以赛亚书 53 章 → 福音书受难叙事
- 诗篇 22 篇 → 十字架受难记载
- 玛拉基书 3:1 → 施洗约翰的开路先锋职分

### **4. 关键批字词或短语连接**

共享同一核心重要词汇或短语：
- “人子”有关经节
- “神的国”有关段落
- 耶稣“我是（I AM）”的崇高宣告

### **5. 语境解释性经文**

进一步阐释、深化或补充该节背景的经文：
- 历史背景段落
- 律法解释性文本
- 时代环境交代

### **6. 引述与呼应**

新约直接引述或间接呼应旧约：
- 明确注明出处的直接引文
- 字词上的典故呼应
- 主题与意象的深层共鸣

## **疑难解答**

**找不到经文串珠：**
- 检查经文参照格式是否正确
- 尝试使用其他通用的书卷缩写
- 部分冷僻经节本身收录的串珠可能较少
- 确认数据库文件是否完整安装

**结果过多：**
- 使用实时关键字筛选缩小范围
- 点击 X 移除关联度较低的经文
- 键入特定书卷名称聚焦于特定书卷
- 尝试缩小搜索的经文范围

**筛选器未生效：**
- 清空输入框后重新键入关键字
- 检查筛选文本的拼写是否正确
- 请注意：筛选器同时对经文出处与正文内容生效
- 必要时重新按 Enter 加载搜索
