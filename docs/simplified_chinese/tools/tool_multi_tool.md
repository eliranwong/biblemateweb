# 多工具工作区

**多工具工作区**允许您在单个工具区域标签页中同时开启并使用多个研经工具与搜索页面，每个工具均拥有独立的容器与滚动区域。

## 开启方式

- **工具菜单**：打开「**工具**」菜单（`build` 图标）或左侧抽屉，选择「多工具工作区」。
- **快速搜索**：输入 `multitool`。

## 功能特色

- **独立工具面板**：点击 `+ 添加工具` 即可加入任何支持的研经工具或搜索页面（注释、经文宝库、经文串珠、形态学分析、索引、原文字典、圣经词典、经文搜索、笔记本等）。每个面板都有独立的滚动区域、工具切换器与状态。
- **响应式排版与高度切换**：在工作区工具栏切换 `1`、`2`、`3` 或 `4` 栏排版，以及 `1x`、`1.5x`、`2x`、`2.5x` 面板高度。窄屏或竖屏下会自动回退为单栏显示，两项选择均会跨刷新保存（`multitool_cols`、`multitool_height_scale`）。
- **单面板控制项**：
  - **工具切换器**：在不影响其他面板的情况下更换当前面板的工具。
  - **同步开关**：控制该面板是否在圣经区切换书卷、章或节时自动刷新。未开启同步的搜索面板会保留其搜索结果。
  - **刷新**：手动将该面板同步至圣经区当前经文。
  - **移动 / 最大化 / 折叠 / 关闭**：调整面板顺序、将单个面板展开为全宽、折叠内容或关闭面板。
- **预设模板与状态记忆**：
  - **记住上次工作区**：重新开启多工具工作区时自动还原上次的面板与栏数排版（`multitool_last`）。
  - **内置预设**：从 `预设` 菜单一键载入精选组合（*Chapter Study*、*Verse Deep Dive*、*Word & Topic Study*、*Study & Notes*）。
  - **自定义预设**：点击保存图标，将当前排版与面板组合保存为自定义预设（`multitool_custom_presets`）。
- **安全链接跳转**：在面板内点击打开其他工具的链接时，会在新的工具标签页中开启，不会覆盖当前的多工具工作区。
