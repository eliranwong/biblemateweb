# 全书索引指南

**全书索引**提供整卷圣经书卷的参考概览仪表板。

- **书卷选择**：直接选择任一圣经书卷并点击 **前往**（无需选择章或节）。
- **全书译本词汇**：于一般译本默认展开（当圣经窗口显示 `ORB`、`OLB`、`OPB`、`OIB`、`ODB`、`OHGB`、`OHGBi`、`LXX`、`LXX1`、`LXX1i`、`LXX2`、`LXX2i` 等原文／逐字对照版本时自动隐藏）。提供 **隐藏常见虚词** 开关、**全书关键词**、**全书罕见原文字词**，点击标签即可在 **经文搜索** 中针对该书卷搜索。
- **全书词汇与罕见词**：于原文圣经版本默认展开，列出**全书高频原文字词**与**全书罕见词（全本圣经出现 ≤ 3 次）**，点击即可打开原文词典。
- **人物关系图谱**：以交互式力导向图谱呈现整卷书的人物与彼此关系。
- **本书地图**：在同一张交互式地图上标记本书卷出现的所有圣经地点。
- **圣经人物**、**圣经地点** 与 **圣经主题**：整卷书去重后的词条标签（**圣经主题**按 `HIT`、`NAV`、`TCR` 等模块分组显示）。
- **导出研读笔记**：下载整卷书的 Markdown 研读笔记。
- **全书工具**：页面底部快捷按钮可在下一个标签页打开 **圣经时间轴**、**书卷分析**（及常用分析分项）、**全章索引** 与 **笔记**（若已配置）。
