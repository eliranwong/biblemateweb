# **圣经注释指南**

本工具提供全面的圣经注释访问功能，逐节解释并阐明圣经经文。

## **什么是注释工具？**

“圣经注释”工具让您即时查阅针对任何圣经经文段落的学术性与灵修性注释。注释提供历史背景、神学见解、语言学解释与实践应用，帮助您更深入地理解经文。

## **如何使用注释工具**

### **基本用法**

1. **选择注释**：从可用注释的下拉菜单中选择。
2. **输入经文参照**：输入圣经经节或段落参照（例如“John 3:16”或“Romans 8:1-17”）。
3. **按下 Enter**：该段经文的注释将立即加载。
4. **浏览查阅**：滚动浏览注释内容，并可点击其中内嵌的任何经文参照。

### **输入选项**

输入框支持：
- **单节经文**：`John 3:16`
- **经文范围**：`Romans 8:1-17`
- **多重参照**：`John 3:16; Romans 8:1; Psalm 23:1-6`
- **自动完成**：开始键入书卷名称即可获得建议提示

### **导航控制项**

| 控制项 | 功能 |
| :---- | :---- |
| **注释下拉菜单** | 选择要查看的圣经注释 |
| **输入字段** | 输入圣经经文参照（支持自动完成） |
| **历史记录图标**（⏱️） | 点击或按向上箭头键还原上一次搜索 |
| **向上箭头键** | 还原您刚才搜索过的经文参照 |

## **可用注释**

本工具提供多种类型的注释：

### **AI 生成注释**

- **AIC**（AI 注释 - 英文）
- **AICTC**（AI 注释 - 繁体中文）
- **AICSC**（AI 注释 - 简体中文）

这些注释以 Markdown 格式提供逐节 AI 生成的见解，并转换为 HTML 以便阅读。

### **经典注释**

- **CBSC**（Cambridge Bible for Schools and Colleges，剑桥圣经学校与学院注释）
- 资源库中提供的许多其他传统经典注释

### **注释内容特色**

不同的注释可能包含：
- 逐节详细释义
- 历史与文化背景
- 希腊文与希伯来文字词研读
- 涉及相关经文段落的经文串珠参照
- 神学概念解释
- 生活实践应用

## **功能特点**

### **多重参照支持**

输入以分号分隔的多个经文参照，即可同时查看数个段落的注释：
```
Genesis 1:1; John 1:1; Revelation 21:1
```

### **经文范围智能处理**

本工具能智能处理经文范围：
- 对于 AI 注释：加载每个单独经节的注释
- 对于经典注释：从全章注释中提取相关部分

### **可点击的经文串珠参照**

注释内容包含交互式链接：
- **圣经经文引用**：点击可在圣经区域中开启该段经文
- **原文词典链接**：点击可开启字词研究（若有提供）
- **网站链接**：外部参照链接会在新的标签页中开启

### **深色模式支持**

注释色彩会根据深色模式自动调整：
- 文字颜色经过优化以提升易读性
- 表格背景适应您的主题
- 字体颜色适度变更

### **即时搜索历史**

- 按**向上箭头键**或点击**历史记录图标**即可还原上一次搜索
- 快速返回先前的经文段落，无需重新键入
- 非常适合用于对比同一段经文在不同注释中的解释

### **动态切换注释**

随时切换不同注释：
1. 从下拉菜单中选择其他注释
2. 工具会自动加载新的注释内容
3. 您当前输入的经文参照将被完整保留

## **输入方式**

### **直接使用 URL 参数**

通过 URL 直接加载特定的注释与经文段落：
```
?tool=commentary&q=CBSC:::John+3:16
```
格式：`commentary_code:::reference`

### **标准输入**

直接在输入字段中键入或粘贴经文参照：
- 自动聚焦以便立即键入
- 书卷名称自动完成提示
- 清除按钮可快速重置输入内容

## **高效使用技巧**

1. **对比注释**：在不同注释中加载同一经文段落，获取多元视角。
2. **上下文阅读**：使用经文范围（不仅是单节），以理解更广泛的上下文脉络。
3. **追踪经文串珠**：点击内嵌参照以深入探索相关经文。
4. **注重历史背景**：留意文化与历史注解，以建立更佳的理解。
5. **关注圣经原文**：在注释中寻找希腊文与希伯来文字词的详细解释。
6. **快速导航**：善用向上箭头键快速还原上一次搜索。
7. **多经文整合**：输入多重参照，将相关经节放在一起研读。

## **工作流程示例**

### **深度字词研读**

1. 输入：`Ephesians 2:8-9`
2. 阅读注释释义
3. 点击任何原文词典链接进行字词研究
4. 切换至其他注释以获得另一种观点

### **比较研读**

1. 输入：`Matthew 5:3-12; Luke 6:20-23`（平行经文段落）
2. 阅读两份记载的注释
3. 记录异同点
4. 点击经文串珠以获取补充背景信息

### **专题研经**

1. 搜索某个主题的核心经文：`Romans 3:23; Romans 6:23; John 3:16; Ephesians 2:8-9`
2. 阅读每节经文的注释
3. 建立对该主题的全面理解

## **键盘快捷键**

- **Enter**：提交搜索
- **向上箭头键**：还原上一次搜索
- **Escape**：清除输入字段（若使用清除按钮）

## **技术说明**

- 注释本地存储在 `~/biblemate/data/commentaries/`
- AI 注释以 Markdown 生成并转换为 HTML
- 经典注释可能是按章或按节组织
- 注释内容支持包含表格、列表与样式的 HTML 排版
- 所有原文词典与经文参照链接均具备交互功能
