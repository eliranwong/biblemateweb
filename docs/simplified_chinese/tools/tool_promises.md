# **圣经应许指南**

本工具将圣经中神的所有应许整理为主题合辑，让您能够轻松在圣经中找到安慰、盼望与确据。

## **什么是圣经应许？**

“圣经应许”工具是按主题归纳分类的神的应许精选合辑。每个合辑将相关的应许汇集在一起，为您展示神向祂子民作出承诺、保证与誓约的所有有关圣经段落。

## **主要涵盖内容**

本工具收录依主题系统整理的应许合辑，例如：
- **供应与看顾**：神应许供应您一切所需
- **保护与平安**：神时刻看顾保守的应许
- **同在**：神应许与您永远同在
- **引导**：神亲自指引方向的应许
- **力量**：神赐下能力与忍耐力量的应许
- **平安**：内心出人意外平安的应许
- **医治**：身体与心灵得蒙医治复原的应许
- **赦免**：神的怜悯与恩典之应许
- **永生**：关于救恩与天国的应许
- **祷告**：祷告蒙垂听与应允的应许
- 以及更多丰富主题……

## **如何使用圣经应许**

1. **开启工具**：从工具菜单中选择“圣经应许”。
2. **浏览合辑**：滚动浏览各应许分类列表。
3. **展开合辑**：点击任何分类即可查看其收录内容。
4. **查看应许**：每个应许均附带圣经经文引用。
5. **点击引用**：点击任何圣经引用即可阅读完整经文段落。

## **合辑显示方式**

每个应许合辑均包含：

### **合辑标题**

- 清晰的主题标题（例如“关于供应的应许”）
- 图标：📚（auto_stories）
- 可展开／折叠区块

### **应许内容**

在每个合辑内部：
- **圣经经文引用**：指向相关经文段落的链接
- **简要上下文**：部分条目包含辅助说明文字
- **多项应许**：所有相关应许分门别类集中展示
- **条理格式**：清晰易读的呈现方式

## **功能特点**

### **可折叠区块**

- 所有合辑默认为折叠状态，便于快速浏览查阅
- 点击任何合辑标题即可展开查看各项应许
- 支持同时打开多个合辑
- 可折叠当前未使用的区块

### **可点击经文引用**

所有圣经引用均具备交互功能：
- 点击即可在圣经区域中开启该经文段落
- 在完整的上下文脉络中研读应许
- 在不同应许之间轻松穿梭切换
- 保持应许列表持续显示在工具区域中

### **主题式组织**

应许依据以下原则分类：
- **专题分类**：针对特定生活情境
- **神学主题**：核心教义概念（救恩、成圣）
- **处境应用**：适用于特定心灵需要（恐惧、忧虑、哀伤）

### **全面广泛的涵盖**

合辑广泛收录：
- 旧约应许
- 新约应许
- 先知预言性应许
- 个人性应许
- 团体性应许（赐予教会／国家）
- 普世性应许（赐予全人类）

## **如何支取神的应许**

### **1. 理解上下文**

- 点击引用阅读完整经文段落
- 理解该应许起初是对谁作出的
- 考量该应许是否附带任何前提条件
- 阅读上下文经文以掌握完整意涵

### **2. 查验前提条件**

部分应许附带条件：
- “你们若常在我里面……”（以顺服为前提）
- “这称为我名下的子民，若是自卑、祷告……”（以行动为前提）
- “你们若专心寻求我，就必寻见”（以真诚为前提）

### **3. 应用于个人生命**

- 辨明该应许如何切实应用于您当前的景况
- 坚信神的信实属性与慈爱
- 本着对应许的信心踏出步伐
- 为神确凿的保证献上感恩

### **4. 坚定站立于应许之上**

- 熟背关键应许经文
- 在患难试炼中思想神的应许
- 与身处难处的肢体分享应许
- 让应许坚固您的信心

## **理解不同类型的应许**

### **无条件应许**

神全然无条件赐下的保证：
- 神与挪亚立约（不再用洪水毁灭全地）
- 亚伯拉罕之约
- 在基督里立的新约
- 基于神永恒属性所立的应许

### **有条件应许**

需要人以顺服或信心回应：
- “你们若寻求我，就必寻见”
- “你们饶恕人的过犯，天父也必饶恕你们”
- “这称为我名下的子民，若是自卑、祷告……”
- 与顺服紧密相连的祝福

### **普世性应许**

适用于全体人类：
- “叫一切信祂的，不至灭亡，反得永生”
- “凡求告主名的，就必得救”
- 赐予万国万民的福音应许

### **特定性应许**

针对特定个人或群体发出：
- 给以色列民的应许
- 给教会的应许
- 给特定人物的应许（大卫、马利亚等）

### **已然未然（Already/Not Yet）应许**

已经部分应验，正等候最终圆满成就：
- 神的国度（现在已临到，将来完全实现）
- 新造的人与新创造（已经开始，尚未完全）
- 身体复活（基督已复活，信徒等候复活）

## **神学根基**

### **神的信实**

- 神决不能说谎（提多书 1:2）
- 神的应许在基督里都是“是的”，都是“阿们”的（哥林多后书 1:20）
- 神所应许的，祂必能作成（罗马书 4:21）
- 祂的信实存到万代

### **基督是应许的圆满实现**

- 一切应许在耶稣里都找到了“是的”
- 旧约所有应许在基督里得到完全成全
- 新约的恩典应许建基于祂在十架上的救赎大工
- 未来的永恒应许由祂的复活作为确凿担保

### **圣灵作为质押凭据**

- 圣灵是我们得基业的凭据／定金（以弗所书 1:13-14）
- 盖上印记直到得赎的日子
- 保证未来应许的终极实现
- 赐力量给信徒使其坚定信靠应许
