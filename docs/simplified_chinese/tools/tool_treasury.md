# **经文宝库指南**

本工具提供查阅《经文宝库》（Treasury of Scripture Knowledge, TSKe）的功能，这是一部包含海量经文串珠与解释性注解的巨著，深刻揭示圣经各经文段落之间的奇妙关联。

## **什么是经文宝库？**

《经文宝库》是一部权威的工具书，将圣经中的每一节经文与整部圣经的有关段落紧密相连。无论您查阅哪一节经文，《经文宝库》都会提供丰富的经文串珠参照、注解与内在关联，帮助您通过与其他经文文本的相互对照，更深邃地理解经意。

## **如何使用经文宝库工具**

### **基本用法**

1. **输入经文参照**：在输入字段中键入圣经经节或段落参照。
2. **按下 Enter**：经文宝库的串珠参照与注解将立即加载。
3. **浏览内容**：滚动浏览详尽的经文串珠与说明。
4. **点击链接**：点击任何内嵌的圣经引用，即可在圣经区域中开启该经文。
5. **搜索历史**：按向上箭头键或点击历史记录图标，即可还原上一次搜索。

### **输入选项**

输入字段支持：
- **单节经文**：`John 3:16`
- **经文范围**：`Romans 8:1-17`
- **多重参照**：`John 3:16; Romans 8:1; Psalm 23:1`
- **自动完成**：开始键入书卷名称即可获得即时建议

## **内容构成**

针对每一节经文，《经文宝库》通常提供：

### **主题式经文串珠**

依主题或核心信息分类组织的链接：
- 具有相似概念的经文
- 平行对照段落
- 呈现对比的经文
- 阐明解释性的段落

### **逐字逐词参照**

针对经文中的核心关键词或短语提供串珠参照：
- “爱”→ 关于爱的所有其他经文
- “信”→ 关于信心／相信的其他经文
- “永生”→ 关于救恩的有关段落

### **语境脉络参照**

- 平行记载（特别是福音书与列王纪／历代志）
- 先知预言的应验
- 历史背景经文段落
- 贯穿始终的主题性链接

### **解释性注解**

简明精炼的注解：
- 澄清艰涩难懂的短语
- 提供历史时代背景
- 阐述神学核心要义
- 串联圣经其他篇章的教导

## **功能特点**

所有三处段落的经文串珠将一同加载，并由分段标题清晰分隔。

### **可点击的经文串珠**

- 点击即可在圣经区域开启对应经文段落
- 开启全章以查看上下文
- 工具区域持续常驻，便于对照查阅

## **理解经文宝库的词条结构**

### **条目组织形式**

经文宝库的条目通常遵循以下架构：

```
经文参照
  关键词：串珠经文 1, 串珠经文 2, 串珠经文 3
  另一关键词：串珠经文 4, 串珠经文 5
  包含额外串珠经文的解释性注解
```

### **经文串珠类型**

1. **直接平行对照**：不同书卷对同一历史事件的记载
2. **主题性关联**：相似的神学主题或道德教训
3. **预言的应验**：旧约先知预言 → 新约基督成就
4. **字词原文字义研读**：同一希腊文／希伯来文字词在圣经各处的用法
5. **语境解释**：进一步解释或扩展该节经意的段落
6. **对比性参照**：呈现对立面或平衡真理的经文

### **常见缩写**

《经文宝库》可能会使用如下拉丁文或英文缩写：
- **cf.**：比较、参照（源自拉丁文 confer）
- **v.**：经节（verse）
- **ch.**：篇章（chapter）
- **ff.**：以及以下数节经文（following verses）
- **i.e.**：也就是、即（that is）
- **viz.**：即是、也就是（namely）

## **高效使用技巧**

1. **由广入深**：查阅一处核心经节，并全面探索其发散出的所有串珠链接。
2. **顺藤摸瓜**：点击串珠经文，追踪一连串环环相扣的有关经文链。
3. **比对多方记载**：用于福音书合参以及列王纪／历代志的历史对照。
4. **字词研读**：追踪核心词汇如何贯穿整部圣经并展开演绎。
5. **神学主题梳理**：观察核心教义在圣经渐进启示中的发展脉络。
6. **语境构建**：通过整部圣经的相互参照，精准锁定经文真义。
7. **快捷历史**：使用向上箭头键，在不同经文的串珠列表间迅速切换比对。
8. **多段并列**：一次输入多节经文，观察它们彼此之间的交互关系。

## **工作流程示例**

### **专题字词研读——“爱”**

1. 输入：`John 3:16`
2. 找到《经文宝库》中关于“爱”的串珠参照
3. 留意核心经文，如：约翰一书 4:9-10、罗马书 5:8
4. 点击每处引用阅读完整经文段落
5. 输入新的经节以查看它们各自的串珠
6. 建立对圣经中神圣之爱的全面透彻理解

### **福音书合参对照**

1. 输入：`Matthew 14:22-33`（耶稣在水面上行走）
2. 《经文宝库》呈现马可福音 6:45-52 与约翰福音 6:16-21 的平行记载
3. 点击每处平行经文阅读详细记载
4. 比对每卷福音书所特有的细节
5. 体会各记载如何彼此相辅相成

### **预言与应验**

1. 输入：`Isaiah 53:5`
2. 《经文宝库》展示新约中的应验经文
3. 找到彼得前书 2:24、马太福音 8:17 等经节引用
4. 点击以查看预言如何在基督身上精确应验
5. 追踪该救赎主题在整部圣经中的贯穿痕迹

### **教义研经——称义**

1. 输入：`Romans 3:24`
2. 寻找关于“称义”的串珠参照
3. 留意紧密相连的经文：罗马书 5:1、加拉太书 2:16、提多书 3:7
4. 点击各经节研读完整的教导脉络
5. 对每处经节再次查阅《经文宝库》以获取更多关联
6. 建立系统性的称义教义体系

## **高级研经技巧**

### **连锁经文链研读法**

1. 从一处关键核心经节出发
2. 找到其最主要的一处串珠经文
3. 在《经文宝库》中查阅该串珠经文
4. 继续追踪该经节的串珠
5. 顺着经文链持续探讨
6. 带着整体的丰富看见回照起初的经节

### **平行对照研读法**

1. 输入历史叙事经文（例如：列王纪中的段落）
2. 找到历代志中的平行记载
3. 并排对照开启两处记载

### **专题脉络追踪法**

1. 选定神圣主题（例如：“立约”）
2. 查阅该主题的代表性经节
3. 顺着串珠参照探索所有立约有关经文
4. 追踪约在圣经救赎历史中的步步深化
5. 形成一份详尽的专题查经报告

### **教义多角度平衡对照**

1. 输入阐述某项教义的经文
2. 寻找支持与印证的经文
3. 同时留意补充平衡或划定界限的经文

## **局限性与注意事项**

### **非绝对穷尽**

- 任何工具书都无法穷尽神话语中所有潜在的关联
- 您个人的深入研读可能会发现更多奇妙的亮光
- 将《经文宝库》作为研经的引导起点，而非封闭的终点

### **历史时代背景**

- 《经文宝库》是一部历经时代沉淀的历史巨著（最初成书于 19 世纪）
- 部分神学分类与注释带有其时代特色
- 建议与现代圣经工具及学术注释互为印证

### **不可替代亲自研读**

- 经文串珠无法取代对篇章本身的细致通读
- 仍须亲自深入每处串珠经文的上下文语境
- 圣灵的亲自引导与光照始终是第一要务
