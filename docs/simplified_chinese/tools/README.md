# 研经工具

工具可从“**工具**”菜单（`build` 图标）、经文／章／书卷[弹出菜单](../integrations/README.md)开启于**工具区域**，或通过[快速搜索](../basics/quick_search.md)（`tool:::query`）开启。

| 工具 | 快速搜索关键字 | 指南 |
|---|---|---|
| 圣经广播 | `podcast` | [圣经广播](tool_podcast.md) |
| 圣经语音 | `audio` | [圣经语音](tool_audio.md) |
| 书卷分析 | `analysis` | [书卷分析](tool_analysis.md) |
| 全章摘要 | `summary` | [全章摘要](tool_summary.md) |
| 圣经注释 | `commentary` | [圣经注释](tool_commentary.md) |
| 经文串珠 | `xrefs` | [经文串珠](tool_xrefs.md) |
| 经文宝库 | `treasury` | [经文宝库](tool_treasury.md) |
| 圣经应许（合辑） | `promises_` | [圣经应许](tool_promises.md) |
| 平行经文（合辑） | `parallels_` | [平行经文](tool_parallels.md) |
| 圣经时间轴 | `timelines` | [圣经时间轴](tool_timelines.md) |

| 圣经笔记（Google 云端硬盘） | `notes` | [圣经笔记](tool_notes.md) |

| 对话模式 / 伙伴模式 / 代理模式 | `chat`, `partner`, `agent` | [AI 功能](../ai_features/README.md) |

搜索页面列于[搜索指南](../search/README.md)。

大多数工具均可开启于您正在阅读的经文（[同步](../layout/sync.md)）；输入框通常支持按 **Enter** 运行，以及按**向上箭头键**还原上一个查询（[键盘快捷键](../basics/keyboard_shortcuts.md)）。
