# 整章译本对照

**整章译本对照**工具以多栏表格并排显示多个圣经译本的同一章经文，方便整章阅读与比较。

## 开启方式

- **全章工具菜单**：在章标题点击右键（或打开三点菜单 → `全章工具`），选择 `👀 整章译本对照`。
- **快速搜索**：输入 `comparechapter`（或 `comparechapter:::KJV,NET,CUV` 指定译本）。

## 功能特色

- **章节导航**：通过书卷／章节选单与 `Go` 按钮跳转章节，或使用底部的 `◀️ 上一章`／`下一章 ▶️` 按钮切换。
- **多译本选择**：使用标签多选下拉选单随时添加或移除译本。从特定译本打开时，该译本会排在第一栏，其余按[整章对照版本偏好设置](../user_preferences/chapter_comparison.md)排列。
- **逐节对照切换**：
  - **关闭（默认）**：以单行多栏显示整章，优先读取 `Bible` 数据表（若无 `Bible` 数据表则自动改读 `Verses` 数据表）。
  - **开启**：按各译本 `Verses` 数据表的经节并集逐节分行显示；若某译本缺少该节，该格留空但仍显示其他译本。
  - 切换状态会自动保存于 `compare_chapter_verse_by_verse`。
- **显示差异切换** *（逐节对照开启时显示）*：以第一栏为基准，标示其他译本的用词差异（保存于 `compare_chapter_diff`）。
- **双向高亮与互动链接**：支持跨栏原文／译本单词双向高亮（`hl1`/`hl0`）、单词提示、Strong's 原文字典链接、脚注与荧光标记。
- **导出 DOCX**：点击 `📥 DOCX` 可将当前的整章对照表格导出为 Word（`.docx`）文档。
