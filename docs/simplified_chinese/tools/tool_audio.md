# **圣经语音播放器指南**

本工具提供按节播放的圣经语音功能，让您在聆听经文朗读的同时，同步对照经文文字显示。

## **什么是语音播放器？**

语音播放器让您在阅读经文的同时，聆听专业朗读的圣经章节。每节经文均可单独控制播放，非常适合灵修默想、经文背诵或辅助无障碍阅读需求。

## **如何使用语音播放器**

### **基本播放操作**

1. **选择经文**：使用顶部的圣经选单选择您要的书卷、章和起始节。
2. **点击“开启”**：加载该章的语音内容。
3. **播放单节**：点击任何经文旁的语音图标（🔊）即可开始播放。
4. **自动接续**：当前节播放完毕时，播放器会自动前进至下一节。

### **导航方式**

- **书卷下拉菜单**：从圣经全部 66 卷书中选择。
- **篇章下拉菜单**：选择所选书卷内的任一篇章。
- **经节下拉菜单**：指定具体的起始经节。
- **“开启”按钮**：应用您的选择并加载语音。

## **播放器控制**

| 控制项 | 功能 |
| :---- | :---- |
| **音量图标** | 点击任何单节旁的图标即可开始／停止该节播放 |
| **语音播放器** | 标准 HTML5 音频控制项（播放、暂停、快进／倒退、音量） |
| **循环开关** | 开启后，章节播毕时会自动从头重新播放 |

## **功能特点**

### **逐节精确控制**

- 点击任何经节即可直接跳转至该节播放。
- 当前播放的经节会以扬声器图标（🔊）高亮显示。
- 未播放的经节则显示静音图标（🔇）。

### **自动推进播放**

当前经节播放结束后，播放器会自动前进至下一节，为整章带来流畅连贯的聆听体验。

### **循环模式**

开启“Loop”（循环）开关可实现：
- 当该章结束时，自动从第 1 节重新开始播放。
- 非常适合用于背诵特定经文段落或进行深度的章节默想。

### **自动加载下一章**

当停用循环模式且整章播放结束时，播放器可自动加载下一章（此功能取决于设定）。

### **多版本支持**

语音播放器支持多种圣经版本与原文圣经：
- **英文译本**：NET、KJV 及其他可用的语音圣经。
- **圣经原文**：旧约希伯来文（BHS5）、新约希腊文（OGNT）。
- **自定义语音**：若您添加了自定义音频文件，它们会出现在版本选单中。

## **原文特色功能**

播放希伯来文或希腊文语音时：
- **希伯来文文本**：由右至左正确排版显示。
- **提示工具说明**：将光标悬停在希伯来文或希腊文字词上，即可查看词汇字典信息。
- **音译对照**：查看字词的发音音译。

## **高效使用技巧**

1. **经文背诵**：使用循环模式并对照文字跟读，有助于背诵经文。
2. **灵修默想**：重复播放单节经文，深度默想其意涵。
3. **无障碍辅助**：为视力障碍者或偏好听觉学习的用户开启语音。
4. **多任务聆听**：在处理其他事务时聆听——自动推进功能让诵读持续不中断。
5. **语言学习**：利用原文语音练习并提升希伯来文或希腊文发音。
6. **从章中段开始**：若您只需要第 15–20 节，加载前可直接将起始节设为 15。

## **键盘快捷键**

标准 HTML5 音频播放器支持常见键盘控制：
- **空格键**：播放／暂停（当焦点在音频播放器上时）
- **方向键**：快进／倒退
- **音量键**：调整音量

## **技术说明**

- 音频文件必须存放在您的数据目录中（`~/biblemate/data/audio/bibles/`）。
- 支持的音频格式：MP3。
- 每节经文均有独立的音频文件，以实现精确控制。
- 无需互联网连接——所有音频均在本地播放。
