# **参考书籍指南**

“参考书籍”工具是 BibleMate AI Web 内专门用于阅读参考书籍文件（`.book` 文件）的阅读器，显示在圣经旁的工具面板中。

## **开启工具**

- 桌面版：打开工具菜单并选择**参考书籍**。
- 移动版／窄屏幕：打开左侧抽屉菜单并选择**参考书籍**。

本工具不受限于当前的圣经篇章，因此更改圣经经文段落不会改变您正在阅读的书籍。

## **阅读书籍**

1. 从**书籍**菜单中选择一本书。
2. 从**章节**菜单中选择章节，或使用上一章／下一章按钮。
3. 章节内容将显示在下方的阅读器中。当您切换章节时，视图会自动滚动回顶部。

深色模式与字体大小偏好设定均会应用于书籍内容。若该书籍没有章节列表，则会自动隐藏章节菜单与导航按钮。

### **交互式链接**

书籍内容中的链接运作方式与应用程序其他部分相同。圣经引用会在圣经区域中开启；指向其他资源的链接（例如原文词典、圣经字典、圣经应许与平行经文）亦会在应用程序中开启。网站链接则会在新的浏览器标签页中开启。书籍内容中的脚本与不安全的内联事件处理程序均已被移除。

## **添加您自己的书籍**

每次开启工具时，系统都会通过扫描文件夹来探索书籍。您可以添加或删除书籍而**无需重启服务器**。

| 文件夹 | 显示对象 |
| :---- | :---- |
| `~/biblemate/data/books` | 所有用户 |
| `~/biblemate/data_custom/books` | 仅限拥有有效[自定义凭证](../user_preferences/custom_token.md)的用户 |

- 仅列出扩展名为 `.book` 的文件。隐藏文件（以 `.` 开头）会被忽略。
- 菜单中显示的书名为去除 `.book` 后的文件名。
- 若自定义书籍与标准书籍同名，对于拥有访问权限的用户，自定义书籍将替换标准书籍。
- 文件夹若不存在将会自动创建。
- 每个文件均为 SQLite 数据库，包含一个 `Reference` 数据表。`Chapter` 字段保存章节标题，`Content` 字段按行顺序保存每章的 HTML 内容。此格式与 [UniqueBible](https://github.com/eliranwong/UniqueBible) 参考书籍所使用的格式相同。

若找不到任何书籍，工具会显示“找不到书籍”。

## **API**

书籍名称亦会在 API 资源列表的 `referenceBookList` 项中返回。

## **界面语言**

本工具已翻译为繁体中文与简体中文（“參考書籍”/“参考书籍”）。
