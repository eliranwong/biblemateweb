# 一年读经计划

内置 365 天读经计划（每日包含旧约、新约与诗篇／箴言），并按界面语言（英文、繁体中文、简体中文）自动显示对应的圣经书卷名称与经节引用。

- **打开方式**：`工具` → `一年读经计划`（或在快速搜索输入 `Reading:::<天数>`）
- **导航**：默认显示今日对应天数（`1–365`），提供 **前一天**、**后一天**、**今天**、**下一个未读** 与 **365 天总览** 网格。
- **阅读方式**：
  - 点击任一段落旁的 **阅读** 按钮，即可在圣经区域打开该段经文。
  - 点击 **在经文搜索中阅读全部**，可在下一个标签页一次加载本日所有经文。
- **进度跟踪**：勾选 **标记本日已完成** 即可保存进度（`reading_plan_completed`），查看完成百分比与**连续天数**，或点击 **重置进度** 重新开始。
