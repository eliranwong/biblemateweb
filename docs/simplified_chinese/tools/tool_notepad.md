# **笔记本指南**

本工具提供本地笔记本，供您以 Markdown 格式撰写个人研经笔记，并支持预览排版效果与下载保存笔记。

## **什么是笔记本？**

“笔记本”是一个本地笔记记录工具，允许您使用 Markdown 语法撰写研经笔记。您的笔记会保存在浏览器的本地存储空间中，并可随时下载为文件。非常适合用于随手记录心得、整理研经大纲，或将个人灵修感悟保存在本机设备上。

## **如何使用笔记本**

1. **开启笔记本**：从工具菜单中选择“笔记本”。
2. **开始键入**：笔记本开启时默认为“编辑模式”，即可立即开始键入。
3. **使用 Markdown 排版**：运用 Markdown 语法为笔记进行格式化排版。
4. **切换至阅读模式**：点击“阅读模式”即可查看渲染后的排版预览。
5. **保存或下载**：使用工具栏按钮管理您的笔记。

## **工具栏功能**

笔记本包含一个具备多项实用功能的工具栏：

| 按钮 | 图标 | 功能 |
| :---- | :---- | :---- |
| **阅读模式 / 编辑模式** | 👁️ / ✏️ | 在纯文本编辑与排版预览之间切换 |
| **下载** | ⬇️ | 将笔记下载为 `.md` 文件 |
| **导入** | ⬆️ | 上传并导入 `.md` 或 `.txt` 文件 |
| **清除** | 🗑️ | 删除所有内容（具备确认对话框） |

## **编辑模式**

在“编辑模式”下，您可以：
- 在文本区域中自由输入
- 使用 Markdown 语法排版
- 编辑既有内容
- 从其他来源复制并粘贴文本

文本区域具备：
- 全高度设计以提供最大书写空间
- 开启工具时自动聚焦输入框
- 自动保存在浏览器本地空间

## **阅读模式**

在“阅读模式”下，您的 Markdown 文本将渲染为格式精美的 HTML：
- 标题转为各级样式标题
- 列表正确排版
- 链接均可直接点击
- 表格优雅清晰展示
- 圣经经文引用自动转为可点击链接

**提示**：在下载或复制笔记之前，先切换至“阅读模式”以查看最终排版效果。

## **Markdown 语法格式**

笔记本支持标准 Markdown 语法：

### **标题**

```markdown
# 标题 1
## 标题 2
### 标题 3
```

### **强调**

```markdown
*斜体文本*
**粗体文本**
***粗斜体文本***
```

### **列表**

```markdown
- 项目符号 1
- 项目符号 2
  - 嵌套项目

1. 编号项目 1
2. 编号项目 2
```

### **链接**

```markdown
[链接文本](https://example.com)
```

### **表格**

```markdown
| 列 1 | 列 2 |
| ---- | ---- |
| 数据 1 | 数据 2 |
```

### **代码块**

```markdown
```
代码块
```
```

### **圣经经文引用**

只需直接输入圣经经文引用，在阅读模式下即可自动转为可点击链接：
```
John 3:16
Genesis 1:1-3
Romans 8:28-39
```

## **功能特点**

### **本地存储**

- 笔记自动保存在您的浏览器中
- 无需互联网连接
- 笔记在不同会话间持久保留
- 仅保存在您的本机设备上

### **下载与导入**

**下载**：
- 将笔记保存为 `biblemate_notes.md`
- Markdown 格式完整保留所有排版格式
- 可在任何文本编辑器或 Markdown 查看器中打开

**导入**：
- 上传 `.md` 或 `.txt` 文件
- 可导入先前下载的笔记
- 覆盖当前内容（请谨慎操作！）

### **清除功能**

- 确认对话框防止误删
- 完全清除所有内容
- 此操作无法撤销

### **圣经经文解析**

笔记本能自动识别并格式化圣经经文参照：
- 经文参照在阅读模式下变为可点击状态
- 点击经文参照可在圣经区域中开启该段经文
- 支持标准参照格式（书卷 章:节）

### **扩展 Markdown 支持**

笔记本包含增强型 Markdown 功能：
- **表格**：完整的表格支持与对齐功能
- **围栏代码块**：语法高亮显示的代码块
- **目录**：自动生成目录（TOC）
- **紧凑列表**：项目之间无空白行的紧凑列表

## **高效使用技巧**

1. **大纲架构**：使用各级标题组织讲道大纲或研经笔记。
2. **快速速记**：阅读时保持笔记本开启，随时记下心得灵感。
3. **灵修日志**：按节记录研经见解。
4. **教导预备**：起草教学材料或小组讨论题目。
5. **经文链接**：键入圣经引用，自动建立快速导航链接。
6. **定期下载**：定期下载重要笔记作为本地备份。
7. **时常切换**：在编辑与阅读模式之间频繁切换以检查排版。

## **工作流程示例**

### **讲道笔记速记**

1. 在讲道经文旁开启笔记本
2. 使用标题标记核心要点：
   ```markdown
   # 罗马书 8 章讲道笔记
   ## 要点一：在圣灵里的生活
   - 核心经文：Romans 8:1
   - 生活应用：...
   ```
3. 切换至阅读模式检阅排版完成的笔记
4. 下载留存备查

### **个人研经**

1. 建立研经架构：
   ```markdown
   # 诗篇 23 篇研经
   ## 经文观察
   - 耶和华是我的牧者
   - 我必不致缺乏

   ## 问题思考
   - 在此语境中“牧者”代表什么意义？

   ## 实践应用
   - 信靠神的丰富供应
   ```
2. 点击圣经经文引用核对经节
3. 下载完成的研经文件

### **代祷清单**

1. 组织代祷事项：
   ```markdown
   # 代祷清单 - 2024 年 1 月
   ## 家庭
   - [ ] 母亲身体健康
   - [ ] 弟弟求职顺利

   ## 教会
   - [ ] 青少年事工成长
   ```
2. 在祷告蒙应允时勾选完成项目
3. 数算并记录神的信实作为

## **笔记本 vs 圣经笔记工具**

| 笔记本 | 圣经笔记（云端） |
| :---- | :---- |
| 仅限本地存储 | 同步至 Google 云端硬盘 |
| 单一笔记本 | 针对特定经节的独立笔记 |
| 通用型笔记 | 按圣经经文结构组织 |
| 无需登录 | 需登录 Google 账号 |
| 手动下载／导入文件 | 跨设备自动同步 |
| 最适合：速记、草稿、大纲 | 最适合：逐节深入研经 |

## **数据隐私**

- 笔记仅存储在浏览器的本地存储空间中
- 不会发送任何数据至服务器
- 笔记不会自动进行云端备份
- 您需自行负责下载重要笔记作为备份
- 清除浏览器缓存与数据将会删除您的笔记

## **键盘快捷键**

文本区域支持大多数标准键盘快捷键：
- **Ctrl/Cmd + A**：全选
- **Ctrl/Cmd + C**：复制
- **Ctrl/Cmd + V**：粘贴
- **Ctrl/Cmd + Z**：撤销
- **Ctrl/Cmd + Y**：重做

## **疑难解答**

**笔记丢失：**
- 检查是否不小心点击了“清除”按钮
- 浏览器缓存数据可能已被清理
- 解决方案：务必随时下载重要笔记备份

**导入失败：**
- 确认文件为 `.md` 或 `.txt` 格式
- 检查文件是否损坏
- 尝试改为手动复制粘贴文本内容

**排版未生效：**
- 请确认您已切换至“阅读模式”
- 检查 Markdown 语法是否正确
- 下载前先预览排版效果
