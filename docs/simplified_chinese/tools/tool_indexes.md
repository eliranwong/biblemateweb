# **单节索引指南**

本工具显示特定圣经经节的综合参考信息，包括与该精确经节相关的人物、地点、主题、应许与平行经文。

## **什么是单节索引？**

单节索引为个别圣经经节提供详尽的参考信息。与展示整章信息的全章索引不同，本工具聚焦于单一经节，展示该节中具体提及或与之相关的所有重要人物、地点、主题、字典词条以及相关资源合辑。

## **如何使用单节索引**

1. **选择经节**：使用圣经选单选择具体的书卷、篇章与经节。
2. **点击“开启”**：加载该经节的索引。
3. **浏览分类**：展开任何分类即可查看与该经节相关的所有项目。
4. **点击参照**：点击任何项目即可深入探索详细内容。

## **索引分类**

本工具将信息组织为七个不同分类：

### **1. 圣经人物**

**图标**：👥 群组（Groups）

列出该节提及或与之相关的所有重要人物：
- 个人或群体的名称
- 简要身份信息
- 相关圣经经文引用
- 指向完整人物资料的链接

**示例**：在约翰福音 3:16 中，您可能会看到有关神、耶稣与世人的条目。

### **2. 圣经地点**

**图标**：📍 地点（Place）

显示该节所参照的所有地理位置：
- 地点名称（城市、地区、地标）
- 简要地理背景
- 该地点出现的有关经文
- 指向附带地图的详细地点信息链接

**示例**：在马太福音 2:1 中，您会看到伯利恒及其地理细节。

### **3. 圣经主题**

**图标**：🏷️ 分类（Category）

标记该节所呈现的神学、道德与主题要点：
- 神学概念（信心、救恩、恩典）
- 道德主题（爱、顺服、罪）
- 文化主题（律法、节期、习俗）
- 指向延伸主题探讨的链接

**示例**：在罗马书 3:23 中，主题包括“罪”、“人类普遍处境”与“人的堕落”。

**注意**：“圣经主题”区块默认为开启状态，便于快速查阅。

### **4. 圣经字典**

**图标**：📚 字典（Dictionary）

为该节使用的核心词汇提供字典定义：
- 字词定义
- 神学解释
- 历史背景
- 圣经语境中的用法

### **5. 百科全书**

**图标**：💎 深度知识（Deep Knowledge）

链接至全面的百科全书文章，内容涵盖：
- 该节中的人物、地点与事件
- 详细的历史与神学背景
- 与相关圣经资料的经文串珠参照
- 学术见解与考古发现

### **6. 圣经应许**

**图标**：🎁 礼物（Gift）

显示与该节相关的神的应许合辑：
- 按主题分类组织（例如“供应的应许”、“同在的应许”）
- 每个应许合辑均有可点击的标签（Chips）
- 每个标签显示主题名称
- 点击标签即可加载包含所有相关经文的完整应许合辑

**示例**：在腓立比书 4:19 中，您可能会看到“关于供应的应许”或“关于神充足供给的应许”标签。

### **7. 平行经文**

**图标**：🔗 链接（Link）

显示福音书平行经文与相关经文段落：
- 其他福音书中的平行记载（针对福音书经文）
- 不同书卷中的类似事件
- 具有相似主题或内容的有关叙事
- 对照合参经文

**示例**：在马太福音 14:22-33（耶稣在水面上行走），您会看到马可福音 6:45-52 与约翰福音 6:16-21 中的平行记载。

## **功能特点**

### **可折叠区块**

- 每个分类均可独立展开或折叠
- “圣经主题”区块默认自动开启
- 空分类会显示“找不到此类别的条目”
- 点击分类标题即可展开／折叠内容

### **交互式链接**

- **人物链接**：点击可在新标签页中开启详细的人物档案资料
- **地点链接**：点击可探索地理信息、地图与历史背景
- **主题链接**：点击可查看全面的主题探讨
- **参照标签**：点击应许或平行经文标签即可查看完整合辑

### **智能数据显示**

- 适当情况下以表格形式呈现内容
- 相关经文分组归类
- 每个分类中的多个条目均有清晰分隔
- 不隐藏任何数据——即使某分类为空，也会清楚显示提示信息

## **单节索引与全章索引的差异**

| 单节索引 | 全章索引 |
| :---- | :---- |
| 仅显示单一特定经节的条目 | 显示整章的所有条目 |
| 精准、聚焦的信息 | 汇总、宏观的视图 |
| 最适合逐节研经 | 最适合章节概览 |
| 必须指定特定经节 | 仅需选择章节 |
| 体积较小、更具针对性的结果集 | 体积较大、更全面的结果集 |

## **高效使用技巧**

1. **单节精读**：对单一经节进行深度分析时使用。
2. **经文串珠研究**：探索经节中提及的人物与地点，进行更深入的研究。
3. **专题研经**：寻找与特定主题或核心信息相关的所有经文。
4. **历史背景**：利用地点与百科全书区块了解经文的历史情境。
5. **领受应许**：辨明哪些圣经应许适用于特定经节。
6. **平行对照**：研究同一事件在不同记载中如何被描述。
7. **讲道预备**：为讲道彻底研究具体的经文。

## **工作流程示例**

### **深度单节分析——约翰福音 3:16**

1. 加载约翰福音 3:16 的单节索引
2. 打开“圣经主题”查看：“爱”、“救恩”、“永生”、“信心”
3. 点击“救恩”主题以深入探讨其神学深度
4. 查看“圣经应许”寻找有关永生的相关应许
5. 利用百科全书条目获取详细的神学背景

### **平行经文研读——马太福音 5:3**

1. 加载马太福音 5:3 的单节索引
2. 查看“平行经文”找到路加福音 6:20（平行经文）
3. 点击平行经文标签加载并对照两处记载
4. 留意措辞与语境上的差异
5. 利用主题区块识别共通的主题

### **历史背景——但以理书 1:1**

1. 加载但以理书 1:1 的单节索引
2. 打开“圣经地点”查看耶路撒冷与巴比伦
3. 点击地点链接查看地图与地理背景
4. 查看“百科全书”了解巴比伦征服的历史背景
5. 检阅“圣经人物”获取尼布甲尼撒的有关信息

## **从结果中导航**

- **点击圣经经文引用**：在圣经区域中开启该经文段落
- **点击人物／地点名称**：在工具区域中开启详细信息
- **点击字典／百科全书链接**：开启详尽的文章
- **点击应许／平行经文标签**：加载完整合辑以供研读
- **点击主题链接**：开启专题探讨与相关经文
