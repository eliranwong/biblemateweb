# **云端圣经笔记指南**

本工具提供按经节组织的笔记记录功能，并自动同步至您的 Google 云端硬盘，让您能在所有设备上维护井然有序的研经笔记。

## **什么是云端圣经笔记？**

“云端圣经笔记”是一套功能强大的笔记系统，让您可以针对特定圣经经节、篇章或整卷书创建并同步笔记。所有笔记均会自动保存至您的 Google 云端硬盘账号，确保您的研经笔记获得安全备份，并可随时从任何设备访问。

## **开始使用**

### **登录要求**

若要使用云端圣经笔记，您必须：
1. 点击“使用 Google 登录”
2. 授权 BibleMate AI 访问您的 Google 云端硬盘
3. 授予在 App Data 文件夹中存储文件的权限

**隐私声明**：BibleMate AI 仅将笔记存储在您自己的 Google 云端硬盘中。本应用程序不会在其服务器上收集、存储或分享您的个人笔记。

### **首次设置**

1. 开启圣经笔记工具
2. 点击“使用 Google 登录”
3. 完成 Google OAuth 授权流程
4. 等待工具初始化您的笔记索引
5. 开始撰写研经笔记！

## **如何使用云端圣经笔记**

### **创建与编辑笔记**

1. **选择经节**：使用圣经选单选择书卷、篇章与经节。
2. **输入笔记**：在文本区域中使用 Markdown 语法撰写笔记。
3. **保存笔记**：点击菜单按钮（⋮）并选择“保存”以同步至云端。
4. **切换经节**：选取不同经节即可创建多篇笔记。

### **特殊笔记类型**

- **单节笔记**：选取特定经节（例如：约翰福音 3:16）
- **全章笔记**：将经节设为“0”，即可为整篇章创建笔记
- **全书笔记**：将篇章设为“0”，即可为整卷书创建笔记

### **圣经选单特殊选项**

圣经选单包含特殊的零选项：
- **篇章 0**：创建书卷层级的笔记
- **经节 0**：创建篇章层级的笔记（当篇章大于 0 时）

## **功能特点**

### **自动云端同步**

- 笔记保存在您的 Google 云端硬盘 App Data 文件夹中
- 在所有已登录的设备间自动同步
- 自动云端备份——永不丢失笔记
- 安全存放在您自己的 Google 账号中

### **Markdown 语法排版**

以 Markdown 格式撰写笔记，并在阅读模式下查看精美排版：

```markdown
# 约翰福音 3:16 研经笔记

## 核心观察
- 神的**爱**是普世性的
- 信靠带来永恒的生命

## 经文串珠
- 罗马书 5:8
- 约翰一书 4:9-10

## 生活实践
今日就要坚定信靠神的慈爱。
```

### **可点击的圣经经文引用**

在笔记中输入圣经引用，在阅读模式下自动变为可点击链接：
- `John 3:16` → 点击即可在圣经区域中开启
- `Genesis 1:1-3` → 自动解析并建立链接
- 同时支持多个经文引用！

### **按经节组织的存储结构**

每篇笔记均以其经节标识符唯一标记：
- **格式**：`BookNumber_ChapterNumber_VerseNumber`
- **示例**：`43_3_16` = 约翰福音 3:16
- **全章笔记**：`43_3_0` = 约翰福音第 3 章
- **全书笔记**：`43_0_0` = 约翰福音全书

### **搜索索引**

本工具维护着所有笔记的搜索索引：
- 追踪哪些经节包含笔记
- 实现快速查询
- 可下载作为备份
- 需要时可随时自动重建

### **导入与导出**

**导出选项**：
- **单篇笔记**：将当前笔记下载为 `.json`
- **所有笔记**：将全部笔记连同索引打包下载为 `.zip`

**导入选项**：
- **单篇笔记**：上传 `.json` 文件
- **批量导入**：上传包含多篇笔记的 `.zip` 文件

## **高效使用技巧**

1. **经常保存**：进行重要修改后，请点击“保存”。
2. **善用 Markdown**：使用标题、列表与粗体强调排版笔记，结构更清晰。
3. **章节总结**：创建篇章层级笔记（经节设为 0）用于书写摘要。
4. **书卷导论**：创建书卷层级笔记（篇章设为 0）用于记录背景导论。
5. **串珠参照**：在笔记中加入相关经节，以便快速导航查阅。
6. **定期备份**：定期下载所有笔记压缩包作为保险备份。
7. **重建索引**：若笔记似乎未显示，请重建索引以重新扫描云端硬盘。
8. **公共电脑务必退出**：在公用设备上使用后请记得退出登录。

## **工作流程示例**

### **逐节精读研经**

1. 选择约翰福音 3:1
2. 记录关于尼哥底母的观察
3. 点击“保存”
4. 选择约翰福音 3:2
5. 依序逐节完成整章的笔记

### **篇章摘要记录**

1. 读完约翰福音 3 章
2. 选择约翰福音第 3 章，经节设为 0
3. 撰写篇章概览：
   ```markdown
   # 约翰福音 3 章 - 重生
   ## 主题：重生得救
   - 与尼哥底母的对话（1-21 节）
   - 施洗约翰的见证（22-36 节）
   ```
4. 保存全章笔记

### **跨经文专题研读**

1. 研读“爱”的主题
2. 分别在以下经节创建笔记：
   - 约翰福音 3:16（神的爱）
   - 罗马书 5:8（爱的显明）
   - 约翰一书 4:8（神就是爱）
3. 在每篇笔记中加入互相参照的经文
4. 全部下载作为备份

### **讲道预备**

1. 选定讲道经文段落
2. 创建详细笔记：
   ```markdown
   # 讲道题目：好牧人
   ## 经文：约翰福音 10:11-18

   ### 大纲
   1. 好牧人为羊舍命（11 节）
   2. 雇工撇下羊逃跑（12-13 节）
   3. 耶稣认识祂的羊（14-15 节）

   ### 例证
   - 牧羊人舍身保护羊群的故事

   ### 生活实践
   - 坚定信靠耶稣为我们的保护者
   ```
3. 保存后可随时从任何设备访问

## **数据管理**

### **重建索引**

索引追踪您的所有笔记。在下列情况下请进行重建：
- 导入笔记后似乎有遗漏
- 笔记计数显示不正确
- 您曾手动在云端硬盘中添加过文件

**如何重建**：
1. 点击菜单按钮（⋮）
2. 选择“重建索引”
3. 等待程序完成（笔记较多时可能需要稍候）
4. 查看成功提示通知

### **备份策略**

**建议备份计划**：
1. Google 云端硬盘会自动同步备份所有笔记
2. 定期点击“全部下载”保存本地备份
3. 妥善保存备份 `.zip` 文件
4. 下载索引文件作为额外安全保障

### **从备份导入恢复**

若要从备份恢复：
1. 点击菜单按钮（⋮）
2. 选择“导入”
3. 选取您的 `.zip` 文件
4. 等待上传与处理完成
5. 必要时点击重建索引

## **隐私与安全性**

### **笔记存储位置**

- **Google 云端硬盘**：App Data 文件夹（在普通云端硬盘界面中默认隐藏）
- **不易察觉**：不会出现在您的主要云端硬盘文件列表中
- **安全保障**：受到您的 Google 账号安全性保护
- **隐私专属**：仅能通过 BibleMate AI 或专门的 Drive API 访问

### **BibleMate AI 的访问权限范围**

- **可以**：读取与写入 App Data 文件夹内的文件
- **不能**：访问您 Google 云端硬盘中的其他任何文件
- **不能**：将您的笔记分享给他人
- **不能**：在 BibleMate 服务器端查看您的笔记内容

### **数据政策**

BibleMate AI：
- **绝不**收集您的个人笔记
- **绝不**将您的笔记存放在本应用服务器上
- **绝不**将您的笔记分享给任何第三方
- **仅**负责协助将数据同步至**您自己的** Google 云端硬盘

## **疑难解答**

**笔记无法保存：**
- 检查网络连接状态
- 确认您已处于登录状态
- 尝试退出登录后重新登录
- 检查 Google 云端硬盘授权权限

**登录后笔记未显示：**
- 点击“重建索引”
- 确认您是否登录了正确的 Google 账号
- 确认笔记未曾被意外删除

**导入失败：**
- 确认文件为有效的 `.json` 或 `.zip` 格式
- 检查文件是否损坏
- 若数据量过大，尝试分批导入
- 确保网络连接稳定

**在 Google 云端硬盘中找不到笔记文件：**
- 笔记存放于 App Data 文件夹（默认隐藏）
- 这是正常现象
- 请使用“全部下载”功能获取可见的本地备份
