# **全章索引指南**

本工具显示整卷圣经章节的综合参考信息，包含该章所提及的人物、地点、主题，以及相关的应许与平行经文。

## **什么是全章索引？**

全章索引为每个圣经篇章提供完整的参考概览，展示与该章任何经节相关的所有重要人物、地点、主题、字典词条以及百科全书条目。这与特定经节的单节索引不同——全章索引汇总了整章的信息。

## **如何使用全章索引**

1. **选择篇章**：使用圣经选单选择书卷与篇章（无需选择经节）。
2. **点击“开启”**：加载该章的索引。
3. **浏览分类**：展开任何分类即可查看与该章相关的所有项目。
4. **点击参照**：点击任何项目即可查看更详细的内容。

## **索引分类**

本工具将信息组织为七个不同分类：

### **1. 圣经人物**

**图标**：👥 群组（Groups）

列出该章提及的所有重要人物：
- 个人或群体的名称
- 简要身份信息
- 相关圣经经文引用
- 指向完整人物资料的链接

**示例**：在创世记 12 章中，您会看到亚伯兰、撒莱、罗得与法老的词条。

### **2. 圣经地点**

**图标**：📍 地点（Place）

显示该章所参照的所有地理位置：
- 地点名称（城市、地区、地标）
- 简要地理背景
- 该地点出现的有关经文
- 指向详细地点信息的链接

**示例**：在约书亚记 6 章中，您会看到耶利哥、约旦河及相关的地理数据。

### **3. 圣经主题**

**图标**：🏷️ 分类（Category）

标记该章所呈现的神学、道德与主题要点：
- 神学概念（信心、立约、审判）
- 道德主题（顺服、罪、救赎）
- 文化主题（献祭、节期、律法）
- 指向延伸主题探讨的链接

**示例**：在罗马书 3 章中，主题可能包括“称义”、“信心”、“律法”与“罪”。

**注意**：“圣经主题”区块默认为开启状态，便于快速查阅。

### **4. 圣经字典**

**图标**：📚 字典（Dictionary）

为该章使用的核心词汇提供字典定义：
- 字词定义
- 神学解释
- 历史背景
- 圣经语境中的用法

### **5. 百科全书**

**图标**：💎 深度知识（Deep Knowledge）

链接至全面的百科全书文章，内容涵盖：
- 该章中的人物、地点与事件
- 详细的历史与神学背景
- 与相关圣经资料的经文串珠参照
- 学术见解

### **6. 圣经应许**

**图标**：🎁 礼物（Gift）

显示与该章相关的神的应许合辑：
- 按主题分类组织
- 每个应许合辑均有可点击的标签（Chips）
- 每一个应许主题的完整经文列表

**示例**：若创世记 12 章包含关于祝福的应许，您会看到“关于祝福的应许”或“立约应许”的标签。

### **7. 平行经文**

**图标**：🔗 链接（Link）

显示福音书平行经文与相关经文段落：
- 其他福音书中的平行记载
- 不同书卷中的类似事件
- 相关叙事
- 对照合参经文

**示例**：在马太福音 5 章（登山宝训），您会看到路加福音中的平行经文。

## **功能特点**

### **可折叠区块**

- 每个分类均可独立展开或折叠。
- “圣经主题”区块会自动开启以供快速参考。
- 点击分类标题即可展开／折叠内容。

### **交互式链接**

- **人物链接**：点击可开启详细的人物档案资料。
- **地点链接**：点击可探索地理信息与地图。
- **主题链接**：点击可查看全面的主题探讨。
- **参照标签**：点击应许或平行经文标签即可查看完整合辑。

### **智能筛选**

若某分类找不到任何项目，工具会显示“找不到此类别的条目”，而非完全隐藏该区块。

## **全章索引与单节索引的差异**

| 全章索引 | 单节索引 |
| :---- | :---- |
| 显示整章的所有条目 | 仅显示特定经节的条目 |
| 汇总视图 | 聚焦视图 |
| 最适合章节层级的研经 | 最适合单节层级的研经 |
| 无需选择特定经节 | 必须指定特定经节 |

## **高效使用技巧**

1. **篇章概览**：在研读某一章之前使用，了解其中涉及的主题与人物。
2. **讲道预备**：迅速识别某段经文中的所有核心主题，用于拟定讲道大纲。
3. **经文串珠研读**：利用平行经文部分，研究不同记载之间的关联。
4. **专题研究**：寻找探讨特定神学主题的篇章。
5. **历史背景**：利用地点与人物区块了解当时的历史情境。
6. **追踪应许**：发掘当前阅读内容中出现的神的应许。

## **工作流程示例**

**研读罗马书 8 章：**
1. 加载罗马书 8 章的全章索引
2. 打开“圣经主题”查看各项主题：“圣灵”、“儿子的名分”、“荣耀”、“预定”
3. 查看“圣经应许”标签，寻找有关盼望与救赎的应许
4. 点击主题链接以深入探讨神学概念
5. 利用此概览构建您的查经或教学大纲

## **从结果中导航**

- **点击圣经经文引用**：在圣经区域中开启该经文段落
- **点击字典／百科全书链接**：在新的标签页中开启详细文章
- **点击合辑标签**：加载完整的圣经应许或平行经文合辑
