# **圣经广播指南**

本工具以广播节目形式提供钦定版（KJV）圣经按卷录制的语音朗读，让您能够通过按章分段播放，连续聆听长篇圣经内容。

## **什么是圣经广播？**

“圣经广播”播放器让您聆听 KJV 圣经全书卷的有声诵读。与逐节播放的“圣经语音”工具不同，“圣经广播”将音频整理为章节片段，非常适合以连续播放的方式沉浸于大段经文中。

## **如何使用广播播放器**

### **基本播放操作**

1. **选择书卷**：使用书卷下拉菜单选择圣经 66 卷书中的任一卷。
2. **选择篇章**：选择要从哪一章开始播放。
3. **点击“开启”**：加载该书卷的广播播放器。
4. **播放**：点击任何篇章分段旁的语音图标（🔊）即可开始播放。
5. **自动接续**：当前分段播放完毕时，播放器会自动前进至下一分段。

### **导航方式**

- **书卷下拉菜单**：从圣经全部 66 卷书中选择
- **篇章下拉菜单**：选择起始篇章
- **“开启”按钮**：应用您的选择并加载广播内容
- **经节选单**：不使用（广播播放器按章分段）

## **播放器控制项**

| 控制项 | 功能 |
| :---- | :---- |
| **音量图标** | 点击任何分段旁的图标以开始／停止播放 |
| **语音播放器** | 标准 HTML5 音频控制项（播放、暂停、快进／倒退、音量） |
| **循环开关** | 开启后，该书卷播毕时会自动从头重新播放 |

## **功能特点**

### **按章分段设计**

- 每章可细分为多个音频片段
- 音频片段在章内依序播放
- 适合长时间聆听的自然分段点

### **自动推进播放**

播放器会自动：
- 当前片段播毕后自动前进至下一片段
- 流畅无缝地播放章节内各片段
- 在停用循环模式时自动推进至下一卷书

### **循环模式**

开启“Loop”（循环）开关可：
- 当该书卷结束时，自动从开头重新开始播放
- 非常适合复习或深度聆听特定书卷
- 播放过程中可随时切换开启／关闭

### **自动加载下一卷书**

当停用循环模式且全书播放完毕时：
- 自动依序加载下一卷书
- 从创世记连续播放至启示录
- 循环往复（启示录 → 创世记）

### **章节标题**

每个分段均显示：
- 书卷缩写（例如：“Gen”、“John”、“Rev”）
- 篇章或分段编号
- 描述性标题（提取自文件名）

### **视觉状态提示**

- **播放中**：🔊（扬声器图标）
- **未播放**：🔇（静音图标）
- **当前标题**：显示在顶部，播放时实时更新
- **悬停效果**：光标悬停时分段项目会高亮突显

## **音频格式**

### **内容规格**

- **圣经版本**：钦定版（King James Version，KJV）
- **文件格式**：MP3 音频文件
- **音质水准**：专业播音员朗读
- **组织架构**：按书卷与篇章分层管理

### **文件结构**

广播播放器采用：
- 每卷书配备播放列表文件（`.m3u`）
- 每卷书包含多个音频片段
- 数字编号分段以确保正确播放顺序

## **技术说明**

- 音频文件存放在：`~/biblemate/data/podcast/`
- 使用 `.m3u` 播放列表文件
- 采用具广泛兼容性的 MP3 格式

- 无需互联网连接（本地文件）

## **疑难解答**

**无声音播放：**
- 检查广播音频文件是否已正确安装
- 确认选取了正确的书卷
- 确保设备音量已开启
- 若问题持续，尝试使用其他浏览器

**分段未自动推进：**
- 检查循环模式设置
- 验证播放列表文件的完整性
- 重新加载播放器

**缺少部分书卷：**
- 并非所有书卷都配备了广播音频文件
- 检查数据目录中的可用内容
- 视需要下载补充的广播音频文件
