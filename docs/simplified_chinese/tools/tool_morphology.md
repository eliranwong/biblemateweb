# **字词形态学分析指南**

本工具提供希伯来文与希腊文圣经原文的详细语法分析，让您能够在字词层级深入研究圣经的语言学结构。

## **什么是字词形态学分析？**

字词形态学分析展示圣经经文中每个希伯来文（旧约）或希腊文（新约）字词的语法形式与结构。这包括词性、动词时态、名词格位以及其他影响字义的语法特征信息。

## **如何使用形态学分析工具**

1. **选择经节**：使用圣经选单选择特定的经节。
2. **点击“开启”**：加载该经节的形态学分析。
3. **查看字词数据**：每个字词均会显示其词形、词典词条与形态标签。
4. **选取形态特征**：点击形态标签（Chips）选取／取消选取欲搜索的语法特征。
5. **进行搜索**：点击搜索按钮，寻找具有相似形态模式的经文。

## **字词显示结构**

经文中的每个字词均呈现在一张卡片中，包含四个主要元素：

### **1. 原文文本**

- **希伯来文字词**：由右至左正确排版显示
- **希腊文字词**：以 Unicode 希腊文字符显示
- **悬停提示**：将光标悬停在字词上即可查看词汇字典信息

### **2. 词元（字典原形，Lexeme）**

- 出现在词典中的字词基础原形
- 可点击并带有提示工具以提供补充信息
- 链接至该字词的原文字典词条

### **3. 逐字对照翻译**

- 逐字英文对照翻译
- 帮助理解字词的基本含义
- 显示在原文文本与形态标签之间

### **4. 形态标签**

可选取的标签，显示各项语法特征，例如：
- **词性（Part of Speech）**：名词、动词、形容词等
- **人称（Person）**：第一、第二、第三人称
- **性别（Gender）**：阳性、阴性、中性
- **数量（Number）**：单数、复数、双数
- **格位（Case）**：主格、属格、与格、宾格（希腊文）
- **状态（State）**：绝对态、构词态（希伯来文）
- **时态（Tense）**：现在时、不定过去时（Aorist）、完成时、未完成时等
- **语态（Voice）**：主动语态、中间语态、被动语态
- **语气（Mood）**：直陈语气、假定语气、祈使语气等

## **搜索功能**

### **形态模式搜索**

查看字词的形态之后，您可以搜索具备相似语法模式的经文：

1. **选取形态标签**：点击橙色标签选取／取消选取语法特征
2. **选择圣经版本**：点击其中一个搜索按钮：
   - **OHGB**：希伯来文与希腊文原文字典圣经
   - **OHGBi**：逐字对照版本
   - **当前圣经（Current Bible）**：您圣经区域中当前开启的圣经版本
   - **首选圣经（Primary Bible）**：您偏好设定中的主要译本
   - **次选圣经（Secondary Bible）**：您偏好设定中的次要译本

3. **运行搜索**：系统将找出该字词以您所选形态特征出现的所有经文

**示例**：搜索特定希腊文动词在“不定过去时、被动语态”下的所有经文出处。

### **高级搜索选项**

- **词条原形搜索**：搜索特定字词的所有形态变化形式（任何语法形态）
- **组合条件搜索**：选取多个形态特征以精确缩小结果范围
- **特定版本搜索**：在圣经原文或特定译本中进行搜索

## **理解形态标签**

### **常见希伯来文标签**

- **verb**：动词
- **noun**：名词
- **qal**：简易主动干（Simple verb stem）
- **perfect**：完成态（已完成动作）
- **construct**：构词态（与后接词的从属修饰关系）
- **masculine/feminine**：阳性／阴性
- **singular/plural**：单数／复数

### **常见希腊文标签**

- **verb**：动词
- **noun**：名词
- **aorist**：不定过去时（单纯过去动作）
- **present**：现在时（持续动作）
- **indicative**：直陈语气（陈述客观事实）
- **imperative**：祈使语气（命令、吩咐）
- **nominative**：主格（主语）
- **accusative**：宾格（直接宾语）
- **active/passive**：主动／被动语态

## **高效使用技巧**

1. **从简单开始**：先查看个别字词，再进行复杂的组合搜索。
2. **对比不同译本**：利用形态学分析理解为何不同译本在翻译上有所差异。
3. **字词深度研究**：追踪字词形态的变化如何影响跨经文的含义。
4. **学习原文语法**：通过真实的经文语境学习希伯来文与希腊文语法。
5. **语法模式识别**：识别圣经中常见的特定语法句型与结构。
6. **神学精准度**：根据语法形态辨明细微但关键的神学差异。
7. **检验翻译**：验证原文语法特征在各译本中如何被呈现。

## **工作流程示例**

### **希腊文动词研读**

1. 加载约翰福音 3:16
2. 找到动词“爱”（ἠγάπησεν）
3. 观察其形态为：不定过去时、主动语态、直陈语气
4. 选取“aorist”与“active”标签
5. 搜索 OHGB，找出动词 ἀγαπάω 在不定过去时主动语态下的其他所有出处
6. 研读此形态如何强调一次性、已成就的确定动作

### **希伯来文名词分析**

1. 加载创世记 1:1
2. 检视 אֱלֹהִים（Elohim - 神）
3. 观察其形态为阳性复数，但在语法上搭配单数动词
4. 点击“Lexicon”阅读关于此独特形式的词典说明
5. 使用经文汇编查看此形式还出现在哪些地方

### **词形对照研究**

1. 加载带有核心动词的经节
2. 观察形态标签
3. 在 OHGB 中搜索该精确词形
4. 切换至主要圣经译本再次搜索
5. 对比不同译本如何处理相同的语法形式
