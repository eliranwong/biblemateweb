# AI Commentary

Verse-by-verse commentary written by AI, shipped as the **AIC** commentary module (English), with **AICTC** (Traditional Chinese) and **AICSC** (Simplified Chinese).

## Open

- **AI** menu → `Commentary`
- Right-click a verse → `🧠 AI Commentary`
- **Tools** menu → `Bible Commentaries` and select AIC.

The module matches your [interface language](../user_preferences/ui_language.md) (`eng` → AIC, `tc` → AICTC, `sc` → AICSC), and is stored as `favorite_commentary`.

## Use

Enter a reference such as `John 3:16` or `Romans 8:1-17`, or let it open at the verse you are reading ([Sync](../layout/sync.md)).

More: [Commentary tool guide](../tools/tool_commentary.md).
