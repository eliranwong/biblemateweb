# Ask BibleMate

Ask the AI about a specific verse or chapter without retyping it.

## Use

1. Right-click (long-press on touch screens) a verse or chapter in the Bible.
2. Choose `💬 Ask BibleMate`.

[Chat Mode](chat_mode.md) opens in an empty Tool Area tab with the passage (reference and text) already in the request box. Add your question and send.

See [Context Menus](../layout/context_menus.md).
