# AI Features

Everything AI in BibleMate AI Web. Chat, Partner, Agent and the generated content open from the **AI** menu (`auto_awesome` icon) in the navigation bar, from the Tools menu, or from a verse's right-click menu. Semantic search opens from the **Search** menu.

## Interactive modes

| Feature | Description |
|---|---|
| [Chat Mode](chat_mode.md) | Conversational Bible assistant |
| [Partner Mode](partner_mode.md) | Multi-step study where you approve each step |
| [Agent Mode](agent_mode.md) | Multi-step study run autonomously |
| [Studio Mode](studio_mode.md) | Integrated `biblemate-agentic-workspace` (CLI/SDK agents, skills, notes & export) |

## Chat Mode options

| Option | Description |
|---|---|
| [Enhance (Prompt Engineering)](prompt_engineering.md) | Improve your prompt before sending |
| [Agent option](chat_agent_option.md) | Let helper agents improve answers |
| [Tools (Tool Selection)](chat_tool_selection.md) | Use Bible study tools and specialist prompts |
| [Review](chat_review.md) | Approve or edit at each stage |
| [Export & Edit Responses](export_edit_responses.md) | Copy, download TXT/DOCX, edit, stop |

## AI content features

| Feature | Description |
