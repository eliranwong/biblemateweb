# Copy, Download, Edit and Stop

## After each response (Chat, Partner, Agent)

| Button | Action |
|---|---|
| 📋 Copy | Copy the response text |
| 📥 TXT | Download as a text file |
| 📥 DOCX | Download as a Word document |
| ✒️ Edit | Edit the response in a dialog (Chat Mode); the edit is kept in the conversation context |

## Whole conversation

`Download the whole Conversation` saves all requests and responses as a `.txt` file (you choose the filename; default `BibleMate_AI_Conversation`). Partner and Agent modes also offer `Download the Final Report Only`.

## Auto-scroll

The `Auto-scroll` checkbox (`auto_scroll`, default On) keeps the view at the end of streaming output.

## Stop a running task

Click **Stop** (the Send button changes while running) and confirm. Partner and Agent modes can then be continued with `Resume`.
