# DOCX Export

Downloading content as Word documents needs the `pandoc` binary.

| OS | Install |
|---|---|
| Debian/Ubuntu | `sudo apt install pandoc` |
| macOS | `brew install pandoc` |
| Windows | <https://pandoc.org/installing.html> |

TXT export needs nothing extra. See [export buttons](../ai_features/export_edit_responses.md).
