# Dark Mode

Switches between dark and light themes. The page reloads after you toggle it.

| | |
|---|---|
| Location | `Preferences` → `Appearance` → `Dark Mode` |
| Storage key | `dark_mode` |
| Default | `On` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `Appearance`.
3. Adjust `Dark Mode`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
