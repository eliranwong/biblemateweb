# API Endpoint

Custom API endpoint URL, needed for the `custom` backend or Azure-hosted backends. Leave blank to use the provider's default. The field is masked; use the eye icon to reveal it.

| | |
|---|---|
| Location | `Preferences` → `AI Backend` → `API Endpoint (Optional)` |
| Storage key | `api_endpoint` |
| Default | `(empty)` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `AI Backend`.
3. Adjust `API Endpoint (Optional)`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
