# Language

Interface language. Options: `eng` (English), `tc` (繁體中文), `sc` (简体中文).

| | |
|---|---|
| Location | `Preferences` → `Language` → `Language` |
| Storage key | `ui_language` |
| Default | `eng` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `Language`.
3. Adjust `Language`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
