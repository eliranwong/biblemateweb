# Primary Color

Theme primary color, used for buttons, sliders and highlights. Enter a hex code or use the color picker.

| | |
|---|---|
| Location | `Preferences` → `Appearance` → `Primary Color` |
| Storage key | `primary_color` |
| Default | `#827e67` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `Appearance`.
3. Adjust `Primary Color`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
