# Similar Verses

Maximum number of verses returned by a semantic Bible verse search. A slider from 5 to 100.

| | |
|---|---|
| Location | `Preferences` → `Semantic Searches` → `Similar Verses` |
| Storage key | `top_similar_verses` |
| Default | `20` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `Semantic Searches`.
3. Adjust `Similar Verses`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
