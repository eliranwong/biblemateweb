# Sync

Keeps the Bible Area and Tool Area on the same book and chapter, and opens tools at the current verse.

| | |
|---|---|
| Where to change | Settings menu → `Sync`, mobile drawer, or URL `s` |
| Storage key | `sync` |
| Default | `True` |

Saved automatically in your browser storage. `Reset All Preferences` restores the default.

See [Sync](../layout/sync.md).
