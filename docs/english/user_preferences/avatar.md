# Avatar URL

URL of an image used as your profile picture. Leave blank for the default avatar, e.g. `https://example.com/avatar.png`.

| | |
|---|---|
| Location | `Preferences` → `User & Custom Data` → `Avatar URL` |
| Storage key | `avatar` |
| Default | `(empty)` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `User & Custom Data`.
3. Adjust `Avatar URL`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
