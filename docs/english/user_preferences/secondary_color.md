# Secondary Color

Theme secondary color, used for headings and accents. Enter a hex code or use the color picker.

| | |
|---|---|
| Location | `Preferences` → `Appearance` → `Secondary Color` |
| Storage key | `secondary_color` |
| Default | `#c7c279` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `Appearance`.
3. Adjust `Secondary Color`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
