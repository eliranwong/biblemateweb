# Similar Entries

Maximum number of entries returned by a semantic search of general resources. A slider from 3 to 30.

| | |
|---|---|
| Location | `Preferences` → `Semantic Searches` → `Similar Entries` |
| Storage key | `top_similar_entries` |
| Default | `5` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `Semantic Searches`.
3. Adjust `Similar Entries`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
