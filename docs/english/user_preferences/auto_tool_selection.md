# Tools (Auto Tool Selection)

Lets the AI choose a Bible study tool for your request.

| | |
|---|---|
| Where to change | AI Chat → `Tools` checkbox |
| Storage key | `auto_tool_selection` |
| Default | `False` |

Saved automatically in your browser storage. `Reset All Preferences` restores the default.

See [Tool Selection](../ai_features/chat_tool_selection.md).
