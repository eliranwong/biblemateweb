# Go Button

Shows or hides the floating Go (select verse) button.

| | |
|---|---|
| Where to change | Settings menu → `Go`, mobile drawer |
| Storage key | `bible_select_button` |
| Default | `True` |

Saved automatically in your browser storage. `Reset All Preferences` restores the default.

See [Floating Buttons](../layout/floating_buttons.md) and [Bible Selection Dialog](../layout/bible_selection_dialog.md).
