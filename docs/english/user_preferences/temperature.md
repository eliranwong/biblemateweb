# Model Temperature

Controls randomness of AI output, from 0.0 to 2.0 in steps of 0.1. Lower values give more focused, deterministic answers; higher values give more varied ones.

| | |
|---|---|
| Location | `Preferences` → `AI Backend` → `Model Temperature (Optional)` |
| Storage key | `temperature` |
| Default | `0.3` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `AI Backend`.
3. Adjust `Model Temperature (Optional)`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
