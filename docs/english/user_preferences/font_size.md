# Font Size

Scales the text size of the whole app. A slider from 50% to 200% in steps of 5; changes apply immediately.

| | |
|---|---|
| Location | `Preferences` → `Appearance` → `Font Size` |
| Storage key | `font_size` |
| Default | `100` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `Appearance`.
3. Adjust `Font Size`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
