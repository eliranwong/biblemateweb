# Fullscreen

Toggles browser fullscreen mode.

| | |
|---|---|
| Location | `Preferences` → `Appearance` → `Fullscreen` |
| Storage key | `fullscreen` |
| Default | `Off` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `Appearance`.
3. Adjust `Fullscreen`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.

> [!NOTE]
> This setting is reset to Off every time the Settings page is opened, so it is not remembered between visits.
