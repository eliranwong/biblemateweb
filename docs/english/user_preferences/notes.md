# Notes (Note Indicators)

Shows 📝 indicators on verses with notes (needs Google Drive notes). Toggling reloads the page.

| | |
|---|---|
| Where to change | Settings menu → `Notes`, mobile drawer |
| Storage key | `notes` |
| Default | `True` |

Saved automatically in your browser storage. `Reset All Preferences` restores the default.

See [Note Indicators](../integrations/note_indicators.md).
