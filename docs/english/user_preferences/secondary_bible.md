# Secondary Bible

Bible version used as the secondary version, e.g. for comparison. The list depends on the resources available on the server.

| | |
|---|---|
| Location | `Preferences` → `Frequently Used Resources` → `Secondary Bible` |
| Storage key | `secondary_bible` |
| Default | `KJV` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `Frequently Used Resources`.
3. Adjust `Secondary Bible`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
