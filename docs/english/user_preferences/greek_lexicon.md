# Greek Lexicon

Lexicon used to look up Greek words. The list depends on the resources available on the server.

| | |
|---|---|
| Location | `Preferences` → `Frequently Used Resources` → `Greek Lexicon` |
| Storage key | `greek_lexicon` |
| Default | `TBESG` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `Frequently Used Resources`.
3. Adjust `Greek Lexicon`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
