# Bible Tabs

Number of Bible tabs opened by default. A slider from 1 to 10.

| | |
|---|---|
| Location | `Preferences` → `Tabs Management` → `Bible Tabs` |
| Storage key | `default_number_of_tabs1` |
| Default | `3` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `Tabs Management`.
3. Adjust `Bible Tabs`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
