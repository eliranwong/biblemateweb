# Negative Color

Color for warning and destructive actions, such as the reset button. Enter a hex code or use the color picker.

| | |
|---|---|
| Location | `Preferences` → `Appearance` → `Negative Color` |
| Storage key | `negative_color` |
| Default | `#ff384f` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `Appearance`.
3. Adjust `Negative Color`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
