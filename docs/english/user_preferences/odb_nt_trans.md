# ODB NT Translation

Bible translation shown for New Testament chapters in [Original Discourse Bible (ODB)](../bibles/original_discourse.md). Options come from available `.bible` translation modules on the server (and `~/biblemate/data_custom/bibles/` when a valid custom token is active).

| | |
|---|---|
| Location | `Preferences` → `Frequently Used Resources` → `ODB NT Translation` |
| Storage key | `odb_nt_trans` |
| Default | `NET` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `Frequently Used Resources`.
3. Adjust `ODB NT Translation`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
