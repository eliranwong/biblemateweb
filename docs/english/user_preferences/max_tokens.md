# Max Tokens

Maximum number of tokens in an AI response. Minimum 2048; clear the field to use the default.

| | |
|---|---|
| Location | `Preferences` → `AI Backend` → `Max Tokens (Optional)` |
| Storage key | `max_tokens` |
| Default | `8192` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `AI Backend`.
3. Adjust `Max Tokens (Optional)`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
