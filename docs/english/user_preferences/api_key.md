# API Key

Your personal API key for the selected backend (Bring Your Own Key). It lets you bypass administrator limits and pick your own provider. Ignored by `grok`, `claude` and `antigravity`.

| | |
|---|---|
| Location | `Preferences` → `AI Backend` → `API Key` |
| Storage key | `api_key` |
| Default | `(empty)` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `AI Backend`.
3. Adjust `API Key`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.

See also [api_key_setup.md](api_key_setup.md).
