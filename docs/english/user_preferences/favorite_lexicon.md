# Favourite Lexicon

The lexicon module last used; remembered automatically.

| | |
|---|---|
| Where to change | Lexicons search, Morphology tool, word tooltips |
| Storage key | `favorite_lexicon` |
| Default | `Morphology` |

Saved automatically in your browser storage. `Reset All Preferences` restores the default.

See [Lexicon Search](../search/search_lexicons.md).
