# Primary Bible

Bible version used as the main version when opening Bible content. The list depends on the resources available on the server (and whether a valid custom token is active).

| | |
|---|---|
| Location | `Preferences` → `Frequently Used Resources` → `Primary Bible` |
| Storage key | `primary_bible` |
| Default | `NET` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `Frequently Used Resources`.
3. Adjust `Primary Bible`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
