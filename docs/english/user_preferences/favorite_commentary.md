# Favourite Commentary

The commentary module opened by default. Set automatically when you pick a commentary; `AI Commentary` selects AIC/AICTC/AICSC by interface language.

| | |
|---|---|
| Where to change | Commentary tool dropdown (or AI Commentary menu item) |
| Storage key | `favorite_commentary` |
| Default | `AIC` |

Saved automatically in your browser storage. `Reset All Preferences` restores the default.

See [Commentary](../tools/tool_commentary.md).
