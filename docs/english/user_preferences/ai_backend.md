# AI Backend

The AI service provider. Options: `default` (server's setting), `googleai`, `openai`, `anthropic`, `cohere`, `deepseek`, `mistral`, `xai`, `azure_*` variants, `ollamacloud`, `custom`. If enabled by the administrator, `grok`, `claude` and `antigravity` use the server's signed-in subscription CLI and need no API key.

| | |
|---|---|
| Location | `Preferences` → `AI Backend` → `AI Backend` |
| Storage key | `ai_backend` |
| Default | `default` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `AI Backend`.
3. Adjust `AI Backend`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.

See also [api_key_setup.md](api_key_setup.md).
