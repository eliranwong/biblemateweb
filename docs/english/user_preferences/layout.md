# Layout

Which areas are visible: `1` Bible only, `2` Bible & Tool (50/50), `3` Tool only.

| | |
|---|---|
| Where to change | Floating Swap button, Settings menu, or URL `l` |
| Storage key | `layout` |
| Default | `2` |

Saved automatically in your browser storage. `Reset All Preferences` restores the default.

See [Toggle Layout](../layout/toggle_layout.md).
