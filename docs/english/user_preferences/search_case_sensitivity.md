# Case-sensitive Search

Makes verse searches and result filtering case-sensitive.

| | |
|---|---|
| Where to change | Verse search page → `Case-sensitive` checkbox |
| Storage key | `search_case_sensitivity` |
| Default | `False` |

Saved automatically in your browser storage. `Reset All Preferences` restores the default.

See [Bible Verse Search](../search/search_bible_verses.md).
