# OPB NT Translation 1

First parallel clause translation shown for New Testament chapters in [Original Parallel Bible (OPB)](../bibles/original_parallel.md). Options come from `.clause` modules in `~/biblemate/data/clauses/` (and `~/biblemate/data_custom/clauses/` when a valid custom token is active).

| | |
|---|---|
| Location | `Preferences` → `Frequently Used Resources` → `OPB NT Translation 1` |
| Storage key | `opb_nt_trans1` |
| Default | `KJV` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `Frequently Used Resources`.
3. Adjust `OPB NT Translation 1`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
