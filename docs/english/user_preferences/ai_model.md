# AI Model

Model id to use with the selected backend. For `grok`, e.g. `grok-4.7`; for `claude`, `sonnet`, `opus`, `haiku` or a full model id; for `antigravity`, e.g. `gemini-3.8-flash-high`. Blank uses the backend's default.

| | |
|---|---|
| Location | `Preferences` → `AI Backend` → `AI Model` |
| Storage key | `ai_model` |
| Default | `(empty)` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `AI Backend`.
3. Adjust `AI Model`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
