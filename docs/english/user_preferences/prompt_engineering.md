# Enhance (Prompt Engineering)

Automatically improves your request before it is answered.

| | |
|---|---|
| Where to change | AI Chat/Partner/Agent → `Enhance` checkbox |
| Storage key | `prompt_engineering` |
| Default | `True` |

Saved automatically in your browser storage. `Reset All Preferences` restores the default.

See [Prompt Engineering](../ai_features/prompt_engineering.md).
