# Auto-scroll

Follows streaming AI output to the end.

| | |
|---|---|
| Where to change | AI pages → `Auto-scroll` checkbox |
| Storage key | `auto_scroll` |
| Default | `True` |

Saved automatically in your browser storage. `Reset All Preferences` restores the default.

See [Export & Edit Responses](../ai_features/export_edit_responses.md).
