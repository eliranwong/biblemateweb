# Swap Button

Shows or hides the floating Swap Layout button.

| | |
|---|---|
| Where to change | Settings menu → `Swap`, mobile drawer |
| Storage key | `layout_swap_button` |
| Default | `True` |

Saved automatically in your browser storage. `Reset All Preferences` restores the default.

See [Floating Buttons](../layout/floating_buttons.md).
