# Search Mode

Verse search method: `1` Literal, `2` Regex, `3` Semantic. Also used to filter results already shown.

| | |
|---|---|
| Where to change | Verse search page → radio buttons |
| Storage key | `search_mode` |
| Default | `1` |

Saved automatically in your browser storage. `Reset All Preferences` restores the default.

Semantic needs [setup](../server_setup/semantic_search_setup.md). See [Bible Verse Search](../search/search_bible_verses.md).
