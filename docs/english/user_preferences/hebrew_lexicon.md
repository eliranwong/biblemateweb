# Hebrew Lexicon

Lexicon used to look up Hebrew words. The list depends on the resources available on the server.

| | |
|---|---|
| Location | `Preferences` → `Frequently Used Resources` → `Hebrew Lexicon` |
| Storage key | `hebrew_lexicon` |
| Default | `TBESH` |

## How to change

1. Open `Preferences` (the `/settings` page).
2. Expand the section `Frequently Used Resources`.
3. Adjust `Hebrew Lexicon`.

Changes are saved automatically in your browser-linked user storage. Use `Reset All Preferences` to restore defaults.
