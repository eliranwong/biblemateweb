# Review

Pauses for you to approve or edit the improved prompt, tool choice and instruction.

| | |
|---|---|
| Where to change | AI Chat → `Review` checkbox |
| Storage key | `chat_mode_review` |
| Default | `False` |

Saved automatically in your browser storage. `Reset All Preferences` restores the default.

See [Review](../ai_features/chat_review.md).
