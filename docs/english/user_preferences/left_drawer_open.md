# Left Drawer

Whether the mobile drawer is open. Closes automatically after you choose an item.

| | |
|---|---|
| Where to change | Hamburger icon on small screens |
| Storage key | `left_drawer_open` |
| Default | `False` |

Saved automatically in your browser storage. `Reset All Preferences` restores the default.

See [Mobile Layout](../layout/mobile_layout.md).
