# FAQ

**Do I need an account?** No. Settings are stored in your browser. Sign in with Google only for [Drive notes](../integrations/google_drive_notes.md) or when a daily limit applies.

**Does it cost anything to use AI?** The server default is set by the administrator. You can use your own key ([BYOK](../user_preferences/api_key_setup.md)).

**How do I read two Bibles side by side?** [Parallel Bibles](../layout/parallel_bibles.md).

**How do I look up a Hebrew or Greek word?** Click it in an original-language Bible ([word tooltips](../integrations/word_tooltips.md)).

**How do I see everything about a verse?** Click its number ([verse menu](../integrations/verse_menu.md)).

**How do I share what I am reading?** [Share a link or QR code](share_link_qr_code.md).

**Why is Agent or Partner Mode showing a CLI page?** The administrator disabled it; use your own API key ([Usage Limits](../ai_features/usage_limits.md)).

**Why does semantic search not work?** [Semantic Search Setup](../server_setup/semantic_search_setup.md).

**How do I reset everything?** `Preferences` → `Reset All Preferences` ([User Data](../user_preferences/user_data_and_storage.md)).

**Can I add my own books or Bibles?** Yes, with [custom resources](../integrations/custom_resources.md).

**Can I use it on a phone?** Yes: [Mobile Layout](../layout/mobile_layout.md), or run the server on Android ([Termux](../android_termux/README.md)).

More: [Troubleshooting](../server_setup/troubleshooting.md).
