# Languages & Fonts

## Interface languages

| Code | Language |
|---|---|
| `eng` | English |
| `tc` | 繁體中文 (Traditional Chinese) |
| `sc` | 简体中文 (Simplified Chinese) |

Change in `Preferences` → Language ([guide](../user_preferences/ui_language.md)) or with the URL parameter `lang`. The language affects menus, dialogs, Bible book names, and the content language of several tools: AI commentary (AIC / AICTC / AICSC), [Book Analysis](../tools/tool_analysis.md), [Chapter Summary](../tools/tool_summary.md), AI welcome messages, and [API](../integrations/rest_api.md) output (`language` parameter).

## Fonts

Hebrew and Greek texts use bundled fonts (Ezra SIL, KoineGreek) so original-language Bibles display correctly on any device. Adjust overall text size with [Font Size](../user_preferences/font_size.md).
