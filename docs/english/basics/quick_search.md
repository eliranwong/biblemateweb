# Quick Search

The box in the navigation bar (in the drawer on mobile). Type and press **Enter**. Autocomplete suggests book names, Bible versions and tool names.

## Examples

| Type | Result |
|---|---|
| `KJV` | Opens KJV in the Bible Area |
| `John 3:16` | Opens John 3 at verse 16 |
| `KJV:::John 3:16` | Same, in KJV |
| `bible:::John 3:16` | Opens it as a parallel Bible in the Tool Area |
| `faith hope love` | Searches verses (results in the Tool Area) |
| `xrefs:::John 3:16` | Opens the Cross-references tool |

Multiple references or free text run a verse search. The box clears after each search.

Full syntax: [Quick Search (layout)](../layout/quick_search.md).
