# Bibles Menu

Icon: `local_library`. Opens Bibles in the **Bible Area**.

| Item | Action |
|---|---|
| Add Bible Tab | New tab in the Bible Area |
| Close Bible Tab | Close the active tab (the last tab cannot be closed) |
| Close Others | Close all tabs except the active one |
| Primary / Secondary Bible | Your two favourite versions ([set them](../user_preferences/primary_bible.md)) |
| Original Reader's, Interlinear, Parallel, Discourse, Linguistic Bibles | ORB, OIB, OPB, ODB, OLB |
| Other Bibles | All other versions on the server (custom Bibles appear with a valid [custom token](../user_preferences/custom_token.md)) |

If a verse is selected or a reference is in the tool query, the Bible opens at that verse.

More: [Bible Window](../layout/bible_window.md), [Tabs Management](../layout/tabs_management.md).
