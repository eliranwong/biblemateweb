# AI Menu

Icon: `auto_awesome`. Opens AI features in the **Tool Area**.

| Item | Purpose |
|---|---|
| Book Analysis | AI analysis of a Bible book |
| Chapter Summary | AI summary of a chapter |
| Commentary | AI commentary on the passage |
| AI Chat | Ask questions in a chat |
| Partner Mode | Study with an interactive partner |
| Agent Mode | Autonomous research agent |

To use your own AI provider, see [BYOK](../user_preferences/api_key_setup.md). More: [AI Menu](../layout/ai_menu.md).
