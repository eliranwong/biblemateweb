# Keyboard Shortcuts

| Where | Keys | Action |
|---|---|---|
| Quick search box | **Enter** | Run the search or navigate |
| Tool / search input boxes (Verses, Commentary, Xrefs, Treasury, Lexicons, Dictionaries, Topics, Characters, Locations, Parallels, Promises, Names, Maps ...) | **Enter** | Run the query |
| Same input boxes | **↑** (Up arrow) | Restore your previous query (also the history icon ⏱️) |
| AI Chat / Partner / Agent request box | **Shift+Enter** | Send |
| Browser | Back / Forward | Move through your navigation history; every Bible and tool change updates the address bar ([URL Parameters](../layout/url_parameters.md)) |

Mouse and touch: click a verse number for the [verse menu](../integrations/verse_menu.md); right-click (long-press) for [context menus](../layout/context_menus.md); drag the [floating buttons](../layout/floating_buttons.md) or the splitter.
