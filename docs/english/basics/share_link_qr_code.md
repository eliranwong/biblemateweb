# Share a Link or QR Code

1. Set up the view you want: Bible, chapter, tool, layout.
2. Click the **avatar / BibleMate AI** button at the top left (on mobile: open the drawer, then tap it).
3. A dialog shows the **URL** and a **QR code** for the current view.
4. Copy the link, or scan the QR code with another device.

The link includes the Bible and tool windows, the verse and the layout, so recipients see the same view. Your personal preferences are not shared.

You can also edit links by hand: [URL Parameters](../layout/url_parameters.md).
