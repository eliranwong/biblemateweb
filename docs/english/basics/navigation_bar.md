# Navigation Bar

The bar at the top of the page.

| Element | Purpose |
|---|---|
| Avatar / **BibleMate AI** | Shows the [link & QR code](share_link_qr_code.md) of the current view |
| Quick search box | [Search or navigate](quick_search.md) by typing |
| Bibles (`local_library`) | [Bibles Menu](menu_bibles.md) |
| Parallel Bibles (`devices_fold`) | [Parallel Bibles Menu](menu_parallel_bibles.md) |
| Tools (`build`) | [Tools Menu](menu_tools.md) |
| Search (`search`) | [Search Menu](menu_search.md) |
| AI (`auto_awesome`) | [AI Menu](menu_ai.md) |
| Settings (`settings`) | [Toggle options](toggle_options.md) and Preferences |

Hover over an icon to see its tooltip. On small screens the title and quick search move into the left drawer opened by the hamburger icon; the five menu buttons stay in the bar.
