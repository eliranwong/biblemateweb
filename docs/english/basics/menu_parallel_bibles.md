# Parallel Bibles Menu

Icon: `devices_fold`. Opens a Bible in the **Tool Area**, beside the Bible Area, for comparison.

| Item | Action |
|---|---|
| Add Parallel Tab | New tab in the Tool Area |
| Close Parallel Tab | Close the active Tool Area tab |
| Close Others | Close all other Tool Area tabs |
| Primary / Secondary Bible | Your favourite versions |
| Original-language Bibles | ORB, OIB, OPB, ODB, OLB |
| Other Bibles | All other versions |

With [Sync](toggle_options.md#sync) on, both windows stay on the same chapter.

More: [Parallel Bibles](../layout/parallel_bibles.md).
