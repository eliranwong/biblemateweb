# Toggle Options

Open the **Settings** (gear) menu in the navigation bar.

| Option | Effect | Default |
|---|---|---|
| Back / Forward arrows | Browser history | – |
| Bible Only / Tool Only / Bible & Tool | [Change layout](../layout/toggle_layout.md) | Bible & Tool |
| Swap | Show/hide the Swap Layout button | On |
| Go | Show/hide the Go (select verse) button | On |
| Notes | Show/hide note indicators (page reloads) | On |
| <a id="sync"></a>Sync | Keep Bible and tool windows on the same chapter ([details](../layout/sync.md)) | On |
| Screen | Toggle fullscreen | Off |
| Dark/Light Mode | Switch theme (page reloads) | Dark |
| Preferences | Open the [Preferences](../user_preferences/README.md) page | – |

On mobile, the same switches are in the left drawer.

Toggles save automatically. More about the floating buttons: [Floating Buttons](../layout/floating_buttons.md).
