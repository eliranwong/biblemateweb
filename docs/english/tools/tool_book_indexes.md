# Book Indexes Guide

**Book Indexes** provides a whole-book reference dashboard for studying an entire Bible book at a glance.

- **Book Selector**: Select any Bible book and click **Go** (no chapter or verse selection required).
- **Book Translation Vocabulary**: Expanded by default for Bible translations (automatically hidden for original-language/interlinear Bibles such as `ORB`, `OLB`, `OPB`, `OIB`, `ODB`, `OHGB`, `OHGBi`, `LXX`, `LXX1`, `LXX1i`, `LXX2`, `LXX2i`). Includes a **Hide common words** toggle, **Key Words in Book**, **Rare-Lemma Words in Book**, and click-to-search scoped to the selected book in **Verses**.
- **Book Vocabulary & Rare Words**: Expanded by default for original-language Bibles, listing **Top Book Lemmas** and **Rare Words in Book (<= 3x in Bible)** with clickable lexicon chips.
- **People Relationship Graph**: Interactive force-directed graph of biblical figures and relationships across the entire book.
- **Book Map**: Interactive Leaflet map plotting all locations mentioned in the book.
- **Bible People**, **Bible Locations**, and **Bible Topics**: Deduplicated chips across the entire book (with **Bible Topics** grouped under modules like `HIT`, `NAV`, `TCR`, etc.).
- **Export Study Sheet**: Download a Markdown study sheet for the book.
- **Book Tools**: Quick-launch buttons at the bottom open **Timelines**, **Book Analysis** (and key analysis sections), **Chapter Indexes**, and **Notes** (when configured) in the next tab.
