# Study Tools

Tools open in the **Tool Area** from the **Tools** menu (`build` icon), from verse/chapter/book [popup menus](../integrations/README.md), or via [Quick Search](../basics/quick_search.md) (`tool:::query`).

| Tool | Quick-search keyword | Guide |
|---|---|---|
| Bible Podcast | `podcast` | [tool_podcast](tool_podcast.md) |
| Bible Audio | `audio` | [tool_audio](tool_audio.md) |
| Book Analysis | `analysis` | [tool_analysis](tool_analysis.md) |
| Chapter Summary | `summary` | [tool_summary](tool_summary.md) |
| Bible Commentaries | `commentary` | [tool_commentary](tool_commentary.md) |
| Cross-references | `xrefs` | [tool_xrefs](tool_xrefs.md) |
| Treasury of Scripture Knowledge | `treasury` | [tool_treasury](tool_treasury.md) |
| Bible Promises (collections) | `promises_` | [tool_promises](tool_promises.md) |
| Bible Parallels (collections) | `parallels_` | [tool_parallels](tool_parallels.md) |
| Bible Timelines | `timelines` | [tool_timelines](tool_timelines.md) |
| Bible Chronology | `chronology` | [tool_chronology](tool_chronology.md) |
| Books | `books` | [tool_books](tool_books.md) |
| Morphology | `morphology` | [tool_morphology](tool_morphology.md) |
| Chapter Indexes | `chapterindexes` | [tool_chapter_indexes](tool_chapter_indexes.md) |
| Compare Chapter | `comparechapter` | [tool_compare_chapter](tool_compare_chapter.md) |
| Verse Indexes | `indexes` | [tool_indexes](tool_indexes.md) |
| Bible Notes (Google Drive) | `notes` | [tool_notes](tool_notes.md) |
| Notepad | `notepad` | [tool_notepad](tool_notepad.md) |
| AI Chat / Partner / Agent | `chat`, `partner`, `agent` | [AI Features](../ai_features/README.md) |

Search pages are listed in [Search Guides](../search/README.md).

Most tools can open on the verse you are reading ([Sync](../layout/sync.md)); inputs usually support **Enter** to run and **Up arrow** to restore the previous query ([Keyboard Shortcuts](../basics/keyboard_shortcuts.md)).
