# BibleMate AI (CLI & MCP)

BibleMate AI Web combines the web UI of [BibleMate AI](https://github.com/eliranwong/biblemate) with [UniqueBible](https://github.com/eliranwong/UniqueBible) resources.

- The companion **BibleMate AI** project provides the CLI version, the MCP server, the full Agent Mode backend and Bible data (`biblematedata` installs the data).
- Agent Mode on servers that disable the web version points users to the CLI ([availability](../ai_features/usage_limits.md)).
- The web app reuses the BibleMate tool definitions ([MCP tool integration](../ai_features/chat_tool_selection.md)) so AI agents and the UI draw on the same resources.
