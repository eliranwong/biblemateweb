# Verse Number Menu

Click a **verse number** in a Bible (or right-click a verse; also via ⋮ → `Verse Tools`) to open the verse popup menu. The verse is selected in the verse dropdown and every tool opens on it, in an empty Tool Area tab.

## Items

| Item | Description |
|---|---|
| 📋 **Copy** | Copies the verse as `[Reference] text` (tags removed) to the clipboard |
| 🔖 **Bookmark Verse** | Bookmarks the verse (manage saved bookmarks from **Tools → Bookmarks**) |
| 📒 **Add to Notepad** | Sends the verse (`[Reference] text`, HTML tags stripped) to the [Notepad](../tools/tool_notepad.md) |
| 🔊 **Bible Audio** | Plays the chapter audio synced to your Bible ([Audio](../tools/tool_audio.md)) |
| 🔗 **Cross-references** | Related passages for the verse ([Xrefs](../tools/tool_xrefs.md)) |
| 🏦 **Treasury** | Treasury of Scripture Knowledge entries ([Treasury](../tools/tool_treasury.md)) |
| 🧠 **AI Commentary** | AI-written commentary (AIC/AICTC/AICSC by interface language) ([guide](../ai_features/ai_commentary.md)) |
| 📚 **Commentaries** | Opens the commentary tool with your favourite commentary ([Commentary](../tools/tool_commentary.md)) |
| 🧬 **Morphology** | Word-by-word original-language analysis ([Morphology](../tools/tool_morphology.md)) |
| 👀 **Comparison** | Shows the verse in several Bibles at once: your primary Bible, the current Bible and the interlinear OHGBi |
| 📑 **Indexes** | Resources that reference this verse ([Verse Indexes](../tools/tool_indexes.md)) |
| 📝 **Add Note / Edit Note** | With Google Drive notes: open the verse note (Edit if one exists). Without: sends the verse to the [Notepad](../tools/tool_notepad.md) |
| 💬 **Ask BibleMate** | Sends the verse to AI Chat ([guide](../ai_features/ask_biblemate.md)) |

## Notes

- Tools open **unsynced** to the verse you clicked, so they do not jump when you scroll.
- On touch devices a tap on the verse number opens the menu.
- **Bookmark Verse**: Right-click a verse or click a verse number to **Bookmark Verse** (manage saved bookmarks from **Tools → Bookmarks**).
- **Color-Coded Highlights**: Right-click a verse or click a verse number → **Highlight** to mark it as **Key Verse**, **Promise**, **Doctrine**, or **Prayer** (theme-aware for both light and dark modes; browse/filter under **Tools → Bookmarks**).
