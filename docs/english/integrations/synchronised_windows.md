# Synchronised Windows

Integration is not just links: windows move together.

- **Chapter sync:** with [Sync](../layout/sync.md) on, a Bible in the Tool Area and the Bible Area stay on the same chapter, and tools open on your current verse.
- **Synchronised scrolling:** a parallel Bible scrolls in step with the Bible Area, so verses line up side by side.
- **Active verse:** choosing a verse scrolls to and highlights it.
- **Shared URL:** both windows are encoded in one [shareable URL](sharing_deep_links.md).

See also [Parallel Bibles](../layout/parallel_bibles.md).
