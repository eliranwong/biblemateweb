# Custom Resources

Administrators can integrate their own private data.

- Put custom Bibles in `~/biblemate/data_custom/bibles` and custom reference books in `~/biblemate/data_custom/books`.
- Users unlock them by entering the [custom token](../user_preferences/custom_token.md), or with `?t=TOKEN` in the URL for a single visit.
- Custom Bibles then appear in the Bibles menus, Preferences lists and API queries.
- The token also bypasses [usage limits](../ai_features/usage_limits.md).

See [Books](../tools/tool_books.md) and [Configuration](../server_setup/configuration.md).
