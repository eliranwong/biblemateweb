# Chapter Tools Menu

Open it from the three-dot menu → `Chapter Tools` or by right-clicking the chapter title. It acts on the selected chapter.

| Item | Description |
|---|---|
| 📋 **Copy** | Copies the whole chapter: heading plus every verse as `[n] text` |
| 📡 **Bible Podcast** | AI-generated podcast of the chapter ([Podcast](../tools/tool_podcast.md)) |
| 🔊 **Bible Audio** | Audio recording of the chapter ([Audio](../tools/tool_audio.md)) |
| 👀 **Compare Chapter** | Side-by-side multi-version chapter comparison ([Compare Chapter](../tools/tool_compare_chapter.md), configured via [Chapter Comparison](../user_preferences/chapter_comparison.md)) |
| 💎 **Chapter Summary** | AI summary ([guide](../ai_features/chapter_summary.md)) |
| 🗺️ **Chapter Map** | Opens Maps with the chapter reference (`Reference:1-180`) ([Maps](../search/search_bible_maps.md)) |
| 📑 **Chapter Indexes** | Resources that cover the whole chapter ([Chapter Indexes](../tools/tool_chapter_indexes.md)) |
| 📝 **Add Note / Edit Note** | Chapter note, only if Google Drive notes are configured ([Notes](google_drive_notes.md)) |
- **Bookmarks & Notepad**: Right-click a chapter title to **Bookmark Chapter** or **Add to Notepad** (manage saved bookmarks from the **Tools → Bookmarks** menu).
