# Quick Search Integration

The navigation-bar [quick search](../basics/quick_search.md) is a single entry point to everything:

- a Bible code (`KJV`, `OIB`) opens a Bible,
- a reference opens a chapter, `bible:::` opens it in parallel,
- `tool:::query` opens any tool or search with your query (e.g. `xrefs:::John 3:16`),
- free text runs a verse search.

Its syntax is the same `keyword:::query` language used by the [REST API](rest_api.md).
