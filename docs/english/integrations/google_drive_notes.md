# Google Drive Notes

Study notes on verses, chapters and books, stored in **your own Google Drive** (hidden app-data folder), not on the server.

## For users

1. Open the Notes tool (or any 📝 menu item) and choose `Login with Google`.
2. Authorise access to the app-data folder.
3. Notes sync across devices.

## Where notes appear

- 📝 items in the [three-dot](three_dot_menu.md), [verse](verse_menu.md), [chapter](chapter_menu.md) and [book](book_menu.md) menus.
- [Note indicators](note_indicators.md) beside verse numbers.
- Without Google configured, the verse menu offers `Add Note` to the [Notepad](../tools/tool_notepad.md).

## For administrators

Create Google OAuth credentials and set the client id/secret in the config: [Google Drive Notes Setup](../server_setup/google_drive_notes_setup.md). The same login is used to track daily limits for [Agent/Partner modes](../ai_features/usage_limits.md).

Tool guide: [Cloud Notes](../tools/tool_notes.md).
