# AI Providers & Subscriptions

BibleMate integrates many AI services behind one interface:

- API providers: Google AI, OpenAI, Anthropic, Cohere, DeepSeek, Mistral, xAI, Azure variants, Ollama Cloud, and custom endpoints.
- Signed-in subscription CLIs (when enabled by the administrator): Grok Build, Claude Code, Antigravity.
- Bring your own key, or use the server default.

Details: [AI Backends](../ai_features/ai_backends.md), [BYOK](../user_preferences/api_key_setup.md). AI features also call the integrated Bible [tools](../ai_features/chat_tool_selection.md).
