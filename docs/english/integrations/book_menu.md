# Book Tools Menu

Open it from the three-dot menu → `Book Tools` or by right-clicking the book title.

| Item | Description |
|---|---|
| ⏳ **Timelines** | Timelines for the book ([Timelines](../tools/tool_timelines.md)) |
| 🔘 **Overview** | Introduction, authorship, date, purpose |
| 📐 **Structural Outline** | Hierarchical divisions of the book |
| 🧵 **Logical Flow** | How the argument or narrative progresses |
| 🕰️ **Historical Setting** | Background and circumstances of writing |
| 🎨 **Themes** | Major theological and literary themes |
| 🏷️ **Keywords** | Significant recurring words and concepts |
| ⛪ **Theology** | Doctrines presented in the book |
| 🚩 **Canonical Placement** | How the book fits the biblical canon |
| 🌱 **Practical Living** | Applications for today |
| 💎 **Summary** | Concise summary of its message |
| 📝 **Add Note / Edit Note** | Book note, only if Google Drive notes are configured |

The ten analysis items each open [Book Analysis](../ai_features/book_analysis.md) at that section ([full guide](../tools/tool_analysis.md)).
