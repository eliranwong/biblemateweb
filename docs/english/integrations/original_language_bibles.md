# Original-Language Bibles

Five integrated Hebrew/Greek editions, each with the same [selectors](bible_selectors.md), [three-dot menu](three_dot_menu.md), verse popup, word tooltips and lexicon links.

| Code | Name | Focus |
|---|---|---|
| ORB | Original Reader's Bible | Readable original text |
| OIB | Original Interlinear Bible | Word-by-word with glosses |
| OPB | Original Parallel Bible | Original beside translation |
| ODB | Original Discourse Bible | Discourse structure |
| OLB | Original Linguistic Bible | Linguistic annotation |

Open via the Bibles or Parallel Bibles menu, or type the code in [quick search](../basics/quick_search.md).

Click a word to jump to the [lexicon](word_tooltips.md), or hover over a word for tooltips and [mutual word & clause highlighting](word_tooltips.md#mutual-word--clause-highlighting) across parallel panes; use 🧬 Morphology in the [verse menu](verse_menu.md) for full analysis.
