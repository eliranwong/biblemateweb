# Cross-reference & Verse Links

References inside Bible text (translation notes, cross-reference markers) and inside tool output (commentaries, notes, search results) are clickable.

| Link | Result |
|---|---|
| Verse reference (e.g. `John 3:16`) | Opens that chapter in a Bible window |
| Cross-reference marker | Opens the referenced passage |
| Verse number | Opens the [verse menu](verse_menu.md) |

## Which window?

- With [Sync](../layout/sync.md) **on**, the link changes the window that contains the link.
- With Sync **off**, it opens the passage in the *other* window, so you can keep your place while following a reference.

Works in translation Bibles and tools alike.
