# Three-Dot Menu

The `⋮` (`more_vert`) button sits right next to the book, chapter and verse selectors at the top of every Bible. It gathers navigation, search, study tools and notes in one place.

It works the same in the translation Bibles and the original-language Bibles (ORB, OIB, OPB, ODB, OLB). Results open in an **empty Tool Area tab** so that your Bible stays in view.

## Items

### Navigation
| Item | Description |
|---|---|
| ◀️ **Prev Chapter** | Go to the previous chapter, rolling over to the last chapter of the previous book (and from Genesis 1 to the last book) |
| ▶️ **Next Chapter** | Go to the next chapter, rolling over to the next book |

### Search (Bible Area only)
These open the Verses search in the Tool Area, using the text currently held in the tool query.

| Item | Description |
|---|---|
| 🔍 **Search *version*** | Search the whole Bible in the selected version, e.g. `Search NET` |
| 🔍 **Search OT** | Restrict the search to the Old Testament |
| 🔍 **Search NT** | Restrict the search to the New Testament |
| 🔍 **Search *book*** | Restrict the search to the selected book, e.g. `Search John` |

See [Bible Verse Search](../search/search_bible_verses.md).

### Study tools
| Item | Description |
|---|---|
| 🧩 **Book Tools** | Opens the [Book Tools menu](book_menu.md) for the selected book |
| 🧩 **Chapter Tools** | Opens the [Chapter Tools menu](chapter_menu.md) for the selected chapter |
| 🧩 **Verse Tools** | Opens the [Verse menu](verse_menu.md) for the selected verse |

(The original-language Bibles show these with a 💡 icon.)

### Notes (only when Google Drive notes are configured)
| Item | Description |
|---|---|
| 📝 **Book Note** | Open the note for the whole book |
| 📝 **Chapter Note** | Open the note for the chapter |
| 📝 **Verse Note** | Open the note for the verse |

See [Google Drive Notes](google_drive_notes.md).

## Tips

- The tools act on the book/chapter/verse **currently chosen in the selectors**, so you can pick a verse in the dropdown and use the menu without scrolling.
- In a parallel Bible (Tool Area) the search items are not shown.
