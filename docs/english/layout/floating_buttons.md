# Floating Buttons

Two small round buttons float in the bottom-right corner of the screen.

| Button | Icon | Tooltip | Action |
|---|---|---|---|
| Swap Layout | `swap_horiz` | Swap Layout | Cycles through [layout modes](toggle_layout.md) |
| Go | `menu_book` | Select Bible Verse | Opens the [Bible Selection Dialog](bible_selection_dialog.md) |

## Moving the buttons

Each button is **draggable**. Drag it and drop it anywhere; it snaps to the drop position. This is useful if a button covers content you want to read. Positions reset when the page is reloaded.

## Showing or hiding

| Button | Storage key | Default |
|---|---|---|
| Swap Layout | `layout_swap_button` | On |
| Go | `bible_select_button` | On |

Toggle them:

- **Desktop:** Settings (gear) menu → switch beside `Swap` or `Go`.
- **Mobile:** open the left drawer (hamburger icon) and use the `Swap` / `Go` switches.

The choice is saved automatically.
