# URL Parameters

The address bar updates as you navigate, so any view can be bookmarked or shared. Example: `/?bbt=NET&bb=43&bc=3&bv=16&l=2`.

| Param | Meaning |
|---|---|
| `l` | Layout: `1` Bible only, `2` Bible & Tool, `3` Tool only |
| `bbt`, `bb`, `bc`, `bv` | Bible Area: version, book number, chapter, verse |
| `tool` | Tool Area content: `bible`, `audio`, `chronology`, a search or tool name |
| `tbt`, `tb`, `tc`, `tv` | Tool Area: version, book, chapter, verse |
| `tq` | Tool query |
| `s` | Sync on/off |
| `d` | Dark mode on/off |
| `fs` | Font size (%) |
| `pc`, `sc`, `nc` | Primary, secondary, negative colors |
| `lang` | Interface language |
| `m` | Display menu (`false` hides the header) |
| `k` | Keep valid parameters in history |
| `t` | Custom token for this visit only (not stored; useful on public devices) |

Books are numbered 1–66.
