# Quick Search

The input box in the header (on mobile, in the left drawer). It has autocomplete for book names, tool names and Bible versions. Press **Enter** to run.

## What you can type

| Input | Result |
|---|---|
| A Bible version, e.g. `KJV` | Opens that Bible in the Bible Area |
| One verse reference, e.g. `John 3:16` | Opens that chapter in the Bible Area |
| `KJV:::John 3:16` | Opens it in the specified version |
| `bible:::John 3:16` | Opens it as a parallel Bible in the Tool Area |
| `bible:::KJV:::John 3:16` | Parallel Bible with specified version |
| `tool:::query`, e.g. `xrefs:::John 3:16` | Opens a tool with the query |
| Anything else, or multiple references | Searches verses in the Tool Area |

The box is cleared after a search. Tool names available for `tool:::` are the names offered by autocomplete.
