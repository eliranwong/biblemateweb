# Tabs Management

Both areas have independent tabs. Bible Area tabs are named `Bible 1, 2, ...`; Tool Area tabs `Tool 1, 2, ...` (relabelled to the loaded content).

## Add a tab

| Area | Menu | Item |
|---|---|---|
| Bible | Bibles (`local_library`) | Add Bible Tab |
| Parallel | Parallel Bibles (`devices_fold`) | Add Parallel Tab |
| Tool | Tools (`build`) | Add Tool Tab |

Parallel and Tool tabs both belong to the Tool Area.

## Close tabs

- Click the small **x** on a tab to close that tab (even if it is not active).
- Menu → `Close Bible Tab`, `Close Parallel Tab` or `Close Tool Tab` closes the active tab.
- Menu → `Close Others` closes all but the active tab.
- The **last remaining tab cannot be closed** (a warning appears).

## Persistence

Tab contents are stored in your user storage and restored on the next visit. Closed tabs are removed from storage.

## Default number of tabs

How many tabs open on a fresh start is set in Preferences:

- [Bible Tabs](../user_preferences/default_number_of_tabs1.md) (`default_number_of_tabs1`, default 3)
- [Tool Tabs](../user_preferences/default_number_of_tabs2.md) (`default_number_of_tabs2`, default 3)

## Tips

- Keep one tab per Bible version to compare translations.
- Search results load into the active Tool tab; open a new tab first to keep earlier results.
