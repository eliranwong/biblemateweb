## Related preferences

- [Similar Entries](../user_preferences/top_similar_entries.md) and [Similar Verses](../user_preferences/top_similar_verses.md) limit semantic search results.
- [Hebrew](../user_preferences/hebrew_lexicon.md) / [Greek](../user_preferences/greek_lexicon.md) lexicon defaults.

## Quick access

Type any text without a verse reference in the [Quick Search](quick_search.md) box to search verses directly.
