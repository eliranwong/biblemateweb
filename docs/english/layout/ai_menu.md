# AI Menu

The **AI** menu (`auto_awesome` icon) offers:

| Item | Opens |
|---|---|
| Book Analysis | AI analysis of a book ([guide](../tools/tool_analysis.md)) |
| Chapter Summary | AI summary of a chapter ([guide](../tools/tool_summary.md)) |
| Commentary | AI commentary on the current passage ([guide](../tools/tool_commentary.md)) |
| AI Chat | Chat page |
| Partner Mode | Interactive study partner |
| Agent Mode | Autonomous agent |

All open in the Tool Area.

## Configuration

- Choose your provider, key and model in [Preferences](../user_preferences/README.md) – see [BYOK](../user_preferences/api_key_setup.md).
- Administrators may limit usage of Agent and Partner modes; using your own key bypasses those limits.
