# Tools

The **Tools** menu (`build` icon) opens study tools in the Tool Area.

## Tab items

`Add Tool Tab`, `Close Tool Tab`, `Close Others` – see [Tabs Management](tabs_management.md).

## Synchronised tools

Most tools open at the verse currently shown in the Bible Area (see [Sync](sync.md)). `Books` does not sync.

## Open a tool from Quick Search

Type `toolname:::query` (e.g. `xrefs:::John 3:16`) – see [Quick Search](quick_search.md).
