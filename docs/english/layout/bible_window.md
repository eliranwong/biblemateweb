# Bible Window

The **Bible Area (Area 1)** is the main reading window.

## Open a Bible

From the **Bibles** menu (`local_library` icon):

- Your **Primary** and **Secondary** Bibles ([preferences](../user_preferences/primary_bible.md)).
- Original-language Bibles: `ORB` Original Reader's Bible, `OIB` Interlinear, `OPB` Parallel, `ODB` Discourse, `OLB` Linguistic.
- Custom Bibles (if a valid [custom token](../user_preferences/custom_token.md) is active) and all other Bibles configured on the server.

Selecting a Bible loads it into the **active tab**. If the Quick Search or selected text contains a verse reference, the Bible opens at that verse.

## Navigate

- [Bible Selection Dialog](bible_selection_dialog.md) via the Go button.
- [Quick Search](quick_search.md), e.g. type `John 3:16`.
- [Context menus](context_menus.md) on verses.

## Tab label and browser title

The tab label shows the Bible version. The browser title is updated to `[Version] Reference`, and the address bar is updated so every location can be bookmarked ([URL Parameters](url_parameters.md)).

## Per-tab memory

Each tab remembers its Bible, book, chapter and verse and restores them when you return.
