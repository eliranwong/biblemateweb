# Context Menus

Right-click (long-press on touch screens) on a book title, chapter title or verse in a Bible to open a context menu. The result opens in an empty Tool Area tab.

## Verse

Copy, Bible Audio, Cross-references, Treasury, AI Commentary, Commentaries, Morphology, Comparison, Indexes, Add/Edit Note (or add to Notepad), Ask BibleMate.

## Chapter

Chapter-level actions such as maps, notes and AI features.

## Book

Timelines, and AI analysis sections: Overview, Structural Outline, Logical Flow, Historical Setting, Themes, Keywords, Theology, Canonical Placement, Practical Living, Summary; plus Add/Edit Note if Google notes are configured.

> [!NOTE]
> Note indicators can be turned on/off with `Notes` in the [Settings Menu](settings_menu.md).
