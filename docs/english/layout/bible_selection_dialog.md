# Bible Selection Dialog

A quick way to navigate to any verse without typing.

## Open

Click the **Go** [floating button](floating_buttons.md) (book icon, tooltip `Select Bible Verse`).

## Steps

1. **Select Book** – a grid of all 66 books (names follow your [interface language](../user_preferences/ui_language.md)). The current book is outlined.
2. **Select Chapter** – chapters of that book. The current chapter is outlined.
3. **Select Verse** – verses of that chapter.

Choosing a verse closes the dialog and opens that location in the active Bible tab, keeping the current Bible version. If [Sync](sync.md) is on, a Bible in the Tool Area follows.

Use the `x` button in the dialog header to close without selecting.
