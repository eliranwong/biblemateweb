# Mobile Layout

On narrow screens, the header shows a **hamburger button** that opens a left drawer, replacing the desktop title and quick search box.

## Drawer contents

- Avatar/title button (shows [URL & QR code](url_qr_code.md))
- [Quick Search](quick_search.md)
- Switches: `Go`, `Swap`, `Tabs`, `Notes`, `Tooltip`, `Sync`, `Fullscreen`, `Dark Mode`
- Expandable lists of Bibles and tools
- Layout options: Bible Only, Tool Only, Bible & Tool

The drawer closes automatically after a choice.

## Portrait mode

In portrait orientation the two areas stack vertically. Use [Toggle Layout](toggle_layout.md) to give a single area the full screen.
