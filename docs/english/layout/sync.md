# Sync

When **Sync** is on, the Bible Area and the Tool Area stay on the same book and chapter.

| Key | Default |
|---|---|
| `sync` | On |

## Toggle

- **Desktop:** Settings (gear) → `Sync` switch.
- **Mobile:** left drawer → `Sync` switch.
- **URL:** `s=true` or `s=false` ([URL Parameters](url_parameters.md)).

## Behaviour

- Changing the chapter in the Bible Area also moves a **parallel Bible** or an active **chapter tool** (`Bible Podcast`, `Bible Audio`, `Compare Chapter`, `Chapter Summary`, `Chapter Indexes`) in the Tool Area (and vice versa).
- Tools opened with sync (Audio, Commentary, Xrefs, Treasury, Morphology, Indexes, etc.) start at the verse shown in the Bible Area.
- With Sync off, tools keep their own book/chapter/verse.
