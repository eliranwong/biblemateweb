# Search Guides

Open from the **Search** menu (`search` icon) or by keyword in [Quick Search](../basics/quick_search.md) (e.g. `verses:::love`).

| Search | Keyword | Guide |
|---|---|---|
| Verses (literal, regex, semantic) | `verses` | [search_bible_verses](search_bible_verses.md), [advanced examples](search_bible_verses_examples.md) |
| Parallels | `parallels` | [search_bible_parallels](search_bible_parallels.md) |
| Promises | `promises` | [search_bible_promises](search_bible_promises.md) |
| Topics | `topics` | [search_bible_topics](search_bible_topics.md) |
| Characters | `characters` | [search_bible_characters](search_bible_characters.md) |
| Relationships | `relationships` | [search_bible_relationships](search_bible_relationships.md) |
| Locations | `locations` | [search_bible_locations](search_bible_locations.md) |
| Maps | `maps` | [search_bible_maps](search_bible_maps.md) |
| Names | `names` | [search_bible_names](search_bible_names.md) |
| Dictionaries | `dictionaries` | [search_dictionaries](search_dictionaries.md) |
| Encyclopedias | `encyclopedias` | [search_encyclopedias](search_encyclopedias.md) |
| Lexicons | `lexicons` | [search_lexicons](search_lexicons.md) |

## Settings that affect search

- [Search Mode](../user_preferences/search_mode.md) (literal / regex / semantic)
- [Case Sensitivity](../user_preferences/search_case_sensitivity.md)
- [Similar Entries](../user_preferences/top_similar_entries.md), [Similar Verses](../user_preferences/top_similar_verses.md)
- Semantic search needs an embedding model: [Semantic Search Setup](../server_setup/semantic_search_setup.md)
- `config.verses_limit` caps result size ([Configuration](../server_setup/configuration.md))

Programmatic equivalents: [REST API](../integrations/rest_api.md).
