# Bibles

BibleMate AI Web offers translation Bibles (100+ on a full install, including Hebrew and Greek source texts) and five original-language Bibles. All share the same [selectors](../integrations/bible_selectors.md), [three-dot menu](../integrations/three_dot_menu.md), [verse popup](../integrations/verse_menu.md) and [sync](../layout/sync.md) behaviour.

| Bible | Guide |
|---|---|
| Translation Bibles (e.g. KJV, NET, CUV) | [bible_translations](bible_translations.md) |
| ORB – Original Reader's Bible | [original_reader](original_reader.md) |
| OIB – Original Interlinear Bible | [original_interlinear](original_interlinear.md) |
| OPB – Original Parallel Bible | [original_parallel](original_parallel.md) |
| ODB – Original Discourse Bible | [original_discourse](original_discourse.md) |
| OLB – Original Linguistic Bible | [original_linguistic](original_linguistic.md) |

Open any of them from the [Bibles menu](../basics/menu_bibles.md) or [Parallel Bibles menu](../basics/menu_parallel_bibles.md), or by typing the code in [Quick Search](../basics/quick_search.md). Set your favourites with [Primary](../user_preferences/primary_bible.md) and [Secondary](../user_preferences/secondary_bible.md) Bible.
