# Install Antigravity CLI

The Antigravity CLI (`agy`) can be used as a subscription-based AI backend (`antigravity`) in BibleMate AI Web – see [AI Backends](../ai_features/ai_backends.md) and `config.show_antigravity` in the [Configuration Guide](../server_setup/configuration.md).

Launch the Ubuntu environment first ([install_ubuntu.md](install_ubuntu.md)):

```
ubuntu
```

Install:

```
curl -fsSL https://antigravity.google/cli/install.sh | bash
```

Start it and sign in:

```
agy
```
