# 譯本聖經

任何位於 `~/biblemate/data/bibles`（以及在使用[自訂權杖](../user_preferences/custom_token.md)時的 `data_custom/bibles`）中的 `.bible` 模組，都會自動出現在選單中（參見[數據與資源](../server_setup/data_and_resources.md)）。

## 功能特點

- 支援全章顯示，並附有可點擊的經文編號（[經文選單](../integrations/verse_menu.md)）。
- 內嵌於經文中的經文串珠與註解標記（[經文連結](../integrations/text_links.md)）。帶有 Strong 編號及形態學字詞標註的聖經支援[浮動提示](../integrations/word_tooltips.md)，不僅可**直接查閱希伯來文／希臘文詞典**，還能在不同譯本之間以及譯本與希伯來文／希臘文原文之間進行**平行對應字詞高亮**。
- 📝 筆記指示圖示（[指南](../integrations/note_indicators.md)）。
- 底部及三點選單中均提供 `◀️ Prev Chapter` / `Next Chapter ▶️` 按鈕。
- 頂部設有版本、書卷、章數與節數選擇器（[指南](../integrations/bible_selectors.md)）。
- 在工具區域中，聖經會以[平行聖經](../layout/parallel_bibles.md)形式呈現，並支援同步滾動。

## 開啟經文

可使用[快速搜索](../basics/quick_search.md)（`KJV:::John 3:16`）、[「開啓」按鈕](../layout/bible_selection_dialog.md)或 URL 參數（`?bbt=KJV&bb=43&bc=3&bv=16`）。
