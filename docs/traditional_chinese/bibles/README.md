# 聖經

BibleMate AI Web 提供譯本聖經（完整安裝下超過 100 種，包含希伯來文和希臘文原文文本）以及五部原文聖經。全部共用相同的[選擇器](../integrations/bible_selectors.md)、[三點選單](../integrations/three_dot_menu.md)、[經文選單](../integrations/verse_menu.md)與[同步](../layout/sync.md)功能。

| 聖經 | 指南 |
|---|---|
| 譯本聖經（例如 KJV、NET、CUV） | [譯本聖經](bible_translations.md) |
| ORB – 原文讀本聖經 (Original Reader's Bible) | [原文讀本聖經](original_reader.md) |
| OIB – 原文逐字對照聖經 (Original Interlinear Bible) | [原文逐字對照聖經](original_interlinear.md) |
| OPB – 原文平行聖經 (Original Parallel Bible) | [原文平行聖經](original_parallel.md) |
| ODB – 原文語法結構聖經 (Original Discourse Bible) | [原文語法結構聖經](original_discourse.md) |
| OLB – 原文語言分析聖經 (Original Linguistic Bible) | [原文語言分析聖經](original_linguistic.md) |

可從[「聖經」選單](../basics/menu_bibles.md)或[「平行聖經」選單](../basics/menu_parallel_bibles.md)開啟其中任何一部，或在[快速搜索](../basics/quick_search.md)中輸入其代碼。你也可以透過[主要](../user_preferences/primary_bible.md)與[次要](../user_preferences/secondary_bible.md)聖經設定偏好的常用版本。
