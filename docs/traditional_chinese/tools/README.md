# 研經工具

工具可從「**工具**」選單（`build` 圖示）、經文／章／書卷[彈出選單](../integrations/README.md)開啟於**工具區域**，或透過[快速搜索](../basics/quick_search.md)（`tool:::query`）開啟。

| 工具 | 快速搜索關鍵字 | 指南 |
|---|---|---|
| 聖經廣播 | `podcast` | [聖經廣播](tool_podcast.md) |
| 聖經語音 | `audio` | [聖經語音](tool_audio.md) |
| 書卷分析 | `analysis` | [書卷分析](tool_analysis.md) |
| 全章摘要 | `summary` | [全章摘要](tool_summary.md) |
| 聖經註釋 | `commentary` | [聖經註釋](tool_commentary.md) |
| 經文串珠 | `xrefs` | [經文串珠](tool_xrefs.md) |
| 經文寶庫 | `treasury` | [經文寶庫](tool_treasury.md) |
| 聖經應許（合輯） | `promises_` | [聖經應許](tool_promises.md) |
| 平行經文（合輯） | `parallels_` | [平行經文](tool_parallels.md) |
| 聖經時間軸 | `timelines` | [聖經時間軸](tool_timelines.md) |
| 聖經時序 | `chronology` | [聖經時序](tool_chronology.md) |
| 參考書籍 | `books` | [參考書籍](tool_books.md) |
| 形態學分析 | `morphology` | [形態學分析](tool_morphology.md) |
| 全章索引 | `chapterindexes` | [全章索引](tool_chapter_indexes.md) |
| 整章譯本對照 | `comparechapter` | [整章譯本對照](tool_compare_chapter.md) |
| 單節索引 | `indexes` | [單節索引](tool_indexes.md) |
| 聖經筆記（Google 雲端硬碟） | `notes` | [聖經筆記](tool_notes.md) |
| 筆記本 | `notepad` | [筆記本](tool_notepad.md) |
| 對話模式 / 夥伴模式 / 代理模式 | `chat`, `partner`, `agent` | [AI 功能](../ai_features/README.md) |

搜索頁面列於[搜索指南](../search/README.md)。

多數工具皆能開啟於您正在閱讀的經文（[同步](../layout/sync.md)）；輸入框通常支援按 **Enter** 執行，以及按**向上箭頭鍵**還原上一個查詢（[鍵盤快捷鍵](../basics/keyboard_shortcuts.md)）。
