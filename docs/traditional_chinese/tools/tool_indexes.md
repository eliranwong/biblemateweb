# **單節索引指南**

本工具顯示特定聖經經節的綜合參考資訊，包括與該精確經節相關的人物、地點、主題、應許與平行經文。

## **什麼是單節索引？**

單節索引為個別聖經經節提供詳盡的參考資訊。與展示整章資訊的全章索引不同，本工具聚焦於單一經節，展示該節中具體提及或與之相關的所有重要人物、地點、主題、字典詞條以及相關資源合輯。

## **如何使用單節索引**

1. **選擇經節**：使用聖經選單選擇具體的書卷、篇章與經節。
2. **點擊「開啓」**：載入該經節的索引。
3. **瀏覽分類**：展開任何分類即可查看與該經節相關的所有項目。
4. **點擊參照**：點擊任何項目即可深入探索詳細內容。

## **索引分類**

本工具將資訊組織為七個不同分類：

### **1. 聖經人物**

**圖示**：👥 群組（Groups）

列出該節提及或與之相關的所有重要人物：
- 個人或群體的名稱
- 簡要身分資訊
- 相關聖經經文引用
- 指向完整人物資料的連結

**範例**：在約翰福音 3:16 中，您可能會看到有關神、耶穌與世人的條目。

### **2. 聖經地點**

**圖示**：📍 地點（Place）

顯示該節所參照的所有地理位置：
- 地點名稱（城市、地區、地標）
- 簡要地理背景
- 該地點出現的相關經文
- 指向附帶地圖的詳細地點資訊連結

**範例**：在馬太福音 2:1 中，您會看到伯利恆及其地理細節。

### **3. 聖經主題**

**圖示**：🏷️ 分類（Category）

標記該節所呈現的神學、道德與主題要點：
- 神學概念（信心、救恩、恩典）
- 道德主題（愛、順服、罪）
- 文化主題（律法、節期、習俗）
- 指向延伸主題探討的連結

**範例**：在羅馬書 3:23 中，主題包括「罪」、「人類普遍處境」與「人的墮落」。

**注意**：「聖經主題」區塊預設為開啟狀態，便於快速查閱。

### **4. 聖經字典**

**圖示**：📚 字典（Dictionary）

為該節使用的核心詞彙提供字典定義：
- 字詞定義
- 神學解釋
- 歷史背景
- 聖經語境中的用法

### **5. 百科全書**

**圖示**：💎 深度知識（Deep Knowledge）

連結至全面的百科全書文章，內容涵蓋：
- 該節中的人物、地點與事件
- 詳細的歷史與神學背景
- 與相關聖經資料的經文串珠參照
- 學術見解與考古發現

### **6. 聖經應許**

**圖示**：🎁 禮物（Gift）

顯示與該節相關的神的應許合輯：
- 依主題分類組織（例如「供應的應許」、「同在的應許」）
- 每個應許合輯均有可點擊的標籤（Chips）
- 每個標籤顯示主題名稱
- 點擊標籤即可載入包含所有相關經文的完整應許合輯

**範例**：在腓立比書 4:19 中，您可能會看到「關於供應的應許」或「關於神充足供給的應許」標籤。

### **7. 平行經文**

**圖示**：🔗 連結（Link）

顯示福音書平行經文與相關經文段落：
- 其他福音書中的平行記載（針對福音書經文）
- 不同書卷中的類似事件
- 具有相似主題或內容的相關敘事
- 對照合參經文

**範例**：在馬太福音 14:22-33（耶穌在水面上行走），您會看到馬可福音 6:45-52 與約翰福音 6:16-21 中的平行記載。

## **功能特點**

### **可收展區塊**

- 每個分類皆可獨立展開或摺疊
- 「聖經主題」區塊預設自動開啟
- 空分類會顯示「找不到此類別的條目」
- 點擊分類標題即可展開／摺疊內容

### **互動式連結**

- **人物連結**：點擊可在新標籤頁中開啟詳細的人物檔案資料
- **地點連結**：點擊可探索地理資訊、地圖與歷史背景
- **主題連結**：點擊可查看全面的主題探討
- **參照標籤**：點擊應許或平行經文標籤即可檢視完整合輯

### **智慧資料展示**

- 適當情況下以表格形式呈現內容
- 相關經文分組歸類
- 每個分類中的多個條目均有清晰分隔
- 不隱藏任何資料——即使某分類為空，也會清楚顯示提示訊息

## **單節索引與全章索引的差異**

| 單節索引 | 全章索引 |
| :---- | :---- |
| 僅顯示單一特定經節的條目 | 顯示整章的所有條目 |
| 精準、聚焦的資訊 | 匯總、宏觀的檢視 |
| 最適合逐節研經 | 最適合章節概覽 |
| 必須指定特定經節 | 僅需選擇章節 |
| 體積較小、更具針對性的結果集 | 體積較大、更全面的結果集 |

## **高效使用技巧**

1. **單節精讀**：對單一經節進行深度分析時使用。
2. **經文串珠研究**：探索經節中提及的人物與地點，進行更深入的研究。
3. **專題研經**：尋找與特定主題或核心信息相關的所有經文。
4. **歷史背景**：利用地點與百科全書區塊了解經文的歷史情境。
5. **領受應許**：辨明哪些聖經應許適用於特定經節。
6. **平行對照**：研究同一事件在不同記載中如何被描述。
7. **講道預備**：為講道徹底研究具體的經文。

## **工作流程範例**

### **深度單節分析——約翰福音 3:16**

1. 載入約翰福音 3:16 的單節索引
2. 打開「聖經主題」查看：「愛」、「救恩」、「永生」、「信心」
3. 點擊「救恩」主題以深入探索其神學深度
4. 查看「聖經應許」尋找有關永生的相關應許
5. 利用百科全書條目獲取詳細的神學背景

### **平行經文研讀——馬太福音 5:3**

1. 載入馬太福音 5:3 的單節索引
2. 查看「平行經文」找到路加福音 6:20（平行經文）
3. 點擊平行經文標籤載入並對照兩處記載
4. 留意措辭與語境上的差異
5. 利用主題區塊識別共通的主題

### **歷史背景——但以理書 1:1**

1. 載入但以理書 1:1 的單節索引
2. 打開「聖經地點」查看耶路撒冷與巴比倫
3. 點擊地點連結檢視地圖與地理背景
4. 查看「百科全書」了解巴比倫征服的歷史背景
5. 檢閱「聖經人物」獲取尼布甲尼撒的相關資訊

## **從結果中導覽**

- **點擊聖經經文引用**：在聖經區域中開啟該經文段落
- **點擊人物／地點名稱**：在工具區域中開啟詳細資訊
- **點擊字典／百科全書連結**：開啟詳盡的文章
- **點擊應許／平行經文標籤**：載入完整合輯以供研讀
- **點擊主題連結**：開啟專題探討與相關經文
