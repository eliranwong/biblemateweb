# **聖經廣播指南**

本工具以廣播節目形式提供欽定版（KJV）聖經按卷錄製的語音朗讀，讓您能夠透過按章分段播放，連續聆聽長篇聖經內容。

## **什麼是聖經廣播？**

「聖經廣播」播放器讓您聆聽 KJV 聖經全書卷的有聲誦讀。與逐節播放的「聖經語音」工具不同，「聖經廣播」將音訊整理為章節片段，非常適合以連續播放的方式沉浸於大段經文中。

## **如何使用廣播播放器**

### **基本播放操作**

1. **選擇書卷**：使用書卷下拉式選單選擇聖經 66 卷書中的任一卷。
2. **選擇篇章**：選擇要從哪一章開始播放。
3. **點擊「開啓」**：載入該書卷的廣播播放器。
4. **播放**：點擊任何篇章分段旁的語音圖示（🔊）即可開始播放。
5. **自動接續**：當前分段播放完畢時，播放器會自動前進至下一分段。

### **導覽方式**

- **書卷下拉式選單**：從聖經全部 66 卷書中選擇
- **篇章下拉式選單**：選擇起始篇章
- **「開啓」按鈕**：套用您的選擇並載入廣播內容
- **經節選單**：不使用（廣播播放器按章分段）

## **播放器控制項**

| 控制項 | 功能 |
| :---- | :---- |
| **音量圖示** | 點擊任何分段旁的圖示以開始／停止播放 |
| **語音播放器** | 標準 HTML5 音訊控制項（播放、暫停、快轉／倒轉、音量） |
| **循環開關** | 開啟後，該書卷播畢時會自動從頭重新播放 |

## **功能特點**

### **按章分段設計**

- 每章可細分為多個音訊片段
- 音訊片段在章內依序播放
- 適合長時間聆聽的自然分段點

### **自動推進播放**

播放器會自動：
- 當前片段播畢後自動前進至下一片段
- 流暢無縫地播放章節內各片段
- 在停用循環模式時自動推進至下一卷書

### **循環模式**

開啟「Loop」（循環）開關可：
- 當該書卷結束時，自動從開頭重新開始播放
- 非常適合複習或深度聆聽特定書卷
- 播放過程中可隨時切換開啟／關閉

### **自動載入下一卷書**

當停用循環模式且全書播放完畢時：
- 自動依序載入下一卷書
- 從創世記連續播放至啟示錄
- 循環往復（啟示錄 → 創世記）

### **章節標題**

每個分段均顯示：
- 書卷簡寫（例如：「Gen」、「John」、「Rev」）
- 篇章或分段編號
- 描述性標題（擷取自檔案名稱）

### **視覺狀態提示**

- **播放中**：🔊（揚聲器圖示）
- **未播放**：🔇（靜音圖示）
- **當前標題**：顯示於頂部，播放時即時更新
- **懸停效果**：游標懸停時分段項目會醒目突顯

## **音訊格式**

### **內容規格**

- **聖經版本**：欽定版（King James Version，KJV）
- **檔案格式**：MP3 音訊檔案
- **音質水準**：專業播音員朗讀
- **組織架構**：按書卷與篇章分層管理

### **檔案結構**

廣播播放器採用：
- 每卷書配備播放清單檔案（`.m3u`）
- 每卷書包含多個音訊片段
- 數字編號分段以確保正確播放順序

- 採用具廣泛相容性的 MP3 格式
- 循序命名的檔案確保正確播放次序
- 無需網際網路連線（本機檔案）

- **方向鍵**：快轉／倒轉
- **音量鍵**：調整音量

## **疑難排解**

**無聲音播放：**
- 檢查廣播音訊檔案是否已正確安裝
- 確認選取了正確的書卷
- 確保裝置音量已開啟
- 若問題持續，嘗試使用其他瀏覽器

**分段未自動推進：**
- 檢查循環模式設定
- 驗證播放清單檔案的完整性
- 重新載入播放器

**缺少部分書卷：**
- 並非所有書卷都配備了廣播音訊檔案
- 檢查資料目錄中的可用內容
- 視需要下載補充的廣播音訊檔案
