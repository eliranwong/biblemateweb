# **筆記本指南**

本工具提供本地筆記本，供您以 Markdown 格式撰寫個人研經筆記，並支援預覽排版效果與下載儲存筆記。

## **什麼是筆記本？**

「筆記本」是一個本地筆記記錄工具，允許您使用 Markdown 語法撰寫研經筆記。您的筆記會保存在瀏覽器的本地儲存空間中，並可隨時下載為檔案。非常適合用於隨手記錄心得、整理研經大綱，或將個人靈修感悟保存在本機裝置上。

## **如何使用筆記本**

1. **開啟筆記本**：從工具選單中選擇「筆記本」。
2. **開始鍵入**：筆記本開啟時預設為「編輯模式」，即可立即開始鍵入。
3. **使用 Markdown 排版**：運用 Markdown 語法為筆記進行格式化排版。
4. **切換至閱讀模式**：點擊「閱讀模式」即可查看渲染後的排版預覽。
5. **儲存或下載**：使用工具列按鈕管理您的筆記。

## **工具列功能**

筆記本包含一個具備多項實用功能的工具列：

| 按鈕 | 圖示 | 功能 |
| :---- | :---- | :---- |
| **閱讀模式 / 編輯模式** | 👁️ / ✏️ | 在純文字編輯與排版預覽之間切換 |
| **下載** | ⬇️ | 將筆記下載為 `.md` 檔案 |
| **匯入** | ⬆️ | 上傳並匯入 `.md` 或 `.txt` 檔案 |
| **清除** | 🗑️ | 刪除所有內容（具備確認對話方塊） |

## **編輯模式**

在「編輯模式」下，您可以：
- 在文字區域中自由輸入
- 使用 Markdown 語法排版
- 編輯既有內容
- 從其他來源複製並貼上文字

文字區域具備：
- 全高度設計以提供最大書寫空間
- 開啟工具時自動聚焦輸入框
- 自動儲存於瀏覽器本地空間

## **閱讀模式**

在「閱讀模式」下，您的 Markdown 文本將渲染為格式精美的 HTML：
- 標題轉為各級樣式標題
- 清單正確排版
- 連結均可直接點擊
- 表格優雅清晰展示
- 聖經經文引用自動轉為可點擊連結

**提示**：在下載或複製筆記之前，先切換至「閱讀模式」以檢視最終排版效果。

## **Markdown 語法格式**

筆記本支援標準 Markdown 語法：

### **標題**

```markdown
# 標題 1
## 標題 2
### 標題 3
```

### **強調**

```markdown
*斜體文字*
**粗體文字**
***粗斜體文字***
```

### **清單**

```markdown
- 項目符號 1
- 項目符號 2
  - 巢狀項目

1. 編號項目 1
2. 編號項目 2
```

### **連結**

```markdown
[連結文字](https://example.com)
```

### **表格**

```markdown
| 欄位 1 | 欄位 2 |
| -------- | -------- |
| 資料 1   | 資料 2   |
```

### **程式碼區塊**

```markdown
```
程式碼區塊
```
```

### **聖經經文引用**

只需直接輸入聖經經文引用，在閱讀模式下即可自動轉為可點擊連結：
```
John 3:16
Genesis 1:1-3
Romans 8:28-39
```

## **功能特點**

### **本地儲存**

- 筆記自動儲存在您的瀏覽器中
- 無需網際網路連線
- 筆記在不同工作階段間持久保留
- 僅保存在您的本機裝置上

### **下載與匯入**

**下載**：
- 將筆記儲存為 `biblemate_notes.md`
- Markdown 格式完整保留所有排版格式
- 可在任何文字編輯器或 Markdown 檢視器中開啟

**匯入**：
- 上傳 `.md` 或 `.txt` 檔案
- 可匯入先前下載的筆記
- 覆寫當前內容（請謹慎操作！）

### **清除功能**

- 確認對話方塊防止誤刪
- 完全清除所有內容
- 此動作無法復原

### **聖經經文解析**

筆記本能自動辨識並格式化聖經經文參照：
- 經文參照在閱讀模式下變為可點擊狀態
- 點擊經文參照可在聖經區域中開啟該段經文
- 支援標準參照格式（書卷 章:節）

### **擴充 Markdown 支援**

筆記本包含增強型 Markdown 功能：
- **表格**：完整的表格支援與對齊功能
- **圍欄程式碼區塊**：語法高亮顯示的程式碼區塊
- **目錄**：自動生成目錄（TOC）
- **緊湊清單**：項目之間無空白行的緊湊清單

## **高效使用技巧**

1. **大綱架構**：使用各級標題組織講道大綱或研經筆記。
2. **快速速記**：閱讀時保持筆記本開啟，隨時記下心得靈感。
3. **靈修日誌**：按節記錄研經見解。
4. **教導預備**：起草教學材料或小組討論題目。
5. **經文連結**：鍵入聖經引用，自動建立快速導覽連結。
6. **定期下載**：定期下載重要筆記作為本機備份。
7. **時常切換**：在編輯與閱讀模式之間頻繁切換以檢查排版。

## **工作流程範例**

### **講道筆記速記**

1. 在講道經文旁開啟筆記本
2. 使用標題標記核心要點：
   ```markdown
   # 羅馬書 8 章講道筆記
   ## 要點一：在聖靈裡的生活
   - 核心經文：Romans 8:1
   - 生活應用：...
   ```
3. 切換至閱讀模式檢閱排版完成的筆記
4. 下載留存備查

### **個人研經**

1. 建立研經架構：
   ```markdown
   # 詩篇 23 篇研經
   ## 經文觀察
   - 耶和華是我的牧者
   - 我必不致缺乏

   ## 問題思考
   - 在此語境中「牧者」代表什麼意義？

   ## 實踐應用
   - 信靠神的豐富供應
   ```
2. 點擊聖經經文引用核對經節
3. 下載完成的研經檔案

### **代禱清單**

1. 組織代禱事項：
   ```markdown
   # 代禱清單 - 2024 年 1 月
   ## 家庭
   - [ ] 母親身體健康
   - [ ] 弟弟求職順利

   ## 教會
   - [ ] 青少年事工成長
   ```
2. 在禱告蒙應允時勾選完成項目
3. 數算並記錄神的信實作為

## **筆記本 vs 聖經筆記工具**

| 筆記本 | 聖經筆記（雲端） |
| :---- | :---- |
| 僅限本地儲存 | 同步至 Google 雲端硬碟 |
| 單一筆記本 | 針對特定經節的獨立筆記 |
| 通用型筆記 | 按聖經經文結構組織 |
| 無需登入 | 需登入 Google 帳號 |
| 手動下載／匯入檔案 | 跨裝置自動同步 |
| 最適合：速記、草稿、大綱 | 最適合：逐節深入研經 |

## **資料隱私**

- 筆記僅儲存在瀏覽器的本地儲存空間中
- 不會傳送任何資料至伺服器
- 筆記不會自動進行雲端備份
- 您需自行負責下載重要筆記作為備份
- 清除瀏覽器快取與資料將會刪除您的筆記

## **鍵盤快捷鍵**

文字區域支援大多數標準鍵盤快捷鍵：
- **Ctrl/Cmd + A**：全選
- **Ctrl/Cmd + C**：複製
- **Ctrl/Cmd + V**：貼上
- **Ctrl/Cmd + Z**：復原
- **Ctrl/Cmd + Y**：重做

## **疑難排解**

**筆記遺失：**
- 檢查是否不小心點擊了「清除」按鈕
- 瀏覽器快取資料可能已被清理
- 解決方案：務必隨時下載重要筆記備份

**匯入失敗：**
- 確認檔案為 `.md` 或 `.txt` 格式
- 檢查檔案是否損毀
- 嘗試改為手動複製貼上文字內容

**排版未生效：**
- 請確認您已切換至「閱讀模式」
- 檢查 Markdown 語法是否正確
- 下載前先預覽排版效果
