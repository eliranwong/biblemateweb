# **聖經註釋指南**

本工具提供全面的聖經註釋存取功能，逐節解釋並闡明聖經經文。

## **什麼是註釋工具？**

「聖經註釋」工具讓您即時查閱針對任何聖經經文段落的學術性與靈修性註釋。註釋提供歷史背景、神學見解、語言學解釋與實踐應用，幫助您更深入地理解經文。

## **如何使用註釋工具**

### **基本用法**

1. **選擇註釋**：從可用註釋的下拉式選單中選擇。
2. **輸入經文參照**：輸入聖經經節或段落參照（例如「John 3:16」或「Romans 8:1-17」）。
3. **按下 Enter**：該段經文的註釋將立即載入。
4. **瀏覽查閱**：捲動瀏覽註釋內容，並可點擊其中內嵌的任何經文參照。

### **輸入選項**

輸入框支援：
- **單節經文**：`John 3:16`
- **經文範圍**：`Romans 8:1-17`
- **多重參照**：`John 3:16; Romans 8:1; Psalm 23:1-6`
- **自動完成**：開始鍵入書卷名稱即可獲得建議提示

### **導覽控制項**

| 控制項 | 功能 |
| :---- | :---- |
| **註釋下拉式選單** | 選擇要檢視的聖經註釋 |
| **輸入欄位** | 輸入聖經經文參照（支援自動完成） |
| **歷史紀錄圖示**（⏱️） | 點擊或按向上箭頭鍵還原上一次搜索 |
| **向上箭頭鍵** | 還原您剛才搜索過的經文參照 |

## **可用註釋**

本工具提供多種類型的註釋：

### **AI 生成註釋**

- **AIC**（AI 註釋 - 英文）
- **AICTC**（AI 註釋 - 繁體中文）
- **AICSC**（AI 註釋 - 簡體中文）

這些註釋以 Markdown 格式提供逐節 AI 生成的見解，並轉換為 HTML 以便閱讀。

### **經典註釋**

- **CBSC**（Cambridge Bible for Schools and Colleges，劍橋聖經學校與學院註釋）
- 資源庫中提供的許多其他傳統經典註釋

### **註釋內容特色**

不同的註釋可能包含：
- 逐節詳細釋義
- 歷史與文化背景
- 希臘文與希伯來文字詞研讀
- 相關經文段落的經文串珠參照
- 神學概念解釋
- 生活實踐應用

## **功能特點**

### **多重參照支援**

輸入以分號分隔的多個經文參照，即可同時檢視數個段落的註釋：
```
Genesis 1:1; John 1:1; Revelation 21:1
```

### **經文範圍智慧處理**

本工具能智慧處理經文範圍：
- 對於 AI 註釋：載入每個個別經節的註釋
- 對於經典註釋：從全章註釋中擷取相關部分

### **可點擊的經文串珠參照**

註釋內容包含互動式連結：
- **聖經經文引用**：點擊可在聖經區域中開啟該段經文
- **原文詞典連結**：點擊可開啟字詞研究（若有提供）
- **網站連結**：外部參照連結會在新的標籤頁中開啟

### **深色模式支援**

註釋色彩會根據深色模式自動調整：
- 文字顏色經過最佳化以提升易讀性
- 表格背景適應您的主題
- 字型顏色適度變更

### **即時搜索歷史**

- 按**向上箭頭鍵**或點擊**歷史紀錄圖示**即可還原上一次搜索
- 快速返回先前的經文段落，無需重新鍵入
- 非常適合用於比對同一段經文在不同註釋中的解釋

### **動態切換註釋**

隨時切換不同註釋：
1. 從下拉式選單中選擇其他註釋
2. 工具會自動載入新的註釋內容
3. 您當前輸入的經文參照將被完整保留

## **輸入方式**

### **直接使用 URL 參數**

透過 URL 直接載入特定的註釋與經文段落：
```
?tool=commentary&q=CBSC:::John+3:16
```
格式：`commentary_code:::reference`

### **標準輸入**

直接在輸入欄位中鍵入或貼上經文參照：
- 自動聚焦以便立即鍵入
- 書卷名稱自動完成提示
- 清除按鈕可快速重設輸入內容

## **高效使用技巧**

1. **比對註釋**：在不同註釋中載入同一經文段落，獲取多元視角。
2. **上下文閱讀**：使用經文範圍（不僅是單節），以理解更廣泛的上下文脈絡。
3. **追蹤經文串珠**：點擊內嵌參照以深入探索相關經文。
4. **注重歷史背景**：留意文化與歷史註記，以建立更佳的理解。
5. **關注聖經原文**：在註釋中尋找希臘文與希伯來文字詞的詳細解釋。
6. **快速導覽**：善用向上箭頭鍵快速還原上一次搜索。
7. **多經文整合**：輸入多重參照，將相關經節放在一起研讀。

## **工作流程範例**

### **深度字詞研讀**

1. 輸入：`Ephesians 2:8-9`
2. 閱讀註釋釋義
3. 點擊任何原文詞典連結進行字詞研究
4. 切換至其他註釋以獲得另一種觀點

### **比較研讀**

1. 輸入：`Matthew 5:3-12; Luke 6:20-23`（平行經文段落）
2. 閱讀兩份記載的註釋
3. 記錄異同點
4. 點擊經文串珠以獲取補充背景資訊

### **專題研經**

1. 搜索某個主題的核心經文：`Romans 3:23; Romans 6:23; John 3:16; Ephesians 2:8-9`
2. 閱讀每節經文的註釋
3. 建立對該主題的全面理解

## **鍵盤快捷鍵**

- **Enter**：送出搜索
- **向上箭頭鍵**：還原上一次搜索
- **Escape**：清除輸入欄位（若使用清除按鈕）

## **技術說明**

- 註釋本機存放在 `~/biblemate/data/commentaries/`
- AI 註釋以 Markdown 生成並轉換為 HTML
- 經典註釋可能是按章或按節組織
- 註釋內容支援包含表格、清單與樣式的 HTML 排版
- 所有原文詞典與經文參照連結均具備互動功能
