# **參考書籍指南**

「參考書籍」工具是 BibleMate AI Web 內專門用於閱讀參考書籍檔案（`.book` 檔案）的閱讀器，顯示於聖經旁的工具面板中。

## **開啟工具**

- 桌面版：開啟工具選單並選擇**參考書籍**。
- 行動版／窄螢幕：開啟左側抽屜選單並選擇**參考書籍**。

本工具不受限於當前的聖經篇章，因此變更聖經經文段落不會改變您正在閱讀的書籍。

## **閱讀書籍**

1. 從**書籍**選單中選擇一本書。
2. 從**章節**選單中選擇章節，或使用上一章／下一章按鈕。
3. 章節內容將顯示在下方的閱讀器中。當您切換章節時，畫面會自動捲動回頂部。

深色模式與字型大小偏好設定均會套用於書籍內容。若該書籍沒有章節清單，則會隱藏章節選單與導覽按鈕。

### **互動式連結**

書籍內容中的連結運作方式與應用程式其他部分相同。聖經引用會在聖經區域中開啟；指向其他資源的連結（例如原文詞典、聖經字典、聖經應許與平行經文）亦會在應用程式中開啟。網站連結則會在新的瀏覽器標籤頁中開啟。書籍內容中的指令碼與不安全的內嵌事件處理常式均已被移除。

## **新增您自己的書籍**

每次開啟工具時，系統都會透過掃描資料夾來探索書籍。您可以新增或刪除書籍而**無需重啟伺服器**。

| 資料夾 | 顯示對象 |
| :---- | :---- |
| `~/biblemate/data/books` | 所有使用者 |
| `~/biblemate/data_custom/books` | 僅限擁有有效[自訂憑證](../user_preferences/custom_token.md)的使用者 |

- 僅列出副檔名為 `.book` 的檔案。隱藏檔案（以 `.` 開頭）會被忽略。
- 選單中顯示的書名為去除 `.book` 後的檔案名稱。
- 若自訂書籍與標準書籍同名，對於擁有存取權限的使用者，自訂書籍將取代標準書籍。
- 資料夾若不存在將會自動建立。
- 每個檔案均為 SQLite 資料庫，包含一個 `Reference` 資料表。`Chapter` 欄位儲存章節標題，`Content` 欄位依資料列順序儲存每章的 HTML 內容。此格式與 [UniqueBible](https://github.com/eliranwong/UniqueBible) 參考書籍所使用的格式相同。

若找不到任何書籍，工具會顯示「找不到書籍」。

## **API**

書籍名稱亦會在 API 資源清單的 `referenceBookList` 項目中傳回。

## **介面語言**

本工具已翻譯為繁體中文與簡體中文（「參考書籍」/「参考书籍」）。
