# **雲端聖經筆記指南**

本工具提供按經節組織的筆記記錄功能，並自動同步至您的 Google 雲端硬碟，讓您能在所有裝置上維護井然有序的研經筆記。

## **什麼是雲端聖經筆記？**

「雲端聖經筆記」是一套功能強大的筆記系統，讓您可以針對特定聖經經節、篇章或整卷書建立並同步筆記。所有筆記均會自動儲存至您的 Google 雲端硬碟帳號，確保您的研經筆記獲得安全備份，並可隨時從任何裝置存取。

## **開始使用**

### **登入要求**

若要使用雲端聖經筆記，您必須：
1. 點擊「使用 Google 登入」
2. 授權 BibleMate AI 存取您的 Google 雲端硬碟
3. 授予在 App Data 資料夾中儲存檔案的權限

**隱私聲明**：BibleMate AI 僅將筆記儲存在您自己的 Google 雲端硬碟中。本應用程式不會在其伺服器上收集、儲存或分享您的個人筆記。

### **首次設定**

1. 開啟聖經筆記工具
2. 點擊「使用 Google 登入」
3. 完成 Google OAuth 授權程序
4. 等待工具初始化您的筆記索引
5. 開始撰寫研經筆記！

## **如何使用雲端聖經筆記**

### **建立與編輯筆記**

1. **選擇經節**：使用聖經選單選擇書卷、篇章與經節。
2. **輸入筆記**：在文字區域中使用 Markdown 語法撰寫筆記。
3. **儲存筆記**：點擊選單按鈕（⋮）並選擇「儲存」以同步至雲端。
4. **切換經節**：選取不同經節即可建立多篇筆記。

### **特殊筆記類型**

- **單節筆記**：選取特定經節（例如：約翰福音 3:16）
- **全章筆記**：將經節設為「0」，即可為整篇章建立筆記
- **全書筆記**：將篇章設為「0」，即可為整卷書建立筆記

### **聖經選單特殊選項**

聖經選單包含特殊的零選項：
- **篇章 0**：建立書卷層級的筆記
- **經節 0**：建立篇章層級的筆記（當篇章大於 0 時）

## **功能特點**

### **自動雲端同步**

- 筆記保存在您的 Google 雲端硬碟 App Data 資料夾中
- 在所有已登入的裝置間自動同步
- 自動雲端備份——永不遺失筆記
- 安全存放在您自己的 Google 帳號中

### **Markdown 語法排版**

以 Markdown 格式撰寫筆記，並在閱讀模式下檢視精美排版：

```markdown
# 約翰福音 3:16 研經筆記

## 核心觀察
- 神的**愛**是普世性的
- 信靠帶來永恆的生命

## 經文串珠
- 羅馬書 5:8
- 約翰一書 4:9-10

## 生活實踐
今日就要堅定信靠神的慈愛。
```

### **可點擊的聖經經文引用**

在筆記中輸入聖經引用，在閱讀模式下自動變為可點擊連結：
- `John 3:16` → 點擊即可在聖經區域中開啟
- `Genesis 1:1-3` → 自動解析並建立連結
- 同時支援多個經文引用！

### **按經節組織的儲存結構**

每篇筆記均以其經節識別碼唯一標記：
- **格式**：`BookNumber_ChapterNumber_VerseNumber`
- **範例**：`43_3_16` = 約翰福音 3:16
- **全章筆記**：`43_3_0` = 約翰福音第 3 章
- **全書筆記**：`43_0_0` = 約翰福音全書

### **搜索索引**

本工具維護著所有筆記的搜索索引：
- 追蹤哪些經節包含筆記
- 實現快速查詢
- 可下載作為備份
- 需要時可隨時自動重建

### **匯入與匯出**

**匯出選項**：
- **單篇筆記**：將當前筆記下載為 `.json`
- **所有筆記**：將全部筆記連同索引打包下載為 `.zip`

**匯入選項**：
- **單篇筆記**：上傳 `.json` 檔案
- **批次匯入**：上傳包含多篇筆記的 `.zip` 檔案

**應用場景**：
- 重大變更前的資料備份
- 在不同帳號之間轉移筆記
- 與他人分享研經筆記
- 從其他系統移轉遷移

### **編輯／閱讀模式**

**編輯模式**：
- 全高度文字輸入區域，書寫流暢舒適
- 使用 Markdown 語法進行格式編排
- 暫時自動儲存至瀏覽器
- 即時編輯

**閱讀模式**：
- 精美格式化 HTML 呈現
- 聖經經文引用均可直接點擊
- 表格、清單與標題均正確渲染
- 可平滑捲動的預覽區域

## **高效使用技巧**

1. **經常儲存**：進行重要修改後，請點擊「儲存」。
2. **善用 Markdown**：使用標題、清單與粗體強調排版筆記，結構更清晰。
3. **章節總結**：建立篇章層級筆記（經節設為 0）用於書寫摘要。
4. **書卷導論**：建立書卷層級筆記（篇章設為 0）用於記錄背景導論。
5. **串珠參照**：在筆記中加入相關經節，以便快速導覽查閱。
6. **定期備份**：定期下載所有筆記壓縮檔作為保險備份。
7. **重建索引**：若筆記似乎未顯示，請重建索引以重新掃描雲端硬碟。
8. **公共電腦務必登出**：在公用裝置上使用後請記得登出。

## **工作流程範例**

### **逐節精讀研經**

1. 選擇約翰福音 3:1
2. 記錄關於尼哥底母的觀察
3. 點擊「儲存」
4. 選擇約翰福音 3:2
5. 依序逐節完成整章的筆記

### **篇章摘要記錄**

1. 讀完約翰福音 3 章
2. 選擇約翰福音第 3 章，經節設為 0
3. 撰寫篇章概覽：
   ```markdown
   # 約翰福音 3 章 - 重生
   ## 主題：重生得救
   - 與尼哥底母的對話（1-21 節）
   - 施洗約翰的見證（22-36 節）
   ```
4. 儲存全章筆記

### **跨經文專題研讀**

1. 研讀「愛」的主題
2. 分別在以下經節建立筆記：
   - 約翰福音 3:16（神的愛）
   - 羅馬書 5:8（愛的顯明）
   - 約翰一書 4:8（神就是愛）
3. 在每篇筆記中加入互相參照的經文
4. 全部下載作為備份

### **講道預備**

1. 選定講道經文段落
2. 建立詳細筆記：
   ```markdown
   # 講道題目：好牧人
   ## 經文：約翰福音 10:11-18

   ### 大綱
   1. 好牧人為羊捨命（11 節）
   2. 雇工撇下羊逃跑（12-13 節）
   3. 耶穌認識祂的羊（14-15 節）

   ### 例證
   - 牧羊人捨身保護羊群的故事

   ### 生活實踐
   - 堅定信靠耶穌為我們的保護者
   ```
3. 儲存後可隨時從任何裝置存取

## **資料管理**

### **重建索引**

索引追蹤您的所有筆記。在下列情況下請進行重建：
- 匯入筆記後似乎有遺漏
- 筆記計數顯示不正確
- 您曾手動在雲端硬碟中新增過檔案

**如何重建**：
1. 點擊選單按鈕（⋮）
2. 選擇「重建索引」
3. 等待程序完成（筆記較多時可能需要稍候）
4. 查看成功提示通知

### **備份策略**

**建議備份計畫**：
1. Google 雲端硬碟會自動同步備份所有筆記
2. 定期點擊「全部下載」儲存本地備份
3. 妥善保存備份 `.zip` 檔案
4. 下載索引檔案作為額外安全保障

### **從備份匯入復原**

若要從備份復原：
1. 點擊選單按鈕（⋮）
2. 選擇「匯入」
3. 選取您的 `.zip` 檔案
4. 等待上傳與處理完成
5. 必要時點擊重建索引

## **隱私與安全性**

### **筆記儲存位置**

- **Google 雲端硬碟**：App Data 資料夾（在一般雲端硬碟介面中預設隱藏）
- **不易察覺**：不會出現在您的主要雲端硬碟檔案清單中
- **安全保障**：受到您的 Google 帳號安全性保護
- **隱私專屬**：僅能透過 BibleMate AI 或專門的 Drive API 存取

### **BibleMate AI 的存取權限範圍**

- **可以**：讀取與寫入 App Data 資料夾內的檔案
- **不能**：存取您 Google 雲端硬碟中的其他任何檔案
- **不能**：將您的筆記分享給他人
- **不能**：在 BibleMate 伺服器端檢視您的筆記內容

### **資料政策**

BibleMate AI：
- **絕不**收集您的個人筆記
- **絕不**將您的筆記存放在本應用伺服器上
- **絕不**將您的筆記分享給任何第三方
- **僅**負責協助將資料同步至**您自己的** Google 雲端硬碟

## **疑難排解**

**筆記無法儲存：**
- 檢查網路連線狀態
- 確認您已處於登入狀態
- 嘗試登出後重新登入
- 檢查 Google 雲端硬碟授權權限

**登入後筆記未顯示：**
- 點擊「重建索引」
- 確認您是否登入了正確的 Google 帳號
- 確認筆記未曾被意外刪除

**匯入失敗：**
- 確認檔案為有效的 `.json` 或 `.zip` 格式
- 檢查檔案是否損毀
- 若資料量過大，嘗試分批匯入
- 確保網路連線穩定

**在 Google 雲端硬碟中找不到筆記檔案：**
- 筆記存放於 App Data 資料夾（預設隱藏）
- 這是正常現象
- 請使用「全部下載」功能獲取可見的本機備份
