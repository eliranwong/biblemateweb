# **字詞形態學分析指南**

本工具提供希伯來文與希臘文聖經原文的詳細語法分析，讓您能夠在字詞層級深入研究聖經的語言學結構。

## **什麼是字詞形態學分析？**

字詞形態學分析展示聖經經文中每個希伯來文（舊約）或希臘文（新約）字詞的語法形式與結構。這包括詞性、動詞時態、名詞格位以及其他影響字義的語法特徵資訊。

## **如何使用形態學分析工具**

1. **選擇經節**：使用聖經選單選擇特定的經節。
2. **點擊「開啓」**：載入該經節的形態學分析。
3. **檢視字詞資料**：每個字詞均會顯示其詞形、詞典詞條與形態標籤。
4. **選取形態特徵**：點擊形態標籤（Chips）選取／取消選取欲搜索的語法特徵。
5. **進行搜索**：點擊搜索按鈕，尋找具有相似形態模式的經文。

## **字詞顯示結構**

經文中的每個字詞均呈現在一張卡片中，包含四個主要元素：

### **1. 原文文本**

- **希伯來文字詞**：由右至左正確排版顯示
- **希臘文字詞**：以 Unicode 希臘文字元顯示
- **懸停提示**：將游標懸停在字詞上即可查看詞彙字典資訊

### **2. 詞元（字典原形，Lexeme）**

- 出現在詞典中的字詞基礎原形
- 可點擊並帶有提示工具以提供補充資訊
- 連結至該字詞的原文字典詞條

### **3. 逐字對照翻譯**

- 逐字英文對照翻譯
- 幫助理解字詞的基本含義
- 顯示於原文文本與形態標籤之間

### **4. 形態標籤**

可選取的標籤，顯示各項語法特徵，例如：
- **詞性（Part of Speech）**：名詞、動詞、形容詞等
- **人稱（Person）**：第一、第二、第三人稱
- **性別（Gender）**：陽性、陰性、中性
- **數量（Number）**：單數、複數、雙數
- **格位（Case）**：主格、屬格、與格、賓格（希臘文）
- **狀態（State）**：絕對態、構詞態（希伯來文）
- **時態（Tense）**：現在式、不定過去式（Aorist）、完成式、未完成式等
- **語態（Voice）**：主動語態、中間語態、被動語態
- **語氣（Mood）**：直陳語氣、假定語氣、祈使語氣等

## **搜索功能**

### **形態模式搜索**

檢視字詞的形態之後，您可以搜索具備相似語法模式的經文：

1. **選取形態標籤**：點擊橘色標籤選取／取消選取語法特徵
2. **選擇聖經版本**：點擊其中一個搜索按鈕：
   - **OHGB**：希伯來文與希臘文原文字典聖經
   - **OHGBi**：逐字對照版本
   - **當前聖經（Current Bible）**：您聖經區域中當前開啟的聖經版本
   - **首選聖經（Primary Bible）**：您偏好設定中的主要譯本
   - **次選聖經（Secondary Bible）**：您偏好設定中的次要譯本

3. **執行搜索**：系統將找出該字詞以您所選形態特徵出現的所有經文

**範例**：搜索特定希臘文動詞在「不定過去式、被動語態」下的所有經文出處。

### **進階搜索選項**

- **詞條原形搜索**：搜索特定字詞的所有形態變化形式（任何語法形態）
- **組合條件搜索**：選取多個形態特徵以精確縮小結果範圍
- **特定版本搜索**：在聖經原文或特定譯本中進行搜索

## **理解形態標籤**

### **常見希伯來文標籤**

- **verb**：動詞
- **noun**：名詞
- **qal**：簡易主動幹（Simple verb stem）
- **perfect**：完成態（已完成動作）
- **construct**：構詞態（與後接詞的從屬修飾關係）
- **masculine/feminine**：陽性／陰性
- **singular/plural**：單數／複數

### **常見希臘文標籤**

- **verb**：動詞
- **noun**：名詞
- **aorist**：不定過去式（單純過去動作）
- **present**：現在式（持續動作）
- **indicative**：直陳語氣（陳述客觀事實）
- **imperative**：祈使語氣（命令、吩咐）
- **nominative**：主格（主詞）
- **accusative**：賓格（直接受詞）
- **active/passive**：主動／被動語態

## **高效使用技巧**

1. **從簡單開始**：先檢視個別字詞，再進行複雜的組合搜索。
2. **比對不同譯本**：利用形態學分析理解為何不同譯本在翻譯上有所差異。
3. **字詞深度研究**：追蹤字詞形態的變化如何影響跨經文的含義。
4. **學習原文語法**：透過真實的經文語境學習希伯來文與希臘文語法。
5. **語法模式識別**：識別聖經中常見的特定語法句型與結構。
6. **神學精準度**：根據語法形態辨明細微但關鍵的神學差異。
7. **檢驗翻譯**：驗證原文語法特徵在各譯本中如何被呈現。

## **工作流程範例**

### **希臘文動詞研讀**

1. 載入約翰福音 3:16
2. 找到動詞「愛」（ἠγάπησεν）
3. 觀察其形態為：不定過去式、主動語態、直陳語氣
4. 選取「aorist」與「active」標籤
5. 搜索 OHGB，找出動詞 ἀγαπάω 在不定過去式主動語態下的其他所有出處
6. 研讀此形態如何強調一次性、已成就的確定動作

### **希伯來文名詞分析**

1. 載入創世記 1:1
2. 檢視 אֱלֹהִים（Elohim - 神）
3. 觀察其形態為陽性複數，但在語法上搭配單數動詞
4. 點擊「Lexicon」閱讀關於此獨特形式的詞典說明
5. 使用經文彙編查看此形式還出現在哪些地方

### **詞形對照研究**

1. 載入帶有核心動詞的經節
2. 觀察形態標籤
3. 在 OHGB 中搜索該精確詞形
4. 切換至主要聖經譯本再次搜索
5. 比對不同譯本如何處理相同的語法形式

## **本章詞彙與罕見詞**

- 在詞形分析頁面底部展開 **本章詞彙與罕見詞**，即可分析整章的原文字詞分佈：
  - **本章高頻原文字詞**：列出本章出現次數最多的前 15 個希伯來文或希臘文詞根（附出現次數與簡明釋義）。
  - **本章罕見詞（全本聖經出現 ≤ 3 次）**：標記本章中的罕見詞與全本聖經僅出現一次的詞彙（hapax legomena）。
- 點擊任一詞彙標籤即可開啟對應的字詞典條目。
