# 多工具工作區

**多工具工作區**允許您在單一工具區域標籤頁中同時開啟並使用多個研經工具與搜索頁面，每個工具皆擁有獨立的容器與捲動區域。

## 開啟方式

- **工具選單**：開啟「**工具**」選單（`build` 圖示）或左側抽屜，選擇「多工具工作區」。
- **快速搜索**：輸入 `multitool`。

## 功能特色

- **獨立工具面板**：點擊 `+ 新增工具` 即可加入任何支援的研經工具、搜索頁面或 AI 模式（註釋、經文寶庫、經文串珠、形態學分析、索引、原文字典、聖經詞典、經文搜索、筆記本、`AI：對話模式`、`AI：夥伴模式`、`AI：代理模式`，以及可用時的 `AI：工作室模式`）。每個面板都有獨立的捲動區域、工具切換器與狀態。
- **響應式排版與高度切換**：在工作區工具列切換 `1`、`2`、`3` 或 `4` 欄排版，以及 `1x`、`1.5x`、`2x`、`2.5x` 面板高度。窄螢幕或直向螢幕下會自動回退為單欄顯示，兩項選擇皆會跨重新整理保存（`multitool_cols`、`multitool_height_scale`）。
- **單面板控制項**：
  - **工具切換器**：在不影響其他面板的情況下更換目前面板的工具。
  - **同步開關**：控制該面板是否在聖經區切換書卷、章或節時自動重新整理。未開啟同步的搜索面板會保留其搜索結果。
  - **重新整理**：手動將該面板同步至聖經區目前經文。
  - **移動 / 最大化 / 摺疊 / 關閉**：調整面板順序、將單個面板展開為全寬、摺疊內容或關閉面板。
- **預設模板與狀態記憶**：
  - **記住上次工作區**：重新開啟多工具工作區時自動還原上次的面板與欄數排版（`multitool_last`）。
  - **內建預設**：從 `預設` 選單一鍵載入精選組合（*Chapter Study*、*Verse Deep Dive*、*Word & Topic Study*、*Study & Notes*）。
  - **自訂預設**：點擊儲存圖示，將目前排版與面板組合儲存為自訂預設（`multitool_custom_presets`）。
- **安全連結跳轉**：在面板內點擊開啟其他工具的連結時，會在新的工具標籤頁中開啟，不會覆蓋目前的多工具工作區。
