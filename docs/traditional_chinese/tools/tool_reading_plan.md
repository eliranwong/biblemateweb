# 一年讀經計劃

內建 365 天讀經計劃（每日包含舊約、新約與詩篇／箴言），並依介面語言（英文、繁體中文、簡體中文）自動顯示對應的聖經書卷名稱與經節引用。

- **開啟方式**：`工具` → `一年讀經計劃`（或在快速搜尋輸入 `Reading:::<天數>`）
- **導覽**：預設顯示今日對應天數（`1–365`），提供 **前一天**、**後一天**、**今天**、**下一個未讀** 與 **365 天總覽** 格狀圖。
- **閱讀方式**：
  - 點擊任一段落旁的 **閱讀** 按鈕，即可在聖經區域開啟該段經文。
  - 點擊 **在經文搜索中閱讀全部**，可在下一個標籤頁一次載入本日所有經文。
- **進度追蹤**：勾選 **標記本日已完成** 即可儲存進度（`reading_plan_completed`），檢視完成百分比與**連續天數**，或點擊 **重設進度** 重新開始。
