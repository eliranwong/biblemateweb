# **平行經文指南**

本工具展示福音書平行經文、合參對照以及跨聖經不同書卷描述相同或相似事件的相關經文段落。

## **什麼是平行經文？**

「平行經文」幫助您研讀聖經中由多卷書共同記載的歷史事件，尤其在四福音書中最為顯著。本工具將平行對照的記載整理為主題合輯，讓您可以輕鬆比對不同作者如何描述同一事件。

## **主要涵蓋內容**

本工具收錄了豐富的平行經文合輯：

### **福音書合參**

四福音書中的平行記載：
- **對觀福音平行記載**：馬太福音、馬可福音與路加福音共同記載的事件
- **約翰福音**：約翰福音獨有的事件或與其他福音書共有的記載
- **降生敘事**：耶穌降生的平行對照記載
- **受難敘事**：耶穌受死與復活的平行對照記載

### **舊約平行經文**

- **列王紀與歷代志**：以色列歷史的平行記載
- **撒母耳記與歷代志**：重疊交錯的敘事
- **出埃及記至申命記**：重複出現的律法與歷史事件

### **歷史合參**

各合輯呈現：
- 不同作者如何記述同一事件
- 各記載之間的時間先後關係
- 各版本中獨具的細節

## **如何使用平行經文**

1. **開啟工具**：從工具選單中選擇「平行經文」。
2. **瀏覽合輯**：捲動瀏覽平行經文合輯清單。
3. **展開合輯**：點擊任何合輯即可查看其內容。
4. **檢視經文**：點擊聖經經文引用即可開啟對應段落。
5. **對照記載**：並排對照閱讀平行經文段落。

## **合輯顯示方式**

每個合輯均依以下結構組織：

### **合輯標題**

- 清晰描述該平行事件或主題
- 圖示：📚（auto_stories）
- 可展開／摺疊區塊

### **內容結構**

在每個合輯內部：
- **表格格式**：經文段落以表格呈現，便於直接對照
- **經文引用連結**：可點擊的聖經經文引用
- **描述性標題**：為每處平行記載提供背景脈絡
- **多方記載**：所有相關經文段落匯集於同一處

## **功能特點**

### **可收展區塊**

- 所有合輯預設為摺疊狀態，便於快速瀏覽
- 點擊任何合輯標題即可展開
- 支援同時檢視多個合輯
- 可摺疊當前未研讀的合輯

### **可點擊經文引用**

所有聖經引用均具備互動功能：
- 點擊即可在聖經區域中開啟
- 開啟完整篇章以檢視上下文
- 在平行經文之間自由切換導覽

### **福音書合參架構**

福音書平行經文依據以下原則組織：
- **時間順序**：依事件發生的先後次序排列
- **主題分組**：相關事件歸類於同組
- **資料來源**：標註該記載收錄於哪些福音書

## **研經益處**

### **全貌理解**

- 透過閱讀所有記載，綜觀事件全貌
- 發掘每位作者獨特記述的細節
- 理解對同一事件的不同視角

### **作者焦點**

每位福音書作者皆有其神學重點與讀者對象：
- **馬太**：針對猶太讀者，著重彌賽亞預言的應驗
- **馬可**：注重行動與敘事緊湊，針對羅馬讀者
- **路加**：注重歷史考證與細節，針對外邦讀者
- **約翰**：著重神學深度與基督的神性

### **化解看似矛盾之處**

平行對照有助於化解表面上的差異與難題：
- 顯明彼此互補的細節
- 揭示不同角度的觀察
- 呈現各記載之間的和諧統一

### **歷史真實性**

多個獨立的記載加強了：
- 歷史的可靠性
- 目擊證人的真實見證
- 核心敘事的一致性

## **高效使用技巧**

1. **仔細比對**：在得出結論之前，先通讀所有平行記載。
2. **留意獨特細節**：每處記載都可能包含其他作者未提及的資訊。
3. **重視上下文**：開啟完整章節，在更寬廣的語境中審視每段平行經文。
4. **追蹤差異**：注意措辭、次序或強調重點上的微妙差異。
5. **綜合融會**：思考各記載如何互為補充而非彼此衝突。
6. **研讀作者特質**：了解每位作者的寫作風格與神學焦點。
7. **結合註釋研讀**：查閱聖經註釋，汲取學者對平行經文的深入見解。

## **工作流程範例**

### **福音書事件研讀**

1. 開啟平行經文工具
2. 找到「登山寶訓／平原寶訓」合輯
3. 展開合輯
4. 觀察：
   - 馬太福音 5–7 章（登山寶訓）
   - 路加福音 6:17-49（平原寶訓）
5. 點擊每處引用閱讀完整經文
6. 比對耶穌在兩種情境下的教導

### **受難週專題研讀**

1. 找到「最後的晚餐」合輯
2. 展開檢視四卷福音書的記載
3. 依序開啟每處記載：
   - 馬太福音 26:17-30
   - 馬可福音 14:12-26
   - 路加福音 22:7-38
   - 約翰福音 13–17 章
4. 梳理綜合時間軸
5. 留意獨特元素（約翰記載的洗腳與長篇臨別吩咐）

### **舊約歷史研讀**

1. 找到列王紀與歷代志平行合輯
2. 範例：「大衛統治時期」
3. 比對：
   - 撒母耳記下 5–24 章
   - 歷代志上 11–29 章
4. 留意歷代志對預備建殿的特別強調
5. 查看額外的家譜細節

## **常見平行經文類型**

### **1. 核心事件完全相同**

同一事件，細節相仿：
- 五餅二魚
- 醫治瞎子
- 潔淨聖殿

### **2. 相似但屬不同事件**

可能發生在不同場合：
- 兩次潔淨聖殿（約翰福音第 2 章 vs 對觀福音）
- 多次不同的醫治記載
- 在不同情境下重複宣講的教導

### **3. 互補性記載**

細節各異，記述同一事件：
- 降生敘事（馬太福音 vs 路加福音）
- 復活後的顯現（每卷福音書補充不同細節）
- 升天記載（路加福音、使徒行傳）

## **神學應用**

### **聖靈默示**

多方記載見證了：
- 多樣中的合一
- 互補的豐富視角
- 始終如一的核心信息
- 神奇妙的引導

### **目擊見證**

記載的細微差異反映了：
- 獨立的見證人
- 不同的觀察視角
- 未經串通的真實記載
- 卓越的歷史可靠性

### **聖經無誤性**

平行對照的和諧表明：
- 並無真正的矛盾
- 資訊相輔相成
- 重點不同而非記載錯誤
- 彼此完全相容

## **歷史語境**

理解平行記載需要認識到：
- **古代傳記體裁**：與現代史學標準有所不同
- **口傳傳統**：在付諸文字前已經廣泛口述流傳
- **主題性編排**：不一定完全按嚴格的時間先後組織
- **作者寫作目的**：每位作者都有特定的牧養目標與受眾

## **進階研讀**

### **合參研究**

深入研讀方法：
1. 建立平行事件的綜合時間軸
2. 標記每篇記載的獨特貢獻
3. 識別每位作者所強調的神學主題
4. 研究早期教父如何對照合參福音書

### **底本批判（Source Criticism）**

了解學術理論：
- 馬太與路加為何享有共同素材
- 馬可福音在成書次序上的優先地位
- Q 典假說
- 約翰福音獨立於對觀福音的特性

### **編輯批判（Redaction Criticism）**

研究每位作者如何：
- 為其福音書選取素材
- 為神學目的編排事件次序
- 為其特定受眾強化主題
- 在捍衛真理的同時塑造敘事結構
