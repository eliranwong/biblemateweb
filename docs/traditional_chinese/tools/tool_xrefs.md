# **經文串珠指南**

本工具採用 ScrollMapper 資料庫為聖經經文提供全面的經文串珠參照，幫助您發掘相關經文段落，並探索貫穿全本聖經的內在連結。

## **什麼是經文串珠？**

經文串珠是聖經經節之間在主題、神學或語境脈絡上相互關聯的橋樑。本工具使用 ScrollMapper 串珠系統，為您所查詢的任何經文段落展示所有相關經節，讓您得以在更廣闊的聖經背景中研讀經文。

## **如何使用經文串珠**

### **基本用法**

1. **輸入經文參照**：在輸入欄位中鍵入聖經經節或段落參照。
2. **按下 Enter**：系統載入並顯示所有經文串珠。
3. **瀏覽結果**：捲動瀏覽包含完整經文內容的相關經節清單。
4. **篩選結果**：在輸入欄位中鍵入字詞，即可即時篩選所顯示的經節。
5. **點擊經文參照**：點擊經節標籤，可透過多種方式開啟經文。

### **輸入選項**

輸入欄位支援：
- **單節經文**：`John 3:16`
- **經文範圍**：`Romans 8:1-17`
- **多重參照**：`John 3:16; Romans 5:8; 1 John 4:9`
- **自動完成**：開始鍵入書卷名稱即可獲得即時建議提示

## **功能特點**

### **全方位經文串珠展示**

針對您所搜索的每一節經文，本工具均會呈現：
- **原始經文**：您所搜索的經節及其完整經文文本
- **所有關聯經文**：所有與您搜索的經節互為串珠參照的經節
- **完整經文文本**：顯示完整經文內容，而非僅僅是經文出處編號
- **條理分明的排版**：清晰、優雅且易於閱讀的卡片式版面

### **即時動態篩選**

搜索結果載入後，您可以即時進行二次篩選：
1. 直接在輸入欄位中鍵入關鍵字
2. 結果將根據您鍵入的內容進行即時動態篩選
3. 可透過以下維度篩選：
   - 聖經經文參照（例如鍵入「John」僅顯示約翰著作經節）
   - 經文內容文字（例如鍵入「愛」僅顯示包含「愛」的經節）
4. 即時查看符合條件的筆數提示

**範例**：搜索「John 3:16」，接著鍵入「永生」，即可快速篩選出所有提及永生的串珠經節。

### **多元靈活的開啟選項**

每個經節參照標籤均提供右鍵選單功能：

| 選項 | 功能 |
| :---- | :---- |
| **在聖經區域開啟** | 在區域 1（主聖經閱讀區域）中開啟該段經文 |
| **在此處開啟** | 在當前工具區域標籤頁中開啟該段經文 |
| **在下一標籤頁開啟** | 在工具區域的下一個標籤頁中開啟該段經文 |
| **在新標籤頁開啟** | 在工具區域的新空白標籤頁中開啟該段經文 |

### **可移除的經文卡片**

- 每節經文均展示在一張帶有可關閉標籤（Chip）的卡片中
- 點擊任何標籤上的 X 按鈕即可從當前畫面中暫時移除該節經文
- 非常有助於排除干擾，專注於最具關聯性的核心經文
- 被移除的經文會在下一次全新搜索時恢復顯示

### **互動式元素**

- **可點擊的經文引用**：點擊任何經節標籤即可彈出開啟選項選單
- **懸停視覺效果**：游標懸停時卡片醒目提示，方便辨識
- **搜索歷史**：按向上箭頭鍵快速還原上一次搜索內容
- **清空重設**：使用清除按鈕一鍵重設輸入欄位

## **介面呈現解析**

### **結果卡片**

每處經文串珠均呈現在卡片中，包含：

1. **經節參照標籤（Chip）**：
   - 書卷簡寫、篇章與經節編號
   - 色彩背景（藍色／強調色）
   - 書本圖示
   - 可移除（X 按鈕）
   - 可點擊彈出操作選單

2. **經文正文**：
   - 該節經文的完整文字內容
   - HTML 排版確保優異的可讀性
   - 必要時可包含聖經原文標籤
   - 清晰的換行排版便於閱讀

### **標題標籤**

當經文串珠載入時，頂部標題將顯示：
- 「經文串珠 - [您的經文參照]」
- 清楚提醒您當前正在查閱哪處經文
- 在連續執行多次搜索時尤為實用

### **結果統計計數**

載入完成後，您會看到：
- 找到的經文串珠總筆數
- 顯示總數的通知提示（例如「找到 25 筆結果」）

## **搜索工作流程**

### **1. 初始搜索**

```
使用者輸入：Romans 8:28
→ 載入所有與羅馬書 8:28 互為串珠的經節
→ 呈現原始經文與所有關聯經文全文
→ 顯示找到的串珠總筆數
```

### **2. 篩選結果**

```
輸入："愛"
→ 將顯示的經節即時篩選為僅包含「愛」的經文
→ 顯示匹配的經節數量
→ 其他不相干經節暫時隱藏
```

### **3. 開啟關聯經文**

```
點擊經節參照標籤
→ 彈出包含 4 種開啟方式的選單
→ 選擇開啟目標位置
→ 經文在指定區域開啟
→ 工具區域中的經文串珠清單持續完整保留
```

### **4. 排除無關干擾**

```
點擊任何經節標籤上的 X
→ 該經節即刻從當前畫面中移除
→ 聚焦於剩餘的核心經節
→ 移除的經節不影響篩選邏輯
```

## **高效使用技巧**

1. **先廣後狹**：先直接搜索經文而不加篩選，綜觀所有潛在的串珠關聯。
2. **策略性篩選**：利用即時關鍵字篩選，精準定位特定主題的串珠。
3. **多標籤並行**：使用「在新標籤頁開啟」並排對照閱讀多處串珠經文。
4. **排除干擾項**：點擊 X 移除關聯度較低的經文，專注於關鍵段落。
5. **連鎖追蹤**：進一步搜索串珠經文的串珠，進行層層深入的查考。
6. **多段同查**：一次輸入多節經文，觀察它們彼此之間如何交織關聯。
7. **善用歷史鍵**：隨時按向上箭頭鍵快速返回剛才的搜索。
8. **跨工具對照**：與《經文寶庫》及「聖經註釋」搭配使用，獲取最全面的理解。

## **工作流程範例**

### **專題主題研經**

1. 搜索：`John 3:16`
2. 綜覽所有關於神的愛與救恩的串珠經節
3. 在輸入框篩選鍵入：「信」
4. 聚焦於將「信靠」與「救恩」緊密相連的經節
5. 點擊經節標籤，在完整語境中細讀每節經文
6. 將核心經節開啟於獨立標籤頁中進行並排對照

### **教義專題研究**

1. 搜索：`Romans 3:23`（世人都犯了罪）
2. 檢視關於人類普遍沉淪與罪性的所有串珠
3. 點擊 X 移除關聯較遠的經節
4. 依序在聖經區域開啟留下的核心經節
5. 建立對該項神學教義的完備認知

### **福音書合參對照**

1. 搜索：`Matthew 14:22`（耶穌在水面上行走）
2. 找到馬可福音 6:45 與約翰福音 6:16 的平行記載
3. 點擊每處平行經文並在新的標籤頁中開啟
4. 並排比對兩份甚至三份記載
5. 記錄每卷福音書所獨具的描寫細節

### **預言與基督成就**

1. 搜索：`Isaiah 53:5`（基督受難的彌賽亞預言）
2. 找到新約中的應驗經節（彼得前書 2:24 等）
3. 篩選輸入：「擔當」或「罪」
4. 開啟應驗篇章詳細閱讀
5. 親眼見證舊約預言與新約應驗的精妙契合

## **進階動態篩選技巧**

### **依書卷名稱篩選**

鍵入書卷名稱或縮寫以限定範圍：
- 「John」→ 僅顯示出自約翰著作的串珠經文
- 「Genesis」→ 僅顯示舊約創世記的淵源連結
- 「Psalm」→ 僅顯示詩篇中的對應經文

### **依主題關鍵詞篩選**

鍵入核心關鍵字探索專題：
- 「信心」→ 僅顯示提及信心的經節
- 「立約」→ 僅顯示涉及聖約的串珠經節
- 「天國」→ 僅顯示天國主題的相關連結

### **依精確片語篩選**

鍵入特定片語精確過濾：
- 「永遠的生命」→ 僅顯示包含該完整片語的經文
- 「神的兒子」→ 精確鎖定該神聖尊稱的經節
- 「在基督裡」→ 篩選所有保羅神學核心片語出處

### **組合條件篩選**

篩選器同時對「經文參照」與「經文正文」生效：
- 「John 永生」→ 篩選約翰福音中關於永生的經節
- 「Romans 信心」→ 篩選羅馬書中提及信心的串珠

## **認識經文串珠的內在類型**

本工具涵蓋各種類型的經文串珠：

### **1. 直接平行對照**

不同書卷記述同一歷史事件：
- 對觀福音平行記載
- 列王紀／歷代志歷史對照
- 聖經中重複出現的篇章（如詩篇中的平行篇）

### **2. 主題性內在關聯**

表達相似主題或教導：
- 愛（約翰福音 3:16 → 約翰一書 4:8）
- 信心（羅馬書 5:1 → 希伯來書 11:1）
- 盼望（羅馬書 8:28 → 羅馬書 15:13）

### **3. 預言與應驗**

舊約先知宣告 → 新約基督成就：
- 以賽亞書 53 章 → 福音書受難敘事
- 詩篇 22 篇 → 十字架受難記載
- 瑪拉基書 3:1 → 施洗約翰的開路先鋒職分

### **4. 關鍵字詞或片語連結**

共享同一核心重要詞彙或片語：
- 「人子」相關經節
- 「神的國」相關段落
- 耶穌「我是（I AM）」的崇高宣告

### **5. 語境解釋性經文**

進一步闡釋、深化或補充該節背景的經文：
- 歷史背景段落
- 律法解釋性文本
- 時代環境交代

### **6. 引述與呼應**

新約直接引述或間接呼應舊約：
- 明確註明出處的直接引文
- 字詞上的典故呼應
- 主題與意象的深層共鳴

## **疑難排解**

**找不到經文串珠：**
- 檢查經文參照格式是否正確
- 嘗試使用其他通用的書卷縮寫
- 部分冷僻經節本身收錄的串珠可能較少
- 確認資料庫檔案是否完整安裝

**結果過多：**
- 使用即時關鍵字篩選縮小範圍
- 點擊 X 移除關聯度較低的經文
- 鍵入特定書卷名稱聚焦於特定書卷

## **最佳研經實踐**

1. **通讀上下文**：務必在完整的篇章語境中研讀串珠經文。
2. **切忌斷章取義**：全面考量所有相關串珠，而非僅挑選符合偏好的經文。
3. **持守真理平衡**：利用多處經文建立周延均衡的聖經真理認識。
4. **親自辨明關聯**：仔細思考兩處經文之間的內在聯繫——並非所有串珠的關聯度都等量齊觀。
5. **綜合多工具**：結合「聖經註釋」、「經文寶庫」等工具進行全方位研讀。
6. **勤做研經筆記**：在「聖經筆記」工具中及時記錄串珠研讀的心得與領受。

## **相關工具**

- **經文寶庫**：收錄豐富背景解釋註記的傳統串珠體系
- **全章索引／單節索引**：按主題系統分類組織的關聯內容
- **聖經註釋**：包含深度背景考據的逐節詳細釋義
- **搜索**：在全本聖經中按關鍵字搜尋經文
- **聖經筆記**：隨時記錄並保存串珠研讀的豐富收穫
