# **聖經語音播放器指南**

本工具提供按節播放的聖經語音功能，讓您在聆聽經文朗讀的同時，同步對照經文文字顯示。

## **什麼是語音播放器？**

語音播放器讓您在閱讀經文的同時，聆聽專業朗讀的聖經章節。每節經文均可單獨控制播放，非常適合靈修默想、經文背誦或輔助無障礙閱讀需求。

## **如何使用語音播放器**

### **基本播放操作**

1. **選擇經文**：使用頂部的聖經選單選擇您要的書卷、章和起始節。
2. **點擊「開啓」**：載入該章的語音內容。
3. **播放單節**：點擊任何經文旁的語音圖示（🔊）即可開始播放。
4. **自動接續**：當前節播放完畢時，播放器會自動前進至下一節。

### **導覽方式**

- **書卷下拉式選單**：從聖經全部 66 卷書中選擇。
- **篇章下拉式選單**：選擇所選書卷內的任一篇章。
- **經節下拉式選單**：指定具體的起始經節。
- **「開啓」按鈕**：套用您的選擇並載入語音。

## **播放器控制**

| 控制項 | 功能 |
| :---- | :---- |
| **音量圖示** | 點擊任何單節旁的圖示即可開始／停止該節播放 |
| **語音播放器** | 標準 HTML5 音訊控制項（播放、暫停、快轉／倒轉、音量） |
| **循環開關** | 開啟後，章節播畢時會自動從頭重新播放 |

## **功能特點**

### **逐節精確控制**

- 點擊任何經節即可直接跳轉至該節播放。
- 當前播放的經節會以揚聲器圖示（🔊）醒目顯示。
- 未播放的經節則顯示靜音圖示（🔇）。

### **自動推進播放**

當前經節播放結束後，播放器會自動前進至下一節，為整章帶來流暢連貫的聆聽體驗。

### **循環模式**

開啟「Loop」（循環）開關可實現：
- 當該章結束時，自動從第 1 節重新開始播放。
- 非常適合用於背誦特定經文段落或進行深度的章節默想。

### **自動載入下一章**

當停用循環模式且整章播放結束時，播放器可自動載入下一章（此功能取決於設定）。

### **多版本支援**

語音播放器支援多種聖經版本與原文聖經：
- **英文譯本**：NET、KJV 及其他可用的語音聖經。
- **聖經原文**：舊約希伯來文（BHS5）、新約希臘文（OGNT）。
- **自訂語音**：若您新增了自訂語音檔案，它們會出現在版本選單中。

## **原文特色功能**

播放希伯來文或希臘文語音時：
- **希伯來文文本**：由右至左正確排版顯示。
- **提示工具說明**：將游標懸停在希伯來文或希臘文字詞上，即可查看詞彙字典資訊。
- **音譯對照**：查看字詞的發音音譯。

## **高效使用技巧**

1. **經文背誦**：使用循環模式並對照文字跟讀，有助於背誦經文。
2. **靈修默想**：重複播放單節經文，深度默想其意涵。
3. **無障礙輔助**：為視力障礙者或偏好聽覺學習的使用者開啟語音。
4. **多工聆聽**：在處理其他事務時聆聽——自動推進功能讓誦讀持續不中斷。
5. **語言學習**：利用原文語音練習並提升希伯來文或希臘文發音。
6. **從章中段開始**：若您只需要第 15–20 節，載入前可直接將起始節設為 15。

## **鍵盤快捷鍵**

標準 HTML5 音訊播放器支援常見鍵盤控制：
- **空格鍵**：播放／暫停（當焦點在音訊播放器上時）
- **方向鍵**：快轉／倒轉
- **音量鍵**：調整音量

## **技術說明**

- 音訊檔案必須存放在您的資料目錄中（`~/biblemate/data/audio/bibles/`）。
- 支援的音訊格式：MP3。
- 每節經文均有獨立的音訊檔案，以實現精確控制。
- 無需網際網路連線——所有音訊均在本地播放。
