# **經文寶庫指南**

本工具提供查閱《經文寶庫》（Treasury of Scripture Knowledge, TSKe）的功能，這是一部包含海量經文串珠與解釋性註記的巨著，深刻揭示聖經各經文段落之間的奇妙關聯。

## **什麼是經文寶庫？**

《經文寶庫》是一部權威的工具書，將聖經中的每一節經文與整部聖經的相關段落緊密相連。無論您查閱哪一節經文，《經文寶庫》都會提供豐富的經文串珠參照、註解與內在關聯，幫助您透過與其他經文文本的相互對照，更深邃地理解經意。

## **如何使用經文寶庫工具**

### **基本用法**

1. **輸入經文參照**：在輸入欄位中鍵入聖經經節或段落參照。
2. **按下 Enter**：經文寶庫的串珠參照與註解將立即載入。
3. **瀏覽內容**：捲動瀏覽詳盡的經文串珠與說明。
4. **點擊連結**：點擊任何內嵌的聖經引用，即可在聖經區域中開啟該經文。
5. **搜索歷史**：按向上箭頭鍵或點擊歷史紀錄圖示，即可還原上一次搜索。

### **輸入選項**

輸入欄位支援：
- **單節經文**：`John 3:16`
- **經文範圍**：`Romans 8:1-17`
- **多重參照**：`John 3:16; Romans 8:1; Psalm 23:1`
- **自動完成**：開始鍵入書卷名稱即可獲得即時建議

## **內容構成**

針對每一節經文，《經文寶庫》通常提供：

### **主題式經文串珠**

依主題或核心信息分類組織的連結：
- 具有相似概念的經文
- 平行對照段落
- 呈現對比的經文
- 闡明解釋性的段落

### **逐字逐詞參照**

針對經文中的核心關鍵詞或片語提供串珠參照：
- 「愛」→ 關於愛的所有其他經文
- 「信」→ 關於信心／相信的其他經文
- 「永生」→ 關於救恩的相關段落

### **語境脈絡參照**

- 平行記載（特別是福音書與列王紀／歷代志）
- 先知預言的應驗
- 歷史背景經文段落
- 貫穿始終的主題性連結

### **解釋性註記**

簡明精練的註記：
- 澄清艱澀難懂的片語
- 提供歷史時代背景
- 闡述神學核心要義
- 串聯聖經其他篇章的教導

## **功能特點**

```
John 3:16; Romans 5:8; 1 John 4:9
```
所有三處段落的經文串珠將一同載入，並由分段標題清晰分隔。

## **理解經文寶庫的詞條結構**

### **條目組織形式**

經文寶庫的條目通常遵循以下架構：

```
經文參照
  關鍵詞：串珠經文 1, 串珠經文 2, 串珠經文 3
  另一關鍵詞：串珠經文 4, 串珠經文 5
  包含額外串珠經文的解釋性註記
```

### **經文串珠類型**

1. **直接平行對照**：不同書卷對同一歷史事件的記載
2. **主題性關聯**：相似的神學主題或道德教訓
3. **預言的應驗**：舊約先知預言 → 新約基督成就
4. **字詞原文字義研讀**：同一希臘文／希伯來文字詞在聖經各處的用法
5. **語境解釋**：進一步解釋或擴展該節經意的段落
6. **對比性參照**：呈現對立面或平衡真理的經文

### **常見縮寫**

《經文寶庫》可能會使用如下拉丁文或英文縮寫：
- **cf.**：比較、參照（源自拉丁文 confer）
- **v.**：經節（verse）
- **ch.**：篇章（chapter）
- **ff.**：以及以下數節經文（following verses）
- **i.e.**：也就是、即（that is）
- **viz.**：即是、也就是（namely）

## **高效使用技巧**

1. **由廣入深**：查閱一處核心經節，並全面探索其發散出的所有串珠連結。
2. **順藤摸瓜**：點擊串珠經文，追蹤一連串環環相扣的相關經文鏈。
3. **比對多方記載**：用於福音書合參以及列王紀／歷代志的歷史對照。
4. **字詞研讀**：追蹤核心詞彙如何貫穿整部聖經並展開演繹。
5. **神學主題梳理**：觀察核心教義在聖經漸進啟示中的發展脈絡。
6. **語境構建**：透過整部聖經的互相參照，精準鎖定經文真義。
7. **快捷歷史**：使用向上箭頭鍵，在不同經文的串珠列表間迅速切換比對。
8. **多段並列**：一次輸入多節經文，觀察它們彼此之間的交互關係。

## **工作流程範例**

### **專題字詞研讀——「愛」**

1. 輸入：`John 3:16`
2. 找到《經文寶庫》中關於「愛」的串珠參照
3. 留意核心經文，如：約翰一書 4:9-10、羅馬書 5:8
4. 點擊每處引用閱讀完整經文段落
5. 輸入新的經節以檢視它們各自的串珠
6. 建立對聖經中神聖之愛的全面透徹理解

### **福音書合參對照**

1. 輸入：`Matthew 14:22-33`（耶穌在水面上行走）
2. 《經文寶庫》呈現馬可福音 6:45-52 與約翰福音 6:16-21 的平行記載
3. 點擊每處平行經文閱讀詳細記載
4. 比對每卷福音書所特有的細節
5. 體會各記載如何彼此相輔相成

### **預言與應驗**

1. 輸入：`Isaiah 53:5`
2. 《經文寶庫》展示新約中的應驗經文
3. 找到彼得前書 2:24、馬太福音 8:17 等經節引用
4. 點擊以檢視預言如何在基督身上精確應驗
5. 追蹤該救贖主題在整部聖經中的貫穿痕跡

### **教義研經——稱義**

1. 輸入：`Romans 3:24`
2. 尋找關於「稱義」的串珠參照
3. 留意緊密相連的經文：羅馬書 5:1、加拉太書 2:16、提多書 3:7
4. 點擊各經節研讀完整的教導脈絡
5. 對每處經節再次查閱《經文寶庫》以獲取更多關聯
6. 建立系統性的稱義教義體系

### **連鎖經文鏈研讀法**

1. 從一處關鍵核心經節出發
2. 找到其最主要的一處串珠經文
3. 在《經文寶庫》中查閱該串珠經文
4. 繼續追蹤該經節的串珠
5. 順著經文鏈持續探討
6. 帶著整體的豐富看見回照起初的經節

1. 輸入歷史敘事經文（例如：列王紀中的段落）

2. 查閱該主題的代表性經節
3. 順著串珠參照探索所有立約相關經文
4. 追蹤約在聖經救贖歷史中的步步深化
5. 形成一份詳盡的專題查經報告

### **教義多角度平衡對照**

1. 輸入闡述某項教義的經文
2. 尋找支持與印證的經文
3. 同時留意補充平衡或劃定界限的經文

5. 避免片面極端的神學偏差

## **局限性與注意事項**

### **非絕對窮盡**

- 任何工具書都無法窮盡神話語中所有潛在的關聯
- 您個人的深入研讀可能會發現更多奇妙的亮光
- 將《經文寶庫》作為研經的引導起點，而非封閉的終點

### **歷史時代背景**

- 《經文寶庫》是一部歷經時代沉澱的歷史巨著（最初成書於 19 世紀）
- 部分神學分類與註釋帶有其時代特色
- 建議與現代聖經工具及學術註釋互為印證

### **不可替代親自研讀**

- 經文串珠無法取代對篇章本身的細緻通讀
- 仍須親自深入每處串珠經文的上下文語境
- 聖靈的親自引導與光照始終是第一要務
