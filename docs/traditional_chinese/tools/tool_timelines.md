# **聖經時間軸指南**

本工具展示精美的視覺化時間軸圖片，透過詳盡的圖表與地圖，生動呈現聖經歷史、時期與重大事件的時間推進脈絡。

## **什麼是聖經時間軸？**

「聖經時間軸」工具提供一套由專業設計的視覺化時間軸圖片合輯，宏觀呈現聖經歷史的浩瀚全貌。這些時間軸巧妙結合了圖片、資訊圖表與地圖，幫助您直觀理解各歷史事件發生的年代，以及它們在時間上的相互關聯。

## **如何使用聖經時間軸**

1. **開啟工具**：從工具選單中選擇「聖經時間軸」。
2. **瀏覽歷史時期**：使用下拉式選單或導覽箭頭選擇歷史時期。
3. **檢視時間軸**：系統載入該時期的時間軸圖片。
4. **切換檢視模式**：在「符合寬度」與「實際大小」檢視之間切換。
5. **導覽跳轉**：使用「上一幅／下一幅」按鈕或下拉式選單在不同時間軸間切換。

## **收錄的時間軸**

本工具包含 25 幅全面詳盡的時間軸圖表，涵蓋：

### **舊約時期**

- **創世至大洪水**：太古歷史
- **先祖時期**：亞伯拉罕至約瑟（創世記）
- **出埃及與曠野漂流**：從埃及到迦南
- **征服與士師時期**：進駐應許之地
- **統一王國時期**：掃羅、大衛、所羅門
- **分裂王國時期**：以色列（北國）與猶大（南國）分立
- **被擄時期**：巴比倫之囚
- **回歸與重建時期**：被擄歸回時期

### **兩約之間時期**

- **沉默年代**：瑪拉基書至馬太福音之間
- **希臘與羅馬統治**：新約時代的歷史背景
- **馬加比時期**：猶太爭取獨立時期

### **新約時期**

- **基督生平**：降生至復活升天
- **使徒行傳**：早期教會的拓展
- **使徒時代**：保羅的事奉與各封書信
- **教會歷史**：第一世紀的基督教傳播

### **先知預言時間軸**

- **但以理的異象**：預言的年代時序
- **啟示錄**：末世事件的進程
- **彌賽亞預言**：預言應驗的時間軌跡

## **檢視模式**

### **符合寬度模式（預設）**

- 時間軸按比例自動縮放以適應您的螢幕寬度
- 無需水平捲動即可瀏覽整幅時間軸
- 最適合宏觀概覽與快速查閱
- 嚴格保持圖片長寬比
- 標題顯示於圖片下方

**最適用於：**
- 宏觀掌握整體歷史脈絡
- 快速掃描事件先後順序
- 講課簡報或課堂教學展示
- 連續比對多個時期時間軸

### **實際大小模式**

- 時間軸以原始超高解析度完整展示
- 可能需要捲動畫面以檢視圖片全部區域
- 纖毫畢現，所有微小字體與細節清晰可見
- 最適合閱讀緊密的文字與年代標記
- 不疊加標題遮蔽

**最適用於：**
- 閱讀密集的細節註釋
- 仔細研究精確年代與關聯連線
- 深入鑽研特定關鍵事件
- 列印輸出或擷取研經講義

**透過「符合寬度」開關即可在兩種模式間自由切換。**

- 新約書卷 → 對應的新約歷史時期

- 列王紀上下 → 分裂王國時期
- 馬太福音至約翰福音 → 基督生平
- 使徒行傳 → 早期教會
- 啟示錄 → 末世預言

## **時間軸包含的元素**

每幅時間軸通常包含：

### **視覺圖形元素**

- **時間刻度軸**：橫軸標記年代數字
- **事件標籤**：標示在時間軸上的重大事件點
- **時期分段**：以不同色彩區塊劃分各大歷史階段
- **平行對照事件**：不同地區同時發生的事件並列展示
- **地圖插入**：為歷史事件提供地理空間背景

### **文本資訊內容**

- **年代**：確切年份或考證估計年份
- **事件名稱**：核心重大事件的清晰標題
- **人物生平**：關鍵歷史人物及其生卒或作王年代
- **王朝／帝國更迭**：當時的世界強權政治背景
- **先知事奉期**：各先知發出預言的具體歷史年代

### **關係連線**

- 呈現事件之間的因果關係
- 標記前因後果的影響脈絡
- 串聯平行記錄的記載
- 展現家族王朝的傳承譜系

## **高效使用技巧**

1. **先用符合寬度**：先宏觀綜覽全圖，再放大至細節。
2. **循序推進瀏覽**：使用上一幅／下一幅按鈕，體會歷史時期之間的承接轉折。
3. **橫向比對事件**：留意同一時期在以色列、猶大以及周邊列國同時發生了什麼。
4. **研讀先知事奉**：觀察先知們相對於列王統治與歷史危機時期的出現時機。
5. **福音書時序梳理**：利用新約時間軸釐清耶穌三年半事奉的進程與足跡。
6. **讀經時的歷史背景**：在閱讀某卷書時，打開對應的時間軸圖表作為背景參考。
7. **教學展示利器**：在教授聖經歷史或主日學時將時間軸投屏展示。
8. **高畫質列印研讀**：切換至實際大小模式，擷取清晰圖面列印為研經輔助教材。

## **工作流程範例**

### **理解被擄與回歸歷史**

1. 選取「分裂王國時期」時間軸
2. 觀察走向滅亡與被擄的衰敗歷程
3. 點擊下一幅進入「被擄時期」時間軸
4. 了解巴比倫 70 年被擄歲月
5. 點擊下一幅進入「回歸與重建時期」
6. 綜覽在以斯拉、尼希米與所羅巴伯帶領下的歸回與重建

### **研讀先知書背景**

1. 選取分裂王國時期的時間軸
2. 標記各先知分別在哪位君王年間作先知
3. 分辨被擄前、被擄期與被擄後的先知群體
4. 掌握每卷先知書宣告時的具體政經危機
5. 將先知書的宣告與時間軸上的歷史事件精準對位

### **福音書生平合參**

1. 選取「基督生平」時間軸
2. 檢視耶穌降生、受浸、早期事奉、受難與復活的年表
3. 掌握三年半事奉期的地理推移與主要節期
4. 了解各大神蹟與講論發生的先後順序
5. 將四福音書的不同記載依歷史順序安置

### **保羅宣教腳蹤**

1. 選取「使徒行傳」時間軸
2. 檢視保羅蒙召歸主的年份
3. 追蹤三次宣教旅行與羅馬之行的年代
4. 將保羅書信按寫作時間與地點嵌入使徒行傳的歷史框架中
5. 理解每封書信成書時使徒所處的境遇

## **年代紀元系統說明**

### **舊約年代考證**

- 多數年代帶有考證估計性質
- 因學者採用不同的計算模型而略有差異
- 建基於聖經家譜、君王年表與古代近東歷史文獻
- 參照亞述、巴比倫、埃及等古代曆法天文記錄互相比對

### **新約年代考證**

- 精確度普遍顯著提高
- 具備豐富的羅馬帝國歷史文獻作對照
- 參照猶太歷史學家約瑟夫等古代文獻
- 部分特定年份仍有學術探討空間（例如：耶穌降生的確切西元年份）

### **西元紀年系統（BC / AD）**

- BC：西元前（Before Christ）
- AD：西元（Anno Domini，主後）
- 西元前年份由大往小倒數至 1 BC，隨後從 AD 1 往上遞增
- 傳統曆法系統中無「西元零年」
