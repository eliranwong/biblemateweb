# 整章譯本對照

**整章譯本對照**工具以多欄表格並排顯示多個聖經譯本的同一章經文，方便整章閱讀與比較。

## 開啟方式

- **全章工具選單**：在章標題按右鍵（或開啟三點選單 → `全章工具`），選擇 `👀 整章譯本對照`。
- **快速搜索**：輸入 `comparechapter`（或 `comparechapter:::KJV,NET,CUV` 指定譯本）。

## 功能特色

- **章節導航**：透過書卷／章節選單與 `Go` 按鈕跳轉章節，或使用底部的 `◀️ 上一章`／`下一章 ▶️` 按鈕切換。
- **多譯本選擇**：使用標籤多選下拉選單隨時新增或移除譯本。從特定譯本開啟時，該譯本會排在第一欄，其餘依[整章對照版本偏好設定](../user_preferences/chapter_comparison.md)排列。
- **逐節對照切換**：
  - **關閉（預設）**：以單列多欄顯示整章，優先讀取 `Bible` 資料表（若無 `Bible` 資料表則自動改讀 `Verses` 資料表）。
  - **開啟**：依各譯本 `Verses` 資料表的經節聯集逐節分列顯示；若某譯本缺少該節，該格留空但仍顯示其他譯本。
  - 切換狀態會自動儲存於 `compare_chapter_verse_by_verse`。
- **顯示差異切換** *（逐節對照開啟時顯示）*：以第一欄為基準，標示其他譯本的用詞差異（儲存於 `compare_chapter_diff`）。
- **雙向高亮與互動連結**：支援跨欄原文／譯本單詞雙向高亮（`hl1`/`hl0`）、單詞提示、Strong's 原文字典連結、註腳與螢光標記。
- **匯出 DOCX**：點擊 `📥 DOCX` 可將目前的整章對照表格匯出為 Word（`.docx`）文件。
