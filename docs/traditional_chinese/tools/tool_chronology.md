# **聖經時序指南**

本工具依時間順序顯示重大聖經事件，呈現聖經歷史中關鍵事件發生的年代與脈絡。

## **什麼是聖經時序？**

「聖經時序」工具以時間軸檢視呈現聖經記載的重要歷史事件，按估計年代編排，並連結至相應的聖經經文引用。這有助於您了解聖經事件的歷史先後順序，以及它們在時間上的相互關聯。

## **如何使用聖經時序**

1. **開啟工具**：從工具選單中選擇「聖經時序」。
2. **捲動時間軸**：事件按時間先後由早至晚依序顯示。
3. **點擊經文引用**：點擊任何聖經經文引用，即可在聖經區域中開啟該經文段落。
4. **閱讀描述**：每個事件均包含簡要描述與估計年代。

## **時間軸呈現方式**

時序以垂直時間軸形式呈現，包含：
- **事件標題**：清晰描述所發生的事件
- **日期／年份**：事件的估計日期或年份
- **聖經經文引用**：指向聖經記載的可點擊連結
- **圖示**：每個事件均配有 📖 書本圖示

## **主要涵蓋內容**

時序涵蓋重大聖經事件，例如：
- **創世與早期歷史**：創世、大洪水、巴別塔
- **先祖時期**：亞伯拉罕、以撒、雅各與約瑟的生平
- **出埃及與曠野時期**：出埃及、頒布律法、曠野漂流
- **征服與士師時期**：進入迦南地、士師時代
- **統一王國時期**：掃羅、大衛與所羅門統治時期
- **分裂王國時期**：北國（以色列）與南國（猶大）
- **被擄與回歸時期**：巴比倫被擄、在以斯拉與尼希米帶領下回歸
- **兩約之間時期**：舊約與新約之間的沉默時期
- **基督生平**：耶穌的降生、事奉、受難與復活
- **早期教會**：五旬節、宣教之旅、早期基督教的拓展

## **功能特點**

### **按歷史時序排列**

事件由最早至最近排序，讓您對聖經歷史的推進脈絡一目了然。

### **可點擊經文引用**

每個事件均附有聖經經文引用連結：
- 點擊後即可在聖經區域開啟對應經文
- 便於閱讀該事件的完整記載
- 幫助您在聖經語境中深入研讀事件

### **估計年代**

時間軸提供學者考證的估計年代：
- 具體年份（例如：「西元前 586 年」）
- 大致時期（例如：「約西元前 1446 年」）
- 相對年代（例如：「在……統治期間」）

### **並排對照閱讀**

當您在聖經區域中閱讀經文時，時序仍保留在工具區域中，讓您可以：
- 比對多個事件
- 在查看時間脈絡的同時閱讀經文記載
- 在各事件之間來回導覽而不會遺失當前閱讀位置

## **理解聖經年代考證**

聖經年代考證本身存在一些不確定因素：
- **舊約年代**：由於古代文化使用的曆法系統各異，年代通常為估計值
- **學術爭鳴**：部分年代在學術界存在多種觀點
- **曆法差異**：古代猶太曆、埃及曆、巴比倫曆與羅馬曆法互有不同
- **西元前／後紀年系統**：年代採用傳統的西元前（BC）與西元（AD）系統標記

## **高效使用技巧**

1. **歷史脈絡**：利用時序了解不同事件之間的相對發生時間。
2. **研讀預備**：在研讀歷史書卷（列王紀、歷代志等）前，先檢閱時間軸。
3. **連結事件**：觀察不同書卷中的事件在時間上的關聯（例如：被擄時期的先知）。
4. **教學輔助**：利用時間軸幫助他人將聖經歷史的宏偉全貌視覺化。
5. **對照閱讀**：在研讀歷史書時同時開啟時序，隨時掌握自己處於整體歷史的哪個節點。
6. **預言研讀**：了解預言發出的時間及其應驗的時間。

## **常見應用場景**

- **認識先知**：了解各先知分別在哪位君王統治期間事奉。
- **福音書合參**：掌握耶穌生平事件的先後順序。
- **保羅行蹤**：追蹤保羅各次宣教之旅相對於其他新約事件的時間點。
- **被擄時期**：掌握猶大滅亡、被擄與回歸的歷史脈絡。
- **舊約全貌**：按順序建立舊約歷史的宏觀視野。
