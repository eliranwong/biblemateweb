# **全章索引指南**

本工具顯示整卷聖經章節的綜合參考資訊，包含該章所提及的人物、地點、主題，以及相關的應許與平行經文。

## **什麼是全章索引？**

全章索引為每個聖經篇章提供完整的參考概覽，展示與該章任何經節相關的所有重要人物、地點、主題、字典詞條以及百科全書條目。這與特定經節的單節索引不同——全章索引匯總了整章的資訊。

## **如何使用全章索引**

1. **選擇篇章**：使用聖經選單選擇書卷與篇章（無需選擇經節）。
2. **點擊「開啓」**：載入該章的索引。
3. **瀏覽分類**：展開任何分類即可查看與該章相關的所有項目。
4. **點擊參照**：點擊任何項目即可查看更詳細的內容。

## **索引分類**

本工具將資訊組織為七個不同分類：

### **1. 聖經人物**

**圖示**：👥 群組（Groups）

列出該章提及的所有重要人物：
- 個人或群體的名稱
- 簡要身分資訊
- 相關聖經經文引用
- 指向完整人物資料的連結

**範例**：在創世記 12 章中，您會看到亞伯蘭、撒萊、羅得與法老的詞條。

### **2. 聖經地點**

**圖示**：📍 地點（Place）

顯示該章所參照的所有地理位置：
- 地點名稱（城市、地區、地標）
- 簡要地理背景
- 該地點出現的相關經文
- 指向詳細地點資訊的連結

**範例**：在約書亞記 6 章中，您會看到耶利哥、約旦河及相關的地理資料。

### **3. 聖經主題**

**圖示**：🏷️ 分類（Category）

標記該章所呈現的神學、道德與主題要點：
- 神學概念（信心、立約、審判）
- 道德主題（順服、罪、救贖）
- 文化主題（獻祭、節期、律法）
- 指向延伸主題探討的連結

**範例**：在羅馬書 3 章中，主題可能包括「稱義」、「信心」、「律法」與「罪」。

**注意**：「聖經主題」區塊預設為開啟狀態，便於快速查閱。

### **4. 聖經字典**

**圖示**：📚 字典（Dictionary）

為該章使用的核心詞彙提供字典定義：
- 字詞定義
- 神學解釋
- 歷史背景
- 聖經語境中的用法

### **5. 百科全書**

**圖示**：💎 深度知識（Deep Knowledge）

連結至全面的百科全書文章，內容涵蓋：
- 該章中的人物、地點與事件
- 詳細的歷史與神學背景
- 與相關聖經資料的經文串珠參照
- 學術見解

### **6. 聖經應許**

**圖示**：🎁 禮物（Gift）

顯示與該章相關的神的應許合輯：
- 依主題分類組織
- 每個應許合輯均有可點擊的標籤（Chips）
- 每個應許主題的完整經文清單

**範例**：若創世記 12 章包含關於祝福的應許，您會看到「關於祝福的應許」或「立約應許」的標籤。

### **7. 平行經文**

**圖示**：🔗 連結（Link）

顯示福音書平行經文與相關經文段落：
- 其他福音書中的平行記載
- 不同書卷中的類似事件
- 相關敘事
- 對照合參經文

**範例**：在馬太福音 5 章（登山寶訓），您會看到路加福音中的平行經文。

## **功能特點**

### **可收展區塊**

- 每個分類皆可獨立展開或摺疊。
- 「聖經主題」區塊會自動開啟以供快速參考。
- 點擊分類標題即可展開／摺疊內容。

### **互動式連結**

- **人物連結**：點擊可開啟詳細的人物檔案資料。
- **地點連結**：點擊可探索地理資訊與地圖。
- **主題連結**：點擊可查看全面的主題探討。
- **參照標籤**：點擊應許或平行經文標籤即可檢視完整合輯。

### **智慧篩選**

若某分類找不到任何項目，工具會顯示「找不到此類別的條目」，而非完全隱藏該區塊。

## **全章索引與單節索引的差異**

| 全章索引 | 單節索引 |
| :---- | :---- |
| 顯示整章的所有條目 | 僅顯示特定經節的條目 |
| 匯總檢視 | 聚焦檢視 |
| 最適合章節層級的研經 | 最適合單節層級的研經 |
| 無需選擇特定經節 | 必須指定特定經節 |

## **高效使用技巧**

1. **篇章概覽**：在研讀某一章之前使用，了解其中涉及的主題與人物。
2. **講道預備**：迅速識別某段經文中的所有核心主題，用於擬定講道大綱。
3. **經文串珠研讀**：利用平行經文部分，研究不同記載之間的關聯。
4. **專題研究**：尋找探討特定神學主題的篇章。
5. **歷史背景**：利用地點與人物區塊了解當時的歷史情境。
6. **追蹤應許**：發掘當前閱讀內容中出現的神的應許。

## **工作流程範例**

**研讀羅馬書 8 章：**
1. 載入羅馬書 8 章的全章索引
2. 打開「聖經主題」查看各項主題：「聖靈」、「兒子的名分」、「榮耀」、「預定」
3. 查看「聖經應許」標籤，尋找有關盼望與救贖的應許
4. 點擊主題連結以深入探討神學概念
5. 利用此概覽建構您的查經或教學大綱

## **從結果中導覽**

- **點擊聖經經文引用**：在聖經區域中開啟該經文段落
- **點擊字典／百科全書連結**：在新的標籤頁中開啟詳細文章
- **點擊合輯標籤**：載入完整的聖經應許或平行經文合輯


## **本章地圖、人物關係圖譜與研讀筆記匯出**

- **本章地圖**：當該章包含聖經地點時，展開 **本章地圖** 即可在同一張互動式地圖上標記本章所有地點與名稱提示。
- **人物關係圖譜**：展開 **人物關係圖譜**，即可透過互動式力導向圖譜檢視本章出現的人物及其彼此關係。
- **匯出研讀筆記**：點擊頁面底部的 **匯出研讀筆記** 按鈕，即可將本章的人物、地點、主題、字詞典、百科條目及高頻原文字詞整合為單一 Markdown 檔案下載保存。
