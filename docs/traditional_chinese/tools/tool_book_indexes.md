# 全書索引指南

**全書索引**提供整卷聖經書卷的參考概覽儀表板。

- **書卷選擇**：直接選擇任一聖經書卷並點擊 **前往**（無需選擇章或節）。
- **全書譯本詞彙**：於一般譯本預設展開（當聖經視窗顯示 `ORB`、`OLB`、`OPB`、`OIB`、`ODB`、`OHGB`、`OHGBi`、`LXX`、`LXX1`、`LXX1i`、`LXX2`、`LXX2i` 等原文／逐字對照版本時自動隱藏）。提供 **隱藏常見虛詞** 開關、**全書關鍵詞**、**全書罕見原文字詞**，點擊標籤即可在 **經文搜索** 中針對該書卷搜尋。
- **全書詞彙與罕見詞**：於原文聖經版本預設展開，列出**全書高頻原文字詞**與**全書罕見詞（全本聖經出現 ≤ 3 次）**，點擊即可開啟原文詞典。
- **人物關係圖譜**：以互動式力導向圖譜呈現整卷書的人物與彼此關係。
- **本書地圖**：在同一張互動式地圖上標記本書卷出現的所有聖經地點。
- **聖經人物**、**聖經地點** 與 **聖經主題**：整卷書去重後的詞條標籤（**聖經主題**依 `HIT`、`NAV`、`TCR` 等模組分組顯示）。
- **匯出研讀筆記**：下載整卷書的 Markdown 研讀筆記。
- **全書工具**：頁面底部快捷按鈕可於下一個標籤頁開啟 **聖經時間軸**、**書卷分析**（及常用分析分項）、**全章索引** 與 **筆記**（若已設定）。
