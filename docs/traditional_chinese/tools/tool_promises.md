# **聖經應許指南**

本工具將聖經中神的所有應許整理為主題合輯，讓您能夠輕鬆在聖經中找到安慰、盼望與確據。

## **什麼是聖經應許？**

「聖經應許」工具是按主題歸納分類的神的應許精選合輯。每個合輯將相關的應許匯集在一起，為您展示神向祂子民作出承諾、保證與誓約的所有相關聖經段落。

## **主要涵蓋內容**

本工具收錄依主題系統整理的應許合輯，例如：
- **供應與看顧**：神應許供應您一切所需
- **保護與平安**：神時刻看顧保守的應許
- **同在**：神應許與您永遠同在
- **引導**：神親自指引方向的應許
- **力量**：神賜下能力與忍耐力量的應許
- **平安**：內心出人意外平安的應許
- **醫治**：身體與心靈得蒙醫治復原的應許
- **赦免**：神的憐憫與恩典之應許
- **永生**：關於救恩與天國的應許
- **禱告**：禱告蒙垂聽與應允的應許
- 以及更多豐富主題……

## **如何使用聖經應許**

1. **開啟工具**：從工具選單中選擇「聖經應許」。
2. **瀏覽合輯**：捲動瀏覽各應許分類清單。
3. **展開合輯**：點擊任何分類即可查看其收錄內容。
4. **檢視應許**：每個應許均附帶聖經經文引用。
5. **點擊引用**：點擊任何聖經引用即可閱讀完整經文段落。

## **合輯顯示方式**

每個應許合輯均包含：

### **合輯標題**

- 清晰的主題標題（例如「關於供應的應許」）
- 圖示：📚（auto_stories）
- 可展開／摺疊區塊

### **應許內容**

在每個合輯內部：
- **聖經經文引用**：指向相關經文段落的連結
- **簡要上下文**：部分條目包含輔助說明文字
- **多項應許**：所有相關應許分門別類集中展示
- **條理格式**：清晰易讀的呈現方式

## **功能特點**

### **可收展區塊**

- 所有合輯預設為摺疊狀態，便於快速瀏覽查閱
- 點擊任何合輯標題即可展開檢視各項應許
- 支援同時打開多個合輯
- 可摺疊當前未使用的區塊

### **可點擊經文引用**

所有聖經引用均具備互動功能：
- 點擊即可在聖經區域中開啟該經文段落
- 在完整的上下文脈絡中研讀應許
- 在不同應許之間輕鬆穿梭切換
- 保持應許清單持續顯示於工具區域中

### **主題式組織**

應許依據以下原則分類：
- **專題分類**：針對特定生活情境
- **神學主題**：核心教義概念（救恩、成聖）
- **處境應用**：適用於特定心靈需要（恐懼、憂慮、哀傷）

### **全面廣泛的涵蓋**

合輯廣泛收錄：
- 舊約應許
- 新約應許
- 先知預言性應許
- 個人性應許

## **如何支取神的應許**

### **1. 理解上下文**

- 點擊引用閱讀完整經文段落
- 理解該應許起初是對誰作出的
- 考量該應許是否附帶任何前提條件
- 閱讀上下文經文以掌握完整意涵

### **2. 查驗前提條件**

部分應許附帶條件：
- 「你們若常在我裡面……」（以順服為前提）
- 「這稱為我名下的子民，若是自卑、禱告……」（以行動為前提）
- 「你們若專心尋求我，就必尋見」（以真誠為前提）

### **3. 應用於個人生命**

- 辨明該應許如何適切應用於您當前的景況
- 堅信神的信實屬性與慈愛
- 本著對應許的信心踏出步伐
- 為神確鑿的保證獻上感恩

### **4. 堅定站立於應許之上**

- 熟背關鍵應許經文
- 在患難試煉中思想神的應許
- 與身處難處的肢體分享應許
- 讓應許堅固您的信心

## **高效使用技巧**

1. **晨更靈修**：每日早晨閱讀與您當前處境相關的應許，開啟新的一天。
2. **專題查考**：系統性探索與特定主題相關的所有應許。
3. **禱告指南**：將神的應許作為禱告呼求與祈求的基石。
4. **肢體勉勵**：將應許合輯分享給正面臨艱難困境的朋友。
5. **背誦金句**：從合輯中選取核心應許經文加以背誦。
6. **堅固信心**：當信心遭遇動搖時，研讀應許合輯以重新得力。
7. **見證主恩**：記錄並數算神如何在您的生命中成就祂的應許。

## **工作流程範例**

### **在困境中尋得安慰**

1. 開啟聖經應許工具
2. 找到「神同在的應許」或「安慰的應許」
3. 展開該合輯
4. 逐一閱讀各項應許，點擊引用檢視完整上下文
5. 選取一節應許深刻默想
6. 背誦並憑信心支取該項應許

### **禱告預備**

1. 釐清您的心靈需要（例如：尋求指引、缺乏供應、身體軟弱）
2. 找到相應的應許合輯
3. 閱讀所有相關經文
4. 將應許化為禱告詞：
   - 「主啊，祢曾應許說……」
   - 「祢的話語宣告……」
   - 「我相信祢必照應許……」

### **福音佈道與見證**

1. 找到「救恩的應許」或「永生的應許」
2. 標記核心福音應許
3. 在分享信仰時善用這些經文
4. 幫助慕道朋友明白神賜給信靠者何等浩大的應許

### **主日學或查經預備**

1. 選定查經專題（例如：「勝過恐懼」）
2. 找到相關應許合輯（例如：「保護的應許」）
3. 條列所有相關經節
4. 以神的應許為核心構建查經大綱
5. 帶領小組一同查考

## **理解不同類型的應許**

### **無條件應許**

神全然無條件賜下的保證：
- 神與挪亞立約（不再用洪水毀滅全地）
- 亞伯拉罕之約
- 在基督裡立的新約
- 基於神永恆屬性所立的應許

### **有條件應許**

需要人以順服或信心回應：
- 「你們若尋求我，就必尋見」
- 「你們饒恕人的過犯，天父也必饒恕你們」
- 「這稱為我名下的子民，若是自卑、禱告……」
- 與順服緊密相連的祝福

### **普世性應許**

適用於全體人類：
- 「叫一切信祂的，不致滅亡，反得永生」
- 「凡求告主名的，就必得救」
- 賜予萬國萬民的福音應許

### **特定性應許**

針對特定個人或群體發出：
- 給以色列民的應許
- 給教會的應許
- 給特定人物的應許（大衛、馬利亞等）

### **已然未然（Already/Not Yet）應許**

已經部分應驗，正等候最終圓滿成就：
- 神的國度（現在已臨到，將來完全實現）
- 新造的人與新創造（已經開始，尚未完全）
- 身體復活（基督已復活，信徒等候復活）

## **神學根基**

### **神的信實**

- 神決不能說謊（提多書 1:2）
- 神的應許在基督裡都是「是的」，都是「阿們」的（哥林多後書 1:20）
- 神所應許的，祂必能作成（羅馬書 4:21）
- 祂的信實存到萬代

### **基督是應許的圓滿實現**

- 一切應許在耶穌裡都找到了「是的」
- 舊約所有應許在基督裡得到完全成全
- 新約的恩典應許建基於祂在十架上的救贖大工
- 未來的永恆應許由祂的復活作為確鑿擔保

### **聖靈作為質押憑據**

- 聖靈是我們得基業的憑據／定金（以弗所書 1:13-14）
- 蓋上印記直到得贖的日子
- 保證未來應許的終極實現
- 賜力量給信徒使其堅定信靠應許
