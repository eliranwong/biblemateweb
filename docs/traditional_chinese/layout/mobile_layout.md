# 行動裝置版面

在窄螢幕上，頁頂標題列會顯示一個**漢堡按鈕**用以開啟左側抽屜，取代電腦版的標題與快速搜索框。

## 抽屜內容

- 頭像/標題按鈕（顯示 [URL 與 QR 碼](url_qr_code.md)）
- [快速搜索](quick_search.md)
- 開關：`Go`、`Swap`、`Tabs`、`Notes`、`Tooltip`、`Sync`、`Fullscreen`、`Dark Mode`
- 可展開的聖經與工具清單
- 版面選項：只顯示聖經、只顯示工具、聖經與工具

做出選擇後，抽屜會自動關閉。

## 直向模式

在直向螢幕下，兩個區域呈垂直堆疊。使用[切換版面](toggle_layout.md)可讓單一區域全螢幕顯示。
