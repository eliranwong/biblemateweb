# URL 參數

網址列會隨著您的導覽操作即時更新，因此任何檢視畫面皆可加入書籤或進行分享。範例：`/?bbt=NET&bb=43&bc=3&bv=16&l=2`。

| 參數 | 說明 |
|---|---|
| `l` | 版面：`1` 只顯示聖經，`2` 聖經與工具，`3` 只顯示工具 |
| `bbt`, `bb`, `bc`, `bv` | 聖經區：版本、書卷編號、篇章、節數 |
| `tool` | 工具區內容：`bible`、`audio`、`chronology`、搜索或工具名稱 |
| `tbt`, `tb`, `tc`, `tv` | 工具區：版本、書卷、篇章、節數 |
| `tq` | 工具查詢字串 |
| `s` | 同步開啟/關閉 |
| `d` | 深色模式開啟/關閉 |
| `fs` | 字型大小（%） |
| `pc`, `sc`, `nc` | 主要、次要、否定色彩 |
| `lang` | 介面語言 |
| `m` | 顯示選單（`false` 會隱藏頁頂標題列） |
| `k` | 在瀏覽器歷史記錄中保留有效參數 |
| `t` | 僅限本次造訪使用的自訂憑證（不會儲存；適用於公用裝置） |

書卷編號為 1–66。
