# 設定選單

頁頂標題列中的齒輪圖示。

| 項目 | 用途 |
|---|---|
| 上一頁 / 下一頁箭頭 | 瀏覽器歷史記錄導覽 |
| 只顯示聖經 / 只顯示工具 / 聖經與工具 | [切換版面](toggle_layout.md) |
| 版面轉換開關 | 顯示/隱藏[版面轉換按鈕](floating_buttons.md) |
| 開啓開關 | 顯示/隱藏[開啓按鈕](floating_buttons.md) |
| 筆記開關 | 顯示/隱藏筆記標記（重新載入頁面） |
| 提示框開關 (Tooltip) | 切換懸停顯示單詞提示框（關閉時需點擊單詞才顯示[提示框](../integrations/word_tooltips.md)） |
| 同步開關 | 切換[同步](sync.md)狀態 |
| 螢幕開關 | 切換全螢幕 |
| 淺色模式 / 深色模式 | 切換[深色模式](../user_preferences/dark_mode.md)（重新載入） |
| 偏好設定 | 開啟完整的[偏好設定](../user_preferences/README.md)頁面 |
