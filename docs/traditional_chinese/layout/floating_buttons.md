# 浮動按鈕

畫面右下角漂浮著兩個圓形小按鈕。

| 按鈕 | 圖示 | 工具提示 | 操作 |
|---|---|---|---|
| 版面轉換 | `swap_horiz` | 版面轉換 | 循環切換[版面模式](toggle_layout.md) |
| 開啓 | `menu_book` | 聖經選單 | 開啟[聖經選單對話框](bible_selection_dialog.md) |

## 移動按鈕

每個按鈕均**可拖曳**。將其拖曳並放置於任意位置；它會吸附至放置位置。如果按鈕遮擋了您想閱讀的內容，此功能非常實用。重新載入頁面時位置會重置。

## 顯示或隱藏

| 按鈕 | 儲存鍵值 | 預設 |
|---|---|---|
| 版面轉換 | `layout_swap_button` | 開啟 |
| 開啓 | `bible_select_button` | 開啟 |

切換開關：

- **電腦版：**設定（齒輪）選單 → `Swap` 或 `Go` 旁邊的開關。
- **行動版：**開啟左側抽屜（漢堡圖示）並使用 `Swap` / `Go` 開關。

選擇結果會自動儲存。
