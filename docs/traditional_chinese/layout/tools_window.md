# 工具

**工具**選單（`build` 圖示）會在工具區中開啟研經工具。

## 標籤頁項目

`新工具標籤頁`（`Add Tool Tab`）、`關閉工具標籤頁`（`Close Tool Tab`）、`關閉其他`（`Close Others`）——請參閱[標籤頁管理](tabs_management.md)。

## 同步工具

大多數工具會在聖經區目前顯示的經文處開啟（請參閱[同步](sync.md)）。`Books` 不會進行同步。

## 從快速搜索開啟工具

輸入 `toolname:::query`（例如 `xrefs:::John 3:16`）——請參閱[快速搜索](quick_search.md)。
