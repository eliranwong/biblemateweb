# 標籤頁管理

兩個區域都有各自獨立的標籤頁。聖經區標籤頁命名為 `Bible 1, 2, ...`；工具區標籤頁命名為 `Tool 1, 2, ...`（會根據載入的內容重新命名）。

## 新增標籤頁

| 區域 | 選單 | 項目 |
|---|---|---|
| 聖經 | 聖經（`local_library`） | 新聖經標籤頁 |
| 平行 | 平行聖經（`devices_fold`） | 新平行標籤頁 |
| 工具 | 工具（`build`） | 新工具標籤頁 |

平行聖經標籤頁與工具標籤頁皆屬於工具區。

## 關閉標籤頁

- 按一下標籤頁上的小 **x** 即可關閉該標籤頁（即使它目前處於非作用中狀態）。
- 選單 → `Close Bible Tab`（關閉聖經標籤頁）、`Close Parallel Tab`（關閉平行標籤頁）或 `Close Tool Tab`（關閉工具標籤頁）可關閉作用中的標籤頁。
- 選單 → `Close Others`（關閉其他）可關閉除作用中標籤頁之外的所有其他標籤頁。
- **最後剩下的一個標籤頁無法關閉**（會顯示警告）。

## 持久性保存

標籤頁內容儲存於您的使用者儲存空間中，並在下次造訪時予以還原。已關閉的標籤頁會從儲存空間中移除。

## 預設標籤頁數量

首次啟動時開啟的標籤頁數量可在偏好設定中進行設定：

- [聖經標籤頁](../user_preferences/default_number_of_tabs1.md)（`default_number_of_tabs1`，預設為 3）
- [工具標籤頁](../user_preferences/default_number_of_tabs2.md)（`default_number_of_tabs2`，預設為 3）

## 提示

- 每個聖經版本各保留一個標籤頁，方便進行譯本對比。
- 搜索結果會載入至作用中的工具標籤頁；若想保留先前的結果，請先開啟一個新標籤頁。
