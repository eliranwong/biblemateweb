# 聖經視窗

**聖經區（第 1 區）**是主要的閱讀視窗。

## 開啟聖經

從**聖經**選單（`local_library` 圖示）：

- 您的**主要**與**次要**聖經（[偏好設定](../user_preferences/primary_bible.md)）。
- 原文語言聖經：`ORB` 原文讀者聖經、`OIB` 逐字對照、`OPB` 平行、`ODB` 篇章語法分析、`OLB` 語言學分析。
- 自訂聖經（若已啟用有效的[自訂憑證](../user_preferences/custom_token.md)）以及伺服器上設定的所有其他聖經。

選取聖經會將其載入至**作用中的標籤頁**。若快速搜索或選取的文字包含經文出處，聖經將直接開啟至該節經文。

## 導覽

- 透過開啓按鈕開啟[聖經選單對話框](bible_selection_dialog.md)。
- [快速搜索](quick_search.md)，例如輸入 `John 3:16`。
- 經文上的[右鍵選單](context_menus.md)。

## 標籤頁標籤與瀏覽器標題

標籤頁標籤會顯示聖經版本。瀏覽器標題會更新為 `[Version] Reference`，且網址列也會隨之更新，以便將任何位置加入書籤（[URL 參數](url_parameters.md)）。

## 各標籤頁獨立記憶

每個標籤頁都會記住其聖經版本、書卷、篇章和節數，並在您返回時予以恢復。
