# AI 選單

**AI** 選單（`auto_awesome` 圖示）提供：

| 項目 | 開啟內容 |
|---|---|
| 書卷分析 | 書卷的 AI 分析（[指南](../tools/tool_analysis.md)） |
| 全章摘要 | 篇章的 AI 摘要（[指南](../tools/tool_summary.md)） |
| AI 註釋 | 目前經文段落的 AI 註釋（[指南](../tools/tool_commentary.md)） |
| 對話模式 | 對話頁面 |
| 夥伴模式 | 互動式研經夥伴 |
| 代理模式 | 自主代理 |

全部均在工具區中開啟。

## 組態設定

- 在[偏好設定](../user_preferences/README.md)中選擇您的提供者、金鑰與模型——請參閱 [BYOK](../user_preferences/api_key_setup.md)。
- 管理員可能會限制代理模式與夥伴模式的使用量；使用您自己的金鑰可不受這些限制。
