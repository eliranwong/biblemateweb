# 切換版面

BibleMate 提供三種版面模式。目前的模式會記住在您的使用者儲存空間中（`layout`，預設為 `2`）。

| 模式 | 數值 | 結果 |
|---|---|---|
| 只顯示聖經 | `1` | 僅顯示聖經區（分隔線位於 100%） |
| 聖經與工具 | `2` | 同時顯示兩個區域，以 50/50 對半分割 |
| 只顯示工具 | `3` | 僅顯示工具區（分隔線位於 0%） |

## 更改版面的方式

1. **版面轉換浮動按鈕**（`swap_horiz` 圖示）。每次點擊依序循環 `1 → 2 → 3 → 1`。請參閱[浮動按鈕](floating_buttons.md)。
2. **設定選單**（頁頂標題列中的齒輪圖示）：直接選擇「只顯示聖經」、「只顯示工具」或「聖經與工具」。
3. **URL 參數** `l=1|2|3`，例如 `/?l=1`。請參閱[URL 參數](url_parameters.md)。

## 自動切換

- 在**只顯示工具**模式下載入內容至聖經區，會自動切換為**聖經與工具**。
- 在**只顯示聖經**模式下載入內容至工具區，會自動切換為**聖經與工具**。

因此，從選單中選取工具或聖經時，一定會使其所屬視窗顯示出來。

## 提示

- 在手機上，可使用「只顯示聖經」進行閱讀，使用「只顯示工具」以獲取最大的研經空間。
- 您也可以在兩個區域之間手動拖曳分隔線。
