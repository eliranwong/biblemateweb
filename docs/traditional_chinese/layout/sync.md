# 同步

當**同步**開啟時，聖經區與工具區會保持在相同的書卷與篇章。

| 鍵值 | 預設 |
|---|---|
| `sync` | 開啟 |

## 切換方式

- **電腦版：**設定（齒輪）→ `Sync` 開關。
- **行動版：**左側抽屜 → `Sync` 開關。
- **URL：**`s=true` 或 `s=false`（[URL 參數](url_parameters.md)）。

## 行為表現

- 在聖經區更改篇章也會將工具區中的**平行聖經**移至相同位置（反之亦然）。
- 在同步模式下開啟的工具（聖經語音、AI 註釋、經文串珠、經文寶庫、形態學分析、資源索引等）將從聖經區顯示的經文處開始。
- 關閉同步時，各工具會保留各自的書卷/篇章/節數。
