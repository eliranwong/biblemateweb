# 快速搜索

頁頂標題列中的輸入框（在行動裝置上位於左側抽屜中）。支援書卷名稱、工具名稱和聖經版本的自動完成功能。按 **Enter** 鍵即可執行。

## 可輸入的內容

| 輸入內容 | 結果 |
|---|---|
| 聖經版本，例如 `KJV` | 在聖經區開啟該聖經 |
| 單一經文出處，例如 `John 3:16` | 在聖經區開啟該篇章 |
| `KJV:::John 3:16` | 以指定的版本開啟它 |
| `bible:::John 3:16` | 在工具區中以平行聖經開啟 |
| `bible:::KJV:::John 3:16` | 指定版本的平行聖經 |
| `tool:::query`，例如 `xrefs:::John 3:16` | 開啟工具並帶入查詢內容 |
| 任何其他內容或多個經文出處 | 在工具區中搜索經文 |

搜索後會清空輸入框。`tool:::` 可用的工具名稱即為自動完成建議中提供的名稱。
