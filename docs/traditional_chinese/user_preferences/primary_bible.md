# 主要聖經 (Primary Bible)

開啟聖經內容時作為主要版本使用的聖經版本。可選清單取決於伺服器上可用的資源（以及是否啟用了有效的自訂權杖）。

| | |
|---|---|
| 位置 | `偏好設定` → `常用資源` → `Primary Bible` |
| 儲存鍵 | `primary_bible` |
| 預設值 | `NET` |

## 如何修改

1. 開啟 `偏好設定`（`/settings` 頁面）。
2. 展開 `常用資源` 區塊。
3. 調整 `Primary Bible`。

變更會自動儲存在與您瀏覽器關聯的使用者儲存空間中。使用 `重置所有偏好設定` 可恢復預設值。
