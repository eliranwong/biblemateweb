# 頭像 URL

用作個人資料頭像的圖片 URL。留空則使用預設頭像，例如 `https://example.com/avatar.png`。

| | |
|---|---|
| 位置 | `Preferences` → `User & Custom Data` → `Avatar URL` |
| 存儲鍵 | `avatar` |
| 預設值 | `(empty)` |

## 如何變更

1. 開啟 `Preferences`（`/settings` 頁面）。
2. 展開 `User & Custom Data` 分類。
3. 調整 `Avatar URL`。

變更會自動保存在與您瀏覽器關聯的用戶存儲中。使用 `Reset All Preferences` 可恢復預設值。
