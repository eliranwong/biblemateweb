# 聖經標籤頁

預設開啟的聖經標籤頁數量。為 1 到 10 的滑桿。

| | |
|---|---|
| 位置 | `Preferences` → `Tabs Management` → `Bible Tabs` |
| 存儲鍵 | `default_number_of_tabs1` |
| 預設值 | `3` |

## 如何變更

1. 開啟 `Preferences`（`/settings` 頁面）。
2. 展開 `Tabs Management` 分類。
3. 調整 `Bible Tabs`。

變更會自動保存在與您瀏覽器關聯的用戶存儲中。使用 `Reset All Preferences` 可恢復預設值。
