# AI 後端

AI 服務提供商。選項包括：`default`（伺服器設定）、`googleai`、`openai`、`anthropic`、`cohere`、`deepseek`、`mistral`、`xai`、`azure_*` 變體、`ollamacloud`、`custom`。若管理員已啟用，`grok`、`claude` 和 `antigravity` 將使用伺服器已登入的訂閱 CLI，無需 API 金鑰。

| | |
|---|---|
| 位置 | `Preferences` → `AI Backend` → `AI Backend` |
| 存儲鍵 | `ai_backend` |
| 預設值 | `default` |

## 如何變更

1. 開啟 `Preferences`（`/settings` 頁面）。
2. 展開 `AI Backend` 分類。
3. 調整 `AI Backend`。

變更會自動保存在與您瀏覽器關聯的用戶存儲中。使用 `Reset All Preferences` 可恢復預設值。

另請參閱 [api_key_setup.md](api_key_setup.md)。
