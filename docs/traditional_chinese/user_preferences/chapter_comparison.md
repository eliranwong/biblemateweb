# 整章對照版本

設定從全章右鍵選單開啟**整章譯本對照**時預設顯示的聖經譯本。

- **位置**：`偏好設定` → `常用資源` → `整章對照版本`
- **儲存鍵值**：
  - `chapter_comparison_mode`：`'default'`（預設）或 `'custom'`
  - `chapter_comparison_bibles`：已選聖經譯本縮寫清單（例如 `['NET', 'KJV', 'CUV', 'OHGBi']`）

## 行為說明

- **預設**：將目前開啟的聖經譯本置於第一欄，接著顯示您的`主要聖經`、`次要聖經`及 `OHGBi`（自動去重）。
- **自訂**：顯示多選標籤下拉選單（`選擇對照譯本`）供您指定常用譯本。從特定譯本開啟時，該譯本會置於自訂清單之前；若未選擇任何譯本，則回退至`預設`。
