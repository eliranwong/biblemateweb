# API 端點

自定 API 端點 URL，適用於 `custom` 後端或由 Azure 託管的後端。留空則使用提供商的預設值。該欄位已遮蔽；點擊眼睛圖示即可顯示。

| | |
|---|---|
| 位置 | `Preferences` → `AI Backend` → `API Endpoint (Optional)` |
| 存儲鍵 | `api_endpoint` |
| 預設值 | `(empty)` |

## 如何變更

1. 開啟 `Preferences`（`/settings` 頁面）。
2. 展開 `AI Backend` 分類。
3. 調整 `API Endpoint (Optional)`。

變更會自動保存在與您瀏覽器關聯的用戶存儲中。使用 `Reset All Preferences` 可恢復預設值。
