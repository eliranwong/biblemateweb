# 自定令牌

自定令牌用於自定資源和 AI 功能的存取控制。

## 給開發者

若要設定自定令牌，請在設定檔 `~/biblemate/biblemateweb.config` 中將字串指定為 `config.custom_token` 的值。

## 給使用者

若要使用由伺服器管理員提供的自定令牌：

1. 向您的伺服器管理員取得令牌
2. 前往 `Preferences`
3. 在 `User & Custom Data` 分類下
4. 在 `Custom Token` 欄位中輸入有效的令牌
