# 次要聖經 (Secondary Bible)

作為次要版本使用的聖經版本，例如用於版本對比。可選清單取決於伺服器上可用的資源。

| | |
|---|---|
| 位置 | `偏好設定` → `常用資源` → `Secondary Bible` |
| 儲存鍵 | `secondary_bible` |
| 預設值 | `KJV` |

## 如何修改

1. 開啟 `偏好設定`（`/settings` 頁面）。
2. 展開 `常用資源` 區塊。
3. 調整 `Secondary Bible`。

變更會自動儲存在與您瀏覽器關聯的使用者儲存空間中。使用 `重置所有偏好設定` 可恢復預設值。
