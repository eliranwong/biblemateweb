# ODB NT Translation

在[原文語法結構聖經 (ODB)](../bibles/original_discourse.md)中顯示的新約譯本。選項來自伺服器上可用的 `.bible` 譯本模組（啟用有效自訂權杖時亦包含 `~/biblemate/data_custom/bibles/`）。

| | |
|---|---|
| 位置 | `Preferences` → `Frequently Used Resources` → `ODB NT Translation` |
| 存儲鍵 | `odb_nt_trans` |
| 預設值 | `NET` |

## 如何變更

1. 開啟 `Preferences`（`/settings` 頁面）。
2. 展開 `Frequently Used Resources` 區塊。
3. 調整 `ODB NT Translation`。

設定會自動儲存在與瀏覽器連結的使用者儲存空間中。使用 `Reset All Preferences` 可恢復預設值。
