# 經文對照版本

控制從經文右鍵選單或單節索引的**單節工具**觸發**版本對比**時所開啟的聖經譯本。

- **位置**：`偏好設定` → `常用資源` → `經文對照版本`
- **儲存鍵**：
  - `verse_comparison_mode`：`'default'`（預設）或 `'custom'`（自訂）
  - `verse_comparison_bibles`：所選聖經譯本縮寫清單（例如 `['NET', 'KJV', 'CUV', 'OHGBi']`）

## 行為說明

- **預設**：比較您的 `主要聖經`、目前開啟或點擊的聖經版本，以及 `OHGBi`。
- **自訂**：顯示多選標籤下拉選單（`選擇對照譯本`），讓您自由指定偏好的對照版本；若清單留空則自動退回**預設**行為。
