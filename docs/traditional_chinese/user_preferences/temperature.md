# 模型溫度 (Model Temperature)

控制 AI 輸出的隨機性，範圍為 0.0 至 2.0，步進值為 0.1。數值較低時回答更專注且具確定性；數值較高時回答更多樣化。

| | |
|---|---|
| 位置 | `偏好設定` → `AI Backend` → `Model Temperature (Optional)` |
| 儲存鍵 | `temperature` |
| 預設值 | `0.3` |

## 如何修改

1. 開啟 `偏好設定`（`/settings` 頁面）。
2. 展開 `AI Backend` 區塊。
3. 調整 `Model Temperature (Optional)`。

變更會自動儲存在與您瀏覽器關聯的使用者儲存空間中。使用 `重置所有偏好設定` 可恢復預設值。
