# OPB OT Translation 1

在[原文平行聖經 (OPB)](../bibles/original_parallel.md)中顯示的舊約第一平行子句譯本。選項來自 `~/biblemate/data/clauses/` 中的 `.clause` 模組（啟用有效自訂權杖時亦包含 `~/biblemate/data_custom/clauses/`）。

| | |
|---|---|
| 位置 | `Preferences` → `Frequently Used Resources` → `OPB OT Translation 1` |
| 存儲鍵 | `opb_ot_trans1` |
| 預設值 | `KJV` |

## 如何變更

1. 開啟 `Preferences`（`/settings` 頁面）。
2. 展開 `Frequently Used Resources` 區塊。
3. 調整 `OPB OT Translation 1`。

設定會自動儲存在與瀏覽器連結的使用者儲存空間中。使用 `Reset All Preferences` 可恢復預設值。
