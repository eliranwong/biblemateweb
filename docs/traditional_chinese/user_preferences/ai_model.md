# AI 模型

與所選後端搭配使用的模型 ID。例如：`grok` 可填寫 `grok-4.7`；`claude` 可填寫 `sonnet`、`opus`、`haiku` 或完整的模型 ID；`antigravity` 可填寫 `gemini-3.8-flash-high`。留空則使用該後端的預設值。

| | |
|---|---|
| 位置 | `Preferences` → `AI Backend` → `AI Model` |
| 存儲鍵 | `ai_model` |
| 預設值 | `(empty)` |

## 如何變更

1. 開啟 `Preferences`（`/settings` 頁面）。
2. 展開 `AI Backend` 分類。
3. 調整 `AI Model`。

變更會自動保存在與您瀏覽器關聯的用戶存儲中。使用 `Reset All Preferences` 可恢復預設值。
