# 使用者資料與儲存空間 (User Data & Storage)

## 偏好設定儲存位置

您的偏好設定儲存在 NiceGUI 的每位使用者專屬瀏覽器儲存空間中，並與伺服器的 `config.storage_secret` 綁定。伺服器上**沒有使用者帳號**，伺服器也不會保留您的個人筆記。

## 儲存的內容

- **設定** – [索引](README.md) 中列出的所有項目。
- **標籤頁狀態** – 每個聖經與工具標籤頁（`tab1_*`、`tab2_*`）：內容、標籤、書卷/章/節以及查詢詞。標籤頁會在您下次造訪時恢復（[標籤頁管理](../layout/tabs_management.md)）。
- **運作中的數值** – 用於在視窗間傳遞上下文的 `bible_*` 與 `tool_*` 書卷/章/節/查詢詞。
- **Google 權杖** – 若您登入 Google（`google_token`）以使用 [雲端硬碟筆記](../integrations/google_drive_notes.md)。
- **自訂權杖** – `custom_token`（[指南](custom_token.md)）。

## 未儲存的內容

- 在網址中透過 `?t=` 傳遞的自訂權杖僅用於該次造訪（適用於公共裝置）。

## 重置

`偏好設定` → `重置所有偏好設定` → `刪除` 會清除所有內容並返回首頁。清除瀏覽器資料也有相同效果。

## 跨裝置轉移

偏好設定不會跨裝置同步。筆記則可透過 Google 雲端硬碟同步。請使用 [可分享連結](../integrations/sharing_deep_links.md) 將檢視畫面轉移至另一台裝置。
