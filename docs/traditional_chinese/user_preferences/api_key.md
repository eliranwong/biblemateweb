# API 金鑰

您用於所選後端的個人 API 金鑰（自備金鑰 / BYOK）。它可讓您繞過管理員限制並選擇自己的提供商。`grok`、`claude` 和 `antigravity` 會忽略此項。

| | |
|---|---|
| 位置 | `Preferences` → `AI Backend` → `API Key` |
| 存儲鍵 | `api_key` |
| 預設值 | `(empty)` |

## 如何變更

1. 開啟 `Preferences`（`/settings` 頁面）。
2. 展開 `AI Backend` 分類。
3. 調整 `API Key`。

變更會自動保存在與您瀏覽器關聯的用戶存儲中。使用 `Reset All Preferences` 可恢復預設值。

另請參閱 [api_key_setup.md](api_key_setup.md)。
