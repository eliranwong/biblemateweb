# **進階聖經搜索指南**

本指南介紹應用程式中提供的強大搜索模式與設定。

## **1. 搜索模式**

應用程式支援三種不同的內容搜索模式，以及一個專門用於尋找經文參照的模式。

### **A. 搜索經文參照（導覽）**

若要快速導覽至特定經文段落，只需輸入聖經參照。

**範例：**

John 3:16; Gen 1:1-5; Ps 23:1-6

### **B. 字面搜索（純文字）**

這是尋找單詞或短語完全相符的預設模式。搜尋引擎會尋找您輸入的特定字符序列。

**範例：**

In the beginning  
The Lord is my shepherd

### **C. 正則表達式（模式）搜索**

**正則表達式（Regex）** 是定義搜索模式的字符序列。此進階模式可讓您在單節經文中尋找複雜模式、單詞變化形式或單詞組合。

*有關 Regex 語法的詳細指南，建議參考外部資源，例如 [regexone.com](https://regexone.com) 或 [regular-expressions.info](https://regular-expressions.info)。*

使用此進階模式可在單節經文中尋找複雜模式、單詞變化形式或單詞組合。

| 模式 | 說明 | 範例 |
| :---- | :---- | :---- |
| **OR 搜索** | 尋找包含所列任一單詞的經文。 | `love|hope|faith` |
| **AND 搜索** | 尋找包含所有指定單詞的經文，無論順序如何。 | `^(?=.\blove\b)(?=.\bhope\b)(?=.\bfaith\b).` |
| **鄰近搜索** | 尋找按特定順序出現的單詞，中間可夾帶其他單詞。 | Naomi.\*?Ruth |

### **D. 語義搜索（含義）**

使用此模式可搜索短語背後的*相似詞*、*含義*或*概念*，而非精確的字詞。這對於尋找表達相似思想的經文非常有用。

**範例：**

* David fled
* wisdom
* new creation

**關於相似度的說明：** 顯示的相似經文最大數量由 **相似經文數量** 設定控制，可在應用程式的偏好設定中進行調整。

## **2. 搜索範圍與設定**

這些選項允許您精細控制搜索執行的位置與方式。

### **搜索範圍**

| 設定 | 說明 | 預設行為 |
| :---- | :---- | :---- |
| **書卷過濾** | 從下拉選單中選取特定書卷，以限制僅在這些書卷中搜索（例如僅搜索福音書）。 | 包含所有書卷。 |
| **多本聖經** | 從聖經下拉選單中選取一本或多本聖經，以同時跨多個譯本進行搜索。 | 若未明確選取聖經，搜索僅針對當前在使用中分頁開啟的聖經執行。 |

### **區分大小寫切換**

此功能讓您可以控制搜索是否區分英文字母的大寫與小寫。

* **適用範圍：** 僅適用於字面搜索與正則表達式（模式）搜索模式。  
* **位置：** 使用專用的核取方塊切換是否啟用區分大小寫的相符。

## **3. 搜索後操作**

### **過濾搜索結果**

搜索完成後，您可以在輸入欄位中輸入其他單詞以篩選結果列表。這會對已找到的經文進行即時過濾。

### **開啟全章**

若要檢視經文的完整上下文，請按一下搜索結果清單中的經文參照按鈕（例如 Jn 3:16）。這將根據您的選擇，在主要聖經區域或工具區域中開啟全章。
