# **經文搜索指南**

此強大的搜索工具可讓您使用三種不同的搜索方法來尋找聖經經文：字面文字搜索、正則表達式（模式）搜索以及由 AI 驅動的語義搜索。

## **什麼是經文搜索？**

經文搜索工具提供三種精密的搜索方式，在整本聖經中精準查找符合您條件的經節。無論您是在尋找特定字詞、字符模式還是屬靈概念，此工具都能協助您準確找到所需內容。

## **搜索方法**

### **1. 字面搜索**

在聖經經文中精確查找特定的字詞或短語。

**運作方式：**
- 查找完全包含您所輸入搜索詞彙的經文
- 預設不區分大小寫
- 支援多詞組合（查找同時包含「所有」輸入字詞的經文）
- 速度飛快且直觀直接

**最適用於：**
- 查找特定字詞或固定短語
- 定位耳熟能詳的名言金句
- 快速查找經文參照
- 查找某個字詞在聖經中的所有出現處

**範例：**
```
Search: "love your enemies"
→ Finds verses containing all three words

Search: "faith hope love"
→ Finds verses with all three words present

Search: "Jesus wept"
→ Finds the shortest verse in the Bible
```

### **2. 模式搜索（正則表達式 Regex）**

利用字元模式相符進行進階複雜搜索。

**運作方式：**
- 採用標準正則表達式（Regex）語法
- 尋找符合複雜結構模式的經節
- 支援通配符、邏輯或（OR）及重複計數
- 功能強大，適合熟悉正則表達式的進階使用者

**最適用於：**
- 基於特定規則模式的結構搜索
- 查找詞形變化與詞根派生
- 複雜的多條件組合檢索
- 聖經語言學與文本分析

**常用 Regex 模式：**

| 模式 | 含義 | 範例 |
| :---- | :---- | :---- |
| `.` | 任意單個字元 | `l.ve` 相符 "love", "live" |
| `*` | 零次或多次重複 | `God.*love` 相符 "God is love", "God shows love" |
| `+` | 一次或多次重複 | `lov+e` 相符 "love", "loove" |
| `?` | 可選字元（零次或一次） | `colou?r` 相符 "color" 或 "colour" |
| `\|` | 邏輯「或」 | `love\|hate` 相符包含任一詞的經文 |
| `^` | 經節開頭 | `^In the beginning` 相符以此短語開頭的經文 |
| `$` | 經節結尾 | `Amen\.$` 相符以 "Amen." 結尾的經文 |
| `[abc]` | 括號內任一字元 | `[Jj]esus` 相符 "Jesus" 或 "jesus" |
| `[a-z]` | 字元範圍 | `[A-Z]ove` 相符 "Love", "Dove", "Move" |
| `\w` | 單詞字元 | `\w+` 相符任意單詞 |
| `\d` | 數字字元 | `\d+` 相符任意數字 |

**範例：**
```
Search: "love.*neighbor"
→ Finds verses with "love" followed by "neighbor"

Search: "(faith|hope|love)"
→ Finds verses with any of these words

Search: "^Blessed"
→ Finds verses beginning with "Blessed"

Search: "Jesus (said|spoke|answered)"
→ Finds verses where Jesus said, spoke, or answered
```

### **3. 語義搜索（AI 驅動）**

運用人工智慧依核心涵義查找經文，而非受限於字面詞句。

**運作方式：**
- 深刻理解您查詢內容的思想意涵
- 尋找在概念上相近或相關的經節
- 不需要字面完全吻合
- 運用向量嵌入（Vector Embeddings）進行相似度計算

**最適用於：**
- 依神學概念或屬靈主題尋找經文
- 發掘您未曾知曉但涵義緊密相關的段落
- 專題查經與靈修默想
- 清楚明白所求涵義卻記不清確切字詞時

**範例：**
```
Query: "God's forgiveness"
→ Finds verses about mercy, pardon, grace, redemption

Query: "trusting in difficult times"
→ Finds verses about faith, perseverance, hope during trials

Query: "treating others with kindness"
→ Finds verses about love, compassion, good works, golden rule

Query: "end times prophecy"
→ Finds verses about second coming, judgment, apocalypse
```

**語義搜索技巧：**
- 使用自然語言提問與查詢
- 清楚描述您所尋求的屬靈概念
- 無須拘泥於特定的聖經專門術語
- AI 能自動理解同義詞與相關概念
- 結果按關聯相似度由高至低智慧排序

## **如何使用經文搜索**

1. **選取搜索類型**：從分頁標籤或下拉選單中選擇「字面」、「模式」或「語義」
2. **輸入查詢語句**：輸入您的搜索字詞、正則模式或思想概念
3. **按 Enter 鍵或點擊搜索按鈕**：執行檢索
4. **檢視結果**：瀏覽滾動相符的經文清單
5. **點擊參照**：點擊任何經文參照即可在完整聖經章節上下文中閱讀

- **搜索類型選擇器**：切換搜索方式的標籤頁或下拉選單
- **搜索輸入欄位**：鍵入查詢內容的文字方塊
- **搜索按鈕**：觸發執行搜索
- **結果顯示區域**：展示相符經文及其詳細參照

- 僅在選定的單一譯本中進行檢索

## **高效搜索技巧**

### **字面搜索技巧**

1. **短語使用雙引號**：`"love your neighbor"` 可精準查找連續短語
2. **多詞邏輯**：多個詞彙必須同時存在（隱含 AND 邏輯）
3. **避免單獨虛詞**：避免單獨搜索 "the", "a", "and" 等高頻常用詞
4. **嘗試詞形變體**：如 "forgive" 與 "forgiveness" 在字面上視為不同單詞
5. **大小寫無關**："GOD"、"God"、"god" 均會視為相同

### **模式搜索（Regex）技巧**

1. **從簡易模式開始**：先構建基礎表達式，再視需要逐步增添複雜度
2. **先測試後使用**：在樣例文本上驗證正則模式的正確性
3. **注意逸出特殊字元**：在 `.?*+[]{}()|^$` 前務必加上反斜線 `\` 進行逸出
4. **善用定位錨點**：使用 `^` 鎖定經節開頭，使用 `$` 鎖定經節結尾
5. **邏輯或（OR）**：使用 `|` 實現多詞任選相符（如 `faith|hope|love`）
6. **單詞邊界**：使用 `\b` 確保整詞相符，避免被包含在更長詞彙中

### **語義搜索技巧**

1. **描述具體生動**：例如「神對全人類無條件的浩大慈愛」
2. **使用自然語言**：以如同向人請教提問的語氣進行輸入
3. **把握核心意涵**：將焦點置於概念本身，而非拘泥於具體字詞
4. **著重檢視頂部結果**：相似度最高的最佳相符項目排在最前列
5. **精細化提問**：若檢索結果過於寬泛，可適度增添具體語境
6. **嘗試不同措辭**：換用不同的敘述方式可能激發出更多維度的寶貴亮光

## **進階特色功能**

### **布林邏輯（字面搜索）**

以隱含的 AND 邏輯組合多個關鍵詞：
- `faith works` = 同時包含這兩個詞的所有經節
- 所有輸入字詞必須同時具備
- 不支援顯式的 OR 運算子（如需 OR 請改用模式搜索）

### **通配符靈活相符（模式搜索）**

運用正則通配符實現強大檢索：
- `.*` 相符任意長度的任意字元
- `\w+` 相符任意完整的單詞
- `\d+` 相符任意數字序列
- `.{3,5}` 相符指定長度範圍內的字元

- 排除特定不相關書卷
- 依歷史時期進行時序篩選（若有元數據支援）

## **常見問題排查**

### **找不到任何結果**

- **核對文字拼寫**：確認輸入的關鍵詞無錯字漏字
- **嘗試同義詞**：換用同一概念的其他表達方式
- **放寬搜索條件**：刪減過於苛刻的限制詞彙
- **切換檢索方式**：若字面搜索無果，嘗試改用語義搜索
- **更換聖經版本**：不同譯本在用字選詞上常有差異

### **結果過多難以瀏覽**

- **增加限定詞**：增添更多關鍵詞以提高字面精確度
- **加用引號**：使用雙引號進行精確短語相符
- **縮小檢索範圍**：限定在單一書卷或單一約章內檢索
- **精確概念描述**：在語義搜索中提供更具體詳盡的情境描述
- **套用篩選器**：啟用書卷或分卷過濾機制

### **正則表達式語法錯誤**

- **檢查語法結構**：核驗正則模式中的括號與運算子是否配對完整
- **注意逸出處理**：確認保留特殊符號前已正確加上反斜線 `\`
- **在線驗證測試**：在專業正則測試網站上先行驗證邏輯
- **化繁為簡**：先從最簡單的模式開始，逐步測試擴展
- **參考語法手冊**：查閱標準 Regex 語法參考指引

## **搜索語法快速參考**

### **字面搜索語法**

- 單詞檢索：`love`
- 多詞同時相符（AND）：`faith hope love`
- 固定短語（強烈推薦）：`"love your neighbor"`
- 不區分大小寫：`GOD` = `god` = `God`

### **模式搜索（Regex）語法**

**基礎元字元：**
- `.`——任意單一字元
- `*`——零次或多次重複
- `+`——一次或多次重複
- `?`——可選（零次或一次）
- `|`——邏輯「或」
- `()`——群組分組
- `[]`——字元集類別
- `^`——行首 / 節首錨點
- `$`——行尾 / 節尾錨點

**預定義字元集：**
- `\w`——單詞字元 [a-zA-Z0-9_]
- `\d`——數字字元 [0-9]
- `\s`——空白字元
- `\W`——非單詞字元
- `\D`——非數字字元
- `\S`——非空白字元

**量詞語法：**
- `{n}`——恰好出現 n 次
- `{n,}`——至少出現 n 次
- `{n,m}`——出現 n 至 m 次

### **語義搜索語法**

- 自然語言輸入
- 無需掌握任何特殊語法
- 句意完整、描述豐富的查詢往往能獲得更佳結果
- 採用提問式句型效果極佳
- 提供適當的上下文背景能大幅提升精準度
