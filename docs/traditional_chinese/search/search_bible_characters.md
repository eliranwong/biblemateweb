# **聖經人物搜索指南**

此工具可協助您發掘並探索整本聖經中提到的人物，從摩西和大衛等著名人物，到豐富了聖經歷史的鮮為人知的人物。

## **什麼是聖經人物搜索？**

聖經人物搜索工具提供對經文中所提及人物的全面資料庫存取。您可以依名字搜索人物，並獲取有關他們是誰、其角色以及在聖經中何處出現的詳細資訊。

## **您將找到的內容**

對於每個聖經人物，該工具提供：
- **名字**：該人物在經文中所出現的名字
- **描述**：他們是誰以及在聖經歷史中的角色
- **關鍵資訊**：人物關係、職業、重要意義
- **聖經參照**：提及他們的經節
- **相關人物**：家庭成員與同工同伴

## **如何使用**

1. **輸入名字**：在搜索框中輸入人物名字
2. **從建議中選擇**：自動完成功能會在您輸入時顯示相符的名字
3. **按 Enter 鍵**：載入該人物的詳細資訊
4. **檢視詳情**：閱讀該人物的描述與經文參照
5. **點擊參照**：開啟經文以在上下文中閱讀該人物的相關事蹟

### **搜索特色**

- **自動完成**：在您輸入時即時顯示建議
- **模糊相符**：即使有輕微拼寫錯誤也能找到名字
- **相似度搜索**：透過 AI 技術相符相近的名字
- **多個結果**：如果找到多個相符項目，可從清單中選擇
- **歷史記錄**：按向上箭頭鍵可恢復您上次的搜索

## **搜索方法**

### **精確名字搜索**

輸入確切的名字：
```
Moses
David
Mary
Paul
```

### **部分名字搜索**

開始輸入並從自動完成中選取：
```
Type: "Abra..."
Suggestions: Abraham, Abram, Abiram, etc.
```

### **相似度搜索**

如果沒有完全相符的項目，AI 會尋找相似的名字：
```
Search: "Nabuchodonazar"
Finds: Nebuchadnezzar (similar name, different spelling)

Search: "Jonah"
Finds: Jonah, Jonas (alternate forms)
```

### **替代名字**

許多人物擁有複數名字：
- **掃羅 / 保羅**（同一人，歸信前 / 歸信後）
- **西門 / 彼得**（耶穌為他取名）
- **亞伯蘭 / 亞伯拉罕**（上帝改變他的名字）
- **雅各 / 以色列**（被賜予新名）

如果一個名字找不到，請嘗試另一種形式。

## **人物資訊顯示**

### **人物簡介**

每個條目包含：

**名字標題：**
- 人物的主要名字
- 圖示指示器（人物圖示）
- 可折疊區塊

**描述：**
- 此人是誰
- 他們的角色或職業
- 關鍵關係（父親、兒子、妻子等）
- 歷史背景
- 在聖經敘事中的重要意義

**聖經參照：**
- 可點擊的經文標籤
- 人物出現的經文參照
- 通往關鍵故事或事件的連結
- 在聖經區域開啟以檢視上下文

### **相關資訊**

部分條目包含：
- **家族譜系**：父母、子女、兄弟姊妹
- **時間線**：生活年代（約略時期）
- **地點**：生活或旅居的地點
- **關鍵事件**：涉及他們的重大故事
- **特徵**：性格特質或顯著品質

## **高效使用技巧**

1. **嘗試不同變體**：搜索不同的名字拼寫（例如 Elijah/Elias）
2. **善用自動完成**：開始輸入並從建議中選取
3. **閱讀上下文**：點擊經文參照以在故事背景中查看人物
4. **探索相關人物**：查閱家族成員與同工
5. **比較不同譯本**：部分名字在不同聖經版本中有所差異
6. **檢查描述內容**：了解鮮為人知的人物
7. **追蹤譜系鏈**：探索家族樹與人物關係

## **工作流程範例**

### **人物查經——彼得**

1. 搜索：`Peter`
2. 閱讀西門彼得的描述
3. 注意他是漁夫，是安得烈的兄弟
4. 點擊經文參照閱讀彼得的關鍵故事：
   - 蒙召（馬太福音 4:18-20）
   - 行走在水面上（馬太福音 14:22-33）
   - 認耶穌為基督（馬太福音 16:13-20）
   - 不認耶穌（馬太福音 26:69-75）
   - 重新被建立（約翰福音 21:15-19）
   - 五旬節講道（使徒行傳 2）
5. 使用「人物關係」工具查看彼得的人際關聯
6. 在「筆記本」中記錄心得洞見

### **家族譜系查經——大衛家系**

1. 搜索：`David`
2. 注意他的父親：耶西
3. 搜索：`Jesse` → 查看大衛的祖先
4. 搜索：`Solomon` → 大衛的兒子，王統延續
5. 追溯世系直到耶穌
6. 繪製家族譜系圖
7. 注意彌賽亞的重要意義

### **聖經女性查經**

1. 搜索：`Sarah` → 第一位族長之妻
2. 搜索：`Deborah` → 士師與女先知
3. 搜索：`Ruth` → 忠貞的摩押女子
4. 搜索：`Esther` → 勇敢的王后
5. 搜索：`Mary` → 耶穌的母親
6. 搜索：`Mary Magdalene` → 耶穌的跟隨者
7. 比較各人的角色與重要意義
8. 注意一貫的主題

### **發揮重大影響的小人物**

1. 搜索：`Ananias`（醫治保羅的人）
2. 搜索：`Onesimus`（逃跑的奴隸）
3. 搜索：`Epaphroditus`（忠心的使者）
4. 搜索：`Phoebe`（女執事與資助者）
5. 發現「小人物」如何扮演了至關重要的角色
6. 應用在小事上忠心的功課

## **理解人物描述**

### **名字含義**

許多描述包含名字的含義：
- **亞伯拉罕**：「多國之父」
- **以撒**：「喜笑」
- **摩西**：「拉出來」（從水中拉出）
- **耶穌**：「耶和華拯救」
- **彼得**：「磐石」

### **職業**

人物簡介通常會註明他們的工作：
- 漁夫（彼得、安得烈、雅各、約翰）
- 稅吏（馬太、撒該）
- 織帳棚者（保羅）
- 牧羊人（大衛、摩西等多人）
- 木匠（耶穌、約瑟）

### **人物關係**

描述包含家族聯繫：
- **父子**：「亞伯拉罕，以撒的父親」
- **兄弟姊妹**：「摩西，亞倫與米利暗的兄弟」
- **配偶**：「亞伯拉罕與撒拉」
- **後裔**：「大衛，耶穌的先祖」

### **性格特徵**

簡介突顯關鍵特質：
- **忠心**：亞伯拉罕、約伯
- **勇敢**：大衛、以斯帖
- **智慧**：所羅門、但以理
- **悔改**：大衛與拔示巴犯罪之後
- **懷疑**：多馬

## **人物分類**

資料庫包含：
- **先知**：傳講神的話語

- **祭司**：在聖殿服事
- **使徒**：耶穌親自揀選的門徒
- **士師**：王國建立前的領袖
- **族長 / 族長之妻**：以色列的建立者
- **勇士**：軍事領袖

## **特殊人物類型**

- **亞伯蘭 → 亞伯拉罕**：多國之父
- **撒萊 → 撒拉**：公主
- **雅各 → 以色列**：與神與人較力
- **西門 → 彼得**：磐石
- **掃羅 → 保羅**：歸信之後

### **同名異人**

部分名字指代不同的人：
- **馬利亞**：新約中至少有 6 位不同的馬利亞
- **雅各**：數位使徒與兄弟
- **約翰**：施洗約翰、使徒約翰等人
- **猶大**：加略人猶大、另一位使徒、耶穌的兄弟

利用描述來加以區分。

### **群體人物**

部分條目代表群體：
- **十二使徒**：使徒群體
- **法利賽人**：宗教黨派
- **撒都該人**：另一個宗教群體
- **利未人**：祭司支派

## **常見搜索問題**

### **找不到人物**

- **嘗試替代拼寫**：不同譯本之間存在差異
- **檢查名字變更**：嘗試改名之前或之後的名字
- **使用部分搜索**：輸入前幾個字母
- **嘗試相關名字**：搜索家庭成員
- **檢查相似度**：AI 可能會建議相近的相符項目

### **多個相符結果**

- **閱讀描述**：區分同名人物
- **檢查時期**：注意每個人生活的時代
- **注意人物關係**：不同的家族線系
- **檢視經文參照**：查看他們出現在哪些書卷中

### **結果不明確**

- **點擊參照**：在上下文中閱讀經文
- **使用註釋**：獲取專家的詮釋
- **相互對照**：運用其他研經工具
- **搜索相關人物**：查閱關聯人物
