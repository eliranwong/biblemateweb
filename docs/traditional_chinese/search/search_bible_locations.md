# **聖經地點搜索指南**

此工具可協助您發掘並探索整本聖經中提到的地理地點，從耶路撒冷和伯利恆等著名城市，到在聖經歷史中扮演重要角色的不知名村莊和地標。

## **什麼是聖經地點搜索？**

聖經地點搜索工具提供對經文中所提及地理地點的全面資料庫存取。您可以依名稱搜索地點，並探索每個地點的詳細資訊，包括描述、經緯度座標以及聖經經文參照。

## **您將找到的內容**

對於每個聖經地點，該工具提供：
- **名稱**：該地點在經文中所出現的名稱
- **描述**：該地點是什麼及其重要意義
- **地理數據**：經緯度座標、所屬區域、現代名稱（如適用）
- **聖經重要性**：在該處發生的關鍵事件
- **聖經參照**：提及該地點的經節
- **地圖視覺化**：在互動式地圖上檢視該地點

## **如何使用**

1. **輸入地點**：在搜索框中輸入地點名稱
2. **從建議中選擇**：自動完成功能會在您輸入時顯示相符的地點
3. **按 Enter 鍵**：載入該地點的詳細資訊
4. **檢視詳情**：閱讀該地點的描述與重要意義
5. **在地圖上檢視**：在互動式地圖上查看標記的地點（若有座標數據）
6. **點擊參照**：開啟經文以在上下文中閱讀與該地點相關的事蹟

### **搜索特色**

- **自動完成**：在您輸入時即時顯示地點建議
- **模糊相符**：即使有輕微拼寫錯誤也能找到地點
- **相似度搜索**：透過 AI 技術相符相近的名稱
- **多個結果**：如果找到多個相符項目，可從清單中選擇
- **歷史記錄**：按向上箭頭鍵可恢復您上次的搜索
- **地圖整合**：直觀視覺化呈現地點位置

## **搜索方法**

### **精確名稱搜索**

輸入確切的地點名稱：
```
Jerusalem
Bethlehem
Nazareth
Egypt
Jordan
```

### **部分名稱搜索**

開始輸入並從自動完成中選取：
```
Type: "Jerusa..."
Suggestions: Jerusalem, Salem, Jebus, etc.
```

### **相似度搜索**

如果沒有完全相符的項目，AI 會尋找相似的名稱：
```
Search: "Golgotha"
Finds: Golgotha, Calvary (same place, different names)

Search: "Red Sea"
Finds: Red Sea, Sea of Reeds (alternate translations)
```

### **替代名稱**

許多地點擁有多個名稱：
- **耶布斯 / 耶路撒冷**（原名與後來的名稱）
- **各各他 / 髑髏地**（亞蘭文與拉丁文）
- **加利利海 / 革尼撒勒湖 / 提比哩亞海**
- **巴別 / 巴比倫**（早期與後期的形式）

如果第一次搜索沒有找到結果，請嘗試替代名稱。

**其他國家：**

- **幼發拉底河**：東部邊界，伊甸園的四河之一

### **山脈與丘陵**

- **西奈山（何烈山）**：摩西頒受律法之地

- **黑門山**：北部邊界，耶穌登山變相之地
- **各各他（髑髏地）**：耶穌被釘十字架之地

### **地區與國家**

- **迦南 / 應許之地**：賜給以色列人的土地
- **加利利**：北部地區，耶穌主要的事工區域

## **最佳實踐**

1. **善用地圖**：視覺地理背景至關重要
2. **閱讀完整經文**：點擊參照以在故事脈絡中理解地點
3. **對照不同譯本**：地名在不同聖經版本中可能有不同譯法
4. **對照現代地理**：將聖經地理與現代地圖相對應
5. **研究行程路線**：掌握古代道路與行進距離
6. **考量自然地形**：山嶽與谷地直接影響敘事解讀
7. **關注考古發現**：了解當代考古挖掘為聖經帶來的實證
