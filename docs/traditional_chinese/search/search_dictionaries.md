# **聖經字典搜索指南**

此工具提供整本聖經中出現的聖經詞彙、神學概念與重要字詞的全面定義與詳盡闡釋。搜索任何詞條即可發掘其原意與屬靈重要性。

## **什麼是聖經字典搜索？**

聖經字典搜索工具讓您能夠查閱詳細的字典詞條，精準定義並深入闡明聖經術語、神學概念、人物、地理地點以及教義思想。這就如同將多部權威聖經字典隨時置於您的指尖。

## **您將找到的內容**

對於每個字典條目，該工具提供：
- **詞條定義**：對該詞彙或概念含義的清晰闡釋
- **聖經用法**：該詞彙在聖經經文中的具體使用情境
- **字源辭源**：詞彙起源與語言學背景（相關時提供）
- **神學重要性**：該詞彙在教義神學中的關鍵地位
- **經文參照**：相關的聖經經文章節
- **歷史背景**：古代文化處境與歷史環境
- **相關詞彙**：關聯概念與同義詞

## **工作流程範例**

### **剖析核心神學名詞——稱義（Justification）**

1. 搜索：`Justification`
2. 研讀定義：
   - 法庭法律用語，意為「被宣判為義」
   - 並非「主觀上被改造成為完全無罪」，而是「在法理地位上被算為義」
   - 屬法理宣告（forensic），而非內在質變（transformative）
3. 追溯字源學：
   - 希臘文：*dikaiosis*（宣判為義）
   - 源自 *dikaios*（公義、義人）
4. 查考聖經用法：
   - 羅馬書 3:24, 28
   - 羅馬書 4:25
   - 羅馬書 5:1
5. 在完整上下文語境中精讀核心章節
6. 與關聯神學術語細緻對比：
   - 成聖（Sanctification，生命被造就聖潔）
   - 重生（Regeneration，獲得全新屬天生命）
   - 得兒女名分（Adoption，成為神的兒女）
7. 記錄全面透徹的神學筆記

### **探索文化名詞——經文匣（Phylactery）**

1. 搜索：`Phylactery`
2. 研讀定義：
   - 內置微型手抄經文的皮革小盒子
   - 佩戴於額前與左臂上
   - 源於對申命記 6:8 字面意義的恪守
3. 理解歷史文化處境：
   - 猶太教傳統虔敬實踐
   - 對律法命令的字面化落實
   - 作為對神委身的公開標記
4. 參照耶穌的親口教訓：
   - 馬太福音 23:5——批評法利賽人故意做寬經文匣以誇耀虔誠
   - 警告切莫落入形式主義與炫耀虛榮
5. 領悟現代屬靈應用：
   - 信仰不在乎外在儀式的炫耀
   - 內心對神真實的敬畏愛慕才是神所悅納的
6. 反思當代基督徒生活：
   - 我們在日常生活中如何真誠「見證」信仰？

### **探討教會體制名詞——聖禮（Sacrament）**

1. 搜索：`Sacrament`
2. 研讀定義：
   - 神聖的屬天聖儀
   - 恩典的傳遞途徑
   - 內在不可見屬天實質的外在可見標記
3. 掌握各宗派傳統差異：
   - 天主教會：七件聖事
   - 基督新教：兩大聖禮（洗禮與聖餐）
   - 理解各自背後不同的神學詮釋架構
4. 扎根聖經權威基礎：
   - 洗禮：馬太福音 28:19、使徒行傳 2:38
   - 聖餐：哥林多前書 11:23-26
5. 帶著相互尊重的態度客觀看待不同神學觀點
6. 確立深具聖經純正根基的信仰立場

### **研讀古代度量衡——肘（Cubit）**

1. 搜索：`Cubit`
2. 研讀定義：
   - 古代通行長度計量單位
   - 前臂長度（自肘關節至中指尖）
   - 約合 18 英吋（約 45 公分）
3. 留意尺寸規格差異：
   - 普通肘：約 18 英吋
   - 長肘（王室肘）：約 20-21 英吋
4. 檢索聖經具體使用實例：
   - 挪亞方舟的建造尺寸（創世記 6:15）
   - 會幕各項聖物的規格（出埃及記 25-27 章）
   - 所羅門聖殿的宏偉尺寸（列王紀上 6 章）
   - 歌利亞的驚人身高（撒母耳記上 17:4）
5. 換算為現代公制單位
6. 在腦海中生動勾勒並視覺化聖經歷史場景
