# **人物關係搜索指南**

此工具可協助您探索並視覺化呈現聖經人物之間的家庭與親屬關係。探索聖經人物的家族樹、譜系世系以及彼此之間的血緣與親屬紐帶。

## **什麼是人物關係搜索？**

人物關係搜索工具提供對經文中所載家庭與親屬關係資料庫的存取。您可以搜索任何聖經人物，並清晰檢視他們的家族關聯——包括父母、子女、兄弟姊妹、配偶以及家族親屬。

## **您將找到的內容**

對於每個聖經人物，該工具提供：
- **姓名**：您所搜索的人物
- **直系親屬關係**：父母、子女、兄弟姊妹、配偶
- **旁系與姻親親屬**：祖父母、孫子女、姻親、堂表兄弟姊妹
- **可點擊姓名**：點擊可進一步探索該家族成員的親屬關係
- **聖經參照**：確立這些親屬關係的經文出處
- **視覺化呈現**：家族樹或親屬關係圖表

## **如何使用**

1. **輸入姓名**：輸入聖經人物的名字
2. **從建議中選擇**：自動完成功能會在您輸入時顯示相符的名字
3. **按 Enter 鍵**：載入家族親屬關係資訊
4. **檢視親屬關聯**：查閱列出的所有家庭成員
5. **點擊姓名**：探索其他家庭成員的人際網絡
6. **點擊參照**：閱讀證明其親屬關係的聖經經文
7. **導覽家族樹**：順著血緣紐帶跨世代追溯

### **搜索特色**

- **自動完成**：在您輸入時即時顯示名字建議
- **模糊相符**：即使有輕微拼寫錯誤也能找到人物
- **可點擊親屬連結**：每個家族成員均為可點擊跳轉的連結
- **經文引證出處**：提供支持親屬關係的聖經經文
- **歷史記錄**：按向上箭頭鍵可恢復您上次的搜索
- **視覺化導覽**：透過點擊姓名輕鬆穿梭於家族樹之間

## **工作流程範例**

### **追溯彌賽亞救贖世系**

1. 搜索：`Adam`
2. 找到兒子：塞特（Seth）
3. 點擊：`Seth`
4. 順著世系鏈持續點擊跳轉：
   - 塞特 → 以挪士 → 該南 → ... → 挪亞
   - 挪亞 → 閃
   - 閃 → ... → 亞伯拉罕
   - 亞伯拉罕 → 以撒
   - 以撒 → 雅各
   - 雅各 → 猶大
   - 猶大 → ... → 大衛
   - 大衛 → 所羅門 → ... → 約瑟
   - 約瑟（法理父親）→ 耶穌
5. 研讀馬太福音 1 章與路加福音 3 章的家譜
6. 讚嘆神貫穿無數世代的奇妙救贖計畫
7. 記錄傳承鏈中的關鍵代表人物

### **研讀雅各的十二個兒子**

1. 搜索：`Jacob`（或 `Israel`）
2. 注意妻子與妾室：拉亞、拉結、辟哈、悉帕
3. 查看十二個兒子及其各自生母的對應關係：
   - 拉亞：流便、西緬、利未、猶大、以薩迦、西布倫
   - 拉結：約瑟、便雅憫
   - 辟哈：但、拿弗他利
   - 悉帕：迦得、亞設
4. 點擊每位兒子的姓名以探索各自後裔與家庭
5. 連結到以色列十二支派的歷史興衰
6. 研讀創世記 29-30 章與 35 章的生子敘事
7. 參照創世記 49 章雅各臨終前的先知性祝福

### **剖析大衛家族的內在糾葛**

1. 搜索：`David`
2. 注意其父：耶西
3. 檢視其七位兄長
4. 點擊妻室檢視大衛的多次婚姻聯姻
5. 探索諸子生平：
   - 所羅門（拔示巴所生）——王位繼承者
   - 押沙龍——發動叛亂
   - 暗嫩——長子，犯罪玷辱胞妹
   - 亞多尼雅——擅自謀奪王位
6. 閱讀撒母耳記下中的家族悲歡敘事
7. 從家庭的掙扎痛苦與神不離不棄的恩典中汲取借鑑

### **全面認識耶穌的世俗親屬**

1. 搜索：`Jesus`
2. 注意世俗父母：約瑟與馬利亞
3. 檢視手足兄弟：雅各、約西、西門、猶大
4. 注意未記姓名的眾姊妹
5. 搜索：`Joseph`（法理父親）
   - 查看其上溯至大衛的尊貴王室世系
6. 搜索：`Mary`（肉身母親）
   - 查驗親屬紐帶：以利沙伯（表姐 / 親戚）
7. 搜索：`James`（胞弟雅各）
   - 後來成為耶路撒冷教會的領袖柱石
   - 寫下雅各書
8. 研討親屬最初的不信與排斥（約翰福音 7:5）
9. 見證復活後家庭全體歸信的翻轉奇蹟（使徒行傳 1:14）

## **理解聖經家庭結構**

### **宗族家長制社會結構**

- **擴展型聯合家庭**：數個世代同堂而居
- **多妻婚姻制度**：在族長與君王時代普遍存在
- **妾室制度**：社會地位低於正妻的副室
- **部落宗族架構**：家庭組合為宗族，宗族凝聚為支派
- **繼承權益法規**：主要經由父系男嗣（尤其是長子雙倍產業）傳承

### **聖經記錄家譜的神聖目的**

**確立合法身分：**
- 支派歸屬權利
- 土地產業繼承憑證
- 王權合法傳承依據
- 祭司與利未人聖職資格

**傳達神學意義：**
- 展現神跨越世代的永恆信實
- 見證神聖應許的步步成全
- 標誌彌賽亞血脈的清晰脈絡
- 彰顯神定意透過家庭單位成就救贖大工

**保存歷史紀錄：**
- 珍藏民族的歷史記憶
- 將各世代生命緊密串連
- 翔實記錄神選民的世系傳承

### **家譜記錄的型態**

**線性家譜（直系單傳）：**
- 單一傳承線條
- 代代相傳的父子鏈條
- 範例：創世記 5 章、創世記 11 章

**分支型家譜（宗族全覽）：**
- 展現多元分支與旁系
- 盡列諸子後嗣
- 範例：創世記 10 章（列國邦國表）

**選擇性家譜（主題聚焦）：**
- 並非巨細靡遺記錄每一代
- 可能略過中間世代（「跳代」寫法）
- 高度聚焦於關鍵里程碑人物
- 範例：馬太福音 1 章（三個十四代的結構編排）

## **常見搜索問題**

### **找不到人物**

- **嘗試替代拼寫**：不同譯本之間的音譯差異
- **檢查改名情況**：嘗試改名之前或之後的名字（雅各 / 以色列）
- **查閱人物工具**：可能在主要人物列表裡有收錄
- **核對譯本文字**：參照您手頭的聖經版本

### **親屬關係記載不全**

- 聖經並未記錄所有歷史人物的完整家譜
- 經文中有許多女性或次要成員未載姓名
- 聖經家譜往往根據神學目的進行選擇性收錄
- 將注意力聚焦於經文所啟示的核心亮光

### **看似矛盾的記載**

- 某些家譜清單存在字面出入（如馬太福音 vs. 路加福音）
- 學界對此提出多種嚴謹合理的學術解釋
- 可能反映了法理世系與血緣世系的不同視角
- 參閱專業研經註釋以獲取深入透徹的剖析
