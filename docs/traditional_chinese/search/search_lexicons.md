# **原文詞典搜索指南**

此工具提供對希伯來文、希臘文與亞蘭文原文詞典的查閱存取，專為研習聖經原文而設計。查閱聖經字詞以發掘其在聖經原文語言中的字面原意、微妙語義差異與具體用法。

## **什麼是原文詞典搜索？**

原文詞典搜索工具讓您能夠存取詳盡完備的原文辭書（聖經古代語言專業詞典），精準定義並深入闡明經文中所載的希伯來文、希臘文及亞蘭文字詞。透過研讀原文語言，能更深層次地領略聖經經文的精妙奧秘。

## **您將找到的內容**

對於每個原文詞條，該工具提供：
- **原文詞彙**：以希伯來文、希臘文或亞蘭文字母書寫的原文形態
- **音譯拼寫**：拉丁字母音譯，輔助發音與拼讀
- **史特朗編號（Strong's Number）**：全球通用的權威參照編碼，便於交叉檢索
- **詞條定義**：該字詞的精確字面定義
- **經文實際用法**：在經文中的具體呈現與文法功用
- **語義範疇（Semantic Range）**：該詞彙所涵蓋的全部可能義項
- **字源學（Etymology）**：字詞起源、構造與語言學字根
- **語法文法資訊**：詞性、性別、單複數、動詞語態等形態學資訊
- **相關詞彙**：同根詞、同源詞與衍生派生詞
- **聖經經文參照**：該詞在全本聖經中出現的所有出處

## **如何使用**

1. **輸入詞彙**：鍵入希伯來文或希臘文字詞、音譯拼寫或史特朗編號
2. **從建議中選擇**：自動完成功能會在您輸入時顯示相符的原文詞條
3. **按 Enter 鍵**：載入詳細的原文詞典條目
4. **研讀定義**：深入學習該詞的精確涵義與用法特點
5. **查驗經文出處**：查看該詞在整本聖經中的出現位置
6. **探索相關詞彙**：點擊連結探索相鄰近的同源字詞
7. **對比各版譯文**：觀察不同聖經譯本如何處理該詞的翻譯

- 該詞如何揭示神的聖潔性情或屬靈真理

- 對正確解經與教義立場所帶來的決定性影響

## **涵蓋的聖經語言**

### **聖經希伯來文**

**舊約絕大部分書卷的原創語言：**
- **字母系統**：希伯來字母表（22 個輔音字母）
- **書寫方向**：由右向左橫向書寫
- **語言學特質**：
  - 輔音文字系統（元音點號係中世紀馬所拉學者後加）
  - 嚴密的三輔音字根體系（三子音詞根）
  - 豐富生動、極具畫面感的具象與隱喻詞彙庫
- **經典範例**：
  - אֱלֹהִים (*Elohim*)——神、造物主
  - שָׁלוֹם (*Shalom*)——和平、整全、平安
  - חֶסֶד (*Chesed*)——堅愛、信實慈愛、守約的愛

### **聖經希臘文（通用希臘語 Koine Greek）**

**新約全書的原創語言：**
- **字母系統**：希臘字母表（24 個字母）
- **歷史時期**：希臘化與羅馬帝國初期的地中海通用語言（主前 300 年 - 主後 300 年）
- **語言學特質**：
  - 極為嚴密精確的動詞時態、語態與時位系統
  - 詞彙極為豐富、表達細緻入微
  - 具備高度成熟的哲學與思辨論證詞彙
- **經典範例**：
  - ἀγάπη (*Agape*)——無條件、捨己的神聖之愛
  - λόγος (*Logos*)——話語、道、神聖理性
  - χάρις (*Charis*)——白白的恩典、恩惠

### **聖經亞蘭文**

**舊約部分特定章節所採用的語言：**
- **字母系統**：與希伯來文極為相近的方塊字母
- **經文分佈**：但以理書部分章節（2:4-7:28）、以斯拉記部分章節（4:8-6:18; 7:12-26）以及耶利米書 10:11
- **語言學特質**：
  - 與希伯來文同屬閃米特語族，語法親緣極深
  - 耶穌與初代門徒在世時日常講說的母語方言
  - 曾是古代近東帝國通行的國際外交與商業通用語言

## **高效使用技巧**

1. **善用史特朗編號**：最可靠、最不容易出錯的精準檢索方式
2. **務必通讀全文**：切勿僅滿足於瀏覽前幾行簡略字義
3. **辨別多重義項**：聖經字詞往往具備寬廣的語義頻譜
4. **緊扣上下文決定詞義**：切記「上下文才是決定詞義的君王」
5. **研究詞族與衍生詞**：同根詞往往能為核心概念提供立體光照
6. **對照各大翻譯譯本**：體會翻譯名家在遣詞用字時的深思熟慮
7. **結合註釋深化研經**：將文字詞彙研究與經文釋義緊密融合
8. **掌握基礎文法常識**：理解詞性與動詞時態能讓原文研究事半功倍

## **工作流程範例**

### **字義深入研讀——Agape（神聖之愛）**

1. 搜索：`Agape` 或 `G26`
2. 研讀詞典條目詳情：
   - **希臘文**：ἀγάπη
   - **音譯**：agapē
   - **史特朗編號**：G26
   - **詞性**：名詞，陰性
   - **精準定義**：專指神對世人主動施予的浩大慈愛，以及基督徒蒙恩後彼此相愛的心
   - **重要辨析**：與希臘文化中其他三種愛的微細分野：
     - *Eros*（男女情愛、肉體吸引——新約從未使用此詞）
     - *Phileo*（弟兄之愛、深厚友情、情感喜愛）
     - *Storge*（親情天倫、血緣之愛——新約僅偶爾出現複合形式）
3. 體會深刻的神學意義：
   - 不求回報的捨己犧牲之愛
   - 神本質屬性的彰顯（約翰一書 4:8）
   - 律法與先知一切道理的總綱（馬可福音 12:30-31）
   - 屬基督門徒最核心的生命標誌（約翰福音 13:35）
4. 精讀關鍵經文段落：
   - 約翰福音 3:16
   - 羅馬書 5:8
   - 哥林多前書 13 章（愛篇）
   - 約翰一書 4:7-21
5. 與 *phileo* 展開對照研究：
   - 搜索 `G5368`（phileo）
   - 深入剖析約翰福音 21:15-17 中耶穌三次詢問彼得時兩個詞彙的微妙交替
   - 掌握字詞變換背後的深情深意
6. 在「筆記本」中整理出震撼心靈的「聖經之愛」研經筆記

### **字義深入研讀——Hesed（堅愛 / 守約的慈愛）**

1. 搜索：`Hesed` 或 `H2617`
2. 研讀詞典條目詳情：
   - **希伯來文**：חֶסֶד
   - **音譯**：chesed
   - **史特朗編號**：H2617
   - **精準定義**：堅定不移的愛、慈愛、憐憫、信實、盟約中的絕對忠誠
   - **內涵之豐厚**：任何單一的中文或英文詞彙皆難以完全窮盡其美
3. 理解其盟約背景：
   - 在神聖盟約關係之內湧流的信實之愛
   - 縱然對方軟弱失信，守約的一方依然堅守承諾
   - 既是神不變的性情，也是神要求其立約子民當活出的品格
4. 觀察各大譯本的翻譯嘗試：
   - 和合本：「慈愛」、「憐憫」、「恩惠」
   - 呂振中譯本：「堅愛」、「忠愛」
   - 英文 KJV："mercy", "lovingkindness"
   - 英文 ESV："steadfast love"
   - 英文 NIV："unfailing love"
5. 研讀核心經文出處：
   - 出埃及記 34:6（神親自向摩西宣告自己的尊名與屬性）
   - 詩篇 136 篇（每節反覆吟詠「因祂的慈愛永遠長存」）
   - 詩篇 89:1-2（歌頌耶和華堅立到永遠的慈愛）
   - 何西阿書（在婚姻破碎背叛的比喻中展現何等震撼的守約之愛）
6. 讚嘆神話語豐富深邃、無可比擬的屬天純全
7. 在禱告中為神那永不動搖的守約之愛獻上敬拜

### **字義深入研讀——Logos（道 / 話語）**

1. 搜索：`Logos` 或 `G3056`
2. 研讀詞典條目詳情：
   - **希臘文**：λόγος
   - **音譯**：logos
   - **史特朗編號**：G3056
   - **多維度涵義**：
     - 話語、言語、宣告
     - 敘述、道理、理由、動機
     - 神聖的話語啟示
     - 專指道成肉身的基督自己
3. 掌握廣闊的語義頻譜：
   - 日常生活中的口頭說話
   - 邏輯嚴密的思想講論
   - 希臘古典哲學中統攝宇宙運行的神聖理性原理
   - 約翰福音開篇所賦予的巔峰神學概念（約翰福音 1:1）
4. 與 *rhema*（G4487）細緻對照：
   - Logos：客觀整全的道、總體的真理原則與永恆信息
   - Rhema：當下具體說出的一句話、即時臨到的具體話語
5. 深入領悟使徒約翰的奇妙用法：
   - 約翰福音 1:1——「太初有道，道與神同在，道就是神」
   - 巧妙融匯了希伯來傳統（神憑話語創造諸世界）
   - 提升了希臘哲學觀念（宇宙萬物的本源秩序）
   - 宣告基督耶穌就是上帝對人類終極、活潑且完滿的神聖溝通
6. 通讀約翰福音 1:1-18 的序言全詩
7. 建立崇高卓越的基督論神學視野

### **同義詞對比分析——和平 / 平安（Peace）**

1. 舊約希伯來文之「平安」：
   - 搜索：`Shalom`（H7965）
   - **涵義**：平安、整全、完備、健全、繁榮興盛
   - **深刻概念**：絕非僅是「沒有戰爭或衝突」的消極被動狀態
   - 遠超越心理上的短暫平靜
   - 乃是身心靈與神、與人、與受造界全面恢復和好、欣欣向榮的和諧狀態
2. 新約希臘文之「和平」：
   - 搜索：`Eirene`（G1515）
   - **涵義**：和平、和睦、安息、平安
   - **新約用法**：深深植根於舊約 Shalom 的神聖土壤中
   - 耶穌基督親自成為我們平安的源頭（約翰福音 14:27）
   - 因信稱義，藉著我們的主耶穌基督得與神相和（羅馬書 5:1）
3. 融會貫通核心概念：
   - 兩者皆遠遠超越世俗字面的「和平」
   - 乃是建立在救贖根基之上的關係性整全
   - 屬靈生命無可奪去的終極穩妥
   - 仰望新天新地的終極末世盼望
4. 撰寫清晰詳實的「聖經平安觀」研讀筆記

### **音譯拼寫指南**

**設計初衷：**
- 讓不懂原文字母的讀者也能準確引用與朗讀原文
- 提供標準規範的發音參考
- 降低原文研習的高聳門檻

**侷限性提醒：**
- 各家拼讀標準可能略有出入
- 無法百分之百精確還原古代發音的所有微妙喉音與吐氣細節
- 元音古代讀法在學界尚存若干學術討論

### **字源與詞根結構**

**詞根規律：**
- 希伯來文：絕大多數詞彙均由三個輔音組成的三子音詞根派生而來
- 希臘文：由詞根加上各類前綴、後綴或複合構詞變化而成
- 把握詞根的本質原意，能讓整組衍生詞的涵義躍然紙上

**經典範例：**
- **希伯來文**：ש-ל-ם（sh-l-m）字根 → 派生出 shalom（平安）、shalam（回報、償還）、shelem（平安祭）等
- **希臘文**：λογ-（log-）字根 → 派生出 logos（道）、logikos（理所當然的 / 屬靈的）等

### **語義範疇的重要性**

**為何切忌以偏概全：**
- 單一原文單詞往往擁有極為豐富的潛在涵義
- 究竟表達何種意義，必須完全由上下文語境來裁決
- 聖經譯者在翻譯時必須根據文脈挑選最貼切的對應詞
- 掌握語義範疇能有效避免「以字面私意取代經文原意」的解經謬誤

**範例——希臘文 *Sarx*（肉體 / 肉身）：**
- 指實體肉身與物理身體（哥林多前書 15:39）
- 指受造的人性本質（約翰福音 1:14「道成了肉身」）
- 指墮落敗壞的罪性與屬肉體的私慾（羅馬書 8:7-8）
- 指世俗屬人的眼光與血氣標準（哥林多後書 5:16）
- 唯有上下文才能精確界定其確切含義

## **常見搜索問題**

### **找不到字詞**

- **核對音譯拼寫**：不同辭書的音譯轉寫可能略有不同
- **改用史特朗編號**：最權威穩妥的直達途徑
- **嘗試概念檢索**：輸入該詞的核心中英文涵義進行搜索
- **嘗試拼寫變體**：嘗試不同的常見音譯形式
- **使用相似度搜索**：AI 會提示相近的相符原文詞條

### **同一個中文詞出現多個原文詞條**

- 同一個中文或英文翻譯詞彙，背後可能對應多個截然不同的原文詞彙
- 必須回到具體經文段落確認背後究竟是哪一個字
- 經文上下文與章節參照能迅速協助您鎖定目標
- 借助史特朗編號能精準加以區分

### **面對繁複的學術詞條**

- 原文詞典往往具有高度專業的學術規範
- 請沉下心來耐性閱讀，切忌急躁走馬看花
- 對於條目中出現的未知文法術語，可借助聖經字典查證
- 綜合參考多部原文辭書以獲取更通俗透徹的啟發
- 結合研經註釋輔助理解

## **最佳實踐**

1. **以史特朗編號為錨**：始終優先使用編號鎖定字詞，避免拼寫混亂
2. **通讀完整條目釋義**：切忌只看第一條定義就斷章取義
3. ** Context is King（語境至上）**：字詞涵義永遠取決於具體經文的上下文
4. **研讀完整詞族網絡**：探索同根衍生詞能讓真理理解更加立體生動
5. **綜合多部詞典考證**：兼採多元學術視角，避免偏執一詞
6. **謹慎運用原文洞見**：避免過度推論單一字詞，切忌「字義膨脹」謬誤
7. **持守全備平衡的解經**：單詞的生命存在於整體的句子與段落思想之中
