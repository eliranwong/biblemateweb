# **聖經名字搜索指南**

此工具可協助您探索整本聖經中所載名字的含義、字源起源與重要意義。了解聖經名字對承載它們的人們意味著什麼，以及名字如何往往反映了性格、命運或神的旨意。

## **什麼是聖經名字搜索？**

聖經名字搜索工具提供對經文中所出現人名、地名及重要術語的全面資料庫存取。每個條目都詳細闡明了該名字的含義、字源學背景以及聖經神學意義。

## **您將找到的內容**

對於每個聖經名字，該工具提供：
- **名字**：該名字在經文中所出現的形式
- **含義**：該名字在原文中的字面意義
- **字源學**：語言來源（希伯來文、希臘文、亞蘭文等）
- **重要性**：該名字在聖經神學中的關鍵意義
- **聖經語境**：該名字在何處以及如何被使用
- **相關名字**：變體與關聯形式
- **聖經參照**：該名字出現的經節

## **如何使用**

1. **輸入名字**：在搜索框中輸入聖經名字
2. **從建議中選擇**：自動完成功能會在您輸入時顯示相符的名字
3. **按 Enter 鍵**：載入該名字的詳細資訊
4. **檢視含義**：閱讀該名字的含義及其重要意義
5. **點擊參照**：開啟經文以在上下文語境中查看該名字
6. **探索相關名字**：發掘關聯或相近的名字

### **搜索特色**

- **自動完成**：在您輸入時即時顯示名字建議
- **模糊相符**：即使有輕微拼寫錯誤也能找到名字
- **相似度搜索**：透過 AI 技術相符變體拼寫
- **多個結果**：如果找到多個相符項目，可從清單中選擇
- **歷史記錄**：按向上箭頭鍵可恢復您上次的搜索
- **字源資訊**：了解原文語言與字根構造

## **理解名字的含義**

### **為何名字至關重要**

在聖經文化中，名字：
- **反映性格**：名字往往描繪內在品格
- **標誌命運**：名字可能具有預言性指引
- **紀念歷史**：名字銘刻重大歷史處境
- **寄託盼望**：父母對兒女的熱切期許
- **歸榮耀與神**：許多名字融入神聖元素

### **神聖名根（Theophoric Names）**

融入神的名字的名字：
- **El**（神）：但以理（Daniel）、加百列（Gabriel）、米迦勒（Michael）、撒母耳（Samuel）、以色列（Israel）
- **Yah / Jah**（耶和華）：以賽亞（Isaiah）、耶利米（Jeremiah）、以利亞（Elijah）、約西亞（Josiah）
- **Baal**（主——有時指假神）：巴力（Baal）、耶路巴力（Jerubbaal）

### **改名換姓**

神親自改變名字以賦予全新身分：
- **亞伯蘭 → 亞伯拉罕**：「尊貴之父」→「多國之父」
- **撒萊 → 撒拉**：名字的昇華，兩者皆有「公主」之意
- **雅各 → 以色列**：「抓奪者」→「與神較力者」
- **西門 → 彼得**：「聽見」→「磐石」
- **掃羅 → 保羅**：希伯來名字 → 希臘 / 羅馬名字

### **複合名字**

由多個詞素構成的名字：
- **約雅敬**——「耶和華堅立」
- **尼布甲尼撒**——「尼波神，請護衛我的疆土」
- **麥基洗德**——「仁義之王」

## **高效使用技巧**

1. **結合語境思考**：名字的含義融入其歷史故事時最為鮮活
2. **注意原文語言**：希伯來文與希臘文名字在涵義上各有特色
3. **留意命名規律**：家族命名的傳統與模式（如撒迦利亞、約翰）
4. **查驗不同變體**：同一名字可能以多種型態出現
5. **深入閱讀參照**：觀察名字如何與性格或重大事件交織
6. **探索字源根基**：原始字根往往揭示更深刻的神學內涵
7. **對比不同譯本**：部分譯本側重意譯，部分譯本側重音譯

## **工作流程範例**

### **人名專題查經——大衛**

1. 搜索：`David`
2. 了解名字含義：「親愛的 / 蒙愛者」
3. 體會其屬靈重要性：
   - 蒙神所愛

   - 被稱為「合神心意的人」

5. 點擊經文參照閱讀大衛的生平事蹟

   - 所羅門（其子——「和平」）
   - 拔示巴（其妻——「誓約之女」）
7. 記錄對神信實慈愛的心得與啟發

### **地名專題查經——伯利恆**

1. 搜索：`Bethlehem`
2. 了解名字含義：「麵包之家 / 糧食之倉」
3. 領會其預言性意義：
   - 大衛的出生地
   - 耶穌的誕生地（生命之糧！）
   - 地名含義與耶穌救贖使命的奇妙呼應
4. 點擊經文參照：
   - 彌迦書 5:2（彌賽亞預言）
   - 馬太福音 2:1（應驗成就）
   - 讚嘆神在微小細節中的主權安排

### **主題查經——神的聖名**

1. 搜索：`El`（神）
2. 搜索：`Elohim`（神 / 創造之主）
3. 搜索：`Yahweh` / `Jehovah`（耶和華 / 自有永有者）
4. 搜索：`Adonai`（主）
5. 搜索複合聖名：
   - `El Shaddai`（全能的神）
   - `Yahweh Jireh`（耶和華以勒——主必預備）
   - `Yahweh Nissi`（耶和華尼西——主是我的旌旗）
6. 系統整理神性情特徵的多元面向
7. 依據神的聖名進入深層的敬拜與讚美

### **藉由名字透視人物轉變**

1. 搜索：`Jacob`
   - 「抓奪者」——出生時抓著以掃的腳跟
   - 性格如其名字（欺瞞詭詐）
2. 搜索：`Israel`
   - 「與神較力者」——在雅博渡口與天使摔跤之後
   - 新的名字，全新的屬靈身分
3. 對比生命蛻變前與蛻變後的差異
4. 應用於個人的屬靈成長旅程

## **常見搜索問題**

### **找不到名字**

- **嘗試替代拼寫**：不同聖經譯本之間的音譯差異
- **檢查變體形式**：嘗試縮寫或完整名稱
- **使用人物搜索**：可能收錄於人物資料庫中
- **嘗試相似度搜索**：AI 會提示相近的相符項目
- **核對譯本**：比對您當前所用的聖經版本

### **多重含義爭議**

- 某些古老名字在字源學上仍存學術爭議
- 不同學者可能提出多種不同詮釋
- 條目中通常會列出主要的可能解釋
- 結合上下文脈絡有助於判斷最貼切的含義

### **翻譯差異**

- 希伯來名字在中文音譯上可能因譯本而異
- 希臘文形式與希伯來原文形式常有轉化
- 部分譯本採意譯，部分譯本採音譯
- 例如：約書亞（希伯來文）對應新約的耶穌（希臘文音譯）
