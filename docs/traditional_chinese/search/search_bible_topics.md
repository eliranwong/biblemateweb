# **聖經主題搜索指南**

此工具可協助您透過組織嚴密的專題條目彙編，深入探索聖經的主題與教導。搜索任何專題以了解聖經對此的真理啟示，並配有完整的相關經文參照。

## **什麼是聖經主題搜索？**

聖經主題搜索工具提供對涵蓋聖經主題、專題與屬靈概念的全面資料庫存取。您可以搜索任何主題，查閱闡釋聖經真理視角的詳細條目，並直接連結至相應的聖經經文段落。

## **您將找到的內容**

對於每個聖經主題，該工具提供：
- **主題名稱**：專題的清晰標題
- **描述**：從聖經視角出發的全面主題闡釋
- **聖經根基**：聖經在此專題上的權威教導
- **關鍵主題**：與該主題緊密關聯的重要概念
- **聖經參照**：論及該主題的相關經文章節
- **相關主題**：供進一步研讀的關聯專題

## **如何使用**

1. **輸入主題**：在搜索框中輸入專題或主題名稱
2. **從建議中選擇**：自動完成功能會在您輸入時顯示相符的主題
3. **按 Enter 鍵**：載入該主題的詳細資訊
4. **檢視內容**：閱讀專題闡述與聖經教導
5. **點擊參照**：開啟經文以在聖經上下文語境中研讀該主題
6. **探索相關主題**：順著主題連結深化屬靈理解

### **搜索特色**

- **自動完成**：在您輸入時即時顯示主題建議
- **模糊相符**：即使有輕微拼寫錯誤也能找到主題
- **相似度搜索**：透過 AI 技術相符關聯的屬靈概念
- **多個結果**：如果找到多個相符項目，可從清單中選擇
- **歷史記錄**：按向上箭頭鍵可恢復您上次的搜索
- **語義理解**：依概念本質而非僅靠關鍵字檢索主題

## **常見搜索問題**

### **找不到主題**

- **嘗試同義詞**：改用不同詞彙表達同一概念
- **擴大檢索範圍**：使用更宏觀概括的名詞
- **借道關聯主題**：從相鄰近的專題切入探索
- **嘗試概念描述**：用句子描述您正在尋找的思想
- **檢查相似度**：AI 會提示相近的相符主題

### **主題過於寬泛**

- **縮小範圍**：搜索更具體的維度或層面
- **善用關聯主題**：導覽至更精準聚焦的子條目
- **查看子專題**：尋找更深入細緻的專項論述
- **設定範圍篩選**：按兩約或特定文體進行過濾

### **結果不甚明確**

- **通讀全文**：避免走馬看花，全面閱讀條目
- **查考所有參照經文**：在完整上下文中仔細琢磨經文
- **查閱專業註釋**：獲取權威解經學者的精闢詮釋
- **對比相鄰主題**：辨析各專題之間的有機聯繫與界限
