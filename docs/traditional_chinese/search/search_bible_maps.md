# **聖經地圖搜索指南**

此工具提供互動式地圖搜索功能，以直觀的視覺方式探索聖經地理地點。搜索經文中提到的地點，並在詳細且可縮放的地圖上查看其標註。

## **什麼是聖經地圖搜索？**

聖經地圖搜索工具將地點搜索與互動式地圖技術相結合。您可以搜索聖經中的地點，並立即在帶有圖釘標記的互動式地圖上查看它們，讓您生動地將聖經事件的地理環境視覺化。

## **您將找到的內容**

對於每個聖經地點，該工具提供：
- **互動式地圖**：可縮放和平移的地圖顯示
- **地點標記**：顯示精確位置的圖釘
- **地點詳情**：每個地點的相關資訊
- **地理脈絡**：周圍區域與自然地形
- **聖經參照**：提及該地點的經節
- **多重視圖選項**：一般地圖、衛星視圖與地形視圖

## **如何使用**

1. **輸入地點**：在搜索框中輸入地點名稱
2. **從建議中選擇**：自動完成功能會在您輸入時顯示相符的地點
3. **按 Enter 鍵**：載入標註有該地點的地圖
4. **檢視地圖**：查看該地點的地理位置
5. **縮放與平移**：探索周圍區域
6. **點擊標記**：檢視有關該地點的詳細資訊
7. **切換視圖**：在地圖、衛星和地形模式之間切換

### **搜索特色**

- **自動完成**：在您輸入時即時顯示地點建議
- **模糊相符**：即使有輕微拼寫錯誤也能找到地點
- **互動式地圖**：基於 Leaflet 的流暢地圖導覽
- **多標記顯示**：可同時顯示多個相關地點
- **標記彈出視窗**：點擊標記即可查看地點詳情
- **歷史記錄**：按向上箭頭鍵可恢復您上次的搜索
- **暫停 / 延遲**：微小延遲以確保標記順暢渲染呈現

## **常見搜索問題**

### **找不到地點**

- **嘗試替代名稱**：許多地點擁有不同歷史名稱
- **核對拼寫**：參照您使用的聖經譯本
- **使用部分搜索**：輸入前幾個字母
- **嘗試相似度搜索**：AI 會提示相近的相符項目
- **查閱地點工具**：可能收錄於地點清單中

### **標記未出現**

- **請稍候片刻**：地圖圖層需要時間渲染
- **縮小視圖**：標記可能落在當前視野之外
- **重新整理**：嘗試再次發起搜索
- **檢查座標**：某些古代遺址的精確位置尚無定論

### **載入緩慢**

- **網路連線**：地圖瓦片需要下載數據
- **縮放層級**：高倍率縮放會載入更多細節
- **多標記**：地點數量過多時耗時較長
- **請耐心等候**：給予地圖瓦片充足載入時間
