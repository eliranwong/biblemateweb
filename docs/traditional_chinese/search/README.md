# 搜索指南

可從 **搜索** 選單（`search` 圖示）開啟，或透過 [快速搜索](../basics/quick_search.md) 中的關鍵字（例如 `verses:::love`）進入。

| 搜索 | 關鍵字 | 指南 |
|---|---|---|
| 經文（字面、模式、語義） | `verses` | [經文搜索](search_bible_verses.md)、[進階範例](search_bible_verses_examples.md) |
| 平行經文 | `parallels` | [平行經文搜索](search_bible_parallels.md) |
| 聖經應許 | `promises` | [聖經應許搜索](search_bible_promises.md) |
| 聖經主題 | `topics` | [聖經主題搜索](search_bible_topics.md) |
| 聖經人物 | `characters` | [聖經人物搜索](search_bible_characters.md) |
| 人物關係 | `relationships` | [人物關係搜索](search_bible_relationships.md) |
| 聖經地點 | `locations` | [聖經地點搜索](search_bible_locations.md) |
| 聖經地圖 | `maps` | [聖經地圖搜索](search_bible_maps.md) |
| 聖經名字 | `names` | [聖經名字搜索](search_bible_names.md) |
| 聖經字典 | `dictionaries` | [聖經字典搜索](search_dictionaries.md) |
| 百科全書 | `encyclopedias` | [百科全書搜索](search_encyclopedias.md) |
| 原文詞典 | `lexicons` | [原文詞典搜索](search_lexicons.md) |

## 影響搜索的設定

- [搜索模式](../user_preferences/search_mode.md)（字面 / 模式 / 語義）
- [區分大小寫](../user_preferences/search_case_sensitivity.md)
- [相似條目數量](../user_preferences/top_similar_entries.md)、[相似經文數量](../user_preferences/top_similar_verses.md)
- 語義搜索需要嵌入模型：[語義搜索設定](../server_setup/semantic_search_setup.md)
- `config.verses_limit` 限制結果數量上限（[設定](../server_setup/configuration.md)）

程式化呼叫方式：[REST API](../integrations/rest_api.md)。
