# 安裝 Antigravity CLI

Antigravity CLI（`agy`）可在 BibleMate AI Web 中作為基於訂閱的 AI 後端（`antigravity`）使用 – 請參閱 [AI 後端](../ai_features/ai_backends.md) 以及 [配置設定指南](../server_setup/configuration.md) 中的 `config.show_antigravity`。

首先啟動 Ubuntu 環境（[install_ubuntu.md](install_ubuntu.md)）：

```
ubuntu
```

安裝：

```
curl -fsSL https://antigravity.google/cli/install.sh | bash
```

啟動並登入：

```
agy
```
