# AI 註釋

由 AI 撰寫的逐節註釋，隨附為 **AIC** 註釋模組（英文），另有 **AICTC**（繁體中文）與 **AICSC**（簡體中文）。

## 開啟

- **AI** 選單 → `AI 註釋`
- 右鍵點擊經文 → `🧠 AI 註釋`
- **工具** 選單 → `聖經註釋` 並選擇 AIC。

此模組會自動配合您的[介面語言](../user_preferences/ui_language.md)（`eng` → AIC、`tc` → AICTC、`sc` → AICSC），並儲存於 `favorite_commentary` 中。

## 使用

輸入經文編號（如 `John 3:16` 或 `Romans 8:1-17`），或讓它自動開啟於您正在閱讀的經文（[同步](../layout/sync.md)）。

更多資訊：[註釋工具指南](../tools/tool_commentary.md)。
