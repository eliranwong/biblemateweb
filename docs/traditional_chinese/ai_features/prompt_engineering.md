# 優化（優化用戶要求）

在回答前自動將您的請求重新改寫為更清晰、更精準的提示詞指示。

| | |
|---|---|
| 位置 | 對話模式、夥伴模式與代理模式中的 `優化` 核取方塊 |
| 鍵值 | `prompt_engineering` |
| 預設 | 開啟 |

## 運作方式

1. 您發送請求。
2. **優化用戶要求** 面板即時串流顯示經優化的指示。
3. 若開啟[審查](chat_review.md)（對話模式），您可以在繼續執行前編輯經優化的指示。
4. 隨後系統將使用該經優化的指示執行後續流程。完成後該面板會自動收合。

若優化過程失敗或未返回任何內容，流程將會停止，您可以重新嘗試。

遇到簡短直接的提問，或希望完全按照您輸入的原始字句提問時，可將此選項關閉。
