# 夥伴模式

適用於複雜多步驟聖經研讀的協作模式。AI 負責規劃並執行各個步驟，但**主導權始終在您手中**：您可以審查並微調計劃、核准工具，並編輯每個步驟的指示。

## 開啟

**AI** 選單 → `夥伴模式`。（請參閱[可用性](usage_limits.md) – 部分伺服器僅提供 CLI 版本。）

## 工作流程

1. **需求 (Request)** – 描述研讀內容（可選擇透過[優化](prompt_engineering.md)加以改進）。
2. **研讀計劃 (Study Plan)** – AI 起草一份總體計劃。您可以審查並編輯該計劃。
3. **回合 (Rounds)** – 在每個回合中，AI 會：
   - 提供下一步的**建議 (Suggestion)**，
   - 提議工具（**選用工具 (Tool Selection)**）；您可以從清單中挑選，或選擇 `更多...` 查看全部工具，
   - 撰寫您可以編輯的**工具指示 (Tool Instruction)**，
   - 執行工具或生成內容，並在每回合後附上**進度 (Progress)** 說明。
4. **總結報告 (Final Report)** – 彙總所有已完成內容的全面報告。

## 執行後的控制選項

`編輯需求`、`編輯計劃`、`編輯回合`、`修剪回合`（從選定位置捨棄之後的回合）、`繼續`（停止後恢復執行）。

## 下載

每個輸出均支援複製、TXT 與 DOCX，另提供 `下載完整對話` 與 `只下載總結報告`。

## 與其他模式比較

| | 對話模式 | 夥伴模式 | 代理模式 |
|---|---|---|---|
| 多步驟計劃 | 否 | 是 | 是 |
| 由您核准工具／指示 | 選用（審查） | 是 | 否 |

請參閱[代理模式](agent_mode.md)與[對話模式](chat_mode.md)。
