# 複製、下載、編輯與停止

## 每次回覆之後（對話模式、夥伴模式、代理模式）

| 按鈕 | 操作 |
|---|---|
| 📋 複製 | 複製回覆文字 |
| 📥 TXT | 下載為純文字檔案 |
| 📥 DOCX | 下載為 Word 文件 |
| ✒️ 編輯 | 在對話方塊中編輯回覆（對話模式）；編輯內容會保留在對話語境中 |

## 完整對話

`下載完整對話` 會將所有請求與回覆儲存為 `.txt` 檔案（可自訂檔名；預設為 `BibleMate_AI_Conversation`）。夥伴模式與代理模式亦提供 `只下載總結報告`。

## 自動滾動

`自動滾動` 核取方塊（`auto_scroll`，預設開啟）可在串流輸出時使畫面始終保持在最新內容處。

## 停止執行中的任務

點擊 **停止**（執行時「發送」按鈕會變為「停止」）並確認。夥伴模式與代理模式隨後可透過 `繼續` 恢復執行。
