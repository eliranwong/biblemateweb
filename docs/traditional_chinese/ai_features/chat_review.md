# 審查

啟用後，AI 會在關鍵節點暫停，以便您在繼續執行前進行核准、編輯或取消。

| | |
|---|---|
| 位置 | 對話模式中的 `審查` 核取方塊 |
| 鍵值 | `chat_mode_review` |
| 預設 | 關閉 |

## 審查節點

- **經優化的指示**（若[優化](prompt_engineering.md)開啟）：編輯重寫後的提示詞指示。
- **工具選擇**（若[工具](chat_tool_selection.md)開啟）：從建議的工具中選擇；`更多...` 可列出全部工具。
- **工具指示**：在執行前編輯工具指示。

在任何對話方塊中取消都會停止該請求，並顯示 `[Cancelled!]`。

在[夥伴模式](partner_mode.md)中，這些審查步驟一律保持開啟。在[代理模式](agent_mode.md)中，這些步驟則不會出現。
