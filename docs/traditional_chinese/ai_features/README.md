# AI 功能

BibleMate AI Web 中的所有 AI 功能。您可以從導覽列中的 **AI** 選單（`auto_awesome` 圖示）、工具選單，或經文的右鍵選單中開啟它們。

## 互動模式

| 功能 | 說明 |
|---|---|
| [對話模式](chat_mode.md) | 對話式聖經助手 |
| [夥伴模式](partner_mode.md) | 需經您逐步核准的多步驟研經模式 |
| [代理模式](agent_mode.md) | 自主執行的多步驟研經模式 |

## 對話模式選項

| 選項 | 說明 |
|---|---|
| [優化（優化用戶要求）](prompt_engineering.md) | 在發送前優化您的提示詞指示 |
| [代理選項](chat_agent_option.md) | 讓輔助代理提升回覆品質 |
| [工具（選用工具）](chat_tool_selection.md) | 使用研經工具與專案提示詞 |
| [審查](chat_review.md) | 在每個階段核准或編輯 |
| [匯出與編輯回覆](export_edit_responses.md) | 複製、下載 TXT/DOCX、編輯、停止 |
