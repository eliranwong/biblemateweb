# 代理選項（對話模式）

`代理` 核取方塊可讓 BibleMate 建立輔助代理，以產出更詳盡、推理更完善的回覆（提示文字：「創建代理優化回應」）。

| | |
|---|---|
| 鍵值 | `use_agent` |
| 預設 | 開啟 |

## 行為運作

- 當開啟此選項並生成純文字回答時，**代理** 面板會顯示代理的工作過程，隨後呈現回答內容。
- 關閉時，AI 會直接給出單次回覆（速度更快、成本更低）。
- 某些專業[工具](chat_tool_selection.md)無論此設定為何，都會自動調用代理。

這與[代理模式](agent_mode.md)不同，後者是專門處理多回合任務的獨立頁面。
