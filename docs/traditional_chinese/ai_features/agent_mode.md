# 代理模式

一種自主執行的模式：描述一項複雜的聖經研讀任務，AI 便會自行規劃、選用工具並執行多個回合，最後產出一份總結報告。

## 開啟

**AI** 選單 → `代理模式`。部分伺服器可能停用網頁版本，轉而顯示導向 [BibleMate CLI](https://github.com/eliranwong/biblemate) 的頁面（詳見[可用性](usage_limits.md)）。

## 工作流程

1. **需求 (Request)** – 可選擇透過[優化](prompt_engineering.md)加以改進。
2. **研讀計劃 (Study Plan)** – 生成一份總體計劃。
3. **回合 (Rounds)** – 每個回合皆包含建議、選用工具（系統會自動使用第一個建議的工具）、工具指示、輸出內容與進度。回合會持續進行，直到 AI 判定完成為止。
4. **總結報告 (Final Report)** – 彙總所有結果的最終回覆。

## 控制選項

`編輯需求`、`編輯計劃`、`編輯回合`、`修剪回合`、`繼續`；點擊 **停止** 可中斷執行。

## 下載

每個輸出均支援複製、TXT、DOCX；`下載完整對話`；`只下載總結報告`。

## 每日限制

管理員可針對未設定自備金鑰的使用者將代理模式限制為每日一次 – 請參閱[使用限制](usage_limits.md)。

如需逐步控制研讀過程，請使用[夥伴模式](partner_mode.md)。
