# 工具選單

圖示：`build`。在**工具區域**中開啟研經工具。

- **標籤頁：** 新工具標籤頁、關閉工具標籤頁、關閉其他。
- **語音：** 聖經廣播、聖經語音。
- **AI 研經：** 書卷分析、全章摘要。
- **註釋與參考：** 聖經註釋、經文串珠、經文寶庫。
- **彙編選輯：** 聖經應許、平行經文。
- **時間：** 聖經時間軸、聖經時序。
- **參考書籍**
- **形態學分析**
- **資源索引：** 全章索引（啟動預設工具）、單節索引。
- **筆記與書籤：** 聖經筆記（當設定 Google 雲端硬碟時）、筆記本、書籤（含螢光標記與閱讀紀錄）。
- **一年讀經計劃：** 365 天每日讀經計劃，支援進度追蹤與多語言經文引用。

多數工具會在您當前閱讀的經節開啟。完整清單與指南請參閱：[工具](../layout/tools_window.md)。
