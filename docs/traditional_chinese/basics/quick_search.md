# 快速搜索

位於導覽列中的輸入框（在行動版中位於抽屜選單內）。輸入內容後按 **Enter**。自動完成功能會推薦書卷名稱、聖經版本和工具名稱。

## 範例

| 輸入 | 結果 |
|---|---|
| `KJV` | 在聖經區域開啟 KJV |
| `John 3:16` | 開啟約翰福音第 3 章第 16 節 |
| `KJV:::John 3:16` | 同上，使用 KJV 版本 |
| `bible:::John 3:16` | 在工具區域將其作為平行聖經開啟 |
| `faith hope love` | 搜索經文（結果顯示於工具區域） |
| `xrefs:::John 3:16` | 開啟經文串珠工具 |

多個經文引用或自訂文字將會執行經文搜索。每次搜索後輸入框會自動清空。

完整語法請參閱：[快速搜索（版面）](../layout/quick_search.md)。
