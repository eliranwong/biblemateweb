# 平行聖經選單

圖示：`devices_fold`。在聖經區域旁的**工具區域**中開啟聖經以進行對比。

| 項目 | 動作 |
|---|---|
| 新平行標籤頁 | 在工具區域建立新標籤頁 |
| 關閉平行標籤頁 | 關閉當前啟用的工具區域標籤頁 |
| 關閉其他 | 關閉當前標籤頁以外的所有其他工具區域標籤頁 |
| 主要 / 次要聖經 | 您偏好的版本 |
| 原文聖經 | ORB, OIB, OPB, ODB, OLB |
| 其他聖經 | 所有其他版本 |

開啟[同步](toggle_options.md#sync)後，兩個視窗將保持在同一章。

更多資訊：[平行聖經](../layout/parallel_bibles.md)。
