# 導覽列

位於頁面頂部的功能列。

| 元素 | 用途 |
|---|---|
| 頭像 / **BibleMate AI** | 顯示目前檢視畫面的[連結與 QR 碼](share_link_qr_code.md) |
| 快速搜索框 | 透過輸入文字進行[搜索或導覽](quick_search.md) |
| 聖經 (`local_library`) | [聖經選單](menu_bibles.md) |
| 平行聖經 (`devices_fold`) | [平行聖經選單](menu_parallel_bibles.md) |
| 工具 (`build`) | [工具選單](menu_tools.md) |
| 搜索 (`search`) | [搜索選單](menu_search.md) |
| AI (`auto_awesome`) | [AI 選單](menu_ai.md) |
| 設定 (`settings`) | [切換選項](toggle_options.md)與偏好設定 |

將滑鼠懸停在圖示上可查看工具提示。在小螢幕裝置上，標題和快速搜索框會移入點擊漢堡圖示開啟的左側抽屜選單中；五個選單按鈕則保留在頂部導覽列中。
