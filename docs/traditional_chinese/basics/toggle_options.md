# 切換選項

開啟導覽列中的**設定**（齒輪）選單。

| 選項 | 效果 | 預設值 |
|---|---|---|
| 返回 / 前進箭頭 | 瀏覽器歷史記錄 | – |
| 只顯示聖經 / 只顯示工具 / 聖經與工具 | [變更版面](../layout/toggle_layout.md) | 聖經與工具 |
| 版面轉換 | 顯示/隱藏版面轉換按鈕 | 開啟 |
| 開啓 | 顯示/隱藏開啓（聖經選單）按鈕 | 開啟 |
| 筆記 | 顯示/隱藏筆記標記（頁面重新載入） | 開啟 |
| 提示框 (Tooltip) | 懸停顯示單詞提示框（關閉時需點擊單詞才顯示；[詳細資訊](../integrations/word_tooltips.md)） | 開啟 |
| <a id="sync"></a>同步 | 保持聖經與工具視窗同步在同一章（[詳細資訊](../layout/sync.md)） | 開啟 |
| 全螢幕 | 切換全螢幕 | 關閉 |
| 深色/淺色模式 | 切換佈景主題（頁面重新載入） | 深色 |
| 偏好設定 | 開啟[偏好設定](../user_preferences/README.md)頁面 | – |

在行動裝置上，相同的切換開關位於左側抽屜選單中。

切換設定會自動儲存。更多關於懸浮按鈕的說明：[懸浮按鈕](../layout/floating_buttons.md)。
