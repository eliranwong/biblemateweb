# 常見問題

**我需要註冊帳號嗎？** 不需要。設定會儲存在您的瀏覽器中。僅在需要使用[雲端硬碟筆記](../integrations/google_drive_notes.md)或受到每日額度限制時，才需要登入 Google 帳號。

**使用 AI 需要付費嗎？** 伺服器預設值由管理員設定。您也可以使用自己的金鑰（[自帶金鑰 (BYOK)](../user_preferences/api_key_setup.md)）。

**如何並排閱讀兩部聖經？** 請參閱[平行聖經](../layout/parallel_bibles.md)。

**如何查詢希伯來文或希臘文字詞？** 在原文聖經中點擊該字詞即可（[單字工具提示](../integrations/word_tooltips.md)）。

**如何檢視與某節經文相關的所有資訊？** 點擊該節經文編號（[經文選單](../integrations/verse_menu.md)）。

**如何分享我正在閱讀的內容？** 請參閱[分享連結或 QR 碼](share_link_qr_code.md)。

**為什麼代理模式或夥伴模式會顯示 CLI 頁面？** 管理員已將其停用；請使用您自己的 API 金鑰（[使用額度限制](../ai_features/usage_limits.md)）。

**為什麼語義搜索無法運作？** 請參閱[語義搜索設定](../server_setup/semantic_search_setup.md)。

**如何重置所有設定？** `偏好設定` → `重置所有偏好設定`（[使用者資料](../user_preferences/user_data_and_storage.md)）。

**我可以新增自己的書籍或聖經版本嗎？** 可以，請參閱[自訂資源](../integrations/custom_resources.md)。

**我可以在手機上使用嗎？** 可以：請參閱[行動版版面](../layout/mobile_layout.md)，或在 Android 上運行伺服器（[Termux](../android_termux/README.md)）。

更多資訊請參閱：[疑難排解](../server_setup/troubleshooting.md)。
