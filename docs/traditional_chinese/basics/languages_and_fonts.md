# 語言與字型

## 介面語言

| 代碼 | 語言 |
|---|---|
| `eng` | English (英文) |
| `tc` | 繁體中文 (Traditional Chinese) |
| `sc` | 简体中文 (Simplified Chinese) |

在 `偏好設定` → 語言（[指南](../user_preferences/ui_language.md)）中變更，或使用 URL 參數 `lang`。語言設定會影響選單、對話框、聖經書卷名稱，以及多項工具的內容語言：AI 註釋 (AIC / AICTC / AICSC)、[書卷分析](../tools/tool_analysis.md)、[全章摘要](../tools/tool_summary.md)、AI 歡迎訊息和 [API](../integrations/rest_api.md) 輸出（`language` 參數）。

## 字型

希伯來文和希臘文文本使用內建字型（Ezra SIL、KoineGreek），因此原文聖經可以在任何裝置上正確顯示。可透過[字型大小](../user_preferences/font_size.md)調整整體文字大小。
