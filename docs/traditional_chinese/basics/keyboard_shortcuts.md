# 鍵盤快捷鍵

| 位置 | 按鍵 | 動作 |
|---|---|---|
| 快速搜索框 | **Enter** | 執行搜索或導覽 |
| 工具 / 搜索輸入框（經文、註釋、串珠、寶庫、原文詞典、聖經字典、主題、人物、地點、平行經文、應許、名字、地圖...） | **Enter** | 執行查詢 |
| 上述輸入框 | **↑**（向上鍵） | 恢復上一筆查詢內容（亦可點擊歷史記錄圖示 ⏱️） |
| AI 對話 / 夥伴 / 代理 / 工作室請求輸入框 | **Ctrl+S**（macOS 為 **Cmd+S**） | 發送 |
| 瀏覽器 | 上一頁 / 下一頁 (Back / Forward) | 在導覽歷史記錄中移動；每次更換聖經和工具都會更新網址列（[URL 參數](../layout/url_parameters.md)） |

滑鼠與觸控操作：點擊經節編號可開啟[經文選單](../integrations/verse_menu.md)；按滑鼠右鍵（長按）可開啟[右鍵選單](../layout/context_menus.md)；拖曳[懸浮按鈕](../layout/floating_buttons.md)或分隔線可調整版面。
