# 聖經選單

圖示：`local_library`。在**聖經區域**中開啟聖經。

| 項目 | 動作 |
|---|---|
| 新聖經標籤頁 | 在聖經區域建立新標籤頁 |
| 關閉聖經標籤頁 | 關閉當前啟用的標籤頁（最後一個標籤頁無法關閉） |
| 關閉其他 | 關閉當前標籤頁以外的所有其他標籤頁 |
| 主要 / 次要聖經 | 您最常用的兩個版本（[前往設定](../user_preferences/primary_bible.md)） |
| 原文讀本、逐字對照、平行對照、語法分析、語言學聖經 | ORB, OIB, OPB, ODB, OLB |
| 其他聖經 | 伺服器上的所有其他版本（輸入有效的[自訂權杖](../user_preferences/custom_token.md)後會顯示自訂聖經） |

如果已選取經節，或工具查詢中包含經文引用，聖經將在該節經文開啟。

更多資訊：[聖經視窗](../layout/bible_window.md)、[標籤頁管理](../layout/tabs_management.md)。
