# 快速入門

在瀏覽器中開啟 BibleMate AI Web。無需登入；您的設定會直接保存在瀏覽器中。

## 介面結構

- **導覽列（頂部）：** 頭像/標題、[快速搜索](quick_search.md)框，以及五個選單按鈕——聖經、平行聖經、工具、搜索、AI，隨後是設定（齒輪）按鈕。
- **聖經區域：** 閱讀聖經的地方，支援分頁標籤。
- **工具區域：** 平行聖經、研經工具、搜索結果和 AI 功能顯示的區域，同樣支援分頁標籤。
- **懸浮按鈕（右下角）：** 版面轉換與開啓（聖經選單）。

## 入門操作

1. 點擊**聖經**按鈕並選擇一個聖經版本，或在快速搜索框中輸入 `John 3:16` 並按 Enter。
2. 點擊**開啓**按鈕以跳轉至其他書卷、章節與經節。
3. 從**工具**中開啟研經工具（例如經文串珠），即可在聖經旁並列檢視。
4. 使用**版面轉換**按鈕專注於聖經、工具或兩者並列顯示。

在手機上，點擊漢堡圖示即可開啟抽屜選單（[行動版版面](../layout/mobile_layout.md)）。
