# AI 提供商與訂閱

BibleMate 在單一介面下整合了多種 AI 服務：

- API 提供商：Google AI、OpenAI、Anthropic、Cohere、DeepSeek、Mistral、xAI、Azure 系列、Ollama Cloud 以及自訂端點。
- 已登入的訂閱式 CLI（管理員啟用時）：Grok Build、Claude Code、Antigravity。
- 自備金鑰（BYOK），或使用伺服器預設設定。

詳細資訊：[AI 後端](../ai_features/ai_backends.md)、[自備金鑰](../user_preferences/api_key_setup.md)。AI 功能亦可調用整合的聖經[工具](../ai_features/chat_tool_selection.md)。
