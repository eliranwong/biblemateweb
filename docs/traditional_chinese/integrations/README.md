# 整合

> [!IMPORTANT]
> **整合各項研經資源是 BibleMate AI Web 最顯著的優勢之一。**
> 聖經、原文文本、原文詞典、形態學分析、聖經註釋、經文串珠、經文寶庫、聖經字典、百科全書、地圖、聖經時間軸、資源索引、聖經筆記、聖經語音與人工智能／AI 並非孤立的模組。它們緊密交織在一起：從任何經節、篇章或書卷，只需輕輕一點，即可開啟所有相關資源，與您正在閱讀的經文並排顯示，並同步至同一段經文。

## 為什麼這很重要

- **單一段落，多種資源。** 點選經節號碼即可在工具區開啟經文串珠、經文寶庫、聖經註釋、形態學分析、資源索引、聖經語音、版本對比或 AI。
- **懸停並點選字詞。** 原文文本與聖經筆記中的字詞均連結至詞典與形態學數據。
- **處處相連。** 聖經註釋、筆記與搜索結果中的經文參照皆可在聖經區開啟。
- **保持同步。** [同步](../layout/sync.md)功能讓聖經視窗與工具視窗維持在同一章。
- **AI 與數據結合。** AI 功能可調用相同的聖經數據工具（[選用工具](../ai_features/chat_tool_selection.md)）。
- **向其他軟體開放。** 支援 REST API、命令列客戶端、Google 雲端硬碟筆記以及自訂數據。
