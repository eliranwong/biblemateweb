# 經文串珠與經文連結

聖經文本內（譯本註記、經文串珠標記）以及工具輸出內容中（註釋、筆記、搜索結果）的參照皆可點擊。

| 連結 | 結果 |
|---|---|
| 經文參照（例如 `John 3:16`） | 在聖經視窗中開啟該章 |
| 經文串珠標記 | 開啟所參照的經文段落 |
| 經文節號 | 開啟[單節選單](verse_menu.md) |

## 在哪個視窗開啟？

- 當[同步](../layout/sync.md)**開啟**時，連結會變更包含該連結的視窗內容。
- 當同步**關閉**時，連結會在*另一個*視窗中開啟該經文段落，讓你在查閱參照時仍能保留原本閱讀的位置。

在譯本聖經與工具中皆以相同方式運作。
