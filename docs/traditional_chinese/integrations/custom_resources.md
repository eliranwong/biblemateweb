# 自訂資源

管理員可以整合自己的私人數據。

- 將自訂聖經放入 `~/biblemate/data_custom/bibles`，並將自訂參考書籍放入 `~/biblemate/data_custom/books`。
- 使用者可透過輸入[自訂權杖](../user_preferences/custom_token.md)來解鎖這些資源，或在單次造訪時於網址中加入 `?t=TOKEN`。
- 自訂聖經隨後會顯示於聖經選單、偏好設定清單以及 API 查詢中。
- 該權杖亦可繞過[使用限制](../ai_features/usage_limits.md)。

請參閱[參考書籍](../tools/tool_books.md)與[配置指南](../server_setup/configuration.md)。
