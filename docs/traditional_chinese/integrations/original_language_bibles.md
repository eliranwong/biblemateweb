# 原文聖經

五種整合希伯來文／希臘文版本，各自具備相同的[選擇器](bible_selectors.md)、[三點選單](three_dot_menu.md)、單節彈出視窗、單詞提示框以及原文詞典連結。

| 代碼 | 名稱 | 重點 |
|---|---|---|
| ORB | Original Reader's Bible（原文朗讀版聖經） | 易讀的原文文本 |
| OIB | Original Interlinear Bible（原文逐字對照聖經） | 逐詞附帶字義釋義 |
| OPB | Original Parallel Bible（原文平行聖經） | 原文與譯本並排對照 |
| ODB | Original Discourse Bible（原文語法分析聖經） | 篇章語法結構 |
| OLB | Original Linguistic Bible（原文語言學聖經） | 語言學標註 |

透過「聖經」或「平行聖經」選單開啓，或在[快速搜索](../basics/quick_search.md)中輸入代碼。

點擊單詞可跳轉至[原文詞典](word_tooltips.md)，或將滑鼠懸停在單詞上以顯示提示框並在平行視窗間觸發[單詞與子句互聯高亮](word_tooltips.md#單詞與子句互聯高亮)；在[單節選單](verse_menu.md)中使用 🧬 形態學分析以取得完整分析。
