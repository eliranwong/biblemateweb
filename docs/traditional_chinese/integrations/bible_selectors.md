# 聖經選擇器

每個聖經視窗頂部都有一排下拉選單，其後接著[三點選單](three_dot_menu.md)。

| 選擇器 | 功能 |
|---|---|
| 版本 | 切換至其他聖經版本；保持當前經文段落 |
| 書卷 | 選擇書卷（名稱依據您的介面語言顯示） |
| 篇章 | 選擇篇章 |
| 經節 | 選擇經節；自動捲動至該節並反白標示 |

選擇任何項目都會重新載入該視窗中的經文。若開啟[同步](../layout/sync.md)功能，另一個視窗也會跟隨同步。

這些選擇器定義了三點選單的上下文：書卷／全章／單節工具以及搜索均使用所選的值。

篇章底部設有：`◀️ 上一章` 與 `下一章 ▶️` 按鈕。
