# 單詞提示框與原文詞典連結

原文聖經與帶有註記的文本中的單詞，在滑鼠懸停（或輕觸）時會開啟互動式快顯視窗。

## 快顯視窗運作方式

- **觸發：** 滑鼠懸停在標記的單詞上時，會在短暫延遲（`100 ms`）後開啟快顯視窗。
- **保持開啟以便播放語音與點擊連結：** 將游標移入快顯視窗內可保持其開啟狀態，以便你播放語音或點擊其中的連結；游標同時離開單詞與快顯視窗 `300 ms` 後，視窗將會關閉。
- **智慧定位：** 根據可用的螢幕空間，自動將自身定位於單詞的上方、下方、右側或左側，並在頁面滾動或視窗調整大小時重新調整位置。
- **隨選即取與快取：** 數據透過 `GET /api/tooltip/{word}` 獲取，並快取於瀏覽器中，以便實現即時的重複查閱。

## 三種快顯視窗類型

### 1. 原文單詞快顯視窗（希伯來文與希臘文）

在[原文聖經](../bibles/README.md)（`ORB`、`OIB`、`OPB`、`ODB`、`OLB`）中，每個希伯來文／亞蘭文（舊約）與希臘文（新約）單詞都配有豐富的形態學與語音快顯視窗：

| 元素 | 描述 |
|---|---|
| **手抄本原形** | 文本中出現的精確屈折單詞形式。**點擊它**即可在工具區域中開啟該詞的原文詞典條目。 |
| **音譯與發音** | 顯示於手抄本形式旁（`word \| transliteration \| pronunciation`）。 |
| **手抄本形式語音** | 內嵌語音播放器（`<audio controls>`），用於播放單詞**手抄本形式（屈折形式）**的發音。 |
| **原形（Lemma）** | 單詞的字典／詞根形式。**點擊它**即可在工具區域中開啟該原形的原文詞典條目。 |
| **原形語音** | 第二個內嵌語音播放器，用於播放單詞**原形（字典形式）**的發音。 |
| **形態學分析** | 文法分析標籤（例如：詞性、時態、語態、語氣、格、性、數、人稱、詞幹）。 |
| **逐字對照釋義** | 逐詞逐字對照釋義。 |
| **翻譯** | 該單詞在上下文中的翻譯。 |

#### 單詞級語音詳情

手抄本形式語音與原形語音均可直接在快顯視窗內播放，無需離開頁面：

- **舊約（希伯來文／亞蘭文 — BHS5）：** 由 `/bhs5_audio/{book}_{chapter}/BHS5_{book}_{chapter}_{verse}_{wordID}.mp3`（手抄本形式）與 `lex_BHS5_{book}_{chapter}_{verse}_{wordID}.mp3`（原形形式）提供。
- **新約（希臘文 — OGNT）：** 由 `/ognt_audio/{book}_{chapter}/OGNT_{book}_{chapter}_{verse}_{wordID}.mp3`（手抄本形式）與 `lex_OGNT_{book}_{chapter}_{verse}_{wordID}.mp3`（原形形式）提供。

> [!NOTE]
> 單詞級語音需要 `~/biblemate/data/audio/bibles/` 中的 `BHS5` 與 `OGNT` 語音檔案（參見[數據與資源](../server_setup/data_and_resources.md)）。

### 2. 詞彙快顯視窗（Strong 號碼）

在帶有 Strong 編號標註的譯本聖經中，滑鼠懸停在 Strong 號碼（`H...` 或 `G...`）上會顯示：

- 可點擊的標頭（`[Lexicon] Strong's ID`），點擊可開啟[原文詞典](../search/search_lexicons.md)中的完整條目。
- 來自你所配置的[希伯來文詞典](../user_preferences/hebrew_lexicon.md)或[希臘文詞典](../user_preferences/greek_lexicon.md)中的詞典定義。
- 定義內包含可點擊的經文串珠與原文詞典連結。

### 3. 聖經筆記快顯視窗

滑鼠懸停在譯本註記標記上時，會顯示筆記文字以及可點擊的聖經經文參照。

## 點擊跳轉至原文詞典

點擊希伯來文／希臘文手抄本單詞、原形或 Strong 連結，即可在工具區域中開啟[原文詞典](../search/search_lexicons.md)，並將該條目作為查詢條件，套用你偏好的希伯來文或希臘文詞典。

## 單詞與子句互聯高亮

在[原文聖經](original_language_bibles.md)（`ORB`、`OIB`、`OPB`、`ODB`、`OLB`）中，將滑鼠懸停在任何希伯來文或希臘文單詞上，會同時在所有已開啟的聖經視窗中高亮顯示相關元素（例如在[平行聖經](../layout/parallel_bibles.md)中並排閱讀 `OPB` 與 `OLB` 時）：

1. **子句高亮（`.c<cl>`）：** 高亮顯示屬於同一文法子句的所有單詞（淺色模式為 `PAPAYAWHIP`；深色模式為 `#d48f28`）。
2. **詞彙互聯高亮（`.G<sn>`）：** 在所有已開啟的視窗中高亮顯示相同詞彙／Strong 編號的每一個出現處（淺色模式為 `#E7EDFF`；深色模式為 `#5d85fc`）。
3. **焦點單詞高亮（`#w<id>`）：** 高亮顯示該目標單詞（淺色模式為 `#C9CFFF`；深色模式為 `#5a64b0`）。

移開游標後即會清除這三層高亮。由於子句與詞彙高亮會查詢整個文件（`document.querySelectorAll`），因此在其中一個視窗懸停單詞時，平行視窗中對應的單詞與子句也會同步高亮。

## 程式化存取

提示框數據由 `GET /api/tooltip/{word}` 提供——參見 [REST API](rest_api.md)。
