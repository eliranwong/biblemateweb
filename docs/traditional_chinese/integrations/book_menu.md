# 書卷工具選單

可從三點選單 → `書卷工具` 開啟，或在書卷標題上按右鍵開啟。

| 項目 | 說明 |
|---|---|
| ⏳ **聖經時間軸** | 該書卷的時間軸（[聖經時間軸](../tools/tool_timelines.md)） |
| 🔘 **概述** | 簡介、作者、寫作日期與目的 |
| 📐 **結構大綱** | 書卷的分層結構劃分 |
| 🧵 **書卷脈絡** | 論述或敘事的推進脈絡 |
| 🕰️ **歷史背景** | 寫作背景與歷史處境 |
| 🎨 **主題** | 主要神學與文學主題 |
| 🏷️ **關鍵詞** | 重要且反覆出現的詞彙與概念 |
| ⛪ **神學** | 書卷中呈現的教義 |
| 🚩 **正典位置** | 該書卷在聖經正典中的定位與關聯 |
| 🌱 **生活應用** | 對今日生活的實踐應用 |
| 💎 **摘要** | 書卷信息的精簡摘要 |
| 📝 **新增筆記／編輯筆記** | 書卷筆記（僅在已設定 Google 雲端硬碟筆記時可用） |

這十項分析項目各自會在[書卷分析](../ai_features/book_analysis.md)中開啟相應區塊（[完整指南](../tools/tool_analysis.md)）。
