# 經文節號選單

在聖經中點擊**經文節號**（或右鍵點擊經文；亦可透過 ⋮ → `Verse Tools`），即可開啟單節快顯選單。該節經文會在節數下拉選單中被選定，且所有工具都會在空的工具區域標籤頁中針對該節經文開啟。

## 選單項目

| 項目 | 描述 |
|---|---|
| 📋 **複製**（Copy） | 將經文以 `[Reference] text` 格式（移除標籤）複製到剪貼簿 |
| 🔊 **聖經語音**（Bible Audio） | 播放與你的聖經同步的全章語音（[聖經語音](../tools/tool_audio.md)） |
| 🔗 **經文串珠**（Cross-references） | 該節經文的相關經文段落（[經文串珠](../tools/tool_xrefs.md)） |
| 🏦 **經文寶庫**（Treasury） | 經文寶庫（Treasury of Scripture Knowledge）條目（[經文寶庫](../tools/tool_treasury.md)） |
| 🧠 **AI 註釋**（AI Commentary） | AI 撰寫的註釋（依介面語言提供 AIC/AICTC/AICSC）（[指南](../ai_features/ai_commentary.md)） |
| 📚 **聖經註釋**（Commentaries） | 使用你最喜愛的註釋開啟經文註釋工具（[註釋](../tools/tool_commentary.md)） |
| 🧬 **形態學分析**（Morphology） | 逐詞原文分析（[形態學分析](../tools/tool_morphology.md)） |
| 👀 **版本對比**（Comparison） | 同時在多個聖經版本中顯示該節經文：你的主要聖經、目前聖經以及逐字對照的 OHGBi |
| 📑 **資源索引**（Indexes） | 引用此節經文的各項資源（[單節索引](../tools/tool_indexes.md)） |
| 📝 **新增筆記／編輯筆記**（Add Note / Edit Note） | 若配置 Google Drive 筆記：開啟該節筆記（若已存在則為編輯）。若未配置：將經文傳送至[筆記本](../tools/tool_notepad.md) |
| 💬 **問 BibleMate**（Ask BibleMate） | 將經文傳送至對話模式（[指南](../ai_features/ask_biblemate.md)） |

## 備註

- 工具開啟時**未同步**於你點擊的經文，因此當你滾動頁面時，工具內容不會隨之跳動。
- 在觸控裝置上，輕觸經文節號即可開啟此選單。

- **加入本節書籤**：點擊經文節號或右鍵點擊經文可選擇 **加入本節書籤**（可於 **工具 → 書籤** 管理已儲存的書籤）。
- **彩色螢光標記**：點擊經文節號或右鍵點擊經文 → **螢光標記**，可標記為**金句**、**應許**、**教義**或**禱告**（支援淺色與深色模式配色，並可於 **工具 → 書籤** 依顏色篩選瀏覽）。
