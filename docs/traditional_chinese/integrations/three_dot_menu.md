# 三點選單

`⋮`（`more_vert`）按鈕位於每本聖經頂端的書卷、章和節選擇器旁邊。它將導航、搜索、研經工具與筆記匯集於同一處。

它在譯本聖經與原文聖經（ORB、OIB、OPB、ODB、OLB）中的運作方式相同。結果會在**空的工具區域標籤頁**中開啟，以便聖經保持在視圖中。

## 選單項目

### 導航
| 項目 | 描述 |
|---|---|
| ◀️ **上一章**（Prev Chapter） | 前往上一章，並自動循環至前一卷書的最後一章（從創世記 1 章則循環至最後一卷書） |
| ▶️ **下一章**（Next Chapter） | 前往下一章，並自動循環至下一卷書 |

### 搜索（僅限聖經區域）
這些選項會在工具區域中開啟經文搜索，並使用目前工具查詢中所保留的文字。

| 項目 | 描述 |
|---|---|
| 🔍 **搜索 *版本***（Search *version*） | 在所選版本中搜索整本聖經，例如 `Search NET` |
| 🔍 **搜索舊約**（Search OT） | 將搜索限制在舊約聖經 |
| 🔍 **搜索新約**（Search NT） | 將搜索限制在新約聖經 |
| 🔍 **搜索 *書卷***（Search *book*） | 將搜索限制在所選書卷，例如 `Search John` |

參見[聖經經文搜索](../search/search_bible_verses.md)。

### 研經工具
| 項目 | 描述 |
|---|---|
| 🧩 **書卷工具**（Book Tools） | 開啟所選書卷的[書卷工具選單](book_menu.md) |
| 🧩 **全章工具**（Chapter Tools） | 開啟所選章的[全章工具選單](chapter_menu.md) |
| 🧩 **單節工具**（Verse Tools） | 開啟所選經文節數的[單節選單](verse_menu.md) |

（原文聖經中這些項目會以 💡 圖示顯示。）

### 筆記（僅在配置 Google Drive 筆記時顯示）
| 項目 | 描述 |
|---|---|
| 📝 **書卷筆記**（Book Note） | 開啟整卷書的筆記 |
| 📝 **全章筆記**（Chapter Note） | 開啟該章的筆記 |
| 📝 **經文筆記**（Verse Note） | 開啟該節經文的筆記 |

參見 [Google Drive 筆記](google_drive_notes.md)。

## 提示

- 工具會針對**選擇器中目前選定的書卷／章／節**執行操作，因此你可以在下拉選單中挑選經文節數並直接使用選單，無需滾動頁面。
- 在平行聖經（工具區域）中不會顯示搜索項目。
